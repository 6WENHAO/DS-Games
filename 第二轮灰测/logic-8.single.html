这台机器是怎么搭起来的

  1. 逻辑门：NOT / AND / OR / XOR / NAND / NOR / XNOR（含 3、4 输入形式）。内核只会算这些原始布尔函数。
  2. 组合件：半加器 = XOR + AND；全加器 = 2 个半加器 + OR；8 位行波进位加法器 = 8 个全加器； 比较器、2:1 与 8:1 多路选择器、一热译码器、按位逻辑阵列、移位器。
  3. 时序件：门控 D 锁存器（4 个 NAND 交叉耦合）→ 主从 D 触发器（上升沿）→ 8 位寄存器（回环保持多路选择器）→ 可载入计数器（PC）。
  4. 存储：RAM 256×8 = 两级地址译码器 + 2048 个 NAND 锁存单元 + 写脉冲驱动 + 读出 OR 树。
  5. 运算：ALU = B 求反阵列 + 加法器 + 逻辑阵列 + 移位器 + 每位一棵 8:1 选择树 + 标志逻辑； 另有一个与 ALU 并行的门级 8 位比较器（逐位 XNOR/AND 链），其 EQ/GT 锁存进标志寄存器， 驱动 JGT / JGE / JLT / JLE。
  6. 控制：微指令表烧进门级 PLA —— 操作码译码器(5→32) × 时序译码器(3→8) × 模式 / 标志条件 构成乘积项 AND 阵列，再由 OR 阵列汇出 22 条控制线。
  7. 总线：8 个"驱动器 + OR 树"构成线或数据总线；地址总线由 MAR 驱动。

为什么不是"假动画"

  • ADD / SUB / AND / CMP 的结果由上面那些门电路的电平决定；JS 只负责把门排进事件队列。
  • 寄存器的值就是触发器里锁存器的 Q 网络电平；RAM 的值就是 2048 个锁存器的 Q 网络电平。
  • 数据从 RAM 到寄存器必须经过：读出 OR 树 → 驱动器 → 线或总线 → 输入多路选择器 → 主锁存 → 从锁存。
  • 每个时钟周期分上升沿（寄存器锁存）与下降沿（时序计数器推进）两相，逐相求解到稳态。
  • "传播单步"按钮可以停在任意波次上，看信号还没走完的中间状态。
