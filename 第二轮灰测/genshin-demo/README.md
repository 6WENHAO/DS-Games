# 原·风起地 — Genshin-like Open World Demo

一个**纯浏览器**运行的「原神 like」开放世界动作 Demo。没有任何外部美术资源：
所有地形、贴图、角色模型、骨骼动画、怪物、UI、音乐与音效**全部由代码在运行时程序化生成**。

```
双击  start.cmd        （Windows，会自动开浏览器）
或    npm start        然后打开 http://127.0.0.1:3099/
```
需要 Node.js 18+ 与支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox）。
> 必须通过 http 访问，不能直接双击 index.html（ES Module 受 file:// 限制）。

## 内容

**世界** — 4096×4096 米（陆地半径 1500 米）的连续地形：蒙德城高原、塞西莉亚湖、
风起地巨树、龙脊雪山（雪线 + 严寒机制）、石门峡谷、风龙废墟、南风海岸与外海。
流式 LOD 地形 + 四路 splat 材质、Preetham 大气天空、PMREM 天空 IBL、昼夜循环、
八种天气（晴/多云/阴/雨/暴雨/雪/暴风雪/雾）含降雨降雪与闪电、反射折射水面。

**动作** — 走/跑/冲刺/跳/坠落/滑翔/攀爬/游泳、5 段连段（含输入缓冲与取消窗口）、
重击、下落攻击、闪避无敌帧、锁定、命中停顿（hitstop）、屏幕震动、
四人队伍切换、元素战技与元素爆发、体力系统、元素反应（蒸发/融化/超载/感电/冻结/超导/扩散/结晶）。

**内容系统** — 主线 7 章 + 支线 6 个 + 7 类谜题 + 25 个宝箱 + 7 个传送锚点 +
48 个采集点 + 12 个 NPC + 丘丘人营地；史莱姆 / 丘丘人（射手·盾牌）/ 丘丘暴徒 /
遗迹守卫 / 骗骗花 / 风魔龙 BOSS。

**表现** — HDR + MSAA + UnrealBloom + 屏幕空间神光柱 + ACES + 分级 + 暗角 + 颗粒 +
色差 + 径向冲刺模糊；卡通渲染角色（描边 + 边缘光 + 程序化动漫脸）。

## 画质与参数

URL 参数（可组合）：
`?q=low|med|high` 画质（high 含 GTAO 环境光遮蔽、4096 阴影、水面反射）·
`?tod=19.5` 时刻 · `?weather=clear|cloudy|overcast|rain|storm|snow|blizzard|mist` ·
`?pos=x,y,z` 出生点 · `?spawn=village` 出生在蒙德城 · `?nointro` 跳过开场 ·
`?nostory` 沙盒模式（不加载任务/NPC，用于测试战斗）· `?debug` 调试面板 ·
`?shot` 截图模式（跳过开场、降低特效）

控制台里还有一个调试入口 `window.__GAME`：
`__GAME.tp(x,z)` 传送 · `__GAME.tod(h)` 设时刻 · `__GAME.weather('storm')` ·
`__GAME.cam(yaw,pitch,dist)` · `__GAME.spawn('mitachurl',3)` 刷怪 ·
`__GAME.modules()` 查看各模块加载状态 · `__GAME.skipDialogue()` 跳过对话

## 实测数据（RTX 5060 Laptop / 1600×900 / q=high）

| 南风海岸（含水面反射） | 1058 | 1.80 M | 60 |

（draw calls 含阴影 pass、GTAO 法线/深度 pass 与水面镜像 pass，实际主 pass 约 1/3。）

## 已知限制

- 这是一个**技术演示**，不是商业级 3A 产品：内容体量、美术精度与动画细腻度远不及真实
  《原神》（后者是数百人年的工程）。这里的目标是在浏览器里、零外部资源的前提下，
  把开放世界 + 卡通渲染 + 动作战斗 + 剧情解谜的**完整闭环**跑起来。
- 首次加载需要几秒生成贴图与地形（有加载界面）。
- 软件渲染（无独显）下帧率很低，建议 `?q=low`。
