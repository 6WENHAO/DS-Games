# 太阳系 · 撞击实验室

> 一个按真实天体数据与真实撞击物理构建的太阳系。可以在任意天体上投放自定义陨石，
> 观察由物理方程解出来的后果：撞击坑、喷出物毯、冲击波、气体行星伤痕、尘幕与气候变化。

打开 `index.html` 即可运行（不需要服务器、不需要联网、没有任何贴图资源 ——
所有星球表面、云带、行星环、星空都是 GPU 程序化生成）。

---

## 一、怎么玩

| 操作 | 效果 |
|---|---|
| 拖拽 | 旋转视角 |
| 滚轮 / 双指捏合 | 缩放（指数级，可从星系全景推到地表几十公里） |
| 左键点击天体 | 锁定该天体 |
| 左键点击**已锁定天体**的表面 | 设定撞击点（准星） |
| 双击 | 强制锁定 |
| 空格 | 暂停 / 继续 |
| F | 投放陨石 |
| R | 复原当前星球 |
| H | 帮助 |

右侧面板设定陨石：**直径**（1 m ~ 1000 km，对数滑杆）、**材质**（彗星冰核 / 致密水冰 /
碳质球粒 / 普通石质 / 铁镍金属，各自有真实密度与抗压强度）、**撞击速度**（下限是该
天体的逃逸速度）、**入射角**与**方位角**，以及地球/泰坦上的**深海撞击**开关。
参数一改，上方预览就会实时重算能量与结局（落地成坑 / 空爆 / 烧毁 / 陨落 / 气层深爆）。

「历史事件预设」里有 8 个真实事件可以一键复现：通古斯 1908、车里雅宾斯克 2013、
巴林杰陨石坑、希克苏鲁伯 K-Pg、SL9 撞木星、月球雨海事件、金星大气过滤、击穿欧罗巴冰壳。

## 二、物理模型

所有屏幕上能看到的变化都由下列方程给出，没有"美术动画"。

### 1. 轨道与自转
* 开普勒轨道：J2000 平均轨道要素 (a, e, i, Ω, ω, M₀, T) 取自 NASA/JPL，
  牛顿迭代解偏近点角，卫星在**母行星赤道面**内公转（所以土星环、泰坦、
  伽利略卫星的倾角是对的）。
* 自转：真实恒星日与转轴倾角，金星、天王星、海卫一都是逆行。
* 日食：太阳按**球面光源**处理，遮挡按两个圆盘的重叠面积算，因此月球会在
  地球上投下带半影的真实本影。

### 2. 大气进入（决定"这颗陨石能不能落地"）
沿入射直线对下列方程做自适应步长积分：

```
dv/dt = −(C_D ρ_air A v²)/(2m) + g(z)·sinθ      气动阻力 + 重力分量
dm/dt = −(σ/2)·C_D·ρ_air·A·v³                   烧蔽质量损失
解体判据:  ρ_air·v² > Y（材料抗压强度）
解体后:    dr_cloud/dt = v·√(3.5 ρ_air/ρ_i)      薄饼模型横向膨胀
崩解判据:  r_cloud ≥ 10 L  → 空爆
```

* 大气按等温指数模型 ρ(z)=ρ₀e^(−z/H)，各天体的 ρ₀ 与 H 用实测值。
* **减速与烧蔽用本体的弹道系数，碎片云的膨胀只用来判断何时彻底崩解**
  （Collins 2005 的处理方式；若用膨胀后的迎风面积算阻力，会把几百米级
  天体错误地完全刹停）。
* 标定：通古斯（60 m 石质）→ 6.3 km 空爆、树木倒伏半径 22 km（实测 20–30 km）；
  车里雅宾斯克（19 m）→ 34 km 解体（实测 29.7 km）；
  巴林杰（50 m 铁）→ 落地成 1.5 km 坑（实测 1.19 km）。
* 屏幕上的减速、发光曲线、解体高度**与报告里的数字同源**：
  `test/entry-consistency.js` 会校验"按高度积分"和"按时间积分"两套实现给出同一结果。

### 3. 成坑（Collins, Melosh & Marcus 2005 的 π 标度律）
```
瞬时坑   D_tc = 1.161 (ρ_i/ρ_t)^(1/3) L^0.78 v^0.44 g^(−0.22) (sinθ)^(1/3)
简单坑   D_fr = 1.25 D_tc                     (D_tc·1.25 < D_c)
复杂坑   D_fr = 1.17 D_tc^1.13 / D_c^0.13     D_c ≈ 3.2 km × (9.81/g)
坑深     简单 0.294 D_fr^0.301 ；复杂 0.4 D_fr^0.3   (km)
坑缘     h = 0.07 D_tc⁴ / D_fr³
熔融体积 V_m = 8.9×10⁻¹² E   (v > 12 km/s)
```
坑形（碗形 / 中央峰 / 阶地 / 内环）与角半径 D_fr/2R 直接送进着色器，
最近 4 个坑用**解析几何**求值（任意缩放都锐利，并给出解析梯度做法线），
更早的坑烘焙进等距柱状伤痕图作为历史沉积。

### 4. 喷出物（一条定律推出全部行为）
喷出物毯厚度 `t(r) = D_tc⁴/(112 r³)`（Melosh 1989）。对其积分得到
`M(>r) ∝ 1/r`，于是单块抛出物落点半径的分布是 `P(range>r) = r_min/r`，
45° 弹道给出发射速度 `v = √(g·r)`。由此：

* 粒子按 `a = −g₀(R/r)²` 的真实平方反比引力做弹道积分，自然出现抛物线弧、
  下游偏置（斜撞击）、以及超过逃逸速度后飞离；
* 逃逸质量比例 `f_esc = r_min/r_esc`，`r_esc = v_esc²/g` ——
  月球上约 0.1%，与"月球陨石很罕见"这一观测事实相符；
* 速度介于环绕与逃逸之间的碎屑会真的**留在轨道上**形成临时碎屑环。

### 5. 冲击波、热辐射、地震、海啸
```
超压     Δp = p_x·r_x/(4r)·(1+3(r_x/r)^1.3)，p_x=75 kPa, r_x=290·E_kt^(1/3)
行星换算 Sachs 定律 Δp = k·Δp_earth(r·k^(1/3))，k = P_地表/P_地球
风速     u = (5Δp/7P)·c/√(1+6Δp/7P)
火球     R_f = 0.002 E^(1/3)，热通量 Φ = K·E/(2πr²)
地震     M = 0.67 log₁₀E − 5.87
海啸     长波速度 √(g·h)，坑缘波高 ≈0.14 R_c，振幅按 1/r 衰减
```
地表气压由 `P = ρ₀·g·H` 算出：地球 1.01 bar、金星 92 bar、火星 8 mbar、
泰坦 1.5 bar —— 于是同一颗陨石在不同星球上的破坏半径差几个数量级，
真空世界干脆没有冲击波（只有 3.5 km/s 的地壳瑞利波）。

### 6. 撞击之后的行星（"看其中的变化"）
| 现象 | 依据 |
|---|---|
| 尘幕光学厚度 | τ = 3fVρ_t/(4ρ_p a A)，f=10⁻³ 细尘比例，a=0.5 µm。K-Pg 量级 → τ≈170（全球黑暗）；1 km 级 → τ≈0.6 |
| 地表日照 | f = e^(−τ) |
| 尘幕沉降 | 指数衰减，e 折时标 1.5 年（皮纳图博火山标定） |
| 雪线移动 | 一维能量平衡 T = T₀·f^(1/4)，年均温梯度 0.55 K/度 → 雪线向赤道推进，极端情况全球冰封 |
| 植被覆盖 | 光合作用需要光：随日照恢复，时标 ~170 年（真实生态完全恢复需 10⁵–10⁶ 年，未模拟） |
| 夜面灯光 | 由直接受灾球冠面积推算（点燃阈值 10⁶ J/m² 与 20 kPa 半径取大者） |
| 熔体辉光 | 辐射结壳时标 t ≈ ρcdΔT/(σT⁴)：几十米厚熔体亮几小时，公里级熔池亮几十天 |
| 冲击波环 | 以当地声速（地球 340 m/s、金星 410、火星 240…）真实扩散，振幅按超压律衰减 |
| 气体行星伤痕 | 爆发深度由积分给出的压强层决定；暗斑直径以 SL9 观测标定，随后被环流剪切拉长 |
| 自转 / 转轴 | 角动量交换 ΔL = m·v·cosθ·R，I = 0.33MR²（通常极小，希克苏鲁伯量级约 −1.9 ms） |

**统一的物理时钟**：公转、自转、进入积分、弹道飞行、尘幕沉降、熔体冷却、
波前扩散全部用同一段模拟时间推进，顶栏显示当前倍率（例如"×2 实时"、
"1年/秒"）。投放时会自动把倍率设成"真实飞行时间 ÷ 12 秒"，撞击后再自动
切到适合观察弹道喷出物的倍率 —— 时间被加速了，但**没有任何物理量被伪造**。

**撞击点是海还是陆，由地形自己说**：点选撞击点后会用一个 1×1 的 GPU 探针
求值同一套地形函数并读回结果，据此判定深海 / 平原 / 高地 / 冰盖，
并自动切换到水靶体（ρ=1000）或岩石靶体 —— 而不是让用户勾一个复选框。

## 三、渲染

* 纯手写 WebGL2 管线：程序化行星表面（simplex 噪声 FBM + 山脊噪声 + 天然坑场）、
  单次散射大气（Rayleigh+Mie，12 步视线 × 4 步光线积分）、体积感云壳、
  带卡西尼缝与本影的行星环、米粒组织与黑子的恒星光球、日冕、
  4000+ 颗按黑体色温着色的恒星与银河带。
* **对数深度缓冲**：同一帧里既能画 1 米的坑缘也能画 45 亿公里外的海王星。
* 相机相对坐标：所有天体位置在上传 GPU 前减去相机位置，规避浮点精度崩塌。
* **真实测光的自动曝光**：每帧把画面降采样成 8×8 的对数亮度图读回 CPU，
  取中央重点加权的几何平均定曝光，并限制在"由辐照度推出的物理曝光值"上下 2 档内。
  于是水星附近会收光圈、海王星附近会开到最大，而一片白热的撞击熔体会像真实相机
  那样把整幅画面压暗 —— 亮部自然过曝，周围依然可读。
* **真实的日食**：太阳按球面光源处理，遮挡按两圆盘重叠面积算，月球会在地球上
  投下带半影的本影；行星本体也会在自己的环上投影。
* **地照（earthshine）**：母天体把阳光反射到卫星夜面，强度 = 反照率 ×
  母天体所受辐照度 × (R/d)²，地球→月球约为日照的 1/12000 —— 于是月球夜面
  不是死黑，而是有一层极淡的灰蓝。
* HDR → Bloom（3 级，阈值随曝光缩放）→ ACES filmic 色调映射 → sRGB 编码后
  再加抖动颗粒（放在编码之后，才不会把星空染灰）。

## 六、已知的简化

诚实起见列出来：

1. 大气按**等温指数**模型，没有分层温度结构；进入路径按**直线**处理
   （Collins 的同一假设），没有算引力弯曲与升力。
2. 喷出物粒子是"质量包裹"的可视化代理，单个粒子的**渲染尺寸**是视觉选择，
   但它的速度、方向、落点分布、飞行时间与逃逸判定都是物理量。
3. 复杂坑的中央峰高度、阶地间距取观测经验值（峰高 ≈0.45 坑深）。
4. 生物圈与夜面灯光是**指示性指标**：受灾球冠面积与光合作用的光照限制是算出来的，
   但"文明重建时标"不是物理定律。植被恢复用了 ~170 年的时标，真实生态系统
   的完全恢复需要 10⁵–10⁶ 年，这里没有模拟那么长。
5. 银河与恒星的**显示亮度不随曝光漂移**（合成上的选择）。真实银河面亮度比
   日照行星暗 10⁶ 倍以上，严格按物理渲染的话，任何能看清行星的曝光下星空都是全黑的。
6. 行星环的分带结构是程序化噪声 + 真实缝隙位置，不是逐环的观测数据。
7. 撞击不改变天体的轨道要素（真实效应远小于渲染精度）。
8. 帧间时间步长上限 0.06 s：极低帧率时物理时钟会比真实时间慢，以换取积分稳定。
9. 太阳没有做真实的日冕磁场结构与耀斑物理，只有程序化的冕流。

## 七、自检

```bash
node test/impact-check.js        # 真实事件标定（通古斯 / 车站 / 巴林杰 / K-Pg / SL9 …）
node test/entry-consistency.js   # 两套积分器一致性（屏幕所见 == 报告数字）
node test/png-view.js  <png> [w] [h] [--log]   # 把截图转成文本视图
node test/png-diff.js  <a.png> <b.png>         # 两张截图差分（验证撞击确实改变了外观）
```

无头浏览器回归（Chrome / Edge 均可）：

```bash
chrome --headless=new --enable-unsafe-swiftshader --use-angle=swiftshader ^
  --window-size=760,470 --virtual-time-budget=4000 --dump-dom ^
  "file:///.../index.html?q=low&dbg=1&t=9000&focus=earth&dist=2.8"
```
`?dbg=1` 会把相机距离、屏幕半径、曝光、绘制批次、粒子数与若干帧缓冲采样值
写进底栏，`#diag` 面板会显示所有着色器编译错误 —— 不打开开发者工具也能排障。
