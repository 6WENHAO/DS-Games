# OPTIMUS RIG · three.js 变形金刚（机器人 ⇄ 卡车）

纯程序化建模的 3D 变形金刚：**经典红/蓝/铬配色**，机器人形态与卡车形态可**双向平滑变形**，
36 个可调关节全部开放到控制面板，支持行走、驾驶、拖挂、武器、夜间、爆炸视图等。

- 无外部模型文件（不需要 .glb/.fbx），全部由倒角盒 / 圆柱 / 轮胎三类基元装配
- 无网络依赖，`three` / `OrbitControls` / `lil-gui` 已本地化到 `vendor/`
- 303 个零件、36 个关节、6 个车轮、10 根手指

## 四、变形是怎么做的

### 1. 单一进度量驱动全身

`Transformer.progress ∈ [0,1]`：0 = 机器人，1 = 卡车。每个关节存两套目标位姿
（`r0/p0/s0` 机器人态、`r1/p1/s1` 载具态）+ 一个**时间窗口** `phase=[a,b]`：

```
关节局部进度 t = ease( clamp01( (progress - a) / (b - a) ) )
位置 = lerp(p0, p1, t)      旋转 = slerp(q0, q1, t)      缩放 = lerp(s0, s1, t)
```

各关节窗口不同 → 手先收、头再缩、腿后折、覆盖件最后合拢，这才是"变形"而不是整体插值。
`分段错峰强度` 滑杆把所有窗口向 `[0,1]` 压缩，0 = 全身同步，1 = 完整错峰。

### 2. 两态几何严格自洽（已被 `tools/smoke.mjs` 校验）

```
机器人态  脚底 y=0   ← coreY 3.10 = 踝高 0.26 + 小腿 1.40 + 大腿 1.30 + 髋偏移 0.14
载具态    轮心 y=R   ← coreY' 0.56，六轮轮心全部落在半径 0.42 上（实测 Δ<0.03）
```

主要变形动作：

| 部位 | 机器人态 → 载具态 |
|---|---|
| 髋 / 膝 | 髋 `rx 0→90°`，膝归零：大腿+小腿摊平成车架纵梁 |
| 踝 / 脚 | 踝 `rx 0→90°`（合计 180°）翻转成尾部平台，并沿车架后移抬升让开后桥 |
| 肩 / 肘 / 腕 | 肩 `rx 0→92°` 后折成侧裙板，腕 `rx→55°` 拳头上折成尾灯座 |
| 肩甲 | `rx 0→-92°` 反向补偿 → 排气管始终竖直，且高出车顶 |
| 颈 / 头 | 颈下缩 0.52、头 `rx→-88°` + 缩放 0.92，完整藏进驾驶室 |
| 车顶板 | `rx 0→-90°`：机器人态的"背包"翻上去成为驾驶室顶（含 3 个示宽灯） |
| 挡风 | 上移 + 后倾 13°，机器人态是胸窗、载具态是前挡风 |
| 前脸总成 | 下移前伸：机器人态的腰腹护板 → 卡车格栅 + 保险杠 + 大灯 |
| 底盘 | `y 3.10 → 0.56`，全车落到六轮上 |

### 3. 动画分层

```
每帧顺序： transformer.apply() 写基础位姿 → animator 叠加 → motion 写世界位移/车轮 → effects
```

因为基础位姿每帧重写，叠加层用 `+=` 不会漂移。叠加层按「机器人权重 / 载具权重」
自动淡入淡出：待机呼吸、环视、步态（髋膝踝+反向摆臂+躯干配重）、挥手、
悬挂起伏、加速俯仰、转向侧倾、发动机抖动、眼睛闪烁。

## 六、二次开发

- **改造型**：`src/rig/poses.js` 里 `VEHICLE_POSE` 就是整个变形定义，改角度/窗口即可换变形逻辑；
  面板里调好后点「导出姿势JSON」，把数值抄回文件即固化。
- **加零件**：在 `robot.js` 里 `part(parent, bevelBox(...), M.red, [x,y,z])`；
  要让它能独立运动就用 `J(rig, parent, 'name', '中文名', '分组', [x,y,z])` 建关节，
  GUI 和变形器会自动收录（无需改 UI 代码）。
- **换配色**：`materials.js` 的 `PALETTE`，或直接在面板 ⑤ 里拾色。

### Node 自检垫片

`tools/smoke.mjs` 里 `import 'three'` 需要一个垫片（浏览器走 importmap，不需要）。
**本目录已经建好**（`node_modules/three/`），删了想重建的话：

```powershell
mkdir node_modules\three
'{"name":"three","version":"0.160.1","type":"module","main":"./index.js","exports":{".":"./index.js"}}' | Set-Content node_modules\three\package.json
"export * from '../../vendor/three.module.js';" | Set-Content node_modules\three\index.js
```
