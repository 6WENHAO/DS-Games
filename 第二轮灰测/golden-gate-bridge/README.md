# 金门大桥 · Golden Gate Bridge · WebGL 3D

一个**单文件、离线可用**的金门大桥三维模型：`golden-gate-bridge.html`（约 1.3 MB，内联了 three.js r160，双击即可打开，无需联网、无需服务器）。

![views](docs/preview.md)

## 一、比例还原（1:1 实测尺寸，1 unit = 1 m）

数据来源：Golden Gate Bridge, Highway & Transportation District 官方 *Facts & Figures*。

| 项目 | 实测 | 模型 |
|---|---|---|
| 主跨（塔间距） | 1 280 m | `towerX = ±640` |
| 边跨 | 343 m × 2 | `anchorX = ±983`（悬吊总长 1 966 m） |
| 塔高（高出水面） | 227 m | `towerTop = 227` |
| 塔高（高出桥面） | 152 m | 桥面在塔处 = 227 − 152 = 75 m |
| 跨中桥面净空 | 67 m | `deckMid = 67`（塔处 75 m，微下凹竖曲线） |
| 主缆垂度 | 145 m | 塔顶 224 m → 跨中 79 m 抛物线，边跨延续同曲率 |
| 主缆直径 | 0.92 m | `cableR = 0.46`，双索间距 27.2 m |
| 桥面全宽 | 27 m | 车行道 19.1 m（6 车道）+ 两侧人行道 |
| 加劲桁架高 | 7.62 m (25 ft) | 节间同为 7.62 m，Warren 式 + 下平联 |
| 吊索间距 | 15.24 m (50 ft) | 258 组索夹、双吊索 |
| 塔柱截面 | ≈18.6 × 11.8 m（根部） | 向顶部收分至 12.6 × 9.2 m，双柱中心距 38.8 m |
| 堡垒点钢拱 | 320 ft ≈ 98 m | 跨越 1861 年古堡的钢拱（模型 160 m 跨含拱上立柱） |

## 二、场景内容

**桥体**：Art Deco 主塔（7 级退台、大面竖向凹槽、8 道门式横撑、索鞍、塔顶航空障碍灯）· 双主缆（TubeGeometry 沿抛物线，末端散索入锚）· 258 组吊索与索夹 · 加劲桁架（上下弦/竖杆/斜杆/横梁/下平联，约 3 300 根杆件）· 路面（程序化沥青贴图：骨料、轮迹、车道虚线、双黄线）· 人行道/缘石/檐板/底板 · 中央可移动护栏 · 栏杆（2 000+ 立柱 + 三道横杆）· 灯柱（每 61 m 弯臂路灯）· 锚碇与混凝土塔门 pylon · 南塔椭圆防撞围堰 · 南北引桥（钢排架 + 板梁 + 矮墩 + 北端隧道口）。

**两岸**：马林海岬（陡崖、斯宾塞炮台山脊、鹰山 280 m、懒汉山 300 m、马蹄湾、罗迪欧谷、贝克堡营房）· 旧金山半岛（堡垒点岬角与 1861 年砖石古堡 + 灯塔、要塞崖壁与柏树林、贝克海滩、克里西场、收费广场与行政楼、远景市区天际线含夜间窗光）· 5 000 株植被 · 岸边巨石与防波堤。

**环境**：解析大气天空（瑞利渐变 + 前向散射 + 太阳/月本体 + fbm 云层 + 星空）· PMREM 环境反射 · 海面（波浪法线叠加 5 组色散波 + 细碎浪、浅滩深度图、岸线白沫、潮流湍流、桥体投影）· 海雾带（26 片体积感 billboard）· 车流 132 辆（含卡车、夜间车灯）· 集装箱船/渡轮/帆船与航迹 · 22 只海鸥。

**光影**：ACES 色调映射 + 5 级双滤波泛光 + 暗角 + 抖动去色带；单向光 3072² 阴影贴图，阴影相机随视点自适应（近景锐利/远景全覆盖）；8 组色板按太阳高度角插值（正午→黄金时刻→日落→蓝调→夜间），驱动天空、雾、灯光与曝光。

## 三、交互

| 操作 | 功能 |
|---|---|
| 左键拖拽 / 单指 | 旋转（自动避让水面与山体） |
| 滚轮 / 双指捏合 | 推拉（14 m ~ 16 km） |
| 右键拖拽 / Shift+拖拽 | 平移 |
| 数字键 1–6 | 六个预设机位：马林角远景 / 桥面行车 / 塔基仰望 / 海面掠行 / 堡垒点 / 航拍全景 |
| 空格 | 自动巡航开关 |
| H | 隐藏/显示界面 |
| X | 结构透视（路面半透明，显露桁架） |
| 底部滑块 | 时间 0–24 h、海雾浓度、车流密度 |

URL 参数：`?q=low|mid|high` 画质 · `?hour=19.2` 时刻 · `?fog=0.2` 雾 · `?view=0..5` 机位 · `?ui=0` 隐藏界面 · `?nopost` 关闭后处理。

## 四、源码结构与构建

产物是单文件；源码分模块，构建时把 three.js 的 `export {}` 块转成命名空间对象后与各模块内联进 HTML（应用代码包一层 IIFE，与 three 内部同名顶层函数隔离）。

```
golden-gate-bridge/
├── golden-gate-bridge.html   ← 交付产物（= index.html）
├── build.mjs                  ← 构建脚本：node build.mjs
├── vendor/three.module.js     ← three r160（内联源）
└── src/
    ├── shell.html   界面骨架 / CSS / 载入动画 / 错误浮层
    ├── 00_boot.js   实测参数 B、竖曲线 deckY/cableY、噪声、Batch 实例化器、程序化贴图与材质
    ├── 10_sky.js    天空着色器 + 太阳/半球/补光 + 色板插值 + PMREM
    ├── 20_water.js  海面（注入 MeshStandardMaterial）+ 海雾带
    ├── 30_terrain.js 地形高程场、上色、深度图烘焙、植被、岩石、建筑
    ├── 40_bridge.js 塔/缆/吊索/桁架/桥面/栏杆/锚碇/塔门/钢拱/引桥
    ├── 50_props.js  车流、船舶与航迹、古堡、收费广场、海鸥、夜间灯光
    ├── 60_post.js   HDR → 泛光 → ACES → 暗角/抖动
    ├── 70_ui.js     自写轨道控制器、机位预设、界面绑定
    └── 80_main.js   启动流程、主循环、阴影跟随、调试接口 window.__ggb
```

重新构建：`node build.mjs`（无需依赖安装）。本地起服务预览：`python3 -m http.server 8971`。

## 五、性能

- 场景约 60 万三角面、150 个 draw call（杆件全部走 InstancedMesh 合批）。
- 桌面独显 1080p 满帧；集显建议 `?q=mid`；移动端 `?q=low`（1024² 阴影、关闭后处理）。
- 界面右上角实时显示 fps 与三角面数。
