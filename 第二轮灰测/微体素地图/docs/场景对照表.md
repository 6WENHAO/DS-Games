# 场景对照表：沙盘坐标 ↔ mod 世界坐标

沙盘不是线性缩放，而是**方位保留 + 中轴对称吸附**的微缩再编排：
站点之间的距离被大幅压缩，站点内部的建筑则按体素尺度重新配比
（1 体素 ≈ 2 个 MC 方块的观感，层高 4 体素）。所以「谁在谁的哪一边」与
「谁比谁大」都还原，绝对距离不还原。

## 四、有意识的再设计（原作没有 / 改动的部分）

为满足「中轴对称的院落布局」与「赛博朋克美化」，以下是刻意的再编排，均在此声明：

1. **喷泉广场移到中轴**（原 (50,50) 偏东南）→ 城区变成严格的四门四塔中心对称。
2. **训练中心东移**成指挥中心的镜像位；**新增 APE 档案馆**作为会议中心的镜像体。
3. **农田西移**成工业区的镜像位。
4. **回忆之境做成浮空岛**并加冲天光柱，作为中轴北端端景（原作是独立口袋维度）。
5. **高架轨道桥改成东西对称两条线**（原作是一条折线连四个卫星站）。
6. **外环八边形路 + 四条对角放射**为沙盘新增，用于把七个站点串成清晰动线。
7. **中央广场金线放射花纹、红毯十字、彩色旗帜带**为赛博朋克/仪式感美化补充。
8. 赛博朋克补充（原作只有基础方块）：霓虹边条与腰带、故障闪断招牌（`neonFlick`）、
   全息广告牌、外挂管线与蒸汽排气、探照灯与光柱、屋顶天线阵与设备层、
   街面积水映霓虹、警示条纹与断路围挡、发光矿脉与熔岩溢流。
9. **大裂缝加深加阶**（原作 y84→y11）→ 沙盘 y68→y5 六阶深谷，并补齐源码缺失的
   观测站、栈道、横跨吊桥、下降井螺旋坡道、探照灯阵。
