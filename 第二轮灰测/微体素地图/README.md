# 微体素地图 · DARLING in the FRANXX 世界沙盘

一个**零依赖、双击即开**的 3D 体素（Minecraft 风格方块拼接）赛博朋克地图场景，
把工作区 `大型国家队mod-1.12.2` 的完整世界压缩成一座 **1280 × 1280 × 224 体素的悬浮微缩沙盘**。

## 一、怎么看

**直接双击 `index.html`**（或运行 `打开地图.bat`）。不需要服务器、不需要联网、不需要安装任何东西。
需要一个支持 WebGL2 的浏览器（Chrome / Edge / Firefox 近几年的版本都行）。
首屏会生成整张地图（约 **2–4 秒**，进度条会报告阶段），完成后进入实时场景。

## 三、渲染与光影

- **烘焙日照阴影**：固定太阳方向（仰角 30°，东南来光），逐面 DDA 光线步进算可见度，
  地面另有半分辨率柔和阴影贴图 → 建筑投影、峡谷阴影、塔影层次都是真实遮挡算出来的。
- **顶点 AO**：标准体素三邻采样，加地形曲率与建筑贴地接触阴影。
- **3D 霓虹光照体积**：所有发光材质（约 19.9 万个发光体素）自动聚合成 **1 万个光源**，
  splat 进 256×45×256 的 3D 纹理，全场景免费获得霓虹溢光；带软上限，密集处饱和而不过曝。
- **晨昏色调**：7 组时段关键帧（太阳色/强度、天顶天际、环境光、霓虹强度、星空、雾、曝光）
  平滑插值。阴影方向烘焙固定，颜色与氛围实时可变。
- **后处理**：HDR → 三级泛光 → ACES 色调映射 → 青影暖高光分离色调 → S 曲线 → 暗角 → 胶片颗粒。
- **玻璃与光晕**：预乘 alpha 三通道渲染（不透明 / 半透明 / 叠加发光），
  穹顶骨架、玻璃幕墙、探照灯光柱、蒸汽柱、光束都在里面。
- **地面处理**：铺装（沥青/石英砖/大理石/金线嵌带/斑马线/缘石）与草地（噪声斑块 + 灌木花丛）
  分层，建筑外圈统一刷铺装并在楼脚埋沙/堆瓦砾，与地面自然衔接。

## 六、改内容 / 扩展

1. 读 `docs/体素建造API.md`（建造 API 契约）。
2. 站点内容都在 `js/world/*.js`，改完刷新浏览器即可，无需构建步骤。
3. 跑校验：`node _dev/build-test.mjs`（材质名审计 + 40 项断言）。
4. 出图：`node _dev/shot.mjs`（需要先建软链接
   `mklink /J _dev\node_modules <某个装了 puppeteer-core 的 node_modules>`）。
5. 全部生成都是**确定性**的（`M.rng(固定种子)` / `M.hash3` / `M.fbm`），
   同一份代码在任何机器上生成完全相同的地图。
