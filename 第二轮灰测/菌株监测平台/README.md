# 菌株监测可视化平台 StrainLab

**单页 HTML 前端 + Python 标准库后端**，零第三方依赖，开箱即跑。

> ⚠ 安全边界：本平台仅用于**非致病安全菌株**（大肠杆菌 K-12 / 酿酒酵母，BSL-1）的培养监测与诱变**教学仿真**。不得用于任何致病微生物的定向改造。

## 运行

**方式一：一键启动（推荐，同事用这个）**

双击 `启动StrainLab.bat`：
- 自动查找本机 Python（PATH / 常见安装目录），找不到会弹出安装指引并自动打开下载页；
- 自动检查端口占用（已有实例运行则直接开浏览器）；
- 后台窗口启动服务 → 等待就绪 → 自动打开浏览器 http://127.0.0.1:8000/ 。

**方式二：命令行**

```bash
cd 菌株监测平台
python app.py
# 浏览器打开 http://127.0.0.1:8000/
```

- Python ≥ 3.8，仅用标准库（http.server / threading / csv / dataclasses），**无需 pip install**。
- 前端 `frontend.html` 由后端直接服务；也可以直接双击打开，此时所有需要后端的功能会提示未连接。

## 功能地图

| 面板 | 内容 |
|---|---|
| 总览 | 36 孔板 × 24 h 交互式生长热力图（Canvas 自绘）+ 动态菌落繁殖动画（逐帧 Logistic 生长 + 扩散 + 分裂）|
| 诱变仿真 | 培养基配比（Monod + 抑制模型）→ 温度扫描（Ratkowsky − 热失活）→ UV/EMS/NTG 剂量-存活率-突变率 → Logistic 培养曲线 → 突变子代估计，全流程显式输出 |
| 突变路径遍历 | N 位点组合完全枚举 2^N（N≤14 全量）/ 束搜索（可配束宽），Top 组合与培育条件曲线 |
| 数据导入 | 浏览器内 CSV 解析实时渲染（自动识别 time/OD/well 列 → 曲线 + 孔板热力图）；服务器白名单目录批量导入 |
| 后台线程 | 服务端常驻仿真线程持续迭代繁殖预测，前端 0.5 s 轮询自动刷新，可安全停止 |
| 方案导出 | 一键下载完整 HTML 实验手册（8 步实操：配基 → 接种 → 诱变 → 复苏 → 初筛 → 纯化 → 保种 → 废弃物处理）|
| **传染病动力学模拟（新增）** | SEIR 分室模型（RK4 积分 + 质量守恒检查）：流行曲线 / 每日新增 / 医疗资源挤兑 / 三种干预策略对比；R₀、潜伏期、病死率、隔离、接种全部可调，5 组情景预设 |

## 接口

```
GET  /              前端页面
GET  /api/status    服务状态与目录
GET  /api/files     白名单导入目录文件列表
GET  /api/worker    后台线程状态
GET  /api/example.csv  示例数据集
POST /api/simulate  诱变仿真（培养基+诱变剂+温度）
POST /api/traversal 突变组合遍历（exact/beam）
POST /api/worker/start|stop
POST /api/import    批量导入白名单目录
POST /api/parse_csv CSV 解析
POST /api/manual    生成实验手册 HTML
GET  /api/epi/presets   传染病情景预设
POST /api/epi           SEIR 模拟
POST /api/epi/compare   三种干预策略对比
```

## 分发给同事

双击 `打包分发包.bat` → 在上一级目录生成 `StrainLab-菌株监测平台-分发包.zip`（约 36 KB，只含运行必需文件，不含运行数据/缓存）。
同事拿到 zip 后：解压 → 双击 `启动StrainLab.bat`。唯一前提：对方电脑装有 Python 3.8+（启动器会引导安装）。

## 传染病模拟的安全边界（重要）

- 该模块是**教学与决策支持工具**：帮助理解 R₀、潜伏期、压平曲线、隔离与接种为什么有效；
- **不是**疫情指挥系统：不接入真实病例数据、不输出医疗建议；参数为公开文献量级参考值，未针对任何具体病原校准；
- 真实疫情处置请以当地疾控中心与卫生行政部门为准；急症（呼吸困难、持续高热等）请立即拨打 120 / 当地急救电话；
- 模型局限（页内已列出）：理想均匀混合、平均时长而非分布、未建模检测延迟/无症状传播/超传播事件/断水断电对医疗能力的二阶影响。

## 已知局限

1. 动力学常数（Ratkowsky b、杀伤系数 k、突变系数 α）为文献量级教学值，不同菌株需实测标定；
2. 突变位点组合为教学模型（固定随机种子，可复现），不代表任何真实基因组；
3. 浏览器上传仅在内存解析、不落盘；批量导入受服务器目录白名单约束，不会扫描其他路径。
