# 花语 · Petal Drift

一个网页端 3D 互动场景，致敬陈星汉《花》(Flower)：你操控**一群飘浮的花瓣**掠过风格化的草原，所过之处草色由枯转翠、鲜花次第绽开；天空是体积云，云影一片片扫过山丘；停下时镜头缓缓推近，背景融成柔焦。

纯前端、零构建、离线可跑：`index.html` + ES 模块 + 本地 vendored three.js r160（无 CDN、无 npm install）。

```bash
node serve.mjs 4321          # 启动静态服务
open http://127.0.0.1:4321/  # 浏览器打开（需 WebGL2）
```

## 操作

| 键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 引导花瓣群（相机坐标系） |
| 鼠标拖动 | 环视；**松手 1.6s 后**镜头自动回到航向后方 |
| 滚轮 | 推拉镜头 |
| `Shift` | 疾风加速 |
| `空格` | 升起（`Ctrl`/`Z` 下沉） |
| `1`…`7` | 切换天气：晓雾 / 晴光 / 风起 / 阴云 / 细雨 / 夕照 / 月夜 |
| `N` | 下一种天气；自动流转默认开启 |
| `C` | 电影黑边 |
| `F` | 自由视角（关闭自动跟拍） |
| `R` | 清空花田与草色记忆 |
| `M` | 静音（面板里另有总音量 / 音乐 / 环境声三档） |
| `H` / 右上角 ☰ | 设置面板（画质、景深、泛光、雾气、曝光、浓郁度、颗粒、声音、风力、花瓣数、开花半径…） |
| `P` | 暂停 |

移动端：屏幕**下三分之一**拖动 = 摇杆前进，其余区域拖动 = 环视。

## 需求对照

| 需求 | 实现 |
|---|---|
| 风格化草坪 | 3 层 GPU 实例化草叶（默认 14.3 万株），锥形叶片 + 分段弯曲 + 叶尖高光 + 背光半透，色彩由"生命场"从枯黄推到浓绿 |
| 风吹麦浪 | 行波（波长≈42m）叠三次谐波，再乘一层缓慢移动的**阵风带**噪声；波峰额外反射阳光，形成一道道扫过草原的亮痕 |
| 阳光下的白云阴影 | 体积云与云影**共用同一片 2D 覆盖场**：每帧把云层沿太阳方向投影、按垂直光学厚度算透射率，烘进 1024² 相机跟随阴影图；地形/草/花/花瓣各取一次采样。实测玩家脚下遮蔽度在 ~10 秒内从 31 扫到 255（云影边缘掠过） |
| 地形高低起伏 | 无限地形：相机相对的**非均匀网格**（脚下 ~0.9m，天边 ~30m），高度在顶点着色器里由 5 个八度值噪声解析求值（含解析梯度，20 次采样同时得到高度与法线）。CPU 用逐位一致的同一套噪声，玩法与画面永不脱节 |
| 主角是一群飘浮花瓣 | 168 片实例化花瓣追逐"引导点"的**延迟路径**（0.9s 内的历史轨迹）+ 涡旋 + 弹簧阻尼，像一条会拉长会聚拢的绸带；花瓣双面半透、迎光发光、翻滚如落叶 |
| 所到之处长出鲜花 | 世界锚定的**生命场**（2048² 持久化 RT，1:1 累加混合、可平移重定心）记录轨迹：草因此变绿变高，地形着色器长出远景花斑；同时按占用网格实例化种下真花（池容量 7000，顶点着色器里做弹性绽放与花瓣张开） |
| 天气变化 | 7 套完整"看法"（太阳角度/颜色/强度、天空三段色、环境光、云量云速云影、雾、风、雨、曝光/饱和/泛光/抬黑…）交叉淡入，默认自动流转；雨天有闪电与湿地反光 |
| 体积云 | 光线步进（高画质 38 步 + 4 步向阳光步进）：覆盖场 × 垂直剖面 × 高度切变 × 细节侵蚀，Henyey-Greenstein 相函数 + powder 项 + 空域跳步；半分辨率离屏渲染后按深度合成 |
| 地面雾气 | 后处理里做两层：解析积分的**指数高度雾**（空气透视）+ **有界雾层**（水平雾毯，山谷自然积雾、山脊露出雾面），雾层带流动噪声与朝阳前向散射；另有可选云隙光 |
| 停下拉近镜头 + 景深 | 松开方向键后 idle 上升 → 镜头 dolly in（12.9 → 4.8）、视场 52°→39°、光圈 0.64 → 2.35；薄透镜 CoC + 18~26 抽样黄金角光斑，亮部优先形成 bokeh。自测已断言该行为 |
| 声音（BGM / 风声 / 雨声） | 全部**程序化合成**，零音频素材：生成式配乐（每种天气一套五声音阶调式与音区，长音垫 + 稀疏拨奏 + 低音持续音，混响脉冲响应实时生成）；风声＝粉噪三段滤波（低频体感 / 阵风带通扫频 / 草叶嘶声），随风力、阵风与飞行速度联动；雨声＝带通雨点层＋低通落地层，随雨量渐变；闪电触发按距离延迟的低频雷鸣；**花开时叮咚一声**（限流，避免变成老虎机）。首次点击画面才会启动（浏览器自动播放策略） |
| 浓郁清新 / 电影感 | HDR 渲染 → 合成 → 泛光 mip 链 → 景深 → ACES + lift/gain 调色 + 饱和 + 暗角 + 胶片颗粒 + 边缘色散；分辨率倍率可做超采样抗锯齿 |

## 结构

```
index.html          页面外壳、HUD、设置面板、错误浮层
serve.mjs           静态服务器（无依赖）
vendor/three.module.js  three.js r160（本地）
src/
  main.js       启动、每帧调度、调试与自测钩子
  config.js     世界常量 + 四档画质预设
  noise.js      共享噪声：CPU/GPU 逐位一致；地形高度 + 解析梯度（GLSL 由同一张八度表生成）
  uniforms.js   全局共享 uniform 对象 + 共享 GLSL 片段（风/云场/生命场/光照/天空/阴影）
  terrain.js    无限起伏地形（相机相对畸变网格 + 风格化着色）
  grass.js      三层实例化草，GPU 环绕包裹 + 麦浪
  flowers.js    花朵实例池、占用网格、绽放动画
  petals.js     主角花瓣群（引导点、延迟轨迹、涡旋、翻滚）
  lifemap.js    生命场（持久 RT、累加喷涂、平移重定心）
  cloudshadow.js  云影烘焙图
  sky.js        天空 + 体积云光线步进（离屏半分辨率）
  particles.js  雨丝与浮尘/流萤
  weather.js    七套天气与交叉淡入、日行迹、闪电
  audio.js      程序化声景：生成式配乐 + 风声 + 雨声 + 雷声 + 花开铃音（零音频素材）
  postfx.js     合成/雾/云隙光 → 泛光 → 景深 → ACES 调色
  camera.js     跟拍相机（自动回位、停下推近、自动对焦）
  input.js      键盘 / 拖动 / 滚轮 / 触摸
  ui.js         HUD 与设置面板
selftest.html   26 项无人值守自测（在 iframe 里手动步进真页面）
tools/
  cdp.mjs       零依赖 Chrome DevTools Protocol 驱动（导航/求值/截图）
  analyze.py    帧的数值体检（裁剪、亮度带、区域色相饱和、细节能量、绿/金/花比例）
  regiondiff.py A/B 分区对比（证明某个特性真的参与成像）
  glprobe.html  WebGL2 能力探针
  verify.sh     一条命令跑完自测 + 七种天气取样分析
```

## 性能

自适应分辨率默认开启（帧时间超过 27ms 逐步降到 0.62×，回落到 13.5ms 以下再升回）。四档画质控制地形网格、草量、云步进、景深抽样、粒子数、分辨率倍率。

无头 Chrome（ANGLE/Metal, Apple M1, 离屏渲染，比上屏更慢）测得：

| 配置 | 帧时间 |
|---|---|
| 盛放 high @1280×720 | ≈23 ms |
| 轻盈 low @720×405 | ≈5–10 ms |

各系统开销（同一环境，A-B-A 去漂移）：草 ≈6ms，景深 ≈10ms，体积云 RT ≈7ms，地形 ≈1ms。

## 验证

```bash
bash tools/verify.sh            # 自测 26 项 + 七天气取样并输出画面体检
```

`selftest.html` 覆盖 38 项：着色器编译、逐帧渲染、按键方向（A/D 与拖动手感）、飞行、花开、七种天气、停下推近与光圈张开、云影图烘焙、生命场写入、**黑块回归检测**（连续 45 帧扫描 NaN/Inf 经 bloom 放大出的黑方块）、声音（音频图建立、风雨音量随天气变化、花开铃音、雷声、静音、首次手势）、面板/滑杆/色片交互、窗口缩放、清空重置、帧耗时。

调试钩子（控制台可用）：

```js
__game.snapshot()            // 帧数/fps/花数/草量/绘制统计
__game.setAuto(false)        // 关掉 rAF，改为手动步进（无头环境用）
__game.tick(1/60, 120)       // 手动推进 120 帧
__game.bench(20)             // 带 GPU 同步的真实帧耗时
__game.debugRT('shadow')     // 把云影图/天空 RT/生命场画到画布并返回 PNG
__game.lockCamera(true)      // 冻结相机（做 A/B 比对）
__game.freezeWeather(true)   // 冻结天气（否则每帧覆写 uniform）
__game.setWeather('sunset')
__game.sound.diag()          // 音频上下文状态、当前调式、已排的音符数、风雨自动化目标值
__game.debugScanBlack()      // 扫描画面近黑像素（黑块回归检测用）
```

URL 参数：`?q=low|medium|high|ultra`、`?res=0.8`、`?grass=0.5`、`?steps=24`、`?w=sunset`、`?manual=1`（不自动跑 rAF）、`?selftest=1`（最小配置）。

## 注意

* 需要 WebGL2（浮点渲染目标 + 顶点纹理采样）。不支持时页面底部会显示红色错误浮层。
* 首屏会编译约 15 个着色器程序，约半秒；`#boot` 遮罩在第 3 帧后淡出。
* 所有资源本地：无网络请求、无字体外链、无 CDN。
