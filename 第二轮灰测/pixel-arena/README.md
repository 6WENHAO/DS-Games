# POCKET ARENA 像素竞技场

一款致敬 GBA《宝可梦 红/蓝/绿宝石》战斗场景与 HD-2D 像素美学的回合制对战游戏。
零第三方渲染库：全部画面由自研 Canvas 2D 像素渲染管线程序化生成；对战规则完整可玩。

## 快速开始

双击 `index.html` 即可在浏览器中运行（推荐 Chrome / Edge，无需服务器）。
若浏览器禁止本地字体加载，游戏会自动回退系统等宽字体，其余功能不受影响。

- 选队画面：方向键 / WASD 选择，`Z`/`Enter`/`Space` 确认，`X`/`Esc` 取消，鼠标可点击。
- 战斗菜单：`战斗`（出招）/ `换人` / `道具`（伤药、高级伤药、万能药）/ `认输`。
- 全局按键：`C` CRT 扫描线 · `G` 像素网格 · `N` 色彩噪点（默认全关）· `M` 静音 · `R` 重置。

特殊 URL 模式：

| 模式 | 说明 |
| --- | --- |
| `index.html#demo` | AI 对战 AI 的自动演示（观看战斗演出） |
| `index.html#selftest` | 无头自检：35 项逻辑 + 渲染管线断言，结果写入页面标题 |
| `index.html#menu` / `#menumove` | 直接进入战斗并停在主菜单 / 招式面板（截图用） |
| `index.html#pick` | 选队界面预选 3 只（查看已选标记与按钮高亮状态） |

### 渲染管线（Stage 1）

- **低分辨率渲染目标**：427×240 内部缓冲 → `imageSmoothingEnabled=false` nearest-neighbor
  整数放大到窗口（无任何线性平滑），CSS 同时声明 `image-rendering: pixelated`。
- **统一 32 色调色板**：所有背景、精灵、UI、粒子只用这 32 色（自检逐像素断言）；
  半透明与渐变一律使用 Ordered Bayer 4×4 抖动，不使用 alpha 混色。
- **程序化场景**：天空色带（抖动过渡）、太阳光晕、像素云、双层山脊、树线、起伏草丘
  （周期函数保证 512px 无缝平铺）、木围栏、大树、岩石、花丛、草丛。
- **多层视差**：天空 0 → 云 0.10 → 远山 0.15 → 树线 0.35 → 丘陵 0.55 → 草地 0.75 →
  地面/平台 1.0 → 前景草缘 1.25，摄像机缓慢漂移 + 事件推挤 + 受击震屏。
- **土路与战斗平台**：贝塞尔土路连接玩家与对手站位；对手站在带描边土台（平台边界）上。
- **像素雾与暗角**：地平线雾带（Bayer 浓度渐变）+ 四角暗角抖动，模拟渲染距离。
- **云影**：以世界 XZ 坐标采样 fbm 噪声，阈值 + Bayer 抖动投影为缓慢漂移的像素云影。
- **天气粒子（8-12fps 量化步进）**：晴天飘落叶片(8fps)、雨天雨丝+水花(12fps)、
  沙暴沙尘(10fps)。
- **2D 精灵动画**：待机 4 帧弹跳 @8fps（GBA 节奏）；招式/受击/濒死动画 @12fps。
- **战斗精灵分层**：脚下椭圆阴影（抖动）→ 本体 → 受击闪白剪影 → 属性特效层
  （火苗/气泡/叶片/电火花/念力星/沙尘），濒死 = 闪白 + Bayer 打孔消散 + 下沉。
- **后处理（默认关闭）**：CRT 扫描线 / 像素网格 / 色彩噪点，`C`/`G`/`N` 切换。

### 对战规则（Stage 2，第三世代风格）

- 属性克制：完整 18 属性克制表（0 / 0.5 / 1 / 2 倍率），本系加成 ×1.5。
- 伤害公式：GBA 三代公式（等级/攻防/威力/随机 85-100%/会心 ×2，1/16 会心率，
  高会心招式 1/8），每次乘算向下取整。
- 先手判定：招式优先度（电光一闪 +1）→ 速度（麻痹 ×0.25）→ 随机。
- 能力变化：攻击/防御/特攻/特防/速度/命中/回避，-6..+6 级（剑舞 +2、冥想 +1+1）。
- 异常状态：中毒(1/8)、剧毒(n/16 递增)、烧伤(1/8+物攻减半)、麻痹(25% 无法行动+减速)、
  睡眠(1-3 回合)、冰冻(20%/回合解冻)、混乱(50% 自伤 40 威力)、畏缩。
- 天气/场地：雨天(水×1.5/火×0.5)、大晴天(火×1.5/水×0.5)、沙暴(岩特防×1.5+每回合
  1/16 伤害)、电气场地(电系×1.5)，持续 5 回合并有对应粒子演出。
- 完整战斗流程：入场动画 → 选择招式/换人/道具 → 先手判定 → 招式动画（飞行物/光束/
  落石/震地/状态光环）→ 伤害结算（HP 条逐像素流逝）→ 异常结算 → 濒死消散退场 →
  强制换人 → 胜负判定 → 一键重置。
- 对手 AI：招式评分（预估伤害×克制×本系×命中 + 状态/天气/强化权重）、被克制时
  概率换人、濒死自动换后备。
- 6 只可选原创精灵（焰尾狐/青芽兽/浪壳龟/电光鼠/幻念猫/岩甲犀），各 4 个招式；
  27 个招式覆盖物理/特殊/变化三类；PP 耗尽自动使用挣扎（1/4 反弹）。
