# 铁幕1994 · IRON CURTAIN 1994

一款**纯前端**（无构建、无依赖、可直接双击打开）的营级回合制战术 RTS：
**《钢铁雄心4》式的军用地图与北约军标画风 + WARNO / 战争游戏：红龙 式的卡组、场外召唤与装备挂载**，
背景设定在架空的 1994 年北约—华约全面战争。

## 运行

直接用浏览器打开 `index.html`（Chrome / Edge / Firefox 均可，支持 `file://`）。
进度、卡组与战略投资保存在浏览器 localStorage 中；主菜单可清除存档。

## 架空世界线

- **1991.08.19**：国家紧急状态委员会政变**成功**，叶利钦被软禁于莫斯科郊外别墅，苏联未解体。
- 苏联又撑了几年：经济崩坏、加盟共和国离心、华约名存实亡。
- **1994**：北约判定对手已虚弱到不可复原，趁虚而入。
- **开战最初 72 小时**：北约联军对前沿梯队、机场、指挥所、渡口实施**战术核突击**，一度打进苏联本土。
- 随后**苏军战术核反击**抹掉北约前锋集群，战线被推回，最终**稳定在西德附近**。
- 游戏从这条僵持战线开始。两条主线：北约线一路向东至**萨马拉决战**；华约线渡莱茵、跨海峡至**伦敦决战**。

## 三种模式

| 模式 | 内容 |
|---|---|
| **标准 · 1991 实编** | 双方 1991 年的实际装备与实际编制数量（48/58 张 1991 卡）。核与化武需战区授权。 |
| **推演 · 1994 进阶** | 加入现实中因冷战结束而取消/缩编的装备：T-80УМ1、Объект 187、БМПТ、Ка-50 量产、Су-27М、С-300ВМ、ТОС-1 ／ M1A2、Block III、M8 AGS、LOSAT、RAH-66 科曼奇、A-12、F-22 早期中队、PzH2000、挑战者2、标枪、ATACMS。 |
| **无尽 · 无限制升级** | 放开一切武器使用权限（核/化学/温压无需授权），预备队无穷无尽，分值收入 ×1.9。 |

## 玩法要点

- **场外召唤**：每回合获得召唤分值（基础收入 + 控制目标点），在部署区从卡组投入部队。
- **卡组编辑（红龙式）**：20 个槽位（外交战可 +3）、每卡可用数量、四档老兵度、**2–5 项改装/挂载**
  （爆反、贫铀弹、热像仪、标枪、扫雷犁、云爆火箭、便携防空、三防、航空挂载含**战术核航弹**）、
  步兵可自选**运输载具**或徒步，另配 4 项场外支援与 3 条超限战指令。
- **战斗模型**：六角格（1 格 500 m）、行动点、**装甲面**（正/侧/后/顶）与随距离衰减的穿深、
  掩体与构筑度、**凝聚力/压制/溃散**、观测 vs 隐蔽的战争迷雾、**警戒射击**、乘车/下车、
  辐射与化学污染区、烟幕、防空拦截空袭、直升机与固定翼的出击轮次。
- **超限战（《超限战》/混合战争）**：
  - 战略层（战役之间，消耗**战略行动点**）：电子战、信息战、**金融战**（直接削减敌方每回合召唤分值）、
    外交战（槽位/盟军/策动倒戈）、特种破袭（桥梁/雷达站/斩首）、核决心（授权概率、化武授权、核预授权）。
  - 战场层（消耗**指挥点**）：通信干扰、雷达压制、数据链攻击、心理战广播、无线电欺骗、
    电子侦察截获、假目标阵地、敌后破袭、斩首打击、战时金融突袭、停火试探。
- **核门槛与作战决心**：核/化武打击需要战区授权。在「超限战」面板**下达作战决心**申请核释放权限，
  成功率由已满足的升级条件（战斗持续 6 回合、损失达 40%、丢失死守目标、敌方先用核化武器、
  升级阶梯≥2、敌方突入纵深）与战略层投资/政治资本决定。获批后升级阶梯与末日指数上升，
  **敌方大概率随之获得核报复授权**；战役层末日指数累积到 10 触发「相互确保毁灭」结局。
  无尽模式下没有任何限制。
- **结局**：每条战线三种结局——胜利 / 失败 / **焦土**（累计使用 ≥3 次核武取胜），外加末日结局。

## 文件结构

```
index.html               入口（经典脚本，按依赖顺序加载）
css/theme.css            HOI4 风格主题
js/core/core.js          随机数、六角格数学、DOM 助手、存档
js/engine/rules.js       地形表、数值标定、改装套用、装甲面
js/engine/battle.js      战斗引擎（部署/移动/射击/支援/核/授权/回合/胜负）
js/engine/ai.js          AI 指挥官（自动配卡、部署、战术、超限战、核决心）
js/data/loadouts.js      36 项改装挂载 + 老兵度 + 14 项场外支援
js/data/units_wp.js      华约 73 张卡（含运输与电子战）
js/data/units_nato.js    北约 88 张卡（含运输与电子战）
js/data/hybrid.js        超限战：18 项战略行动 + 12 条战场指令 + 升级阶梯
js/data/lore.js          全部中文叙事：时间线、学说、14 个任务简报、6 种结局、无线电台词
js/data/campaign.js      两条战役 14 个任务的机制参数
js/data/maps.js          16 种地形剖面的程序化地图生成器
js/ui/render.js          Canvas 地图渲染（地形缓存 + 10 种北约军标 + 7 种特效）
js/ui/ui.js              提示条/悬浮说明/弹窗/卡片信息
js/ui/deck.js            卡组编辑器
js/ui/battleui.js        战斗界面与交互
js/ui/screens.js         菜单/战役与战略层/简报/结果/结局/设定集
js/main.js               存档、战略效果合并、启动
tools/simulate.js        无头 AI vs AI 全任务模拟（平衡校验）
tools/uitest.js          无头端到端 UI 测试（配 tools/dom_stub.js）
docs/*.md                数据契约与渲染接口契约
```

## 自检命令

```bash
node tools/simulate.js            # 三种模式 × 14 个任务的 AI 对战模拟

node tools/uitest.js              # 无头端到端 UI 测试
```
