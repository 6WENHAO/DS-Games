# 小车-倒立摆（cart-pole）Python 参考实现

本目录是同项目网页交互版的 **Python 数值参考实现**，用于课堂讲解、生成教学图表，
并作为网页版数值结果的**交叉验证基准**。四个文件即全部内容：

| 文件 | 作用 |
| --- | --- |
| `pendulum.py` | 核心库（**不含任何绘图**）：动力学、RK4、线性化、自研 LQR/Riccati 求解、4 种控制器、统一仿真入口 |
| `demos.py` | 命令行演示入口（唯一用到 matplotlib 的文件），9 个 demo |
| `test_pendulum.py` | 纯 `assert` 自检脚本（**不需要 pytest**），16 项，直接 `python test_pendulum.py` |
| `crosscheck.py` | **与网页版 JS 实现的逐位交叉验证**（41 项对照 + scipy 第三方复核），见第 10 节 |

## 3. 各 demo 的教学要点（一句话）

| demo | 一句话教学要点 |
| --- | --- |
| `pid` | 单环 PID 能把**角度**稳住，但小车会一路漂走 —— 因为"小车匀速漂移"这个模态在角度测量里被零极点对消了，**不是调参问题**。 |
| `cascade` | 串级 PID：外环（慢）把位置误差翻译成"该往哪边倒"的角度给定，内环（快）跟踪它；**时标分离**是它能工作的前提。 |
| `lqr` | 一次把 4 个状态全用上，Q/R 直接表达"你在乎什么"；顺带打印 K、闭环极点、P 和两个通道的零点。 |
| `compare` | 同一冲量扰动下，LQR 用**更少的控制能量**换到**更小的累积代价 J**（它就是 J 的最优解），但峰值力更大、位置回中稍慢。 |
| `qr-sweep` | R 从 0.01 扫到 100：极点轨迹 + "响应快慢 vs 控制能量"的帕累托前沿；Bryson 定则（Q_ii=1/x_max², R=1/u_max²）只是一个量纲合理的起点。 |
| `swingup` | 摆起阶段被控量是**能量**而不是角度；能量泵到位后用 LQR 的代价函数 V=eᵗPe 判断已进入吸引域，再切换接住。 |
| `sampling` | 连续域设计 + ZOH 实现，采样太慢必然失稳；临界值可精确算出（离散闭环谱半径=1），本例 **Ts_crit ≈ 47.9 ms**。 |
| `robust` | 真实摆长/质量与设计值不符时：LQR 的容限约 0.4×–2.5×，串级 PID 只有 0.5×–1.6×。 |
| `animate` | 小车+摆杆实时动画（`FuncAnimation`），HUD 显示 t / x / theta / u / 当前模式。 |

## 4. 建模约定（与网页版严格一致，勿改）

状态量 `s = [x, x_dot, theta, theta_dot]`；`theta` 为摆杆与**竖直向上**方向的夹角，
`theta = 0` 即直立平衡点。摆杆为**均匀细杆**：`l = L/2`，`I = m*L²/12`，`J = I + m*l² = m*L²/3`。

非线性运动方程（拉格朗日法）：解 2×2 线性方程组

```
[ M+m            m*l*cos(theta) ] [x_ddot    ]   [ u - b*x_dot + m*l*sin(theta)*theta_dot^2 ]
[ m*l*cos(theta)  I + m*l^2     ] [theta_ddot] = [ m*g*l*sin(theta) - c*theta_dot           ]
```

在 `theta = 0` 处线性化（`D0 = (M+m)*(I+m*l²) - (m*l)²`）：

```
A = [[0, 1,                 0,                0            ],
     [0, -(I+m*l^2)*b/D0,   -(m*l)^2*g/D0,    m*l*c/D0     ],
     [0, 0,                 0,                1            ],
     [0, m*l*b/D0,          (M+m)*m*g*l/D0,   -(M+m)*c/D0  ]]
B = [[0], [(I+m*l^2)/D0], [0], [-m*l/D0]]
```

**`B[3] < 0`**：向右推小车，摆杆相对向左倒 —— 这是倒立摆"方向反直觉"的根源。
在上述方程里 `theta > 0` 对应杆的质心偏向 `+x` 一侧，动画就按
`(x + L*sin(theta), L*cos(theta))` 画杆端点，与方程自洽。

默认参数：`M=0.5, m=0.2, L=0.6, g=9.81, b=0.1, c=0.005, u_max=10 N`；
物理积分 **RK4 定步长 dt=0.002 s**，控制器按 **Ts=0.01 s 零阶保持(ZOH)** 更新
（`simulate()` 会自动把 `dt` 调成 `Ts/round(Ts/dt)`，保证采样边界精确对齐）。

### 与网页版的**唯一**约定差异：势能零点

| 量 | 本实现 | 网页版 `model.js` |
| --- | --- | --- |
| `energy(s, p)` 默认 | `V = m*g*l*(cos(theta) - 1)`，**直立静止 = 0** | `V = m*g*l*cos(theta)`，转轴水平面为零点 |
| 换算 | `E_here = E_web - m*g*l`（默认参数下 `m*g*l = 0.5886 J`） | |
| 兼容 | `energy(s, p, ref='pivot')` 与网页版**逐位相同** | |
| `pendulum_energy(s,p)` | 直立静止 = 0，下垂静止 = `-2*m*g*l = -1.1772 J` | 直立 = `+0.5886`，下垂 = `-0.5886` |

取"直立为零"的好处：`theta=pi/2` 自由摆动时参考能量不为 0（相对误差才有意义），
且能量法摆起的目标可以直接写成 `E_target ≈ 0`。

## 6. `pendulum.py` API 速查

```python
p = PendulumParams()                      # 参数（含派生属性 l, I, J, D0；replace() 造失配模型）
ds = dynamics(s, u, p)                    # 非线性导数
s1 = rk4_step(s, u, p, dt)                # 定步长 RK4
A, B = linearize(p)                       # theta=0 处解析线性化
E  = energy(s, p, ref='upright')          # 总机械能（'pivot' 与网页版一致）
Ep = pendulum_energy(s, p)                # 摆杆自身能量（摆起用）
K, P, eigs = lqr(A, B, Q, R)              # 自研 CARE 求解（下面详述）
C, rank, cond = ctrb(A, B)                # 可控性矩阵 / 秩 / 条件数
z  = tf_zeros(A, B, [1, 0, 0, 0])         # SISO 传递函数零点（纯 numpy）
Ad, Bd = c2d_zoh(A, B, Ts)                # ZOH 精确离散化（自研 expm）
res = simulate(ctrl, s0, t_end, p, ...)   # 统一仿真入口
m   = metrics(res)                        # 最大角偏/稳定时间/控制能量/累积代价 J
```

**LQR 是自己实现的**，没有直接调用 `scipy.linalg.solve_continuous_are`：

1. **值迭代**：把 Riccati 微分方程按反向时间 `tau = T - t` 化为初值问题
   `dP/dtau = A'P + PA - PBR⁻¹B'P + Q, P(0)=0`，用 RK4 积分到"K 已能稳定闭环"为止（得到粗解）；
2. **Kleinman–Newton 迭代**（二次收敛）：`K_k = R⁻¹B'P_k`，`Ac = A - B K_k`，
   解 Lyapunov 方程 `Ac'P + P Ac = -(Q + K_k'R K_k)`；该 Lyapunov 方程用 **Kronecker 积**
   展开成 **16×16** 线性方程组 `[(Ac'⊗I) + (I⊗Ac')] vec(P) = -vec(W)` 直接求解。

默认参数下 4 次 Newton 迭代即收敛，CARE 残差约 `1.6e-13`（内部断言 < 1e-8），
装了 scipy 时再与 `solve_continuous_are` 交叉校验（断言相对误差 < 1e-6，实测 8e-15）。

**`simulate()` 支持的实验条件**（都在同一个入口里）：

| 参数 | 说明 |
| --- | --- |
| `ref` | 参考轨迹 `fn(t) -> [x_ref,0,0,0]`，`make_reference('step'/'square'/'zero', ...)` |
| `disturbances` | `{'type':'impulse','t':2.0,'force':0.4}`（对小车的 N·s 冲量，按广义动量跳变施加）、`{'type':'impulse','t':2.0,'torque':0.05}`、`{'type':'force','t0':1,'t1':3,'F':1.5}`（持续风力 N） |
| `noise` | 测量高斯噪声标准差 `{'x':1e-3,'theta':5e-4, ...}` |
| `quantize` | 传感器量化步长 `{'x':1e-3,'theta':2e-4}`（先加噪声再量化） |
| `delay_steps` | 控制延迟，**整数个采样周期** |
| `Q, R` | 累积代价 `J = ∫(eᵗQe + uᵗRu)dt`（`e = s - s_ref`） |
| `p_true` | 真实物理参数（与设计用 `p` 不同即模型失配） |

返回字典的时间序列约定：`t[i]` 是第 i 个物理步的**起点**，`u[i]` 是区间
`[t[i], t[i]+dt)` 内实际施加的控制量，所以 `plt.step(t, u, where='post')` 画出来
就是真实的 ZOH 波形。

控制器都实现了 `reset()` 与 `__call__(s, t) -> u`，内部完成限幅与抗积分饱和
（`aw='backcalc'` 反计算 / `aw='cond'` 条件积分）：

* `PID`：单环，只反馈角度。误差取 **`e = theta - theta_ref`**（不是 `ref - meas`），
  因为 `B[3] < 0`，这样取正增益才是负反馈方向。
* `CascadePID`：外环位置 → 角度给定 → 内环角度。内环微分**作用于测量值**而非误差
  （derivative-on-measurement）；否则会多出一项与 `x_ddot`（进而与 `u`）成正比的
  代数正反馈，回路直接发散 —— 这是本项目实测踩过的坑，代码注释里有记录。
* `LQRController`：`u = -K(s - s_ref)`。
* `SwingUpController`：Åström–Furuta 能量法 `u = k_E*(E_p - E_target)*theta_dot*cos(theta)`
  叠加小车回中项；`E_target = 0.22*m*g*l` 略高于直立能量（补偿上行摩擦损耗，
  否则摆杆会停在 `|theta| ≈ 0.65 rad` 的极限环上翻不过去）；切换判据用
  **LQR 代价函数 `V(e)=eᵗPe < 5.0` 估计吸引域**并带滞环，切换时刻记录在 `switch_times`。

## 7. 自检覆盖的 16 项

1. 无控制、无摩擦时总机械能守恒（`theta=pi/2` 自由摆动 5 s，相对漂移 **3.2e-10** < 1e-6）
2. 中心差分数值雅可比 vs 解析 `A`、`B`（误差 **1.4e-11 / 2.2e-16** < 1e-6）
3. 线性化残差实际是 **三阶** 的（二阶项系数恒为零，`残差/eps³` 三个尺度一致）
4. Riccati 残差 **1.6e-13** < 1e-8，闭环极点全部严格在左半平面（多组 R 都测）
5. 与 `scipy.linalg.solve_continuous_are` 一致（相对误差 **8e-15** < 1e-6，无 scipy 则 SKIP）
6. `P` 对称正定，且 `K = R⁻¹B'P`
7. 可控性矩阵满秩 `rank = 4`（附一个真正不可控的反例）
8. LQR 闭环 `theta0=0.2 rad` → `|theta| < 1e-3`（实测 1.8e-5）且小车静止
9. 串级 PID 在冲量扰动下角度与位置**同时**稳定
10. 单环 PID 稳住角度但小车漂走（教学反例也要"可复现"）
11. RK4 的 4 阶收敛性（步长减半误差约降到 1/16）
12. ZOH 保持与整数采样周期控制延迟的实现正确性（逐拍核对施加序列）
13. 饱和与抗积分饱和：`|u| <= u_max` 恒成立，积分项有界（两种 anti-windup 都测）
14. 能量法摆起：`theta0=pi` → 只切换一次 → 收敛到 `|theta| < 1e-3`
15. `wrap_pi`、质量阵行列式恒正、自研 `expm` 与 `c2d_zoh`
16. `u->x` 通道的右半平面零点 = `sqrt(3g/(2L))`，`u->theta` 通道原点双重零点

## 10. 与网页版 JS 实现的交叉验证（`crosscheck.py`）

```bat
python crosscheck.py        :: 打印 6 节对照表，全部通过退出码 0
```

### 10.1 为什么这件事值得做

两边的 ARE 求解器是**完全独立**的两条技术路线，只共享公式、不共享一行代码：

| | Python（本目录） | 网页版 `src/lqr.js` |
| --- | --- | --- |
| 初值 | Riccati 微分方程**反向时间积分**（value iteration） | **Bass 关系式** |
| 迭代 | Kleinman–Newton | Kleinman–Newton |
| Lyapunov 求解 | Kronecker 积展开成 16×16（增广 25×25）线性方程组 | 纯 JS 自实现 |
| 第三方复核 | `scipy.linalg.solve_continuous_are` | 无 |

两条路线在 K、P、闭环极点、静差、临界采样周期上都对得上，就基本排除了
"实现写错"和"公式推错"这两类错误。

### 10.2 对照口径（重要）

网页版提供的基准值是**四舍五入过的**，本身带 ±0.5·10⁻ᵈ 的量化误差，
所以除了看相对偏差，更要看**量化比 = 绝对偏差 ÷ 基准末位半单位**：≤ 1 就说明
偏差完全落在基准的打印精度之内，不可能再往下比。

`crosscheck.py` 侦测到：**基准的 K 虽然打印了 6 位小数，但实际只有 4 位有效**
（先舍入到 4 位再补零）。证据：`K[1]` 的正确 6 位舍入应为 `-29.525938`，而基准写作
`-29.525900`；并且全部 16 个 `P` 元素满足 `round(P_python, 4) - P_js ≡ 0`（差为**精确的 0**）。
若网页版真有 1e-6 量级的求解误差，这种"全部精确round-trip"是不可能出现的。

### 10.4 第三条独立验证路径：解析不变量（不依赖任何求解器）

由 Kalman 频域等式（谱分解恒等式）在 `A` 的零特征值方向上取 `s→0` 极限，可得

```
R·K_x² = q_x   =>   K_x = -sqrt(q_x/R)      （与其它三个权重完全无关！）
```

* 普通 LQR：`K_x = -sqrt(4/0.01) = -20` **精确**，两边实测偏差 5.0e-13；
* 增广 LQI（原点变成二重极点，同一推导）：`k_i = -sqrt(q_I/R) = -sqrt(16/0.01) = -40` **精确**，偏差 6.8e-13。

也就是说这两个数字是**可以手算出来的精确值**，两边实现都命中了它。

### 10.5 `u→x` 通道零点：解析式验证与 `b` 无关性

对线性化模型做 Laplace 变换并消去 `Θ`：

```
X/U = (J s² + c s − m g l) / { [(M+m)s² + b s](J s² + c s − m g l) − (m l)² s⁴ },   J = I + m l² = m L²/3
```

**分子只含 `J`、`c`、`m g l`**，于是零点

```
s = ( −c ± sqrt(c² + 4·J·m·g·l) ) / (2J)        c = 0 时退化为 ±sqrt(m g l/J) = ±sqrt(3g/(2L))
```

| 来源 | 左零点 | 右零点(RHP) |
| --- | --- | --- |
| 解析式（含 `c=0.005`） | −5.0575342781 | **+4.8492009448** |
| 本实现 `tf_zeros` 数值解 | −5.0575342781 | **+4.8492009448** |
| 无摩擦 `±sqrt(3g/(2L))` | −4.9522722058 | +4.9522722058 |
| 网页版 `analyze().zRHP` | — | +4.9523 |

* 解析式 vs 数值：最大偏差 **4.1e-14** ✔
* **`b` 无关性成立**：`b` 取 0 / 0.1 / 1 / 10 / 100（跨 3 个数量级）零点变化 ≤ 7.1e-13（纯浮点噪声）。
* 附带发现：与小车质量 `M` 也无关（`M` 跨 500 倍变化 ≤ 1.5e-12）；只随 `c` 变化——
  `c` 增大时 RHP 零点左移（非最小相位程度减轻）、LHP 零点右移，`c=0` 时对称。

### 10.6 静差解析式

风扰 `d` 与 `u` 同一入口（`B_d = B`）。稳态时 `ẋ = θ̇ = 0`，消去 `θ` 得
`(u_ss + d)·(a₁ − a₃b₁/b₃) = 0`，而 `a₁ − a₃b₁/b₃ = 1/(M+m) ≠ 0`，故

```
u_ss = −d ,  θ_ss = 0 ,  x_ss = d / K_x       （与其它三个增益无关）
```

`d = 1 N` 实测（非线性仿真 40 s）：`x_ss = −0.050000000000`（理论 `1/(−20) = −0.05`，
偏差 **4.3e-15**），`θ_ss = 2.1e-16`，`u_ss = −1.0000000000`。
**杆保持严格竖直，小车偏置 5 cm 停住** —— 这是个很好的课堂问题："为什么静差出现在位置上而不是角度上？"
LQI 把它压到 `x_ss = −1.2e-16 m`（要求 < 1e-3 ✔），过渡过程 `max|x| = 1.27 cm`、`max|u| = 1.24 N`。

### 10.8 `u→θ` 通道到底有没有有限零点

```
Θ/U = −m l s² / { [(M+m)s² + b s](J s² + c s − m g l) − (m l)² s⁴ }
```

分子恒为 `−m l s²`；**分母能提出几个 `s`** 决定约简后还剩几个零点：

| 情形 | 分母可提出 | 约简后有限零点 |
| --- | --- | --- |
| `b=0, c=0`（网页版公式的前提） | `s²` | **无**（分子约简为常数） |
| `b=0, c=0.005` | `s²` | **无** |
| `b=0.1, c=0.005`（**默认参数**） | `s¹` | **1 个，位于原点 s=0** |

* `b=0` 时分母 `= s²(D₀s² − m g l(M+m))/D₀`，与分子 `s²` 完全抵消 →
  `Θ/U = −m l/(D₀s² − m g l(M+m))`，分子是常数、**没有有限零点** ——
  **网页版的推导在 `b=0` 前提下完全正确**。
* 默认 `b = 0.1 ≠ 0` 时分母只能提出 `s¹`（常数项为 0，`s` 的系数
  `= −m g l b/D₀ = −4.459091 ≠ 0`），约简后 `Θ/U = −(m l/D₀)·s/(三次多项式)`，
  **还剩 1 个位于原点的零点**。它正是"小车匀速漂移在角度通道里看不见"（DC 增益 = 0）
  的数学表述，也解释了为什么纯 PD 稳不住角度环：三次分母常数项 `= −m g l b/D₀ < 0`，
  Routh–Hurwitz 恒不满足，**必须加积分项**。

### 10.9 给网页版的 2 点修改建议（其余数值全部正确，无需改动）

1. **`analyze().zRHP` 建议用精确式**。现在用的 `sqrt(m·g·l/J) = 4.952272` 是 `c = 0` 的近似值，
   默认参数（`c = 0.005`）下精确 RHP 零点是 **4.849201**，现值偏高 **2.13%**。
   改法（只多一个开方）：
   ```js
   const disc = Math.sqrt(p.c * p.c + 4 * d.J * p.m * p.g * d.l);
   const zRHP = (-p.c + disc) / (2 * d.J);       // 精确值；c=0 时自动退化为 sqrt(mgl/J)
   const zLHP = (-p.c - disc) / (2 * d.J);
   ```
   同理 `pUnstable = sqrt(m·g·l·(M+m)/D0) = 5.586917` 也是无摩擦值，
   含摩擦的真实开环不稳定极点是 **+5.437414**（低 2.7%，无简单闭式，需数值求根）。
   两者作为"无摩擦解析参考"没问题，但若在 UI 上标成"本系统的极点/零点"就会和
   实际极点零点对不上。
2. **"ARE 残差 < 1e-12" 建议注明范数口径**。在这组 `Q/R` 下：

   | 求解器 | ‖res‖_F | max\|res\| | res/(1+‖P‖_F) |
   | --- | --- | --- | --- |
   | Python 自研 | 3.33e-12 | 1.76e-12 | **1.03e-13** |
   | scipy | 6.94e-12 | 5.80e-12 | **2.15e-13** |

   参与相消的项 ‖P·B·R⁻¹·B'·P‖_F ≈ 4.88e+02，double 精度下残差量级下限就在 1e-13，
   所以**绝对** Frobenius 残差不可能 < 1e-12（scipy 自己是 6.9e-12，比本实现还大）。
   建议把断言写成**归一化**残差 `res/(1+‖P‖_F) < 1e-12`（此时成立），
   或注明用的是逐元素最大值范数。这只是口径问题，不是求解器不一致。
