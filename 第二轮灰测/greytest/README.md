# 小车-倒立摆仿真教学平台

一个**教学与理论并重**的倒立摆（cart-pole）仿真：网页端可交互实时仿真 + 完整理论推导 + 独立 Python 参考实现，
四种控制器（单环 PID / 串级 PID / LQR / 增广 LQI）外加能量法摆起，全部数值结论都有可复现的自检脚本背书。

**零依赖、零安装、零联网**：双击 `index.html` 即可运行（纯 HTML + 原生 JS，连 CDN 都不用）。
LQR 的代数 Riccati 方程是在**浏览器里现场解**的 —— 拖动权重滑块，你就在实时重解 ARE。

## 功能一览

**七种运行模式**

| 模式 | 教学作用 |
|---|---|
| 无控制 | 先看清"敌人"：开环有多快倒，量化不稳定极点 |
| 单环 PID | 摆能站住但小车必然漂走 —— **结构性**缺陷的现场演示 |
| 串级 PID | 外环位置 → 内环角度，体验右半平面零点造成的带宽上限 |
| LQR | 全状态最优反馈，一次解 Riccati 把四个状态一起管住 |
| LQR + 积分 | 增广 LQI：消除常值扰动下的位置静差（并看清它的代价） |
| 摆起 + LQR | 能量法把摆从下垂甩起来，进入捕获区后交给 LQR |
| **PID vs LQR 对比** | 上下两条轨道，同一扰动、同一模型、**同一份噪声实现**，定量比较 |

**可交互的一切**
- 物理参数：`M, m, L, b, c, g, u_max, 导轨长度` + 6 组预设（标准/重摆/长摆/短摆/无摩擦/弱执行器）
- LQR 权重：`q_x, q_v, q_θ, q_ω, ρ, q_I`（Bryson 定则）+ 5 组预设（均衡/激进/省力/只顾角度/位置优先）
- PID 参数：既可按"闭环形状" `ωn/ζ` 解析反解增益，也可直接给 `Kp/Ki/Kd`
- 数字实现：采样周期 `Ts`（零阶保持）、计算延迟（0–10 拍）
- 传感器：角度/位置高斯噪声、量化步长（模拟编码器分辨率）
- 扰动：恒定风扰、角速度冲击、键盘手推
- 给定：恒定位置或方波跟踪
- **模型误差**：控制器按"设计参数"算，被控对象按另一组"真实参数"跑 —— 鲁棒性实验的标准做法

**实时可视化**
- 动画：导轨刻度与限位、力箭头（长度 ∝ |u|，饱和时闪红）、倾角圆弧、
  外环下发的倾角给定 `θ_ref`（紫色虚线）、摆尖拖尾、风力箭头、失败横幅
- 三张时域曲线（θ / x / u，带限幅带）+ 第四张可切换：相图 θ–θ̇ / s 平面极点图 / 能量曲线
- 极点图同时显示开环极点、闭环极点（对比模式下两种控制器同图）、`u→x` 通道零点
- 实时指标：`max|θ|`、`∫u²dt`、累积代价 `J`、饱和率

**分析面板（每次改参数都实时重算）**
- 结构性质：`J`、`D₀`、不稳定极点 `p`、误差倍增时间、RHP 零点 `z`、能控性秩与条件数、开环极点
- 状态空间矩阵 `A`、`B`
- LQR 求解结果：`K`、`P`、`λ(P)`、闭环极点、**ARE 残差**（≈1e−13）、牛顿迭代步数
- PID 的闭环极点（把积分器当状态算出来，因此能和 LQR 放在同一张图上比较）
- 鲁棒性：增益裕度区间、**临界采样周期 `Ts_crit`** 并提示当前 `Ts` 是否安全

## 关键数值（默认参数）

```
不稳定极点         无摩擦解析 p = 5.5869 rad/s，含摩擦实际 = 5.4374 rad/s
                   →  误差倍增时间 ln2/p = 0.1275 s（按实际值）
u→x 右半平面零点   z = (−c+√(c²+4Jmgl))/(2J) = 4.8492009448 rad/s  →  外环带宽上限 z/2 = 2.42 rad/s
                   （与小车摩擦 b、小车质量 M 完全无关；无摩擦近似值 4.9523 偏高 2.1%）
u→θ 通道           b≠0 时有 1 个原点零点（DC 增益 = 0）→ 小车漂移在角度信号里"看不见"
p/z = 1/√(1−3m/(4(M+m))) = 1.128152  →  只取决于质量比，与 L、g 无关
能控性矩阵         rank = 4, cond = 156.0

LQR   K = [−20.0000000000, −29.5259377571, −216.7705431105, −23.6446060662]
      闭环极点 = −0.75534087 ± 0.71366937i（归位）,  −26.36412344 ± 11.43655196i（扶摆）
      ARE 残差：绝对 5.46e−13 / 归一化 1.69e−14；增益裕度 α ∈ [0.057, ∞)；Ts_crit = 37.4 ms
      精确不变量 K_x = −√(q_x/R)（可手算校验，与 m、L、g、摩擦无关）
LQI   kᵢ = −√(q_I/R) = −40.0（q_I=16），风扰 1 N 下静差 1.4e−17 m（普通 LQR：−0.0500 m = d/K_x）
PID   内环 Kp/Ki/Kd = 38.55 / 4.0 / 4.75（ωn=12, ζ=0.9）；**Ki 必须 > b·g = 0.981**
      外环 Kp/Ki/Kd = 0.147 / 0.05 / 0.171（ωo=1.2, ζo=0.7）
      闭环极点 = −0.104, −0.728±0.486i, −1.037, −3.728±9.707i
      增益裕度 α ∈ [0.385, 212]，Ts_crit = 110.7 ms
摆起  k_E=4, k_x=1.0, k_v=1.5  →  2.51 s 完成摆起，最大行程 0.868 m
```

四个反直觉但可验证的结论，每一个都在文档里给了推导与实测：

1. **`K` 四项全为负** —— `K_x < 0` 意味着"车在右边就继续往右推"。这是 RHP 零点在增益上的指纹（§4.6）。
2. **`z < p` 恒成立**，且 `p/z` 只取决于质量比 —— 这才是串级结构"外环必须慢"的真正理论依据（§3.4）。
3. **`b > 0` 时纯 PD 连角度都稳不住**，必须 `Ki > b·g`。教科书里"PD 就能稳住倒立摆"只在无摩擦模型下成立（§5.1）。
4. **LQR 对采样周期比 PID 更敏感**（37 ms vs 111 ms）—— 更优的连续设计不等于更优的数字实现（§6.2）。

| 检验项 | 结果 |
|---|---|
| 无摩擦自由摆动能量守恒 | 相对漂移 **3.2e−10**（以 mgl 为尺度） |
| 解析线性化 vs 中心差分数值雅可比 | `‖ΔA‖ = 1.4e−9`，`‖ΔB‖ = 0` |
| ARE 残差（绝对 / 归一化） | **5.5e−13 / 1.7e−14** |
| 两种独立 ARE 解法（Bass+Newton vs 自适应值迭代） | 相对差 **3.9e−11** |
| 精确不变量 `K_x = −√(q_x/R)`（4 组权重，含 q_x/R=80000） | 最大偏差 **9e−13** |
| 传输零点：`det([[A−zI, B],[C,0]])` | `|det(z)| / |det(1.15z)| = 3.0e−16` |
| `p/z` 解析式 vs 数值 | 吻合到 **1e−12** |
| 小车摩擦 `b` 不影响 `u→x` 零点（b: 0.1→10） | 变化 < **1e−12** |
| 纯 PD 不可稳 + 积分门限 `Ki > b·g` | b=0.1, Ki=0 ⇒ max Re = **+0.0308**；1.1×门限 ⇒ +3e−6 |

## 开发中真实踩到的三个坑（都写进了教学材料）

1. **抗积分饱和不能用反计算。** 教科书上的 back-calculation 在"比例项本身就远超限幅"时，
   会把积分器推到巨大的反向值，误差回落后积分项接管 → **小车飞到 8.9 m**。
   改用条件积分 + 积分限幅后同一工况末态 `x = 0.0015 m`。（§5.5）
2. **手写 LQR 积分项符号会反。** 因为 `K_x < 0`，直觉上的 `u = −Ks − kᵢ∫e` 是发散的。
   正确做法是做增广 LQR，让 Riccati 方程自己给出符号。（§4.8）
3. **离散谱半径不能用"特征多项式 + 求根"。** 小 `Ts` 时离散特征值全聚在 `z=1` 附近，
   多项式求根对聚簇根病态，会虚假地报告"不稳定"。改用 Gelfand 公式 + 反复平方。（§6.2）

还有两个"教科书没讲但实测必须处理"的问题：摆起时摩擦让摆**差一点**过不了顶（需要 4% 能量过冲），
以及 LQR 捕获失败的真凶是**小车速度**而不是摆角（`K_v·ẋ` 会把 10 N 推力全部吃光）。详见 §7.3。

**跨实现交叉验证还纠正了两个理论表述**：
`u→x` 的 RHP 零点必须用含摩擦的精确式（无摩擦近似偏高 2.1%）；
以及 `b≠0` 时 `u→θ` 存在原点零点，由此得到"纯 PD 恒不可稳、必须 `Ki > b·g`"这个更强的结论。
两套独立实现互相挑错，比任何一方单独"自检通过"都可靠。
