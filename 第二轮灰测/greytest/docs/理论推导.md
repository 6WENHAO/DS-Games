# 小车-倒立摆：完整理论推导

> 本文档与代码严格对应。文中每一个数值都由 `node tests/bench.js` 与 `node tests/selftest.js` 现场算出，
> 不是抄来的教科书数字。默认参数：`M=0.5 kg, m=0.2 kg, L=0.6 m, g=9.81 m/s², b=0.1 N·s/m, c=0.005 N·m·s, u_max=10 N`。

## 0. 符号与约定

| 符号 | 含义 | 默认值 |
|---|---|---|
| $x$ | 小车位置（向右为正） | — |
| $\theta$ | 摆杆与**竖直向上**方向的夹角，$\theta=0$ 即直立平衡点 | — |
| $u$ | 作用在小车上的水平驱动力 | $\lvert u\rvert \le 10$ N |
| $M,\ m$ | 小车质量、摆杆质量 | 0.5、0.2 kg |
| $L,\ l$ | 摆杆总长、质心到转轴距离 $l=L/2$ | 0.6、0.3 m |
| $I,\ J$ | 绕质心转动惯量 $I=mL^2/12$；绕转轴等效惯量 $J=I+ml^2=mL^2/3$ | 0.006、0.024 kg·m² |
| $b,\ c$ | 小车粘性摩擦、转轴粘性摩擦 | 0.1、0.005 |
| $D_0$ | 线性化耦合行列式 $(M+m)J-(ml)^2$ | 0.0132 |

状态向量统一取 $s=[x,\ \dot x,\ \theta,\ \dot\theta]^\mathsf{T}$。

**关于摆杆模型的说明**：本项目按**均匀细杆**建模（$J=mL^2/3$），而不是很多教材用的"杆末端集中质量"。
两者差别在 $J$ 的取值，会改变全部数值结果。选细杆是因为它更接近真实实验台。

## 1. 建模：拉格朗日方程

### 1.1 动能与势能

摆杆质心位置为 $(x+l\sin\theta,\ l\cos\theta)$，求导得质心速度：

$$\dot x_p=\dot x+l\cos\theta\,\dot\theta,\qquad \dot y_p=-l\sin\theta\,\dot\theta$$

$$\dot x_p^2+\dot y_p^2=\dot x^2+2l\cos\theta\,\dot x\dot\theta+l^2\dot\theta^2$$

于是

$$T=\underbrace{\tfrac12M\dot x^2}_{\text{小车}}+\underbrace{\tfrac12m(\dot x_p^2+\dot y_p^2)+\tfrac12I\dot\theta^2}_{\text{摆杆（平动+转动）}}
=\tfrac12(M+m)\dot x^2+ml\cos\theta\,\dot x\dot\theta+\tfrac12(I+ml^2)\dot\theta^2$$

$$V=mgl\cos\theta$$

注意势能零点取"摆杆水平"，故直立时 $V=+mgl$、下垂时 $V=-mgl$。这个选择让摆起控制的目标能量恰好是 $E_d=mgl$。

### 1.2 两条运动方程

拉格朗日量 $\mathcal L=T-V$。对 $x$：

$$\frac{\partial \mathcal L}{\partial \dot x}=(M+m)\dot x+ml\cos\theta\,\dot\theta
\ \Longrightarrow\ \frac{d}{dt}(\cdot)=(M+m)\ddot x+ml\cos\theta\,\ddot\theta-ml\sin\theta\,\dot\theta^2$$

而 $\partial\mathcal L/\partial x=0$，广义力为 $u-b\dot x$，故

$$\boxed{(M+m)\ddot x+ml\cos\theta\,\ddot\theta-ml\sin\theta\,\dot\theta^2=u-b\dot x}\tag{1}$$

对 $\theta$：

$$\frac{\partial\mathcal L}{\partial\dot\theta}=ml\cos\theta\,\dot x+(I+ml^2)\dot\theta
\ \Longrightarrow\ \frac{d}{dt}(\cdot)=ml\cos\theta\,\ddot x-ml\sin\theta\,\dot x\dot\theta+(I+ml^2)\ddot\theta$$

$$\frac{\partial\mathcal L}{\partial\theta}=-ml\sin\theta\,\dot x\dot\theta+mgl\sin\theta$$

两者相减，$-ml\sin\theta\,\dot x\dot\theta$ 恰好抵消，广义力为 $-c\dot\theta$：

$$\boxed{(I+ml^2)\ddot\theta+ml\cos\theta\,\ddot x-mgl\sin\theta=-c\dot\theta}\tag{2}$$

### 1.3 矩阵形式与可解性

把 (1)(2) 写成 $\mathbf{A}(\theta)\,[\ddot x,\ \ddot\theta]^\mathsf{T}=\mathbf{f}$：

$$\begin{bmatrix} M+m & ml\cos\theta\\ ml\cos\theta & I+ml^2\end{bmatrix}
\begin{bmatrix}\ddot x\\ \ddot\theta\end{bmatrix}=
\begin{bmatrix}u-b\dot x+ml\sin\theta\,\dot\theta^2\\ mgl\sin\theta-c\dot\theta\end{bmatrix}$$

行列式

$$\Delta=(M+m)(I+ml^2)-(ml\cos\theta)^2=(M+m)I+m^2l^2\Big(\frac{M+m}{m}-\cos^2\theta\Big)>0$$

因为 $(M+m)/m>1\ge\cos^2\theta$。**质量矩阵永远正定，方程永不奇异**——这保证了任意状态下都能唯一解出加速度，
仿真不会在某个角度突然崩掉。代码实现见 `src/model.js` 的 `dynamics()`。

### 1.4 能量与守恒性检验

$$E=T+V=\tfrac12(M+m)\dot x^2+ml\cos\theta\,\dot x\dot\theta+\tfrac12J\dot\theta^2+mgl\cos\theta$$

**这是最重要的模型自检手段**：令 $b=c=0$、$u=0$，从 $\theta_0=\pi/2$ 自由摆动 5 s，能量相对漂移应当只由积分器误差贡献。
实测（RK4，$dt=2$ ms）：**相对漂移 $3.16\times10^{-10}$**（以 $mgl=0.5886$ J 为尺度）。
如果这一项超过 $10^{-6}$，一定是动力学方程写错了，而不是"数值误差"。

## 2. 线性化与不稳定性的量化

### 2.1 平衡点

令所有导数为零：由 (2) 得 $mgl\sin\theta=0\Rightarrow\theta\in\{0,\pi\}$；由 (1) 得 $u=0$。
$\theta=0$（直立）与 $\theta=\pi$（下垂）都是平衡点，前者不稳定、后者稳定。所有反馈控制器都在 $\theta=0$ 处工作。

### 2.2 雅可比矩阵

在 $\theta=0,\dot\theta=0,u=0$ 处取一阶近似（$\sin\theta\to\theta$, $\cos\theta\to1$, $\dot\theta^2\to0$）：

$$\begin{bmatrix} M+m & ml\\ ml & J\end{bmatrix}\begin{bmatrix}\ddot x\\ \ddot\theta\end{bmatrix}
=\begin{bmatrix}u-b\dot x\\ mgl\,\theta-c\dot\theta\end{bmatrix}$$

求逆（$D_0=(M+m)J-(ml)^2$）：

$$A=\begin{bmatrix}
0&1&0&0\\
0&-\dfrac{Jb}{D_0}&-\dfrac{m^2l^2g}{D_0}&\dfrac{mlc}{D_0}\\
0&0&0&1\\
0&\dfrac{mlb}{D_0}&\dfrac{(M+m)mgl}{D_0}&-\dfrac{(M+m)c}{D_0}
\end{bmatrix},\qquad
B=\begin{bmatrix}0\\ \dfrac{J}{D_0}\\ 0\\ -\dfrac{ml}{D_0}\end{bmatrix}$$

默认参数下的数值（`tests/selftest.js` 打印）：

```
A = [ 0      1        0        0     ]        B = [ 0      ]
    [ 0     -0.1818  -2.6755   0.0227]            [ 1.8182 ]
    [ 0      0        0        1     ]            [ 0      ]
    [ 0      0.4545  31.2136  -0.2652]            [-4.5455 ]
```

**验证**：与中心差分数值雅可比对比，$\lVert A_{\text{解析}}-A_{\text{数值}}\rVert_F=1.4\times10^{-9}$、
$\lVert B_{\text{解析}}-B_{\text{数值}}\rVert_F=0$（Python 参考实现独立复算：$1.4\times10^{-11}$、$2.2\times10^{-16}$）。

> **$B_4=-ml/D_0<0$ 是整个项目最重要的一个负号**：向右推小车，摆杆向左转。
> 倒立摆所有"反直觉"的操作——想让车往右走要先往左推、角度环输出必须与角度同号——全部源于此。

### 2.3 特征值的解析解

令 $b=c=0$，$A$ 的特征多项式为 $\lambda^2\big(\lambda^2-\frac{mgl(M+m)}{D_0}\big)$，于是

$$\lambda=0,\ 0,\ \pm p,\qquad \boxed{p=\sqrt{\frac{mgl(M+m)}{D_0}}}$$

默认参数：$p=5.586917$ rad/s（自检中与无摩擦模型的数值特征值吻合到 $10^{-9}$）。
**含摩擦时的真实开环极点**（数值特征值，Python 参考实现独立复算一致）：

$$\{+5.437414,\ 0,\ -0.142832,\ -5.741552\}$$

摩擦让不稳定极点从 5.5869 慢到 5.4374（−2.7%），但**改变不了它在右半平面的事实**。
本平台的分析面板同时显示两者：解析值用于讲清公式结构，实际值用于算反应时间。

两个零特征值的含义：$x$ 与 $\dot x$ 构成的"小车漂移模态"——没有任何物理机制把小车拉回原点。
这解释了后面 §5.1 单环 PID 的结构性失败。

### 2.4 留给控制器的反应时间

误差按 $e^{pt}$ 增长，倍增时间

$$T_2=\frac{\ln 2}{p}=\begin{cases}0.1241\ \text{s} & \text{无摩擦解析值}\\ 0.1275\ \text{s} & \text{含摩擦实际值}\end{cases}$$

这是全部数字实现要求的源头：采样周期必须远小于 0.12 s，否则控制器"看一眼的功夫"误差就翻倍了。
§6.2 会给出定量的临界值 $T_{s,\text{crit}}=37.4$ ms。

## 3. 结构性障碍：一个执行器 + 一个右半平面零点

### 3.1 能控性

$$\mathcal{C}=[B\ \ AB\ \ A^2B\ \ A^3B],\qquad \operatorname{rank}\mathcal C=4,\quad \operatorname{cond}_2\mathcal C=156.0$$

满秩 ⇒ 四个状态理论上都可控。但**只有一个输入**：任何时刻都在用同一只手同时扶摆和拉车，
所以"多目标权衡"不是设计风格问题，而是物理约束。这正是 LQR 的代价函数所要表达的东西。

### 3.2 传递函数

对线性化方程做 Laplace 变换（先取 $b=c=0$ 以看清结构）：

$$\big[(M+m)s^2\big]X+ml s^2\Theta=U,\qquad ml s^2X+(Js^2-mgl)\Theta=0$$

消元得

$$\frac{\Theta(s)}{U(s)}=\frac{-ml}{D_0s^2-mgl(M+m)},\qquad
\frac{X(s)}{U(s)}=\frac{Js^2-mgl}{s^2\big(D_0s^2-mgl(M+m)\big)}$$

- $u\to\theta$ 通道在**无摩擦**时没有有限零点（分子是常数）；负号再次体现 $B_4<0$。
- $u\to x$ 通道的零点为 $\pm\sqrt{mgl/J}=\pm\sqrt{3g/2L}$（细杆），**其中一个在右半平面**。

**含摩擦的准确结果**（这里有一个容易讲错的地方）。保留 $b,c$ 重做上面的消元：

$$\big[(M+m)s^2+bs\big]X+mls^2\Theta=U,\qquad mls^2X+(Js^2+cs-mgl)\Theta=0$$

$$\boxed{\frac{\Theta(s)}{U(s)}=\frac{ml\,s}{m^2l^2s^3-\big[(M+m)s+b\big](Js^2+cs-mgl)}}$$

$$\frac{X(s)}{U(s)}=\frac{Js^2+cs-mgl}{s\Big\{\big[(M+m)s+b\big](Js^2+cs-mgl)-m^2l^2s^3\Big\}}$$

两个重要修正：

1. **$u\to x$ 的零点变得不对称**：

$$\boxed{z=\frac{-c+\sqrt{c^2+4Jmgl}}{2J}}\qquad z=4.8492009448,\quad z_{\text{LHP}}=-5.0575342781$$

（无摩擦值 $\pm4.9522722058$，偏差 2.1%。Python 参考实现独立算得同样的 10 位数字。）

分子只含 $J,c,mgl$，**与小车摩擦 $b$ 无关，也与 $M$ 无关**——把 $b$ 从 0 改到 100（跨 3 个数量级）、
把 $M$ 改动 500 倍，零点变化都在 $10^{-12}$ 以内（纯浮点噪声）。
物理含义：这个零点描述的是**摆杆自身绕转轴的动力学**，与小车受多少阻力、有多重都无关。

2. **$b\ne0$ 时 $u\to\theta$ 出现原点零点。** 未约简的形式是

$$\frac{\Theta(s)}{U(s)}=\frac{ml\,s^2}{s\Big\{m^2l^2s^3-\big[(M+m)s+b\big](Js^2+cs-mgl)\Big\}}$$

分子为 $ml\,s^2$（**原点双重零点**）。这里有个容易含糊的地方值得说清楚：
**未约简的分子恒为 $ml\,s^2$，有无摩擦都一样**（自检实测 $N(s)/s^2=-ml/D_0=-4.545455$，在两个量级上保持常数）。
真正的区别在**分母原点极点的重数**：

| | 分母原点极点重数 | 约简后 | 剩余原点零点 |
|---|---|---|---|
| $b=0$ | **2**（开环极点 $\{0,0,\pm p\}$） | 2 阶，分子为常数 | 无 |
| $b\ne0$ | **1**（开环极点 $\{0,-0.1428,+5.437,-5.742\}$） | 3 阶 | **剩 1 个** |

即：$b=0$ 时 $s^2$ 被完全约掉，退化为 §3.2 开头那个二阶式；$b\ne0$ 时只约掉一个 $s$，**剩下一个原点零点**。

> 核对时的提醒：直接对四阶系统 $(A,B,C=[0,0,1,0])$ 数值求传输零点会得到 $\{0,0\}$（未约简），
> 而约简后只剩一个（$b\ne0$）或零个（$b=0$）。两种说法都对，区别只在是否约简。
> 本文档默认给约简形式（因为 §5.1 的稳定性分析用的是它），
> Python 参考实现的 `tf_zeros()` 给未约简的 $\{0,0\}$。自检脚本对分子重数与分母极点重数都做了断言。

无论用哪种形式，结论一致：

- **DC 增益为 0**：常值力产生不了稳态倾角（物理上显然：稳态时 $mgl\sin\theta=0\Rightarrow\theta=0$）。
  换句话说，**小车的漂移在角度信号里完全"看不见"**——这正是 §5.1 单环 PID 失败的频域解释。
  Python 参考实现用另一条路径（$a_1b_2-a_2b_1\equiv0$）独立验证了同一件事，
  并进一步指出系统存在一整族"匀速漂移平衡点"。
- 更强的结论见 §5.1：$b\ne0$ 时它导致**纯 PD 角度环恒不可稳**（而 $b=0$ 时纯 PD 可以稳住角度——
  两者的分界正是上表那一行原点极点重数的差别）。

### 3.3 右半平面零点意味着什么

RHP 零点是**无法用反馈消除**的硬限制（想用极点去"抵消"它会导致内部不稳定）。后果：

1. **阶跃响应必然先反向**：想让小车往右移动，必须先向左推让摆杆向右倾倒，再"追"过去。
2. **位置环带宽有上限**，经验判据 $\omega_o\lesssim z/2$。超过它，"先反向"的那一段会被高增益放大成正反馈。

### 3.4 一个容易讲错的地方：$p$ 与 $z$ 并不构成"夹逼"

初看会以为"内环要快于 $p$、外环要慢于 $z/2$，而 $z/2<p$，所以无解"。这是**错的**，因为两个约束作用在**不同的回路**上：

- $p$ 约束**内环**（被控对象是 $u\to\theta$，该通道无 RHP 零点）：需要 $\omega_n\gtrsim 2p$；
- $z$ 约束**外环**（被控对象是 $\theta_{\text{ref}}\to x$，该通道有 RHP 零点但**没有** RHP 极点，因为内环已经把它稳定了）：需要 $\omega_o\lesssim z/2$。

进一步可以证明（无摩擦、细杆）：

$$\frac{p}{z}=\sqrt{\frac{J}{J-\frac{m^2l^2}{M+m}}}=\frac{1}{\sqrt{1-\dfrac{3m}{4(M+m)}}}>1$$

推导：$z^2=mgl/J$，而 $p^2=\frac{mgl(M+m)}{(M+m)J-(ml)^2}=\frac{mgl}{J-\frac{m^2l^2}{M+m}}$，相除即得；
再代入 $J=mL^2/3,\ l=L/2$ 化简。**这个比值只取决于质量比 $m/(M+m)$，与摆长 $L$、重力 $g$ 完全无关**，
且由于 $\frac{3m}{4(M+m)}<\frac34$，恒有 $p/z<2$。

默认参数：解析 $p/z=1.128152$，数值 $1.128152$（自检吻合到 $10^{-12}$）。

**结论**：$z<p$ 恒成立，所以内环下限 $2p$ 与外环上限 $z/2$ 之间必然相差约 $4p/z\approx4.5$ 倍。
**两个回路被迫时标分离——这就是串级结构成立的理论依据**，也是"外环必须慢"的定量出处。

### 3.5 摆越短为什么越难

$p$ 与 $z$ 都按 $\propto\sqrt{g/L}$ 同比例增大（比值不变）：

| L (m) | p (rad/s) | z 含摩擦 | z 无摩擦 | p/z 无摩擦 | 内环建议 ≥2p | 外环上限 z/2 | 时标分离比 |
|---|---|---|---|---|---|---|---|
| 0.20 | 9.677 | 7.691 | 8.578 | 1.1282 | 19.35 | 3.85 | 5.0× |
| 0.30 | 7.901 | 6.599 | 7.004 | 1.1282 | 15.80 | 3.30 | 4.8× |
| 0.60 | 5.587 | 4.849 | 4.952 | 1.1282 | 11.17 | 2.42 | 4.6× |
| 0.90 | 4.562 | 3.997 | 4.044 | 1.1282 | 9.12 | 2.00 | 4.6× |
| 1.20 | 3.951 | 3.476 | 3.502 | 1.1282 | 7.90 | 1.74 | 4.5× |
| 1.60 | 3.421 | 3.018 | 3.033 | 1.1282 | 6.84 | 1.51 | 4.5× |

所以"短摆难控"的本质**不是稳定性理论问题，而是硬件跟不上**：采样率、执行器带宽、传感器噪声都被同比例抬高要求。
反过来，杂技演员在手上竖长杆比竖短铅笔容易得多，也是同一个 $\sqrt{g/L}$。

## 4. LQR：从代价函数到 Riccati 方程

### 4.1 问题

$$\min_{u(\cdot)}\ J=\int_0^\infty\big(s^\mathsf{T}Qs+u^\mathsf{T}Ru\big)\,dt
\qquad\text{s.t. }\dot s=As+Bu,\quad Q\succeq0,\ R\succ0$$

### 4.2 推导（HJB / 配方法）

猜最优值函数为二次型 $V(s)=s^\mathsf{T}Ps$（$P$ 对称）。稳态 HJB 方程为

$$\min_u\Big[s^\mathsf{T}Qs+u^\mathsf{T}Ru+\nabla V^\mathsf{T}(As+Bu)\Big]=0,
\qquad \nabla V=2Ps$$

括号内对 $u$ 是严格凸二次式（$R\succ0$），求导置零：

$$2Ru+2B^\mathsf{T}Ps=0\ \Longrightarrow\ \boxed{u^*=-R^{-1}B^\mathsf{T}Ps\equiv-Ks}$$

代回并利用 $s^\mathsf{T}(A^\mathsf{T}P+PA)s=2s^\mathsf{T}PAs$，因对任意 $s$ 成立，得**代数 Riccati 方程**：

$$\boxed{A^\mathsf{T}P+PA-PBR^{-1}B^\mathsf{T}P+Q=0}$$

### 4.3 为什么稳定性是"免费"的

设 $P\succ0$ 是 ARE 的解，$K=R^{-1}B^\mathsf{T}P$，令 $A_{cl}=A-BK$。把 ARE 改写：

$$A_{cl}^\mathsf{T}P+PA_{cl}=(A-BK)^\mathsf{T}P+P(A-BK)=-Q-K^\mathsf{T}RK\preceq0$$

这正是 Lyapunov 方程，取 $V=s^\mathsf{T}Ps>0$ 得 $\dot V=-s^\mathsf{T}(Q+K^\mathsf{T}RK)s\le0$。
配合 $(A,B)$ 可稳、$Q\succeq0$ 的可检测性条件，可得 $A_{cl}$ 严格稳定。

**这一点是 LQR 与 PID 最本质的区别**：只要 $Q\succeq0,R\succ0$，你怎么调都是稳定的；
而 PID 的稳定性必须自己逐一验证。

### 4.4 Q、R 怎么选：Bryson 定则

$$Q_{ii}=\frac{q_i}{x_{i,\max}^2},\qquad R=\frac{\rho}{u_{\max}^2}$$

$x_{i,\max}$ 是"该状态允许的最大偏差"，$q_i,\rho$ 是无量纲的相对重视程度。
量纲问题交给 $x_{i,\max}$，调参就只剩下"我更在意角度还是位置"这种物理判断。

本平台默认：$x_{\max}=0.5$ m, $v_{\max}=1$ m/s, $\theta_{\max}=10°$, $\omega_{\max}=1$ rad/s, $u_{\max}=10$ N，
$q=(1,\ 0.1,\ 10,\ 0.5)$、$\rho=1$，于是

$$Q=\operatorname{diag}(4.000,\ 0.100,\ 328.281,\ 0.500),\qquad R=[0.01]$$

### 4.5 数值解法（本平台在浏览器里现场求解）

**为什么不用"反向积分 Riccati 微分方程"作主算法**：当 $R$ 很小时 $PBR^{-1}B^\mathsf{T}P$ 项可达 $10^8$ 量级，
微分方程变成刚性方程，固定步长显式积分直接发散（开发时实测到 $\lVert P\rVert\sim10^{74}$）。

**第 1 步：Bass 算法给出保证稳定的初始增益。**
取 $\beta>\max\operatorname{Re}\lambda(A)$（实现里取 $\lVert A\rVert_F+1$），令 $M=A+\beta I$，解 Lyapunov 方程

$$MS+SM^\mathsf{T}=2BB^\mathsf{T}\ \Longrightarrow\ K_0=B^\mathsf{T}S^{-1}$$

**证明其稳定性**：令 $P=S^{-1}$，把上式左右各乘 $P$：$PM+M^\mathsf{T}P=2PBB^\mathsf{T}P$，
即 $PA+A^\mathsf{T}P+2\beta P=2PBB^\mathsf{T}P$，于是

$$(A-BB^\mathsf{T}P)^\mathsf{T}P+P(A-BB^\mathsf{T}P)=2PBB^\mathsf{T}P-2\beta P-2PBB^\mathsf{T}P=-2\beta P\prec0$$

由 Lyapunov 定理 $A-BK_0$ 稳定。$\square$
（$S\succ0$ 由 $(A,B)$ 能控保证：$S=2\int_0^\infty e^{-Mt}BB^\mathsf{T}e^{-M^\mathsf{T}t}dt$ 是能控 Gramian。）

**第 2 步：Kleinman–Newton 迭代**（对 ARE 做牛顿法，二次收敛）：

$$(A-BK_i)^\mathsf{T}P+P(A-BK_i)=-(Q+K_i^\mathsf{T}RK_i),\qquad K_{i+1}=R^{-1}B^\mathsf{T}P$$

每步是一个 Lyapunov 方程。实现上按元素展开成 $n^2\times n^2$（$n=4$ 时仅 $16\times16$）线性方程组直接高斯消元：

$$(A^\mathsf{T}P+PA)_{ij}=\sum_k A_{ki}P_{kj}+\sum_k P_{ik}A_{kj}=-Q_{ij}$$

**默认参数下的求解结果**（`tests/bench.js`；全精度数值供交叉验证用）：


### 4.5b 一个可以手算的精确不变量

$$\boxed{K_x=-\sqrt{q_x/R}}$$

其中 $q_x=Q_{11}$。这个等式**精确成立**，与 $m,L,g$、摩擦、其他权重**全都无关**。
由 Kalman 谱分解恒等式（$R+B^\mathsf{T}(-s I-A^\mathsf{T})^{-1}Q(sI-A)^{-1}B=R\lvert1+K(sI-A)^{-1}B\rvert^2$）
在 $A$ 的零特征值方向取 $s\to0$ 极限即得。

数值验证（自检断言，4 组权重）：

|---|---|---|

| 100 | −10.0000000000 | −10 |

同理，LQI 的积分增益满足 $k_i=-\sqrt{q_I/R}$（默认 $q_I=16,R=0.01\Rightarrow k_i=-40$ 精确命中）。

### 4.6 增益符号的解读

$$K=[-20.0,\ -29.5,\ -216.8,\ -23.6]$$

四个增益**全为负**，即 $u=-Ks=+20x+29.5\dot x+216.8\theta+23.6\dot\theta$。

- $\theta>0$（摆向右倒）⇒ $u>0$（向右推）：正确，把车挪到摆下面。
- $x>0$（车在右边、需要往左回）⇒ $u>0$（**继续向右推**）：这看起来完全违反直觉，
  但正是 §3.3 的"欲进先退"——先向右推让摆杆向左倒，之后车才能被"拉"回左边。
  **这个符号是 RHP 零点在增益上的直接指纹。**

### 4.7 LQR 的天然裕度

单输入 LQR 的回路传函 $L(s)=K(sI-A)^{-1}B$ 满足 Kalman 频域不等式 $\lvert1+L(j\omega)\rvert\ge1$，
由此可证：增益裕度区间必包含 $[\tfrac12,\infty)$，相位裕度 $\ge60°$。

本平台用"把执行器增益乘 $\alpha$，扫描闭环稳定区间"的方式实测：

| 控制器 | 稳定的 α 区间 |
|---|---|
| LQR | $[0.057,\ \infty)$ |
| 串级 PID | $[0.385,\ 212.1]$ |
| 单环 PID | $[0.245,\ 2.95]$（且位置模态本就临界稳定） |

LQR 的实际裕度远好于理论下界，且**上界是无穷**（推力标定偏大永远不会失稳）；PID 的上界是有限的。

### 4.8 静差与增广 LQR（LQI）

给小车加常值扰动 $d$（风、导轨倾斜、电机零漂）。平衡态要求 $\theta=0$ 且合力为零，故 $u_{\text{ctrl}}=-d$；
而 $u_{\text{ctrl}}=-K_x(x-x_{\text{ref}})$，于是

$$\boxed{x_{ss}-x_{\text{ref}}=\frac{d}{K_x}}$$

默认 $K_x=-20$ N/m、$d=1$ N ⇒ 静差 $-0.05$ m。**仿真实测 $-0.05000$ m，与解析式完全一致**（自检断言之一）。

消除办法**不是**手工外挂积分项——注意 $K_x<0$，手写时符号极易搞反（开发时确实写反了，
导致积分项缓慢把系统推向失稳）。正确做法是把积分器并入状态做**增广 LQR**：

$$\dot z=x-x_{\text{ref}},\qquad
A_{\text{aug}}=\begin{bmatrix}0&e_1^\mathsf{T}\\ 0&A\end{bmatrix},\quad
B_{\text{aug}}=\begin{bmatrix}0\\ B\end{bmatrix},\quad
Q_{\text{aug}}=\operatorname{diag}(q_I,\ Q)$$

对增广系统解 ARE，Riccati 方程**自动给出符号正确的 $k_i$**：

```
q_I = 16 (= 4/0.5²)  ⇒  K_aug = [ −40.000, −70.463, −57.163, −253.910, −34.967 ]
闭环极点 = −0.7704 ± 1.1091i,  −1.1844,  −26.3640 ± 11.4365i
风扰 1 N 下的稳态位置误差：1.4e−17 m（普通 LQR：−0.05 m）
```

$q_I=0$ 时解出的 $k_i$ 恰为 0（数值上 $\sim10^{-5}$，物理可忽略），自动退化为普通 LQR。
增广系统可控性要求 $u\to x$ 通道在 $s=0$ 处没有零点——由 §3.2 分子在 $s=0$ 处等于 $-mgl\ne0$ 保证。

**代价**：积分作用不是免费的。方波跟踪工况下 LQI 的控制能量比普通 LQR 高 5 倍以上（54.98 vs 10.10），
因为每次给定跳变都会让积分器重新充放电。**只在真的存在常值扰动时才用它。**

## 5. PID：能做到什么，做不到什么

### 5.1 单环 PID 的结构性失败（两个可证明的结论）

只反馈角度：$u=K_p\theta+K_i\!\int\!\theta+K_d\dot\theta$。把积分器作为第 5 个状态，闭环矩阵为

$$A_{cl}=A+BF,\qquad F=[0,\ 0,\ K_p,\ K_d,\ K_i],\qquad \dot I=\theta$$

**结论一：位置永远只是临界稳定。** 默认增益下的闭环极点：

```
0.0000,  −0.0000,  −0.0967,  −10.9706 ± 4.6450i
```

**两个极点在原点**。原因很直白：$A$ 的第一列全为零（没有任何量依赖 $x$），$B$ 的第一个元素也为零，
而反馈向量 $F$ 的前两项为零 ⇒ $A_{cl}$ 的第一列仍然全为零 ⇒ $\det(A_{cl})=0$，必有零特征值。
物理上：**没有任何机制把小车拉回原点**。频域上：漂移模态在 $u\to\theta$ 通道被零极点对消（§3.2），
角度信号里根本"看不见"位置。

结论：角度渐近稳定，位置只有临界稳定 ⇒ 任何微小扰动都让小车匀速漂走，直到撞限位。
**调任何 $K_p,K_i,K_d$ 都不可能改变。**

实测：$\theta_0=0.1$ rad 起，15 s 后 $\lvert\theta\rvert=3.2\times10^{-4}$ rad（角度稳得很好），但 $x=1.40$ m（已撞限位）。

**结论二（更强，也更容易被忽略）：$b>0$ 时纯 PD 连角度都稳不住。**
把 §3.2 的含摩擦传函 $\Theta/U=ml\,s/\text{den}(s)$ 代入 $u=(K_p+K_i/s+K_d s)\theta$，
约简掉分子分母公共的 $s$ 后得到三次特征方程：

$$D_0s^3+\big[(M+m)c+bJ+mlK_d\big]s^2+\big[mlK_p-(M+m)mgl+bc\big]s+\big(mlK_i-b\,mgl\big)=0$$

三次多项式稳定要求**全部系数同号**（Routh–Hurwitz 必要条件）。常数项为 $mlK_i-b\,mgl$，于是

$$\boxed{K_i>\frac{b\,mgl}{ml}=b\,g}$$

**默认参数下门限是 $K_i>b\,g=0.981$。$K_i=0$（纯 PD）时常数项为负 ⇒ 必有右半平面根 ⇒ 恒不可稳。**

数值验证（自检断言）：

| $b$ | $K_i$ | 闭环 $\max\operatorname{Re}\lambda$ | 结论 |
|---|---|---|---|
| 0.1 | 0 | **+0.03081** | 不稳定 |
| 0.1 | 0.5（$<$ 门限） | **+0.01514** | 不稳定 |
| 0.1 | 1.079（$1.1\times$ 门限） | $+3\times10^{-6}$ | 稳定（仅剩原点极点） |
| 0.1 | 4（默认） | 0 | 稳定（仅剩原点极点） |
| **0** | 0 | 0 | 稳定（仅剩原点极点） |

也就是说：**教科书里"PD 就能稳住倒立摆角度"的说法，只在无摩擦模型下成立。**
一旦小车有粘性摩擦，积分项就不是"可选的精修"，而是**必需品**。
这个结论是在与 Python 参考实现做交叉验证时发现的——两个独立实现都给出同样的门限 $b\,g$。

### 5.2 串级结构

$$\theta_{\text{ref}}=K_{p,o}(x_{\text{ref}}-x)-K_{d,o}\dot x+K_{i,o}\!\int\!(x_{\text{ref}}-x)dt$$
$$u=K_p(\theta-\theta_{\text{ref}})+K_i\!\int\!(\theta-\theta_{\text{ref}})dt+K_d\dot\theta$$

**符号的来历**（两处都容易错）：

- 内环：因为 $\partial\ddot\theta/\partial u<0$，所以 $u$ 必须与 $\theta$ **同号**才能产生纠正力矩。
- 外环：稳态时由 (2) 得 $ml\cos\theta\,\ddot x=mgl\sin\theta$，即 $\ddot x=g\tan\theta$。
  想往右加速就必须**先往右倾**，故外环增益取正。

外环把内环近似为理想的 $\ddot x\approx g\,\theta_{\text{ref}}$，即一个双积分器，增益为 $g$。

### 5.3 解析调参公式

内环（忽略摩擦）：由 $\Theta/U=-g_0/(s^2-p^2)$（$g_0=ml/D_0=4.5455$），闭环特征方程

$$s^2-p^2+g_0(K_p+K_ds)=0\ \Longrightarrow\
\boxed{K_p=\frac{\omega_n^2+p^2}{g_0},\qquad K_d=\frac{2\zeta\omega_n}{g_0}}$$

外环（双积分器 $g/s^2$）：

$$\boxed{K_{p,o}=\frac{\omega_o^2}{g},\qquad K_{d,o}=\frac{2\zeta_o\omega_o}{g}}$$

注意 $K_p$ 必须大于 $p^2/g_0=6.87$ 才可能稳定——这就是"内环带宽必须超过 $p$"的代数表现。

### 5.4 默认参数与筛选过程

取 $\omega_n=12$ rad/s（$>2p/1.07$，即约 $2.1p$）、$\zeta=0.9$、$\omega_o=1.2$ rad/s（$<z/2=2.42$）、$\zeta_o=0.7$：

```
内环 Kp = 38.55,  Ki = 4.0,   Kd = 4.75,  τ_D = 0.02 s
外环 Kp = 0.147,  Ki = 0.05,  Kd = 0.171, θ_ref 限幅 = 0.18 rad
闭环极点 = −0.1038, −0.7283 ± 0.4862i, −1.0366, −3.7277 ± 9.7065i
```

这套参数是在 $4\times2\times3\times4\times2\times3=576$ 组候选（$\omega_n\in\{8,10,12,16\}$、
$\zeta\in\{0.7,0.9\}$、$K_i\in\{0,4,8\}$、$\omega_o\in\{0.8,1.2,1.6,2.0\}$、$\zeta_o\in\{0.7,1.0\}$、
$K_{i,o}\in\{0,0.02,0.05\}$）中按"三种工况的总稳定时间 + 控制能量"筛出来的。
其中激进方案（$\omega_n=16,\omega_o=1.6$）稳定时间只快 0.1 s，但控制能量是 10 倍（6.2 vs 0.6），故不取。

### 5.5 工程细节不是可选项

**(a) 微分必须滤波。**$u$ 中含 $K_d\dot\theta$，$K_d=4.75$；若角度噪声 $\sigma_\theta=0.01$ rad 经差分放大，
执行器会高频抖动直至饱和。实现用一阶低通 $\tau_D\dot d_f=d-d_f$。代价是相位滞后，$\tau_D$ 不能太大。

**(b) 抗积分饱和不能用反计算。** 本平台用**条件积分（clamping）+ 积分限幅**，
而**没有**用反计算（back-calculation）。原因是开发过程中实测到的一个真实故障：

> 反计算的做法是"把积分器拉到刚好让输出等于限幅值"。当比例项本身就远超限幅时
> （例如位置误差达到数米，$K_{p,o}\cdot e_x$ 早已超过 $\theta_{\max}$），
> 反计算会把积分器推到一个巨大的**反向**值；误差回落后比例项缩小，
> 巨大的积分项接管，造成反向飞车。**实测小车飞到 8.9 m。**

改成条件积分后同一工况末态 $x=0.0015$ m。这是"教科书上正确、实现上致命"的典型例子。

**(c) 微分作用于测量而非误差。** Python 参考实现记录了另一个坑：
若内环微分作用于误差 $e=\theta-\theta_{\text{ref}}$，而 $\theta_{\text{ref}}$ 又由外环从 $x$ 算出，
会形成与 $u$ 成正比的代数正反馈（环路增益 > 1），实测 $x$ 跑到 $-112$ m。
本平台内外环的微分项都直接取测量量（$\dot\theta$、$\dot x$），从结构上避免了这个问题。

## 6. 数字实现：把漂亮的设计毁掉的两个旋钮

### 6.1 零阶保持离散化

$$s[k+1]=A_ds[k]+B_du[k],\qquad A_d=e^{AT_s},\quad B_d=\int_0^{T_s}e^{A\tau}d\tau\,B$$

$A$ 奇异（有零特征值），不能用 $A^{-1}(A_d-I)B$。改用**增广矩阵技巧**：

$$\exp\left(\begin{bmatrix}A&B\\0&0\end{bmatrix}T_s\right)=\begin{bmatrix}A_d&B_d\\0&I\end{bmatrix}$$

矩阵指数用缩放-平方 + 泰勒展开实现。验证：与 $10^{-6}$ 步长精细积分线性系统对比，误差 $5.6\times10^{-16}$。

### 6.2 临界采样周期

把控制器积分器用前向欧拉离散，物理部分用精确 ZOH，得到离散闭环矩阵，扫描 $T_s$ 找谱半径穿过 1 的点：

| 控制器 | 最快闭环极点 | $\lvert\lambda\rvert_{\max}$ | $T_{s,\text{crit}}$ | 采样频率 | $T_{s,\text{crit}}\lvert\lambda\rvert_{\max}$ | $p\,T_{s,\text{crit}}$ |
|---|---|---|---|---|---|---|
| 串级 PID | $-3.73\pm9.71i$ | 10.40 | 110.7 ms | 9 Hz | 1.151 | 0.618 |
| LQR | $-26.36\pm11.44i$ | 28.74 | **37.4 ms** | 27 Hz | 1.075 | 0.209 |
| LQR+积分 | $-26.36\pm11.44i$ | 28.74 | 36.6 ms | 27 Hz | 1.053 | 0.209 |
| 单环 PID | — | — | 无意义（闭环本就临界稳定） | — | — | — |

**用非线性仿真独立验证**：$0.8\times T_{s,\text{crit}}$ 稳定、$1.25\times T_{s,\text{crit}}$ 发散（自检断言之一）。

**该盯哪个极点来选采样率？** 很多教材用被控对象的不稳定极点 $p$ 作判据，但实测表明它并不稳定。

| $\lvert\lambda\rvert_{\max}$ | 143.97 | 68.28 | 28.74 | 19.25 | 12.40 | 8.13 |
| $T_{s,\text{crit}}$ (ms) | 13.1 | 20.8 | 37.4 | 61.5 | 158.8 | 140.0 |
| $T_{s,\text{crit}}\lvert\lambda\rvert_{\max}$ | 1.888 | 1.420 | **1.075** | 1.185 | 1.970 | 1.138 |
| $p\,T_{s,\text{crit}}$ | 0.073 | 0.116 | 0.209 | 0.344 | 0.887 | 0.782 |

$p\,T_{s,\text{crit}}$ 跨了一个数量级（0.07→0.89），而 $T_{s,\text{crit}}\lvert\lambda\rvert_{\max}$ 稳定在 **1.05–1.97**。于是得到可用判据：

$$\boxed{T_{s,\text{crit}}\approx\frac{1\ \text{到}\ 2}{\lvert\lambda\rvert_{\max,\text{闭环}}}}\qquad
\text{工程取值 }T_s\le\frac{1}{10\lvert\lambda\rvert_{\max}}\ \text{（留 10\textasciitilde20 倍余量）}$$

**采样率应当由你自己设计出来的最快闭环极点决定，而不是被控对象的不稳定极点。**

**由此看清一个反直觉现象**：LQR 对采样周期比 PID 更敏感（37 ms vs 111 ms），但这**不是 LQR 的缺陷**——
两者的 $T_{s,\text{crit}}\lvert\lambda\rvert_{\max}$ 几乎相同（1.075 vs 1.151），
差别完全来自"LQR 的最快闭环极点快了 2.8 倍"，而那是我们自己在 $Q,R$ 里要求的。
想要宽松的采样率，把 $\rho$ 调大即可（$\rho=30$ 时 $T_{s,\text{crit}}$ 升到 159 ms），代价是响应变慢。
课堂结论：**"更优的连续设计"必然对应"更苛刻的数字实现要求"，这是同一枚硬币的两面。**

> **数值实现细节**：判定离散谱半径时不能直接用"特征多项式 + 求根"。
> 小 $T_s$ 时全部离散特征值都聚在 $z=1$ 附近，而多项式求根对聚簇根是病态的，
> 算出来的模长会虚假地略大于 1，导致 $T_{s,\text{crit}}$ 被误判（开发时确实出现了"连续域闭环本身不稳定"的错误报告）。
> 改用 Gelfand 公式 $\rho(M)=\lim_k\lVert M^k\rVert^{1/k}$，以反复平方（$k=2^{16}$）+ 归一化防溢出实现，对聚簇谱稳健。

### 6.3 计算延迟

延迟 $n$ 拍等价于附加 $e^{-nT_ss}$ 的相位滞后。经验判据：总延迟应满足 $\tau_{\text{total}}\cdot\omega_c\ll1$。
本平台把延迟做成 FIFO 队列（`delayBuf`），可以直观看到 2~3 拍延迟就足以让 LQR 从"漂亮"变成"抖动"。

## 7. 摆起：能量法（非线性控制）

### 7.1 为什么线性方法必然失效

LQR/PID 都基于 $\theta=0$ 处的线性化。下垂位置 $\theta=\pi$ 离平衡点 180°，
$\sin\theta$ 的一阶近似完全失效（连符号都反了）。而且从能量看：直立比下垂高出 $2mgl=1.18$ J，
**必须先把能量注入系统**，这不是"稳定性"问题而是"可达性"问题。

### 7.2 能量泵浦律的推导

取摆杆能量（以转轴为参考、忽略小车动能）$E=\tfrac12J\dot\theta^2+mgl\cos\theta$，目标 $E_d=mgl$。
由 (2) 得 $J\ddot\theta=mgl\sin\theta-c\dot\theta-ml\cos\theta\,a$（$a=\ddot x$ 为小车加速度），于是

$$\dot E=J\dot\theta\ddot\theta-mgl\sin\theta\,\dot\theta
=\dot\theta\big(mgl\sin\theta-c\dot\theta-ml\cos\theta\,a\big)-mgl\sin\theta\,\dot\theta$$

$$\boxed{\dot E=-c\dot\theta^2-ml\,a\,\dot\theta\cos\theta}$$

要让 $E$ 上升，只需 $a\,\dot\theta\cos\theta<0$。取 $a=-k\dot\theta\cos\theta$（$k>0$）得

$$\dot E=mlk(\dot\theta\cos\theta)^2-c\dot\theta^2\ >0\quad(\text{只要 }k\text{ 足够大})$$

再令 $k=k_E(E_d-E)$，即得本平台使用的泵浦律：

$$\boxed{a=k_E\,(E-E_d)\,\dot\theta\cos\theta}$$

它自带"能量过多时反向抽能"的性质。取 $V=\tfrac12(E-E_d)^2$ 作 Lyapunov 函数，
则 $\dot V=(E-E_d)\dot E=-mlk_E(E-E_d)^2(\dot\theta\cos\theta)^2-c(E-E_d)\dot\theta^2$，
在 $\dot\theta\cos\theta\ne0$ 时严格负定 ⇒ $E\to E_d$。

**所需驱动力由完整非线性模型精确反解**（不是近似）：由 (1)(2) 消去 $\ddot\theta$，

$$u=a\Big[(M+m)-\frac{(ml\cos\theta)^2}{J}\Big]+\frac{ml\cos\theta}{J}\big(mgl\sin\theta-c\dot\theta\big)-ml\sin\theta\,\dot\theta^2+b\dot x$$

代码见 `Controllers.forceForCartAccel()`。

### 7.3 两个必须靠实测标定的细节

**(a) 摩擦让摆"差一点"过不了顶。** 泵浦到稳态时 $\dot E=0$ 意味着能量注入与摩擦损耗平衡，
实测能量差 $E-E_d\approx-0.037$ J，对应停摆角

$$\cos\theta_{\max}=\frac{E}{mgl}=1+\frac{\Delta E}{mgl}=0.937\ \Rightarrow\ \theta_{\max}=0.355\ \text{rad}$$

——刚好卡在 0.30 rad 的捕获窗之外，反复摆动几十秒都进不去。
解决：把泵浦目标设为 $E_d(1+\varepsilon)$，$\varepsilon=4\%$。

**(b) 真正限制捕获的是小车速度，不是摆角。** 本平台扫描了 LQR 在 $\pm10$ N 饱和下的真实吸引域：

| 条件 | 结果 |
|---|---|
| 小车静止居中，$\theta_0$ 从 0.2 到 0.6 rad | **全部捕获成功** |
| 小车静止居中，$\theta_0=0.7$ rad | 失败 |
| $\theta_0=0.35$ rad，$\dot\theta_0$ 从 $-2$ 到 $+2$ rad/s | 全部成功 |
| $\theta_0=0.35,\ x_0=0.3$ m，$\dot x_0=1.0$ m/s | **失败** |
| $\theta_0=0.35,\ x_0=0.6$ m，$\dot x_0=0.5$ m/s | **失败** |

原因很清楚：$K_v=-29.5$，$\dot x=0.5$ m/s 单独就贡献 $14.8$ N 的控制需求，
把 10 N 的执行器能力全部吃光，摆角项无力可用。

于是切换判据取四条**同时**满足：$\lvert\theta\rvert<0.45$、$\lvert\dot\theta\rvert<2.5$、
$\lvert\dot x\rvert<0.5$、$\lvert x-x_{\text{ref}}\rvert<0.7$，并带滞环（$\lvert\theta\rvert>0.75$ 才退回摆起）。

**(c) 无扰接管。** 捕获瞬间把位置给定设为**当前小车位置**，再以 0.25 m/s 斜坡滑回真正的目标位置。
否则 LQR 会立刻为了"回中"而猛拽小车，把刚接住的摆再甩掉。

**实测结果**（默认 $k_E=4,\ k_x=1.0,\ k_v=1.5$）：$t=2.51$ s 完成摆起并切换，
全程小车最大行程 0.868 m（导轨 $\pm1.2$ m 内），末态 $\lvert\theta\rvert=2\times10^{-11}$ rad。

> Python 参考实现采用了另一种切换判据：直接用 LQR 的代价函数 $V(e)=e^\mathsf{T}Pe<5.0$ 估计吸引域
> （带滞环），9 组初值全部一次切换成功。两种判据都可用，$V(e)<c$ 的形式理论上更优雅
> （$P$ 本来就是 Lyapunov 函数），阈值判据在课堂上更容易解释。

## 9. 一页总结

| | 串级 PID | LQR |
|---|---|---|
| 需要的先验 | 只需知道"谁快谁慢" | 完整状态空间模型 $A,B$ |
| 需要的测量 | $\theta,x$（速度可差分） | 四个状态全部（实机需观测器/Kalman） |
| 稳定性 | 自己保证，逐一验证裕度 | $Q\succeq0,R\succ0$ 即数学保证 |
| 调参对象 | 6 个增益，交互耦合 | 5 个权重，物理意义单调 |
| 多目标权衡 | 靠串级结构人为分离 | 写进代价函数一次求解 |
| 鲁棒裕度 | 有限区间 $[0.385,\ 212]$ | 先天含 $[\tfrac12,\infty)$，实测 $[0.057,\infty)$ |
| 采样敏感性 | $T_{s,\text{crit}}=111$ ms | $T_{s,\text{crit}}=37$ ms（更敏感！） |
| 控制能量 | 更省 | 更费（换取速度） |
| 扩展性 | 加自由度要重搭结构 | 加状态只是把矩阵变大（LQI→LQG→MPC 同一路线） |
| 大范围机动 | 不适用 | 不适用（需能量法等非线性方法） |

**教学结论**：PID 是"局部经验的胜利"，LQR 是"模型知识的胜利"。
倒立摆之所以是经典教具，正因为它在一个学生能亲手玩的系统里同时暴露了：

- 单环 PID 的**结构性**失败（不是调参能救的）；
- 右半平面零点造成的**时标分离**必然性；
- LQR 对模型与全状态的**依赖**，以及"最优"只是相对于你自己选的 $Q,R$；
- 更优的连续设计**不等于**更优的数字实现（$T_{s,\text{crit}}$ 反而更小）；
- 线性方法在大范围机动上的**彻底失效**，以及能量法这类非线性思路的分工。
