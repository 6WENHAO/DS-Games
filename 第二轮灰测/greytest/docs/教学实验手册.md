## 使用前须知

**默认参数**：`M=0.5 kg, m=0.2 kg, L=0.6 m（均匀细杆）, g=9.81, b=0.1, c=0.005, u_max=10 N, 导轨 ±1.2 m`

**符号约定**（务必先讲清楚，否则后面全是符号错误）：
- `θ` 从**竖直向上**量起，`θ=0` 即直立；`θ>0` 表示摆杆向 **+x（右）** 倾倒。
- `u>0` 表示向右推小车。
- 关键事实：`∂θ̈/∂u < 0`，**向右推小车，摆杆向左转**。

**界面速览**：
- 顶栏：7 种控制模式 / 运行暂停 / 单步 / 复位 / 给摆一击 / 速度倍率
- 左侧：动画舞台 + 实时读数 + 四张曲线图（θ、x、u、第四张可切相图/极点图/能量）
- 右侧：控制器 / 模型 / 传感与扰动 / 分析 / 理论 / 实验 六个面板
- 快捷键：`空格` 运行暂停、`R` 复位、`K` 冲击、`← →` 用手推小车（±4 N）

**动画上能看到的物理证据**：力箭头长度 ∝ |u|（饱和时变红闪烁）、倾角圆弧、
紫色虚线 = 外环下发的倾角给定 `θ_ref`（只有串级 PID 有）、摆尖拖尾、导轨刻度与限位块、风力箭头。

**建议课时安排**

| 场景 | 建议 |
|---|---|
| 一次 45 min 演示课 | 实验 1 → 2 → 5 → 10（认识对手 → PID 天花板 → 同台对比 → 摆起，观赏性最强） |
| 一次 2 h 实验课 | 实验 1–6，重点做 3 和 4（带宽限制与权重直觉） |
| 完整专题（4–6 h） | 全部 10 个实验，实验 7–9 作为"从仿真走向实机"的桥梁 |
| 课后作业 | 每个实验末尾的"思考题"，其中带 ★ 的需要动笔推导 |

## 实验 1：认识对手 —— 开环有多快倒

**目标**：建立"倒立摆有多难"的定量直觉，理解不稳定极点 `p` 的物理含义。

**理论准备**（§2.3–2.4）：无摩擦时 `p = √(mgl(M+m)/D₀)`，误差按 `e^{pt}` 增长，倍增时间 `T₂ = ln2/p`。

**步骤**
1. 载入实验 1（模式：无控制，`θ₀ = 0.12 rad`）。
2. 打开"分析"面板，记下 `p` 与 `ln2/p`。
3. 观察 θ 曲线：从 0.12 rad 涨到 0.24 rad 用了多久？用"单步"按钮精确读数。
4. 把"重力 g"调到 1.62（月球），重复步骤 2–3。
5. 把摆长 L 从 0.6 调到 0.2 与 1.6，观察 `p` 的变化。

**预期结果**

| 条件 | p (rad/s) | ln2/p (s) |
|---|---|---|
| 默认 | 5.587 | 0.124 |
| g = 1.62（月球） | 2.271 | 0.305 |
| L = 0.2 m | 9.677 | 0.072 |
| L = 1.6 m | 3.421 | 0.203 |

实测的倍增时间在小角度阶段应与 `ln2/p` 吻合；角度大了以后 `sinθ < θ`，非线性使实际倒得比线性预测**稍慢**。

**思考题**
1. 为什么摆越长越容易控制？请从 `p ∝ √(g/L)` 解释杂技演员为什么用长竿。
2. ★ 若采样周期取 `Ts = 0.1 s`，在一个采样间隔内误差会增长到原来的几倍？这说明了什么？
3. 观察 θ 超过 90° 之后的运动，能量守恒吗？（提示：`b=0.1, c=0.005`，把它们置零再看）

## 实验 2：单环 PID 的天花板

**目标**：亲眼看到"一个执行器管不了两个自由度"，并理解这是**结构性**缺陷而非调参问题。

**理论准备**（§5.1）：单环 PID 的闭环矩阵第一列恒为零 ⇒ `det(A_cl) = 0` ⇒ 必有零特征值。

**步骤**
1. 载入实验 2（模式：单环 PID，`θ₀ = 0.1 rad`）。
2. 观察：θ 很快收敛到 0 附近（角度控制得很好），但小车**持续向一个方向漂移**。
3. 打开"分析"面板，找到闭环极点列表 —— 应该看到**两个位于原点的极点**。
4. 尝试"抢救"：把内环 `Kp`（切到"直接给增益"模式）在 10–200 之间随便调，`Ki`、`Kd` 也随便调。
5. 记录：有没有任何一组参数能让小车停下来？
6. **进阶（很反教科书的一步）**：把内环 `Ki` 调到 **0**（纯 PD）。观察角度是否还稳得住？
   再把 `Ki` 调到 0.5、1.0、2.0，找出角度重新稳住的门限。
7. 把"小车摩擦 b"调到 0，重复步骤 6。

**预期结果**
```
闭环极点：0.0000,  -0.0000,  -0.0967,  -10.9706 ± 4.6450i
15 s 后：|θ| ≈ 3.2e-4 rad（角度极好）    x ≈ 1.40 m（已撞限位）
```
无论怎么调参，永远有两个极点在原点。小车最终必然撞限位（界面会打出"控制失败"横幅）。

步骤 6–7 会得到一个**教科书上通常没写**的结论（§5.1 有完整证明）：

| b | Ki | 闭环 max Re | 角度 |
|---|---|---|---|
| 0.1 | 0（纯 PD） | **+0.0308** | **稳不住** |
| 0.1 | 0.5 | +0.0151 | 稳不住 |
| 0.1 | 1.079 | +3e−6 | 刚好稳住 |
| 0.1 | 4（默认） | 0 | 稳住 |
| **0** | 0（纯 PD） | 0 | 稳住 |

门限恰好是 **`Ki > b·g = 0.981`**。原因：`b≠0` 使 `u→θ` 出现原点零点，
约简后的三次特征方程常数项为 `mlKi − b·mgl`，必须为正（Routh–Hurwitz）。
**"PD 就能稳住倒立摆角度"只在无摩擦模型下成立**——有粘性摩擦时，积分项是必需品。

**思考题**
1. 为什么角度环"看不见"小车位置？（提示：写出 `A_cl` 的第一列；再从 `u→θ` 的 DC 增益 = 0 想一遍）
2. ★ 证明：只要反馈量里不含 `x`，闭环矩阵必定奇异。
3. ★ 由三次特征方程推出门限 `Ki > b·g`，并解释为什么门限与摆的质量、长度都无关。
4. 如果给小车加一个很强的摩擦 `b = 2`，小车会不会停下来？停在哪里？这算"解决问题"吗？
   （注意：此时 `Ki` 门限升到 19.6！）

## 实验 3：串级 PID —— 为什么外环必须慢

**目标**：体验右半平面零点造成的带宽上限，理解"欲进先退"。

**理论准备**（§3.2–3.4）：`u→x` 通道有 RHP 零点 `z = 4.849 rad/s`（含摩擦精确值），
经验判据 `ω_o ≲ z/2 = 2.42 rad/s`；而内环需 `ω_n ≳ 2p = 11.2 rad/s`。

**步骤**
1. 载入实验 3（模式：串级 PID，方波给定 ±0.3 m，周期 10 s）。
2. **先看"欲进先退"**：给定跳到 +0.3 m 的瞬间，仔细观察 x 曲线的最初 0.2 s ——
   小车先往**反方向**走一小段。同时看紫色虚线 `θ_ref`：外环先命令摆杆往目标方向倾倒。
3. 逐步把"外环带宽 ω_o"从 1.2 调到 2.0、2.5、3.0、4.0 rad/s，每次观察：
   反向段是否变大？位置响应是否开始振荡？什么时候彻底失稳？
4. 反过来把 ω_o 调到 0.4：位置响应变得多慢？
5. 把"内环带宽 ω_n"从 12 降到 8、6、5 rad/s（`p = 5.59`），观察什么时候连角度都稳不住。

**预期结果**
- `ω_o = 1.2`：位置响应平稳，反向段约 2 cm。
- `ω_o ≳ 2.5`（接近 `z/2`）：反向段显著增大、出现明显振荡。
- `ω_o ≳ 3.5–4`：失稳（撞限位或摆倒）。
- `ω_n ≲ p = 5.59`：内环从原理上就压不住重力（回顾 §5.3：`Kp > p²/g₀ = 6.87` 是硬下界）。

**思考题**
1. 为什么"想往右走必须先往左推"？请用摆杆受力/力矩解释一遍，再用 RHP 零点解释一遍。
2. ★ 由 §5.3 的公式验证：`ω_n = 12, ζ = 0.9` 时 `Kp = 38.55, Kd = 4.75`。
3. 内环带宽下限 `2p` 与外环上限 `z/2` 相差 4.6 倍。若换一个摆使 `m/(M+m)` 接近 1，这个比值会变成多少？（§3.4）

## 实验 4：LQR 的权重直觉

**目标**：把 `Q/R` 权重、闭环极点位置、控制能量三者建立联系。

**理论准备**（§4.4–4.5）：Bryson 定则 `Qᵢᵢ = qᵢ/xᵢ,max²`、`R = ρ/u_max²`。

**步骤**
1. 载入实验 4（模式：LQR，第四张图已切到"s 平面极点"）。
2. 观察默认极点：两个快极点（扶摆）+ 两个慢极点（归位）。记下数值。
3. **只调 ρ**（控制代价）：0.01 → 1 → 10 → 100 → 300。每次记录：
   - 闭环极点往哪个方向移动？
   - 读数条里的 `∫u²dt` 如何变化？
   - 摆的收敛快慢如何变化？
4. **只调 q_θ**（角度权重）：0.1 → 10 → 300。观察极点与 `max|θ|`。
5. **只调 q_x**（位置权重）：0.01 → 1 → 100。观察小车回中速度与角度牺牲。
6. 试试预设按钮"激进""省力""只顾角度""位置优先"，各自观察 5 s 并记录三项指标。
7. 观察"ARE 残差"始终在 1e−13 量级 —— 每次拖动滑块都在浏览器里**重解了一次 Riccati 方程**。

**预期结果**

| 权重变化 | 极点 | ∫u²dt | 现象 |
|---|---|---|---|
| ρ ↑（控制变贵） | 向虚轴收缩 | 下降 | 变慢、变温柔 |
| ρ ↓（控制便宜） | 向左远离 | 上升 | 变快、易饱和 |
| q_θ ↑ | 快极点更快 | 上升 | 角度偏差小、小车动作大 |
| q_x ↑ | 慢极点更快 | 上升 | 回中快、角度偏差大 |

默认值参考：`K = [−20.00, −29.53, −216.77, −23.64]`，极点 `−0.755±0.714i, −26.36±11.44i`。

**思考题**
1. 为什么 `K` 的四个分量**全是负数**？特别是 `K_x < 0` 意味着"车在右边就继续往右推"，这合理吗？（§4.6）
2. ★ 当 `ρ → 0`，理论上极点会怎样？为什么实机上不能这么干？（提示：饱和 + 噪声 + 采样）
3. LQR 的"最优"是相对于什么而言的？换一套 `Q/R` 后原来的解还最优吗？

## 实验 5：PID vs LQR 同台竞技

**目标**：在**完全相同**的扰动、模型、饱和限制下定量比较两种控制器。

**步骤**
1. 载入实验 5（对比模式：上轨道串级 PID、下轨道 LQR，冲击强度 3 rad/s）。
2. 注意：两条轨道共享同一时间轴、同一扰动、**同一份传感器噪声实现**，比较是公平的。
3. 按 `K` 给两个摆同时一击。观察并记录读数条中每一路的 `max|θ|`、`∫u²dt`、`代价 J`、`饱和率`。
4. 打开方波给定（传感与扰动面板 → 位置给定 → 方波，幅值 0.3 m），比较跟踪能力。
5. 第四张图切到"s 平面极点"，同时看到两者的闭环极点分布。
6. 把冲击强度加大到 6、8 rad/s，找出**谁先失败**。

**预期结果**（默认参数，`node tests/bench.js` 可复现）

| 工况 | 指标 | 串级 PID | LQR |
|---|---|---|---|
| 初始倾角 0.2 rad | 稳定时间 / ∫u²dt / J | 5.6 s / 4.01 / 2.4 | **3.3 s** / 8.77 / **1.4** |
| 位置阶跃 0.4 m | 稳定时间 / max\|θ\| | 7.8 s / 5.25° | **3.9 s** / **2.10°** |
| 角速度冲击 2 rad/s | 稳定时间 / max\|θ\| | 7.4 s / 11.57° | **4.0 s** / **7.15°** |
| 方波跟踪 ±0.3 m | max\|θ\| / ∫u²dt | 7.85° / **7.93** | **3.19°** / 10.10 |

**LQR 全面更快、角度偏差更小，但控制能量普遍高约 1–2 倍。** 这不是"LQR 更好"，
而是"我们选的 `Q/R` 把速度看得比省电更重"。

**思考题**
1. 若把 ρ 调大到让 LQR 的 `∫u²dt` 与 PID 相当，此时谁更快？（动手试）
2. LQR 需要四个状态全部可测，PID 只要 θ 和 x。若真机上没有测速传感器，两者的实现代价差多少？
3. ★ 用 §8 的表说明："最优控制"中的"最优"是一个**带前提**的说法。

## 实验 6：常值风扰与积分作用

**目标**：理解静差的解析来源 `x_ss = d/K_x`，以及增广 LQR（LQI）如何消除它。

**理论准备**（§4.8）：平衡态要求 `u_ctrl = −d`，而 `u_ctrl = −K_x·e_x`，故 `e_x = d/K_x`。

**步骤**
1. 载入实验 6（模式：LQR，风扰 2 N）。
2. 等系统稳定（约 20 s），读出稳态位置 x。
3. 在"分析"面板读出 `K_x`，计算 `d/K_x` 并与实测对比。
4. 把风扰改成 1 N、3 N、−2 N，验证静差与 d 成正比。
5. 切到"LQR + 积分"模式，把"积分权重 q_I"从 0 慢慢调到 4、16。观察静差如何被消除，
   以及积分器状态 z（动画左上角显示）如何积累到一个非零常值。
6. **观察代价**：把给定改成方波，比较 LQR 与 LQR+积分 的 `∫u²dt`。

**预期结果**
```
d = 2 N, K_x = −20 N/m  ⇒  解析静差 = −0.100 m，实测 ≈ −0.100 m
d = 1 N                 ⇒  解析 −0.050 m，实测 −0.05000 m（自检脚本断言吻合）
q_I = 16 时：静差 → 1.4e−17 m，积分增益 kᵢ = −40.0
方波跟踪：LQR ∫u²dt = 10.10，LQR+积分 = 54.98（5.4 倍！）
```

**思考题**
1. 为什么 `q_I = 0` 时算出的 `kᵢ` 恰好是 0？（提示：代价函数里 z 没有权重）
2. ★ 为什么手工外挂积分项容易搞错符号？写出 `u = −Ks − kᵢz` 与 `u = −Ks + kᵢz` 两种情形，判断哪个稳定。
3. 积分作用在什么情况下**不该**加？结合方波跟踪的能量数据回答。

## 实验 7：采样周期与延迟的杀伤力

**目标**：找到临界采样周期并验证解析预测；理解"数字实现会毁掉漂亮的连续设计"。

**理论准备**（§6.1–6.3）：ZOH 离散化 + 谱半径判据。

**步骤**
1. 载入实验 7（模式：LQR，`Ts = 10 ms`，`θ₀ = 0.05 rad`）。
2. 在"分析"面板读出 `Ts_crit`（应为 37.4 ms，即 27 Hz）与 `p·Ts_crit`。
3. 把 `Ts` 调到 30 ms（`0.8×Ts_crit`）：仍稳定，但已能看到明显的"台阶感"与抖动。
4. 调到 47 ms（`1.25×Ts_crit`）：**发散**。界面会显示"已超过临界值，必然失稳"。
5. 把 `Ts` 调回 10 ms，改为增加"控制延迟"：1、2、3、5 拍。观察 2–3 拍就足以让系统抖动/失稳。
6. **对比实验**：切到串级 PID 模式，重新读 `Ts_crit`。
7. **找出真正的判据**：回到 LQR，把控制代价 `ρ` 依次设为 0.05、1、30，
   每次从极点图读出最快闭环极点的模长 `|λ|max`、从分析面板读出 `Ts_crit`，填下表并算两个乘积。

**预期结果**

| 控制器 | 最快闭环极点 | \|λ\|max | Ts_crit | Ts_crit·\|λ\|max | p·Ts_crit |
|---|---|---|---|---|---|
| 串级 PID | −3.73±9.71i | 10.40 | 110.7 ms | 1.151 | 0.618 |
| LQR (ρ=1) | −26.36±11.44i | 28.74 | **37.4 ms** | 1.075 | 0.209 |
| LQR (ρ=0.05) | — | 143.97 | 13.1 ms | 1.888 | 0.073 |
| LQR (ρ=30) | — | 12.40 | 158.8 ms | 1.970 | 0.887 |

**关键发现**：`p·Ts_crit` 跨了 12 倍（0.073→0.887），完全不能当判据；
而 `Ts_crit·|λ|max` 稳定在 **1.05–1.97**。所以

> **采样率要看你自己设计出来的最快闭环极点，而不是被控对象的不稳定极点。**
> 工程取值：`Ts ≤ 1/(10·|λ|max)`。

**反直觉的结论也随之澄清**：LQR 比 PID 对采样更敏感（37 ms vs 111 ms），
但两者的 `Ts_crit·|λ|max` 几乎相同（1.075 vs 1.151）——差别完全来自"LQR 的最快极点快了 2.8 倍"，
而那是我们自己在 `Q/R` 里要求的，**不是 LQR 的缺陷**。想要宽松的采样率就把 ρ 调大，代价是响应变慢。

**思考题**
1. 为什么"更优的连续设计"反而对采样更挑剔？这对选 MCU 主频有什么现实含义？
2. ★ 若要给系统留 10 倍余量，实机采样频率至少要多少 Hz？换成 `L = 0.2 m` 的短摆呢？
3. 延迟 2 拍与把 `Ts` 增大 2 倍，对稳定性的影响一样吗？为什么？
4. ★ 从"ZOH 相当于附加约 `Ts/2` 的纯延迟"出发，解释判据 `Ts·|λ|max ≈ 1` 的量级来源。

## 实验 8：噪声与微分项

**目标**：看清"微分放大噪声"的实际后果，以及滤波带来的相位代价。

**步骤**
1. 载入实验 8（模式：串级 PID，PID 已切到"直接给增益"模式，角度噪声 σ_θ = 0.01 rad）。
2. 观察 u 曲线：高频抖动，读数条里的"饱和率"上升。
3. 把内环 `Kd` 从 4.75 降到 2、1，观察抖动减小但收敛变差。
4. 把 `Kd` 调回，改为增大"内环微分滤波 τ_D"：0.02 → 0.05 → 0.1 s。抖动减小，但相位滞后增加，
   继续增大最终会失稳。
5. 打开"角度量化步长" 0.003 rad（模拟 2000 线编码器），观察极限环式的小幅振荡。
6. 切到 LQR 模式，同样加噪声。LQR 用 `K_ω = −23.6` 乘 `θ̇`，本质上也是微分作用 —— 它也会抖。

**预期结果**
- σ_θ = 0.01 rad、Kd = 4.75 时，噪声在 u 上引起约 `Kd·σ_θ/τ_D` 量级的抖动。
- τ_D 增大能压住抖动，但 τ_D ≳ 0.1 s 后相位滞后开始吃掉稳定裕度。
- 量化会产生**持续的极限环**（不会衰减到零），这是实机上"摆一直轻微抖"的常见原因。

**思考题**
1. ★ 为什么噪声经过微分后被放大？从 `d/dt` 的频域特性 `jω` 解释。
2. 若不能换传感器，有哪三种办法减小抖动？各自的代价是什么？
3. 观测器（Kalman 滤波）能解决这个问题吗？它与简单低通滤波的本质区别是什么？

## 实验 9：模型误差下的鲁棒性

**目标**：比较 PID 与 LQR 在"真实对象 ≠ 设计模型"时的表现，并用增益裕度解释结果。

**步骤**
1. 载入实验 9（对比模式，真实摆杆质量 = 设计值的 2.0×、真实摆长 = 1.5×）。
2. 注意"分析"面板出现橙色警告框，列出设计参数与真实参数、以及真实对象的不稳定极点。
3. 观察两个控制器谁的表现更差；按 `K` 加冲击看谁先倒。
4. 逐步加大失配：质量 2.5×、3.0×，摆长 1.8×、2.0×，找出各自的**失效边界**。
5. 在"分析"面板读出两者的增益裕度区间，看它是否能解释边界。
6. 反向失配也要试：质量 0.3×、摆长 0.5×。

**预期结果**
- 增益裕度：LQR `α ∈ [0.057, ∞)`；串级 PID `α ∈ [0.385, 212]`。
- 一般来说 LQR 对"执行器增益变大"完全免疫（上界无穷），而 PID 有有限上界。
- 但注意：质量/长度失配**不等价于**单纯的增益变化（它同时改变 `p`、`z` 与耦合），
  所以增益裕度只能作为**定性**参考。Python 参考实现用质量比例扫描得到的容限是
  LQR `0.40×–2.50×`、串级 PID `0.50×–1.60×`，同样是 LQR 更宽。

**思考题**
1. 为什么增益裕度不能完全预测参数失配下的鲁棒性？还需要什么工具？（提示：结构化不确定性、μ 分析）
2. ★ 摆长增大 1.5× 会让真实 `p` 变成多少？控制器却仍按旧 `p` 设计，后果是什么？
3. 工程上如何减小模型误差的影响？（提示：辨识、自适应、鲁棒设计、加大裕度）

## 实验 10：能量摆起

**目标**：理解基于能量的非线性控制，以及"全局策略 + 局部最优"的分工。

**理论准备**（§7）：`Ė = −cθ̇² − ml·a·θ̇cosθ`，取 `a = k_E(E−E_d)θ̇cosθ` 可保证 `Ė > 0`。

**步骤**
1. 载入实验 10（模式：摆起 + LQR，从 `θ = π` 下垂开始，第四张图已切到"能量"）。
2. 观察能量曲线 `E` 如何**逐周期**逼近目标 `mgl = 0.5886 J`；摆幅越来越大。
3. 记录切换时刻（动画左上角显示"切换于 t = ? s"），默认应为约 2.5 s。
4. 观察切换瞬间：位置给定先停在当前位置，再以斜坡缓慢滑回 0（无扰接管）。
5. **削弱执行器**：把 `u_max` 降到 6 N、4 N、3 N。看它是否还能摆起来、需要几次摆动。
6. **收窄导轨**：把导轨半长降到 0.8 m、0.6 m。默认摆起需要 0.868 m 行程，会撞限位吗？
7. 把"摆杆质量"或"摆长"改掉，看能量法是否仍然有效（它只依赖能量关系，不依赖线性化）。

**预期结果**
```
默认：t = 2.51 s 切换成功，全程最大行程 0.868 m，末态 |θ| ≈ 2e−11 rad
u_max = 4 N：仍能摆起，但需要更多次摆动
导轨 ±0.8 m：可能撞限位 —— 摆起是"用空间换能量"
```

**思考题**
1. 为什么在 `θ = π` 且 `θ̇ = 0` 时泵浦项恒为零？代码里怎么解决的？（提示：起步"踢一脚"）
2. ★ 为什么摩擦会让摆"差一点"上不去？由 `cosθ_max = 1 + ΔE/(mgl)` 计算 `ΔE = −0.037 J` 时的停摆角。

4. 能量法能不能一直用到直立点？为什么必须切换到 LQR？

## 附录 B：从仿真走向实机的检查清单

1. **状态从哪来？** LQR 需要 4 个状态。实机通常只有编码器（x、θ），`ẋ`、`θ̇` 需要差分+滤波或卡尔曼滤波。
2. **采样率够不够？** 至少 `3/Ts_crit`。默认参数下 LQR 需要 ≥ 80 Hz，短摆需要更高。
3. **执行器建模对不对？** 真实电机是"电压→转矩→力"，有死区、齿隙、电流限幅，不是理想力源。
4. **限位保护做了吗？** 软件限位 + 硬件限位开关，撞限位必须立即卸力。
5. **传感器分辨率够不够？** 用实验 8 的量化功能先在仿真里试出可接受的最小分辨率。
6. **摩擦辨识了吗？** `b`、`c` 直接影响 `p` 与零点位置，可用自由摆动的衰减曲线辨识。
7. **失效检测。** `|θ| > 阈值` 或 `|x| > 阈值` 时主动卸力，别让它自己乱撞。
