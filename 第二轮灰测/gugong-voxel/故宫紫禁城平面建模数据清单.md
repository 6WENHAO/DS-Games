# 北京故宫（紫禁城）总体平面尺寸数据清单 — 供程序建模

## 0. 检索状态说明（必读）
- web_search **可调用**，但本次仅返回来源 URL 列表，绝大多数结果**不含可提取正文摘要**；
  尝试用 pwsh 直连抓取原文（dpm.org.cn、zh.wikipedia.org）全部失败：`基础连接已经关闭: 接收时发生错误` / curl 空返回 → 本会话**无网页正文读取能力**。
- 因此本清单采用三级标注：
  - 【核】= 本次检索返回的标题/片段中**直接出现**该数字（附域名）
  - 【记】= 凭记忆的建筑史文献常见值（《紫禁城宫殿》于倬云、《故宫辞典》、傅熹年测绘系列），本次**未能读到原文核对**
  - 【推】= 由【核】【记】数据几何推算的自洽估值，**仅供建模占位，需按实测总平面图校正**
- 坐标系：原点 = 南城墙外皮 × 中轴线交点；x 东为正，y 北为正，单位 m。
