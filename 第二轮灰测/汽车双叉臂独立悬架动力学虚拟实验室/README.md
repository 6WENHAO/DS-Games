# 双叉臂独立悬架 · 动力学虚拟实验室

单文件 Web 应用：**`index.html`**（双击即可用浏览器打开，需联网加载 Three.js CDN）。
深色工业风界面，左 70% 为 WebGL 三维工程模型，右 30% 为实时图表与控件。

> 核心不是"看起来会动"，而是**真的按刚体约束解出来**：上下摆臂绕车架铰轴转动、
> 转向节由两个球头定位、横拉杆定长约束解出转向节绕主销的扭转角。
> 外倾角、主销后倾/内倾角、轮距变化、束角变化全部是几何后果，不是插值动画。

## 三、模型与算法

### 硬点（右前轮，单位 m，x 前 / y 上 / z 向车外）

```
下臂铰轴 (0, 0.112, 0.160) 轴向 2.0°     下球头 ( 0.013, 0.128, 0.600)
上臂铰轴 (0, 0.390, 0.255) 轴向 −1.4°    上球头 (−0.013, 0.455, 0.540)
轮心     (0, 0.315, 0.655)  轮胎 R=315   转向节臂 (−0.095, 0.215, 0.595)
齿条球头 (−0.095, 0.174, 0.190)          减震器 (0,0.120,0.430) → (0,0.615,0.215)
```

设计位：**外倾 −0.50° · 后倾 4.55° · 内倾 10.40° · 束角 0.00° · 主销偏移距 +31.5mm ·
侧倾中心高 23mm · 前视瞬心 z=−1177mm · 弹簧长 539.7mm**（接地点正好落在 y=0）。

### 求解链（一个自由度，全解析）

1. 下臂转角 θ<sub>L</sub> → 下球头 B<sub>l</sub>（罗德里格斯绕轴旋转）
2. 上球头在圆上，且 |B<sub>u</sub>−B<sub>l</sub>| = 转向节长 → **圆-球交解析解**
   `A·cosθ + B·sinθ = K` → `θ = atan2(B,A) ± arccos(K/√(A²+B²))`，按连续性选支
3. 主销轴线 u = normalize(B<sub>u</sub>−B<sub>l</sub>)；转向节姿态 = 最短弧对齐(u₀→u) ∘ 绕 u 扭转 δ
4. 横拉杆定长约束 → 同一套圆-球解析解求出 δ（**因此转向、轮跳耦合，天然出现 bump-steer**）
5. 轮跳高度 → θ<sub>L</sub> 用二分反解（工作区间单调，42 次迭代，误差 < 1e-9 mm）

外倾 γ = −asin(n·ŷ)（n 为车轮自转轴）；束角 = atan2(n<sub>x</sub>, n<sub>z</sub>)；
后倾 = atan2(−u<sub>x</sub>, u<sub>y</sub>)；内倾 = atan2(−u<sub>z</sub>, u<sub>y</sub>)；
接地点取轮平面内最低点；前视瞬心为两摆臂轴线延长交点，侧倾中心为瞬心-接地点连线与中轴线交点。

### 动力学

m·ẍ + c·ẋ + k·x = 0，c = 2ζ√(km)。冲击以初速度施加，v₀ 由解析首峰值反算，
保证在任意 m/k/ζ 下首峰恒为 45mm，便于对比不同阻尼的衰减快慢。

## 五、说明

- Three.js 通过 `importmap` 指向 **unpkg**；运行时若失败会自动依次回退
  jsDelivr → npmmirror → cdnjs，四者皆不可达时显示醒目错误页。
- 摆臂铰轴给了 2° / −1.4° 的水平内倾，这是为了让"主销后倾角"随行程产生真实变化
  （纯 X 轴平行铰轴时后倾几乎恒定）；界面按要求标注该读数为**估算值**。
- `轮距变化量` 按双侧计（接地点横移量 ×2）。
