# AURORA · 纯白三角钢琴（3D 精细模型 / 可弹奏）

一个**完全程序化建模**的纯白三角钢琴：所有几何、材质、纹理与音色都由代码生成，
没有任何外部模型或音频资源，**双击 `index.html` 即可离线运行**。

![no-deps](https://img.shields.io/badge/依赖-仅本地_three.js_r160-lightgrey) ![offline](https://img.shields.io/badge/运行-file:%2F%2F%20双击即可-brightgreen)

---

## 一、快速开始

直接双击 **`index.html`**（Chrome / Edge / Firefox 均可）。
第一次点击画面或琴键时才会创建 AudioContext（浏览器策略要求），之后即可发声。

> 无需 Node、无需本地服务器、无需联网。`js/three.min.js` 是随包的 three.js r160。

预览图在 `preview/` 目录（为便于离线核对，这三张是**软件渲染**（SwiftShader）截图，
真机 GPU 渲染的抗锯齿、高光与阴影会更细腻）：

## 二、操作说明

| 操作 | 效果 |
| --- | --- |
| 拖动 | 环绕旋转（带阻尼） |
| 滚轮 / 双指捏合 | 推拉镜头 |
| `Shift`+拖动 / 右键拖动 | 平移 |
| 点击琴键、按住横向滑动 | 弹奏 / 滑奏（glissando） |
| `Z S X D C V G B H N J M , L . ; /` | 下排键盘（默认 C3 起） |
| `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` | 上排键盘（默认 C4 起） |
| `空格` | 延音踏板（制音器整排抬起） |
| `←` `→` | 整体移低 / 移高一个八度 |
| 右侧面板 | 视角预设、琴盖开合、键盘盖、自动旋转、演示曲、音量、混响 |
| 右下三枚按钮 | 弱音 / 选择延音 / 延音踏板（可长按） |

## 三、模型细节（尺寸按真实 7 尺三角琴，单位：米）

* **琴壳**：直脊 + 圆尾 + 弯边的经典"竖琴"轮廓，样条曲线生成后向内偏移出 56 mm 侧板厚度，
  前端做成**开口 U 形环带 + 矮腹梁**——和真琴一样，坐在琴凳上能越过腹梁看到铸铁排与琴弦。
* **88 键**：52 白键 + 36 半音键。白键按真实开槽逻辑生成（每组 3/4 个白键与其间黑键**等分让位**，
  节距 23.5 mm、缝隙 1.3 mm），前端圆角、台阶处倒圆；半音键为**顶面收窄 + 前脸斜切**的锥形楔块。
  每个键绕后端支点转动，落键约 0.047 rad。
* **内部结构**：白化云杉音板（程序化木纹）、长马桥 + 低音马桥、白漆铸铁排（周框 + 4 根支撑梁 + 弦枕板）、
  **227 根琴弦**（低音单根缠弦 / 中音双根 / 高音三根，长度按 2^(-i/17.6) 排布成扇形）、
  88 组调音钉、**88 支可摆动弦槌**、**68 个随按键与踏板抬落的制音器**。
* **可动部件**：两折大琴盖（前折先翻到主盖背上再整体掀起，带动态求解的支撑杆与三处合页）、
  两折键盘盖（前半折到后半上后整体翻转平放于名牌板）、可立起/收平的开槽谱架、
  三条车削琴腿 + 双轮脚轮、踏板架（lyre）与三枚可踩踏板。
* **纯白**：琴体为高光钢琴白漆（clearcoat 清漆层），象牙白键、白铬五金、白毛毡；
  半音键默认同为纯白，仅以哑光与形体区分——面板里可切换成"浅灰"以便看清键位。

## 四、渲染与音色

* 程序化生成的**白色摄影棚环境贴图**（PMREM），一盏带 2048² 软阴影的主光 + 侧光 + 轮廓光，
  ACES Filmic 色调映射，柔和接地阴影，CSS 渐变背景 + 暗角。约 13 万三角面、130 个 draw call。
* 纯 **WebAudio 加法合成**：基频 + 6 个微失谐泛音（各自衰减曲线）+ 击弦瞬态噪声 +
  随音高变化的低通与声场展开，母线经卷积混响（合成脉冲响应）与压缩器输出；
  26 声部上限，延音踏板按下时保留自然衰减。
* 演示曲《致爱丽丝》主题：主旋律 + 左手琶音 + 自动踏板，弹奏时琴键、弦槌、制音器同步动作。

## 五、文件结构

```
钢琴/
├─ index.html          页面与界面结构
├─ _snap.html          单帧快照/调试页（#view=hero|side|top|keys|player|inside|closed&bg=dark|light&debug=1）
├─ css/style.css       纯白毛玻璃 UI
├─ js/three.min.js     three.js r160（随包，离线可用）
├─ js/geom.js          几何/纹理工具（多边形内偏移、挤出、锥形棱柱、程序化纹理）
├─ js/piano.js         钢琴建模（琴壳/键盘/内部结构/琴盖/琴腿/踏板）
├─ js/orbit.js         轻量轨道相机（阻尼、缩放、平移、触摸、自动旋转）
├─ js/audio.js         钢琴音色合成器
├─ js/app.js           场景、灯光、交互、动画、演示曲
├─ preview/            预览截图
└─ verify/             无头自检脚本（可选，需要 Node）
```

调试入口：页面加载后 `window.PianoApp` 暴露 `piano / state / renderer / scene / camera / controls`，
可在控制台直接调姿态、换视角或关阴影。

## 六、自检（可选）

```bash
node verify/headless-test.js       # 建模校验：键位、包围盒、开合姿态、支撑杆长度
node verify/headless-app-test.js   # 集成校验：初始化、点击拾取、键盘、踏板、演示曲、构图
```

两个脚本用 DOM / WebAudio / WebGLRenderer 桩在 Node 中真实跑一遍逻辑（几何与射线是真实的 three.js 运算），
用于在没有浏览器的环境里回归验证。
