# 万世纪元 · Imperium Aeternum

一款融合《十字军之王3》（角色 / 王朝 / 继承 / 密谋）与《欧陆风云4》（地块 / 发展度 / 科技 / 外交 / 战争）的
**公元 0–1600 年全球大战略网页游戏**。

## 快速开始

```bash
cd imperium
node build.mjs        # 一键构建地图与 12 个书签（如需重新生成数据时运行）
node server.mjs       # 启动本地服务器
# 打开 http://localhost:4173
```

> 数据已预生成在 `web/data/mapdata.json`（约 3.8 MB）；`build.mjs` 用于改数据后重建。

## 玩法

- **书签**：12 个时代起点（1 / 200 / 400 / 600 / 800 / 1000 / 1100 / 1200 / 1300 / 1400 / 1500 / 1600），
  每个时代含 **237–432 个政权**（史实大国 + 程序化补齐的部落/城邦/封臣），全图 1757 省 100% 有主。
- **CK3 层**：统治者人物（真名/王朝/生年/特质）、继承法（长子/分割/兄终弟及/选举/任命）、
  婚姻生育、死亡与继位、分割继承导致帝国崩解、僭主内战、宫廷与事件抉择。
- **EU4 层**：发展度（每省有史实兴衰曲线）、税收/人力/军队、行政/外交/军事科技（13 个科技组、
  12 条史实轨道，超前昂贵、落后追赶）、宣战与和谈（割地/赔款/附庸化）、同盟、附庸与朝贡、
  叛乱独立、距离首都的离心力、无主之地拓殖与部落形成、贵族分封与削藩。
- **时间**：按日推进，可暂停 / 1–5 倍速；Ctrl+S 存档到浏览器本地，可读档继续；支持旁观模式。

## 规模

| 项 | 数量 |
|---|---|
| 陆地省份 | **1757**（全球 0.2° 栅格 + 最短陆路距离沃罗诺伊） |
| 大区 region / 地区 area | 139 / 653 |
| 命名海域 | 111（含里海、咸海、五大湖、贝加尔、维多利亚等内陆湖） |
| 跨海海峡/连接 | 101（自动检测 + 孤岛救援） |
| 史实政权（12 书签合计） | 576 条（其中 12 个书签的大国各自成表） |
| 文化 / 宗教 | 237 / 47 |
| 地形 / 商品 / 政体 / 科技组 | 16 / 57 / 19 / 13 |

海岸线由 10 个区域多边形（非洲 / 西亚 / 东亚 / 大洋洲 / 欧洲×3 / 美洲×2 / 补丁）并集而成，
在游戏分辨率（0.2°）下 **242/242 个陆地校验点、47/47 个海面校验点全部命中**。

## 数据与规则说明

- **发展度（dev）**：每省一条 `[[年, 发展度], …]` 史实曲线，如罗马 1 年=28→600 年=6→1600 年=16，
  巴格达 900 年=32→1300 年=8（蒙古屠城）。引擎让世界沿史实轨道漂移，玩家可用事件与建设扰动。
- **宗教/文化**：每省有更替时间线（如埃及 kemetic→chalcedonian→miaphysite→sunni）。
- **科技史实轨道**（`TECH_CURVES`，锚点 0/400/800/1000/1200/1400/1600）：西欧 3→22、
  东亚 8→20、伊斯兰 4→18、印度 6→16、草原 4→11、非洲 2→8、中美洲 2→7、北美 1→4、大洋洲 0→3。
- **政权数量守恒**：继承分裂、叛乱、拓殖、分封与削藩共同作用，长期模拟（1600 年跨度）结束时政权数量
  保持在 200+，最大帝国约占总地图的 15%（符合史实的帝国规模上限）。

## 已知取舍

- 本机无网络、无地图库，海岸线与省份均为手工/程序化生成，精度约 0.2°（~22 km），小岛有简化；
  航线/海峡由算法自动推断。
- 时间轴自公元 1 年起（“公元 0 年”在历法上不存在，1 年即纪元之初）。
- 战争为抽象结算（部队质量、围城、占领、和谈），无逐格走位与海运单位。
