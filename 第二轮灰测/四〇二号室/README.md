# アパート四〇二号室 — APARTMENT 402

第一人称日式心理恐怖探索游戏原型（网页版）。复古 PS1/PS2 低多边形美学，
Three.js + WebGL 实时渲染，**全部素材程序化生成，无外部资源依赖，可完全离线运行**。

## 快速开始

方式一（最简单）：用浏览器直接打开 `index.html`（已内置本地 three.js，双击即可）。

方式二：本地静态服务器（推荐，避免部分浏览器 file:// 限制）：

```bash
cd <本目录>
python3 -m http.server 8080
# 打开 http://localhost:8080
```

> 若删除了 `vendor/three.min.js`，页面会自动回退到 CDN（需联网）；
> 也可用 `?cdn=1` 强制走 CDN。

## 游戏内容

- **结构**：狭长昏暗的公寓走廊（沿 -Z 延伸），两侧是可进入的和室、浴室、储物间、厨房；
  储物间纵深 9.5m，远超建筑外观应有的体积 —— 异常空间。
- **循环叙事（P.T. 式）**：推开尽头黑门会"回到起点"，每圈世界进一步腐化——
  灯一盏盏熄灭、门自动虚掩、神龛遗照变黑、椅子自己转向、皮球移动；
  第 4 圈出现"它"，第 6 圈和室里跪坐着"一家人"。
- **怪物**：身高约 2.1m、头小臂长的人形，以低帧率姿势切换僵硬移动；
  仅在你移开视线时行动（哭泣天使规则），被手电筒直视会冻结；
  抓住你会触发白噪惊吓并回退一圈（无血腥）。
- **氛围系统**：冷蓝绿环境光、闪烁荧光灯、手电筒动态阴影、指数雾、漂浮尘埃、
  SSAO 环境遮蔽、Bloom 泛光、VHS 噪点/扫描线/色差/5bit Bayer 抖动后处理；
  程序化音频（环境嗡鸣、脚步声、门、耳语、心跳、电视雪花、电话、惊悚音刺）。
- **交互**：拾取电池、阅读双语（日/中）纸条与旧报纸、开关走廊灯、开电视（雪花+人声）、
  地藏像、全家福（脸被刮掉）、冰箱里的人形玩具……

## 技术实现（自研，无游戏引擎）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 外壳：标题画面 / HUD / 笔记 / 暂停菜单 / 惊吓脸 / 设置面板 / three.js 双源加载器 |
| `src/core.js` | 命名空间、种子随机、设置持久化、全局错误兜底 UI |
| `src/textures.js` | 16+ 种 Canvas2D 程序化低分辨率贴图（墙纸/霉斑/榻榻米/锈蚀/报纸/御札…），magFilter=Nearest 复古像素感 |
| `src/ps1fx.js` | ① 材质补丁：onBeforeCompile 注入顶点像素吸附（wobble）+ 仿射 UV（vUvAff/vHZw 破坏透视校正，只替换 map_fragment，编译失败自动全局降级）② 后处理链：低分辨率 RT → 深度编码 pass → SSAO → Bloom（阈值+分离高斯）→ VHS 合成（GLSL 全 ES1 兼容写法） |
| `src/world.js` | 走廊/房间/门/灯光/道具/尘埃/碰撞体；循环腐化系统 applyLoop |
| `src/entity.js` | 低模异常人形（比例失调、空洞眼眶）+ 僵硬姿势动画 + 视线冻结 AI；跪坐人偶 |
| `src/audio.js` | WebAudio 程序化音景（噪声/振荡器合成 + Convolver 走廊混响） |
| `src/game.js` | 玩家控制器（碰撞滑动、头晃、体力/电池）、交互射线、随机恐怖事件调度、主循环 |

## 排障参数（URL 加 ?xx=1）

| 参数 | 作用 |
| --- | --- |
| `?safe=1` | 关闭全部后处理与着色器补丁（最保守，排查黑屏首选） |
| `?raw=1` | 只绕过后处理链，保留 PS1 材质补丁 |
| `?cdn=1` | 强制从 CDN 加载 three.js |
| `?autostart=1` | 跳过标题画面（测试用） |

游戏内按 **F3** 关顶点抖动、**F4** 关仿射 UV，设置自动存 localStorage。
