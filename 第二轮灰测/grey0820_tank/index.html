M-27 中型坦克模拟器

你是一辆二战中型坦克的全体乘员：驾驶员、炮长、装填手、车长。
车内每一个开关、手柄、脚踏板、方向机、炮闩和待发弹都可以真的操作。

点击屏幕或按任意键进入车内

需要 WebGL · 建议使用桌面浏览器与耳机

操作说明 · CONTROLS

视角 / 乘员位置

右键拖动环视车内（自由视角）
Q锁定鼠标（连续环视，Esc 退出）
1驾驶员席 · 自由视角
2驾驶员潜望镜
3炮长瞄准镜（滚轮变倍）
4车长指挥塔潜望镜
5装填手席
6开盖出舱（车长）
7 / 8车外跟随 / 环绕视角
Y依次切换乘员位置

启动程序（照检查单做）

M蓄电池总开关
F燃油泵
I点火 / 磁电机
G（按住）起动机
P驻车制动
1–4 / 0 / 9（Shift+数字）档位 / 空档 / 倒档
[ ]降档 / 升档

驾驶

W油门踏板
S脚制动
A / D左 / 右操纵杆（拉杆制动该侧履带即转向）
K / V车内灯 / 通风机
L / H前照灯 / 舱盖

射击

← →炮塔方向机（T 打开电传动更快）
↑ ↓高低机
B炮闩开 / 闭（开闩会抛壳）
点击待发弹装填该发炮弹（AP 穿甲 / HE 榴弹）
Z一键装填（开闩→取弹→关闩）
空格击发主炮
C / X并列机枪 / 车体机枪
J倒空废弹壳袋
F（车长席）发射烟幕弹
F9灭火器
R / N电台 / 车内通话

提示：炮长瞄准镜里鼠标右键拖动即为瞄准，左键击发。发动机水温超过 128°C 会损坏、超过 145°C 会起火——注意通风与油门。 车内每个部件都有名称提示，把鼠标放上去看看。
