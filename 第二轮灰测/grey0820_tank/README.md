# M-27 中型坦克模拟器 · Tank Simulator with Interactive Interior

一个**零依赖**的浏览器坦克模拟器：手写 WebGL 渲染器、程序化生成的地形与贴图、Web Audio 合成音效，
以及一个**每个开关都能真的按下去**的可互动战斗室内饰。

直接用浏览器打开 `index.html` 即可（不需要服务器、不需要联网、不需要构建步骤）。

---

## 1. 它是什么

你不是"操作一辆坦克"，而是**同时扮演全体乘员**：驾驶员、炮长、装填手、车长。
坦克不会自动启动——你必须按真实顺序去合开关、踩起动机、松驻车、挂档、开炮闩、从待发弹架取弹、
关闩、瞄准、击发。屏幕左侧的检查单会一步步引导你完成第一次启动与射击。

**49 个可互动部件**（鼠标移上去有名称、当前状态与快捷键；左键按下 / 拖动操作）：

| 站位 | 可操作部件 |
| --- | --- |
| 驾驶员 | 蓄电池总开关、燃油泵、点火磁电机、起动按钮、前照灯、车内灯、通风机、四联仪表（车速/转速/油压/水温）+ 燃油表、四个警告灯、左右操纵杆、油门与制动踏板、H 型档位杆、驻车制动棘轮、潜望镜、舱盖手柄、罗盘（真的随车体转）、灭火器、车体机枪 |
| 炮长 | 望远瞄准镜、高低机手轮、方向机手柄、主炮击发开关、并列机枪脚踏、电传动开关、瞄具照明旋钮、方位指示器（针随炮塔转） |
| 装填手 | 8 发立式待发弹架（每发单独可点，AP / HE 两种）、炮闩操作杆、废弹壳帆布袋、舱盖 |
| 车长 | 指挥塔潜望镜（6 个观察窗）、19 号无线电（开关 + 音量 + 调频，表盘会亮）、车内通话器、烟幕发射器、炮身象限仪 |

仪表**不是贴图**：每根指针都是独立的 3D 几何体，按真实读数旋转；表盘在合上总开关后会亮起。

## 2. 模拟内容

* **电气/发动机**：总开关→燃油泵→点火→起动机的真实时序；起动失败会有原因提示；机油压力、
  水温随负荷变化；>128 °C 损坏、>145 °C 起火（警告灯 + 蜂鸣 + 灭火器可救）；燃油会烧完。
* **传动与行走**：R/N/1-4 档，每档不同的牵引力与极速；差速转向（拉哪侧操纵杆就往哪侧转，
  原地也能微转）；坡度阻力、悬挂弹跳、履带按真实距离滚动（履带贴图 UV 滚动 + 负重轮/主动轮旋转）。
* **火炮**：开闩/抛壳/取弹/关闩/击发的完整循环；后座 34 cm 并带动车体点头；炮口焰、烟、扬尘；
  AP 790 m/s、HE 640 m/s 的弹道（重力 + 空气阻力 + 曳光弹迹）；命中判定、破片溅射、
  目标击毁与燃烧；发射后车内积聚炮烟（开通风机才散得快）。
* **战场**：1024 m 程序化地形（含平整的射击场走廊与远处山脊）、18 个不同距离的目标
  （靶板 / 油桶 / 报废坦克 / 掩体，100–800 m）、距离标牌、树木（会被压倒）、岩石、沙袋工事。

## 3. 操作

打开后按任意键进入，`Tab` 随时呼出完整操作表。要点：

* **右键拖动** = 环视车内；`Q` = 锁定鼠标连续环视
* `1` 驾驶席 / `2` 驾驶员潜望镜 / `3` 炮长瞄准镜 / `4` 车长潜望镜 / `5` 装填手 / `6` 开盖出舱 / `7` `8` 车外视角
* `M` `F` `I` `G`(按住) = 总电源、燃油泵、点火、起动机；`P` 驻车；`Shift+1..4` 档位
* `W` 油门、`S` 制动、`A` `D` 左右操纵杆
* `←→` `↑↓` 炮塔方向/高低机；`B` 炮闩；点击弹架取弹（或 `Z` 一键装填）；`空格` 击发
* 瞄准镜里：右键拖动瞄准、滚轮 ×3/×5/×8 变倍、左键击发

## 4. 代码结构（8700 行，全部手写，无第三方库）

```
index.html          页面 + HUD/检查单/帮助面板（中文）
css/style.css       军用风格 HUD 样式
js/math.js          vec3 / mat4（列主序）/ 射线-AABB、射线-球求交
js/gl.js            WebGL1 前向渲染器：半球环境光 + 平行光 + 4 点光源、雾、
                    发光/无光照材质、UV 滚动、透明排序、多深度范围分层渲染
js/geom.js          程序化几何：box/cyl/sphere/dome/torus/lathe/prism/pipe、
                    带矩形开口的墙（观察缝/舱口就是这样挖出来的）、高度网格
js/tex.js           程序化贴图（Canvas2D）：仪表盘面、铭牌、迷彩、钢板、
                    履带、瞄准镜分划、无线电刻度盘、木纹、帆布…
js/audio.js         Web Audio 合成：随转速变化的发动机、起动机、履带吱嘎、
                    炮声、爆炸、炮闩撞击、开关声、蜂鸣…（无音频文件）
js/assets.js        贴图缓存与容错桥接
js/world.js         地形/天空/云/景物/目标靶场
js/fx.js            粒子系统：尘土、烟、火、火花、碎片、炮口焰、地面焦痕
js/tank.js          车体外形（含尺寸表 TankDef）、炮塔、后座炮、行走装置
js/cockpit.js       ★ 全部内饰几何 + 49 个可互动部件的定义与命中盒
js/sim.js           ★ 电气/发动机/传动/转向/火炮/弹道/损伤/检查单/计分
js/main.js          启动流程、7 种相机、输入路由与拾取、两遍渲染、HUD
```

**为什么分两遍渲染**：3 cm 的开关和 1 km 外的靶子无法共用一个深度范围。
第一遍用 `near=0.35` 画世界（车内视角时隐去车体外壳），清深度后第二遍用 `near=0.02`
画内饰并换成车内光照——所以从观察缝里能看见外面，而车内又不会 Z-fighting。

## 5. 自带的无头测试工具

因为不能靠"打开看看"来验证，仓库里带了三个工具（需要 Node）：

```bash
node tools/smoke.js       # 桩化 DOM/WebGL，构建全部子系统、跑完启动+行驶+装填+射击，
                          # 并对 49 个部件做射线拾取覆盖率检查（要求 100% 可点到）
node tools/smoke-ui.js    # 连 main.js 一起跑：键盘启动流程、7 种视角、鼠标悬停/点击/拖动、
                          # HUD 更新；元素 id 与 index.html 交叉校验
node tools/smoke-audio.js # 用「严格」Web Audio 桩真正执行 audio.js：指数斜坡到 0、非有限值、
                          # 负时间、非法节点类型都会抛错；同时验证 setEngine 每帧零分配、
                          # 一次性音效会被 stop+disconnect 回收、游戏请求的音效名全部已实现
pwsh -File tools/shots.ps1 # 用 headless Chrome 截 11 个视角的图，并用 tools/png.js
                          # 把 PNG 解码成亮度/色调文本图，在终端里"看"渲染结果
```

`tools/png.js` 也可单独用：`node tools/png.js shots/chase.png 100 38`

## 6. 调试用 URL 参数

`index.html?autostart=1&engine=1&load=1&view=sight&az=12&elev=2&zoom=1&hatch=1`

`autostart` 跳过开场、`engine` 直接把车打着、`load` 预先装填、`view` = driver/gunner/loader/
commander/periscope/sight/cupola/unbuttoned/chase/orbit、`az`/`elev` 炮塔与炮身角度、
`yaw`/`pitch` 视线、`pos=x,z` 车辆位置、`gear`、`hatch`。
