# 紫禁城 · 体素沙盘

一个**零依赖**、用纯 WebGL2 手写引擎的体素（Voxel）风格紫禁城沙盘。用 220 万余枚体素细致复原了明清故宫的宫墙殿宇、中轴线格局与山水花木，并支持**上帝视角俯瞰点选**与**第一人称漫步**两种体验方式。

## 打开方式

- 无需安装、无需联网、无需构建：直接用较新版本的 Chrome / Edge / Firefox 打开 `index.html` 即可（也支持 `file://` 协议）。
- 首次加载会显示营建进度条，约 1–2 秒完成（内含体素营建、表面网格化、GPU 装配、小地图绘制）。
- 若使用本地服务器：`python3 -m http.server` 后访问 `http://localhost:8000`。

## 两种视角

### 上帝视角（俯瞰沙盘）
| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 绕城旋转 |
| 右键 / 中键拖动 | 平移 |
| 滚轮 | 向光标处缩放（可缩到贴近瓦面，也可拉到全城） |
| 点击建筑 | 打开信息卡（形制、历史沿革） |
| `WASD` / 方向键 | 平移视野 |
| `Shift` | 加快平移 / 缩放 |
| `V` | 就地切换为第一人称 |
| 右上「俯瞰」 | 一键上帝俯视全城 |
| 左下小地图 | 点击任意位置快速定位 |

### 第一人称（身临其境）
点击画面锁定鼠标后：

| 操作 | 功能 |
| --- | --- |
| `WASD` | 行走（可走进殿门、登上台阶、沿马道登上城墙） |
| `Shift` | 疾行 |
| `空格` | 跳跃 |
| `F` | 飞行模式（Shift 加速，Space/Ctrl 升降） |
| `滚轮` | 视野宽度 |
| `G` | 回到上帝视角 |
| 落入护城河 | 自动游泳，可游回岸边 |

### 中轴导览
点击「中轴导览」或按 `T`，镜头将沿北京中轴线自动漫游：天安门 → 端门 → 午门 → 内金水桥 → 太和门 → 登上三台 → 步入太和殿 → 中和殿 → 保和殿 → 乾清门 → 后三宫 → 御花园 → 神武门 → 景山回望。空格暂停、← → 切换站点、Esc 结束。

## 主要特色

- **写实布局**：以 1 体素 = 1 米的比例，按史料铺排宫城 753m×961m 的格局——凹字形午门五凤楼、工字形三台与三大殿、后三宫、东西六宫、文华殿/文渊阁（黑瓦绿剪边）、武英殿、慈宁宫、养心殿、宁寿宫与畅音阁、御花园堆秀山、四座三重檐十字脊角楼、护城河与内金水河、景山五亭，另含端门、天安门、太庙与社稷坛。
- **古建构件级体素**：庑殿/歇山/攒尖/圆攒尖/盝顶/十字脊/卷棚屋顶（含翼角起翘、正脊吻兽、宝顶）、须弥座台基、汉白玉栏板望柱、御路踏跺、檐柱槛墙、隔扇门窗、额枋斗拱彩画、殿内金柱藻井与九龙宝座、铜龟铜鹤日晷嘉量、宫灯松柏。
- **手写渲染器**：贪心网格化 + 顶点环境光遮蔽、逐格色差与格线（体素质感）、三级级联软阴影、程序化天空（北京纬度太阳轨迹/星夜）、水面反射、大气雾、ACES 色调映射，可切换时辰。
- **建筑索引**：240 个有名称的殿宇/宫门/园林，含中文简介，搜索或点选后一键「飞抵此处 / 在此漫步」。
- **体量**：2,200,312 枚体素 → 贪心合并后约 122 万面，`128m` 区块批量绘制（视锥内约 200 余批次）；自适应画质保证低端设备可用。

## 技术说明

- 无任何外部资源：所有着色器、色板、UI 均为内联或本地脚本，可离线使用。
- 碰撞体直接取自体素体与 2D 地面高度图；行走支持 1 格自动上台阶，因此可沿踏跺登上八米高台、沿马道走上城墙顶。
- 阴影采用三张级联阴影贴图，远级联做脏标记缓存，减少重绘开销。
- 体素面按 `128m` 区域打包为单个 VAO，配区域原点 uniform，视锥内单帧约 200 余次绘制调用。

*模型基于公开的故宫建筑史料与平面资料归纳制作，为体素艺术风格的比例化复原，仅供观赏学习。*
