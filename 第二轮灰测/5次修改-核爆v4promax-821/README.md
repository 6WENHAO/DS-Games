# 核爆 3D 物理效果 · 实时 WebGL2 仿真

一个**离线、零依赖**的核爆炸三维物理演示：火球自相似膨胀 → 双闪光 → 冲击波与马赫反射 →
涡环翻卷 → 尘茎抽升 → 蘑菇云上升 → 对流层顶砧状铺开。所有物理量都从标定律和流体
模型算出来，不是关键帧动画。

```
直接双击打开 index.html 即可（file:// 可用，无需服务器、无需联网）
```

需要支持 **WebGL2 (OpenGL ES 3.0)** 的浏览器。若想用本地服务器：
`python3 -m http.server 8000` 然后访问 `http://127.0.0.1:8000/`。

## 物理模型

### 1. 冲击波

近场用 **Sedov–Taylor 点爆炸自相似解**

```
R(t) = ξ (E/ρ₀)^(1/5) t^(2/5)          ξ = 1.033 (γ=1.4)
```

全程用「经验超压–缩放距离幂律 + Rankine–Hugoniot」数值积分得到 `R(t)`：

```
Δp(bar) = 0.345 · (Z/0.64)^(-1.9)       Z = R[km] / W_eff[kt]^(1/3)
M = √(1 + (γ+1)/(2γ) · Δp/p₀)           dR/dt = c(z)·M(R)
q = 2.5Δp²/(7p₀+Δp)                     u₂ = 2/(γ+1)·(M²−1)/M·c₀
```

幂律锚定「5 psi @ Z=0.64」，它**同时**复现 20 psi 与 1 psi 的公开数值（见下表）。
`Z < 0.08`（火球内部）切换为强激波立方律 `Δp ∝ R⁻³`。地面反射按接地程度把有效当量
放大最多 1.8 倍。

粒子受到的风由 **Friedlander 波形**给出：

```
u(R,t) = u₂(R) · (1−φ) e^(−φ)           φ = (t − t_a(R)) / t₊(R)
```

`φ>1` 时自动变负 —— 这就是负压相（余风回吸），也是尘茎的成因，不需要额外造一个「吸力场」。

### 2. 火球与双闪光

火球半径 `R_fb = R_max(1 − e^(−R_shock/R_max))`，`R_max = 70·W^0.4` m ——
早期紧贴激波，随后在激波脱离时饱和。

表观表面温度走**双闪光**曲线（log-log 分段插值），特征时标 ∝ W^0.5：
`t_min = 2.5·√W ms`、`t_2max = 32·√W ms`。锚点按「第一极大峰值功率约为第二极大的
30 倍、但持续极短」标定（`P = 4πR²σT⁴`）。颜色直接由**黑体轨迹**给出（Planck 轨迹拟合，
CPU 与 GLSL 两份实现保持一致），亮度 ∝ T⁴。

### 3. 蘑菇云上升（浮力热泡 ODE）

以**浮力通量 F**（m⁴/s²）为状态量，而不是从任意初始体积反推温度：

```
dz/dt  = w
dRc/dt = α|w|                                      α = 0.14（上升期夹卷）
dw/dt  = F/V − w·(3α|w|/Rc) − C_d w|w|/Rc          动量被夹卷空气稀释
dF/dt  = −N²(z)·V·w + (g/θ)·η·δθ_L·dV/dt           层结耗散 + 潜热补充
```

* **初始浮力受 Archimedes 硬约束**。定压下把体积 V 的空气加热到 T 需要
  `E = pV·γ/(γ−1)·(1−T₀/T)`，于是 `F₀ = g·V·min(1, E(γ−1)/(γpV))` ——
  即热气泡的浮力**永远不可能超过同体积真空泡的 `g·V`**。
  1 kt–1 Mt 全部落在这个上限上（无自由参数）。
* **潜热是主导浮力源，这是能量守恒逼出来的结论**：1 Mt 火球即使抽成真空，
  `g·V_fb ≈ 5.6×10¹⁰ m⁴/s²`，而云要顶到 21.6 km 需要约 8 倍于此。缺口只能来自
  卷入湿空气抬过凝结高度后释放的潜热
  `δθ_L = (L_v/c_p)·q_s·RH·e^(−z/2200)`。
  其中干空气卷入会把凝结水重新蒸发掉，故乘一个积云物理里的存活效率
  `η = Rc/(Rc+900 m)` —— 这一项自然压出了正确的当量标度（小云团发展不起来）。
* **对流层顶自动出现砧状顶**：平流层的 `N²` 比对流层大近一个数量级，
  `dF/dt = −N²Vw` 于是迅速把浮力抽干。停滞高度是**涌现**的，不是写死的。
* 混合层（<1200 m）按中性层结处理（ISA 的均匀 3.3 K/km 稳定层结在近地面不成立）。

### 4. 涡环翻卷与尘茎

蘑菇的「形状」来自涡环。把环面简化为**子午面内一对镜像 Lamb–Oseen 涡**：

```
v_θ = Γ/(2πs)·(1 − e^(−s²/r_c²))
Γ   = 4πR·w / (ln(8R/a) − 0.25)        由涡环自诱导速度公式反解
```

旋向决定一切：轴线上向上、核外侧向下回流、核**上方**向外铺开（云盖）、核**下方**向内收拢
（喂养尘茎）。二维涡对的远场衰减是 `1/r`，而真实涡环是 `~1/r³`，因此加了包络窗把环流
限制在云团尺度内 —— 否则远处的尘幕会被虚假远场速度甩出去，得到一个「倒蘑菇」。
二维涡对只给出 `Γ/(4πR)` 的自平移，缺少的 `ln(8R/a)−0.25` 因子作为云团包络内的均匀
平移补上，使可见云体严格跟随 ODE 解。

**茎与盖必须连通** —— 这是「蘑菇」形态的定义性特征。三个真实细节也一并建模：
交界处有明显**缩颈**（茎远细于盖）；高空爆最初几秒尘柱确实短于云底
（尘土要以余风速度从地面长上去，`base ≤ (t−t_decouple)·110 m/s`）；后期风切变
把茎相对盖横向拉偏。播种规则有两处关键点：

* **上限伸进云盖下缘**（`cz − 0.35·Rc`）。若按云底 `cz − 1.05·Rc` 截断，柱顶与
  盖底之间会留下约 20% 云高的空洞（21 kt 约 1.8 km，1 Mt 约 3.7 km），云盖看着
  像悬空的。
* **高度按对数均匀（1/y）分布**。被线性速度场 `u = w·y/cz` 拉伸的柱体，其数密度
  ∝ 1/y ⇒ 高度服从 log-uniform。原先用 `u³` 会把上半段饿死（近轴计数 465 → 0），
  柱子在 60% 高度就断掉。
* **寿命随播种高度增加**：近地粗尘沉降（数十秒），被抬到上部的细尘长期滞留。
  若一律给长寿命，配额会被赖在近地的粒子占满（近地拉伸速度极慢），新的高位播种
  无槽可用 —— 同样会让柱子上半段变空。

尘柱半径主要由火球尺度决定（`0.42·R_fb + 0.06·R_c`），随云团半径增长得很弱：
真实 20 kt 级尘柱直径只有几百米，远细于云盖，播种过宽会丢掉「细茎」特征。

尘茎的轴向输运叠加两段并取 max：

* 连续性要求的**线性拉伸场** `u = w·y/cz`（地面 0、云底 w），把尘土拉成连续柱体；
* 涡环在轴线上的**精确 Biot–Savart 诱导** `u_z = ΓR²/2(R²+d²)^{3/2}`，在云底附近迅速吸入。

### 5. 砧状云盘：停滞后的重力流侵入

云到中性浮力层后不再上升，而是以重力流形式横向侵入。侵入前沿持续夹卷（γ≈1 ⇒ V ∝ R²）
⇒ **厚度守恒、半径近似线性增长**：

```
h = (4/3)Rc          dR/dt = Fr·N·h          Fr = 0.72
```

这正是实测「云盘半径 ≈ 0.2–0.45 × 云顶高度」的物理来源。粒子侧对应一个自相似铺展
速度场 `u_r = Ṙ·(r/R)` 并按体积守恒竖直压扁 —— 于是砧状顶自己长出来。

### 6. 热辐射与地面

```
Q(R) = f·E/(4πR²)·e^(−R/λ)  [cal/cm²]        f = 0.35, λ = 能见度
```

地面着色器直接用这个剂量场做炭化/焦环（阈值 8 / 20 cal/cm²），再叠加弹坑
（`R ≈ 40·W^0.3` m）、激波扫痕、地面激波亮环、尘环。火球作为**点光源**照亮
地面/建筑/云体，强度按 `P/(4πr²)`（单位 = 太阳常数）计算。

城区范围内地面换成**沥青路网 + 街区铺装**，与建筑共用同一套网格与朝向，
因此从空中俯视是连贯的城市肌理，而不是"贴在草地上的一堆盒子"。

### 7. 城市与破坏

**城区尺度**：真实城市不会因当量变大而变大，一座特大城市的半径也就 10–15 km。
因此城区半径取 `min(3×R5, 14 km) × 城区规模`；兆吨级下整座城市都落在毁伤圈内 ——
这正是事实。建筑上限随城区尺度放宽到 1.1 万栋（≈3 万实例），否则 14 km 半径下
只有 8.7 栋/km²（真实城市 10²–10³ 栋/km²），画面里「空得看不出是城市」。

**布局**不是随机散点，而是街区路网：主干网格（随机朝向）→ 街区内**沿街周边式**
排布（临街面朝道路、内部留院落）→ 市中心塔楼群（带上部退台）+ 混合裙楼/中高层。
街区按到爆心距离排序后再用全局密度因子压到实例上限，因此**核心区必定建成**且
密度由内向外递减。工业区散布烟囱/铁塔等细长结构。

**结构分类**决定一切。抗力用"倒塌超压阈值"表达，对标常用建筑易损性分级：

| 类别 | 全毁超压 | 幕墙剥离 | 点燃阈值 |
|---|---|---|---|
| 木/轻质（1945 年式民居） | 3–5 psi | ~1.2 psi | 9 cal/cm² |
| 砖石承重墙 | 4–7 psi | ~2.2 psi | 14 |
| 钢筋混凝土多层 | 8–12 psi | ~2.8 psi | 22 |
| 钢框架高层 | 10–16 psi | ~2.6 psi | 26 |
| 细长结构（烟囱/铁塔） | 1.2–3 psi（动压弯折） | — | — |

"建造年代"整体平移这个分布：同当量下 1945 木构城市与现代钢混城市的**重度毁伤
半径差 1.7 倍**（实测 2.35 km vs 1.35 km），这是核效应里最显著的差异之一。

**载荷**：`load = Δp + q·(0.7 + 0.8·slenderness)` —— 超压压碎 + 动压拖曳，
细长/高耸结构对动压更敏感。两点关键处理：

* **迎风遮挡**：按 96 个方位扇区沿径向累积前排建筑的迎风面积比，
  `shield = e^(−0.62·blockage)`，并让遮挡随距离按 ~620 m 绕射回填。
  于是大楼背后的建筑存活率明显更高（密集城区里约 90% 建筑受到不同程度遮挡）。
* **不重复计入反射**：超压经验幂律本身就锚定在"空爆地面（马赫反射区）"的公开
  毁伤半径上，所以**不再**额外乘 1.8 倍反射系数 —— 否则建筑毁伤半径会比 HUD
  显示的 psi 环大 30% 以上，二者必须自洽。

**渐进破坏状态机**（不是"倒/不倒"二元）：

```
>0.22 psi     玻璃破碎        窗格变成黑洞（内部无光）
>幕墙阈值      外墙剥离        露出楼板与框架，色调转向混凝土
>0.62×抗力     部分倒塌        上部楼层坐塌 → 残存主体 + 脚下废墟堆
>抗力          完全倒塌        整体坐塌成废墟，背爆心方向轻微倾斜
>3.2×抗力      清扫至基础      几乎荡平，仅留基础与薄层废墟
```

**坍塌是重力驱动的**：特征时间 `T ≈ 1.6·√(2h/g)`（自由落体量级 × 阻力修正），
100 m 高楼约 7 s 坐塌完；废墟堆高度取原高的 17%（清扫工况 6%），底面外扩 1.3 倍
——与拆除录像和震害照片的量级一致。普通建筑**坐塌而非整体翻倒**（不做多米诺），
只有细长结构绕底边径向倒伏 90°，这正是核爆现场最典型的标志物。

**火灾与火风暴**：热剂量超过材料点燃阈值即起火；强冲击波（>4.5 psi）有 55%
概率扑灭初期火，但其中 45% 的废墟随后复燃 —— 这正是广岛火风暴的形成过程。
浓烟用**炭黑反照率**（0.085）的粒子表达，按羽流夹卷（`τ ≈ 尺度/0.1w`）缓慢冷却，
因此能真正升起成烟柱（实测平均高度 363 m → 1.12 km）。发射速率按
"预算 /（寿命 × 燃烧栋数）"自适应，否则最先起火的少数几栋楼就会吃光配额。

### 8. 渲染

建筑用实例化立方体绘制，每栋楼最多 3 个子实例（主体 / 塔楼退台 / 废墟堆），
倾覆与坍塌倾斜在顶点着色器里用 Rodrigues 旋转绕"背离爆心的水平轴"完成，
支点取底面在径向上的边缘。立面以世界坐标定义 3.2 m × 3.6 m 的窗格模块
（跨建筑一致），玻璃破碎→黑洞、幕墙剥离→楼板与框架、迎爆面按 `dot(N, 指向爆心)`
炭化、燃烧建筑从窗洞透出火光（夜间尤其明显）。

**HDR 数值稳健性**（这类问题的表现是「画面里有个闪烁的黑方块」）：

* 火球被当作点光源时，`1/r²` 在 `r→0` 处发散。火球内部的粒子会拿到约 10⁷ 的
  照度，**超出 half-float 上限 65504 → +Inf**，Inf 进 ACES 得 `Inf/Inf = NaN`，
  显示为黑；再被泛光的高斯模糊扩散成约 100 px 的方块。
  修法：火球是**有限尺寸的面光源**，距离以火球半径为下限
  （`bl = max(|p−C|, 0.75·R_fb)`）—— 进入火球内部后照度自然饱和。
* 所有着色器输出经 `hdrSafe()` 钳制到 40000（half-float 安全区）。
* 亮度提取 / 高斯模糊 / 合成三处都显式拦截 `isnan/isinf`。
  注意 **`NaN×0` 仍是 NaN**，所以「把泛光强度调成 0」并不能挡住污染扩散，
  必须在采样处拦截。
* 闪光带**各向同性散射分量**（`ndb + 0.22`）：核爆闪光把整片天空点亮，
  背对爆心的立面靠漫射照明仍然可见。缺这一项时，曝光被压到 1e-5 的瞬间
  背光面会变成纯黑矩形。
* 曝光自适应用**时间常数**（变亮 τ=0.08 s、变暗 τ=0.30 s）而不是每帧固定比例：
  否则适应速度与帧率耦合，且双闪光的极小值之后会留下一段「除火球外全黑」的窗口。
* 自动构图时视点被抬到附近建筑之上，避免近处高楼贴脸占满画面。

`RGBA16F` 场景缓冲 → 深度拷贝（软粒子要采样深度，不能读正在写的附件）→
激波壳（加性菲涅尔边缘）→ 威尔逊凝结云 → **按视深计数排序**的预乘 alpha 粒子 →
激波屏幕空间折射（含色散）→ 两级高斯泛光 → ACES 色调映射。

曝光是**物理量驱动**的：由 `P = 4πR²σT⁴` 算出相机处照度（以太阳常数为单位），
再模拟视网膜/胶片的非对称适应（变亮快、变暗慢）。闪光时整个天空被打亮、地面被点光源
照透，这是自动出现的，不是叠了一层白。

## 标定：哪些是物理，哪些是拟合

诚实交代。**两个标量**由「一维 ODE 预积分 + 二分」在每次改参数时自动拟合，
其余全部是物理：

| 系数 | 作用 | 典型值 | 为什么需要 |
|---|---|---|---|
| `sStrat` | 层结耗散系数 → 匹配云顶经验曲线 | 0.004 – 0.4 | 不可压顶帽模型不含湿中性深对流与气泡膨胀，兆吨级会低估平流层穿透 |
| `cSpread` | 铺展系数 → 匹配云盘半径经验曲线 | 0.5 – 6 | 铺展项只读 Rc、不反馈进上升解，可独立标定 |

标定只改这两个标量，**上升速率、过冲振荡、砧状铺开、涡环翻卷等全部动力学形状不变**。
HUD 里实时显示这两个值以及「仿真 / 经验」的比值，随时可以看出纯物理解偏离多少
（`sStrat = 1` 即纯物理）。

经验目标曲线：`H_top = 21.6·(W/Mt)^0.2 km`，`R_disk/H = 0.20 → 0.45`（随当量增大）。

## 验证（不使用任何视觉模型）

两套自动化检查，全部是**数值/文本断言**：

```bash
node test/physics-check.js     # 97 项：标定律、数值健壮性、形态学
./test/headless.sh             # chromium + SwiftShader 跑真 WebGL2，读 DOM 文本断言
```

`test/physics-check.js` 覆盖：

* **标定律对标公开数据**（1 Mt 空爆）

  | 量 | 仿真 | 公开值 |
  |---|---|---|
  | 20 psi 半径 | 3.09 km | ≈3 km |
  | 5 psi 半径 | 6.40 km | ≈6.4 km |
  | 1 psi 半径 | 14.9 km | ≈15 km |
  | 三度烧伤半径 | 13.4 km | ≈12.8 km |

  另检查立方根标定律（W×8 ⇒ R×2，误差 <2%）、`Δp→0 ⇒ M→1`、到达时间单调、
  Sedov 段衔接、ISA 各层气压温度声速、平流层 `N²` 显著大于对流层、
  `F₀ ≤ g·V`（Archimedes 上限）、双闪光时序。

* **数值健壮性**：无 NaN/Inf、无粒子穿地、云顶不塌缩、粒子池利用率、
  时间轴回退**逐粒子级严格复现**。

* **茎盖连通性**（第 ⑥ 组）：沿云轴做垂直密度剖面（近轴柱体内的粒子计数），

* **形态学**（数值判据代替肉眼）：云盖 90 分位半径 / 尘茎中位半径 > 1.6（蘑菇形，

  基底涌浪比尘茎铺得更远、云轴随风切变向下风倾斜。亚千吨级改为检验**柱状形态**

## 已知局限

* **兆吨级平流层穿透被低估约 15%**（15 Mt：仿真 30 km vs 经验 37 km）。不可压顶帽热泡
  模型不含气泡的可压缩膨胀与湿中性深对流；`sStrat` 只在停滞高度上做了修正。
* **亚千吨级**（<5 kt）云盖与尘茎宽度趋同：云团小、相对湍流强，且环形涡的再循环在环量
  衰减前把云盖约束在涡核半径附近。真实亚千吨云形态本身也更像「蓬松柱」。
* **1 kt 云顶只到经验式的 52%**（2.9 km vs 5.4 km）。但 `H = 21.6·(W/Mt)^0.2` 是用
  兆吨级数据拟合的，向下外推四个数量级本身就不可靠 —— 千吨级实测云顶通常也就 2–3 km，
  所以这里更可能是**经验式偏高**而不是仿真偏低。自检对 <5 kt 相应放宽了阈值。
* 激波用球对称模型 + 反射放大近似，没有解析真正的马赫反射三波点结构。
* 放射性落尘的输运只体现为尘粒沉降，没有粒径谱与剂量场。
* 时间轴回退（往左拖）会重跑仿真，晚期约需 2–5 s。
* 城市建筑上限 4000 栋。兆吨级当量下城区可达数十公里，此时街区尺度会被放大，
  单栋建筑相应变大 —— 否则要十万级实例才能铺满。
* 破坏是**逐栋独立**判定的：不模拟倒塌碎块砸中邻楼、火灾在建筑间蔓延、
  以及倒塌堆积对后续激波的再遮挡（遮挡只在初始化时算一次）。
* 少数派结构（如现代城市里位于郊区的木构房）在毁伤圈内没有样本，
  其毁伤边界无法被自检验证 —— 测试会显式 SKIP 并给出原因。

## 性能

单线程 CPU 仿真是瓶颈（渲染在 GPU 上很轻）。实测（Node，单核）：

| 粒子数 | 每帧仿真 | 仿真侧 fps 上限 |
|---|---|---|
| 1.2 万 | 4.0 ms | 250 |
| 3.2 万（默认） | 11.7 ms | 85 |
| 5 万 | 15.4 ms | 65 |
| 9 万 | 26.4 ms | 38 |

界面里可切换粒子数与渲染分辨率。热点循环已做过针对性优化：云轴查表代替逐粒子二分、
Friedlander 波形按壳层剪枝、拖曳松弛因子外提、消除逐粒子闭包分配、`x^1.5 → x·√x`。
