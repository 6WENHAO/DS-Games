# 微缩体素城市灾难沙盘

一个纯前端的微缩城市灾难沙盘：打开页面立即进入全屏 3D 场景，用底部工具栏对一座
约 4.7 万体素的低多边形玩具城市释放九种灾难。所有内容（城市、车辆、行人、天空、
音效、贴花纹理）都是运行时程序化生成的原创资产，没有任何外部素材。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5180/
npm run build    # tsc --noEmit && vite build
npm run preview
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 在瞄准圈位置释放已选灾难 |
| 左键拖动 | 环绕旋转 |
| 右键拖动 / 双指拖动 | 平移 |
| 滚轮 / 双指捏合 | 缩放 |
| WASD / 方向键 | 操控龙卷风、黑洞、雷暴中心 |
| Esc / 右键单击 | 取消待释放的灾难 |
| 再次点击同一按钮 | 提前结束持续型灾难 |
| 空格 | 切换慢动作 |

底部工具栏另有慢动作、声音、重建、**威力** 与 **移轴** 两个滑块。

## 九种灾难

| 灾难 | 表现 |
| --- | --- |
| 💥 定点爆破 | 球形削除 + 冲击波环 + 碎片定向抛射 + 焦痕 |
| ☄️ 陨石坠落 | 高空燃烧陨石带尾迹坠落，命中后更大范围爆炸与弹坑 |
| ⚡ 天罚落雷 | 分叉闪电 + 白闪 + 火花 + 小范围损伤与焦痕 |
| 🌪️ 龙卷风 | 可见旋转漏斗，持续移动、可键盘操控，吸起体素/车/人 |
| 🕳️ 微型黑洞 | 紫黑核心 + 吸积盘，先绕转后吞噬，结束时紫白坍缩爆闪 |
| ☢️ 核弹 | 投放倒计时 → 全屏白闪 → 火球 + 多层冲击波 + 蘑菇云 + 长时间燃烧 |
| 📳 大地震 | 城市与镜头持续摇晃，逐步开裂、掉落、倾倒，可提前停止 |
| 🌊 大洪水 | 半透明蓝水由低处上涨、淹没道路与低层，推动漂浮物，可退水 |
| ⛈️ 雷暴 | 天空压暗、云层加速、区域内连续随机落雷，中心可键盘操控 |

## 主要文件

- `src/main.ts` — 装配 Engine / Sandbox / DisasterManager / HUD / 控制器，单一 rAF 循环
- `src/core/engine.ts` — 渲染器、相机、后处理链、自适应画质、`frame(dt, render)`
- `src/core/postfx.ts` — 移轴（tilt-shift）与调色（曝光/饱和/暗角/闪光）着色器
- `src/core/controls.ts` — 阻尼轨道相机、点击与拖拽分离、触摸手势、键盘方向
- `src/world/city.ts` — 程序化城市（空心塔楼、窗格、楼板、地标、公园、郊区）+ 结构失效判定
- `src/world/voxels.ts` — 单 `InstancedMesh` 体素场、空间网格查询、GPU 摇晃材质
- `src/world/{terrain,sky,water,traffic,crowd,models}.ts` — 地面、天空/云/光、水面、车流、人群
- `src/fx/*` — 固定容量池：碎片、刚体块、粒子、冲击波、贴花、闪电、屏幕特效、力场
- `src/disasters/*` — 九种灾难的实现、规格表与调度器
- `src/ui/{hud,reticle}.ts` — 玻璃质 HUD 与地面瞄准圈
- `src/audio/audio.ts` — Web Audio 程序化音效（爆炸、碎石、雷、风、地鸣、核爆）
- `tools/*.mjs` — 无头 Chromium 自检脚本（截图、像素分析、灾难探针、性能与缩放检查）

## 性能约束

- 全城静态体素为一个 `InstancedMesh`，逐槽位交换删除，脏区间增量上传；静态体素没有刚体
- 碎片 / 粒子 / 冲击波 / 贴花 / 刚体块全部固定容量池，超限即复用最旧个体
- 单一 rAF 循环；重建与窗口缩放不会新建循环，`ResizeObserver` 保证缩放后缓冲区正确
- 按 CPU 核数 / 内存 / 移动端 UA 选择画质档，帧率持续偏低时最多自动降级两次

## 已知限制

- 破坏是"视觉可信"的近似：碎片受重力、空气阻力、地面/屋顶回弹与力场影响，但不是真实刚体解算
- 倾倒以整段楼层为单位（最多同时 10 组），不做逐块连接性分析
- 水面是单张动态平面，没有真实流体；水下不做折射
- 无头软件渲染环境下的 FPS 不具参考意义，真实 GPU 上才有意义
