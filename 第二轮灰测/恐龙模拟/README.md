# 侏罗纪求生 · 网页恐龙生存模拟器（魔幻纪元）

纯前端（零依赖、零构建、零素材文件）的恐龙生存模拟器，**同时支持手机触屏和电脑键鼠**。
所有图形都由 Canvas 2D 程序化绘制，所有音效都由 WebAudio 实时合成，整个游戏只有十几个文本文件。

## 快速开始

- **电脑**：直接双击 `index.html`（脚本用普通 `<script>` 加载，file:// 下也能跑）。
- **手机**：让手机和电脑在同一 WiFi，在项目目录起一个静态服务器：

```powershell
python -m http.server 8000      # 或 npx --yes serve -l 8000
```

手机访问 `http://<电脑局域网IP>:8000/`。用 http(s) 打开时会注册 Service Worker，
可"添加到主屏幕"，之后离线也能玩（全屏、无地址栏）。

| 动作 | 手机 | 电脑 |
| --- | --- | --- |
| 移动 | 左半屏任意位置按下拖动（浮动摇杆） | WASD / 方向键 |

## 玩法

### 生存
- **五条状态**：生命 / 饱食 / 水分 / 耐力 / **魔力**，另有成长条。饱食或水分归零就掉血。
- **食性**：肉食靠捕猎与啃食尸体，植食吃蕨类与灌木（会随时间长回来，雨天更快）。
- **成长**：幼年 → 亚成年 → 成年 → 霸主，体型/血量/伤害同步提升。幼年期有伤害减免，
  开局还有 45 秒适应期（掠食者暂时不盯上你）。
- **昼夜与天气**：完整昼夜循环（夜里只有身边一圈视野）、晴/多云/雨/雷暴/浓雾，雷暴真的会落雷劈伤生物。
- **巢穴**：吃饱喝足可筑巢 → 白天产蛋 → 幼崽跟随作战；夜里可在巢中睡觉快进到天亮（有掠食者会惊醒）。

### 元素吐息（消耗魔力）
| 物种 | 吐息 | 效果 |
| --- | --- | --- |
| 霸王龙 | 烈焰吐息 | 锥形高伤，**点燃**目标并在地面留下火焰 |
| 迅猛龙 | 雷霆吐息 | 直线穿透，**连锁 2 个**额外目标并短暂眩晕 |
| 三角龙 | 大地震荡 | 环形冲击，**击退 + 眩晕**全场敌人 |
| 副栉龙 | 霜冻吐息 | 锥形**减速**，还能扑灭自己身上和地面的火 |

魔力平时缓慢回复，站在**魔力水晶**或**符文圈**旁回复速度提升 3~4.5 倍。

### 人类部落（第三方阵营）
- 地图上有 **3 座营地**：帐篷、篝火、木桩、骸骨与中央的**图腾柱**。
- 成员：**猎人**（投掷长矛）、**长矛战士**（冲锋近战）、**萨满**（火球 + 治疗/护盾族人）、**酋长**（精英）。
- 他们对**所有恐龙**都动手，会主动围猎野生恐龙 —— 你可以坐看两边互殴再去捡尸体。
- 咬碎图腾柱可让营地**停止派兵**并掉落一件**遗物**，同时酋长会被惊动亲自冲上来。
- 随机事件「**部落狩猎队**」会派一支小队从远处直扑你。

### 远古魔法
- **魔力水晶**（12 处）：夜里发光，靠近狂回魔力。
- **符文圈**（5 处）：站进去按进食键**祈祷**，随机获得 60 秒祝福 —— 力量（+35% 伤害）/ 迅捷（+25% 速度）/ 守护（护盾）。
- **遗物变异**（最多 4 件，永久）：炽心（吐息 +40%、免疫燃烧）、石肤（减伤 20%）、风鳞（+15% 速度）、
  再生鳞、龙魂（+25% 生命、+40 魔力上限）、咒牙（撕咬附带燃烧）、霜心（撕咬减速）、灵脉（回魔翻倍、吐息更快更省）。
- **幽影龙**：夜间出现的半透明魔法恐龙，会**瞬移**到你背后偷袭，击杀回魔。
- **熔岩暴龙（龙王）**：第 5 天起可能触发「**龙王降临**」，脚下留下燃烧火痕，击杀掉落炽心遗物。
- 事件「**魔潮**」：全场回魔 x3、符文圈全部刷新、幽影成群出现。

### 其它
状态效果（燃烧 / 冰缓 / 眩晕 / 护盾 / 祝福）都有独立的画面表现；成就、评分、自动存档（含遗物与营地状态）。


## 开发自测（无需浏览器）

`tools/` 用假 DOM/Canvas 在 Node 里跑**真实**的游戏与渲染代码，还自带软件光栅器把画面转成
ASCII 轮廓 / PNG，用于没有浏览器时的视觉检查。

```powershell
node tools/uicheck.mjs    # JS 引用的 id/class/文件是否都存在
node tools/smoke.mjs      # 冒烟：四物种 x 22 秒 + 事件/天气/巢/睡眠/存档/死亡重开
node tools/probe.mjs      # 玩法探针：吃草、喝水、捕猎、啃尸、咆哮、生态自持、性能
node tools/probe2.mjs     # 卡位自救 + 四种吐息 + 部落/图腾/遗物 + 符文 + 幽影/龙王
node tools/inspect.mjs    # 恐龙 ASCII 轮廓 + 场景配色 + 屏内生物密度
node tools/inspect2.mjs   # 地形分布 / 岸边画面 / 夜幕光圈
node tools/inspect3.mjs   # 人类与图腾 ASCII 轮廓 + 吐息方向 + 营地画面
node tools/snap.mjs       # 输出 tools/shots/*.png 供肉眼查看
```

## 想调平衡改哪里

- 物种数值：`src/species.js`（速度/血量/伤害/食量/胆量/远程攻击/吐息类型）。
- 吐息与遗物：`src/magic.js` 顶部的 `BREATHS` / `RELICS` / `BLESSINGS` 表。
- 饥渴速度、成长曲线：`src/game.js` 的 `controlPlayer`、`src/species.js` 的 `expNeed`。
- 生态密度与刷怪半径：`src/game.js` 的 `popTargets` / `updatePopulation`。
- 部落派兵数量：`src/magic.js` 的 `updateVillages`（`want = 3 + min(4, day)`）。
- 昼夜长度：`src/game.js` 的 `dayLength`（默认 195 秒一天）。
- 地形比例：`src/world.js` `generate()` 的分位阈值（深水 12% / 浅水 7% / 沙滩 7% / 山岩 4.5%）。
