怎么活下去

  • 饱食 / 水分会随时间下降。归零后开始掉血。
  • 肉食恐龙靠撕咬猎物，尸体可以反复啃食；植食恐龙吃地上的蕨类与灌木，植物会慢慢长回来。
  • 走到水边按住"进食/饮水"补充水分；下雨天也会缓慢回水。
  • 进食与击杀都能获得成长值：幼年 → 亚成年 → 成年 → 霸主，体型、血量、伤害同步变强。
  • 咆哮会吓退比你弱的生物，但也会把远处的掠食者吸引过来。
  • 吃饱喝足时可以筑巢：在巢中睡觉能安全度过夜晚，产蛋孵化的幼崽会跟随你一起战斗。
  • 夜晚掠食者更凶猛，注意暴雨、迷雾、血月、陨石雨等天灾事件。
  • 元素吐息：每个物种都有独门吐息（焰/霜/雷/震），消耗魔力。站在魔力水晶或符文圈旁边回魔极快。
  • 人类部落：地图上有三座营地。猎人投长矛、萨满扔火球并治疗族人、酋长是精英。他们也会围猎野生恐龙，你可以坐看两边互殴。
  • 咬碎营地中央的图腾柱可以让它停止派兵，并掉落一件遗物（永久强化，最多 4 件）。
  • 符文圈里按进食键可以祈祷，随机获得力量 / 迅捷 / 守护祝福（60 秒）。
  • 夜里会出现瞬移偷袭的幽影龙；第 5 天起可能触发 龙王降临，熔岩暴龙脚下会留下火痕。
  • 小地图：绿=植食，红=掠食者，白=人类，橙方块=营地，青=魔力水晶，紫=符文圈，金点=你的巢。

操作

  • 手机：左半屏任意位置按下即出现摇杆；右下角为咬 / 冲刺 / 进食 / 咆哮 / 巢穴。
  • 电脑：WASD 或方向键移动，J 撕咬，Shift 冲刺，E 进食饮水，R 咆哮，N 巢穴，Esc 暂停。
