# 新冠病毒入侵人体细胞 · 3D 交互科学可视化

> SARS-CoV-2 从识别受体到释放子代的完整感染过程，做成一个可以拖着看、能点开每个分子问
> “这是什么”的 3D 网页。定位是**生物医学科普与科学可视化**，同时兼顾课堂教学与展台展示。

技术栈：**React 19 + TypeScript + Three.js（react-three-fiber）**
所有三维结构由代码**程序化生成**，不加载任何外部模型 / 贴图 / 字体，整站纯静态、可离线运行。

---

## 一、快速开始

```bash
npm install
npm run dev          # 开发服务器 http://127.0.0.1:5173
npm run build        # 类型检查 + 生产构建 → dist/
npm run preview      # 本地预览生产构建
npm run package      # 构建并生成部署包 → deploy/sars-cov-2-3d-v1.0.0.zip
```

环境要求：Node 18+（开发用），浏览器需支持 WebGL 2。

## 二、演示内容（8 步）

| 步骤 | 标题 | 核心分子事件 |
| --- | --- | --- |
| 1 | 病毒整体结构 | 囊膜 + 30 个刺突三聚体 + M / E 蛋白 + N 蛋白包裹的 +ssRNA |
| 2 | 接近与附着 | 布朗运动漂近气道上皮，RBD 在“上/下”构象间切换 |
| 3 | 受体结合 | RBD 抬起为“上”构象，结合 ACE2 肽酶结构域顶端 |
| 4 | 切割与膜融合 | TMPRSS2 切 S2′ → S1 脱落 → 前发夹中间体插膜 → 六螺旋束折叠 → 融合孔 |
| 5 | 基因组释放 | 核衣壳过孔进入**细胞质**，N 蛋白解离，暴露 5′帽 / 3′poly(A) |
| 6 | 翻译与复制 | 多聚核糖体翻译 pp1a/pp1ab → 16 个 nsp → RdRp 在 DMV 内经 −RNA 合成 +RNA |
| 7 | ERGIC 装配 | S/E/M 在 ER 合成 → M 蛋白晶格招募核衣壳 → 向 ERGIC 腔出芽 |
| 8 | 胞吐释放 | 分泌囊泡沿微管运输 → 与质膜融合 → 子代病毒释放 |

每一步都有解说词、要点、关键分子、可展开的「深入阅读」，第 4/5/6/8 步还带**常见误区纠正**。

## 三、使用说明

### 视角

| 操作 | 效果 |
| --- | --- |
| 拖动（单指拖动） | 旋转视角 |
| 滚轮（双指捏合） | 缩放 |
| 右键拖动 / `Shift` + 拖动 / 双指拖动 | 平移 |
| 静止 2 秒后 | 恢复缓慢自动旋转 |

切换步骤时相机会平滑飞向该步的导演机位，并在步内缓慢推移；手动操作过的偏移会在切步骤时
温和回收，保证每一步的构图正确。

### 播放与交互

- 底部时间轴：点击任意步骤跳转，进度条可拖动到任意时刻
- 播放 / 暂停、上一步 / 下一步、0.5×–2× 调速、循环开关
- **点击任意分子或结构**（也可点标签胶囊、图例条目）→ 右侧弹出词条：中英文名、归属、
  功能、关键参数、深入阅读
- 顶栏：标签开关、自动旋转、复位视角、图例、术语表（含参考文献）、画质、使用说明

### 快捷键

`空格` 播放/暂停 · `←/→` 上/下一步 · `1`–`8` 跳转步骤 · `L` 标签 · `R` 自动旋转
`E` 图例 · `G` 术语表 · `H` 使用说明 · `Q` 画质 · `P` 帧率 · `0` 复位 · `+/-` 缩放 · `Esc` 关闭弹层

### URL 参数（教学预设 / 展台 / 截图）

```
?step=4&t=0.6&paused=1        定格在第 4 步 60% 处
?quality=high|medium|low      强制画质（关闭自动升降档）
?labels=0&rotate=0&panel=0    关闭标签 / 自动旋转 / 信息面板
?perf=1                       显示实时帧率
?selftest=1                   运行页面内科学不变量自检
```

## 四、目录结构

```
src/
├── data/            内容数据层（纯文本，不含任何坐标）
│   ├── types.ts       类型契约：26 个分子 id 的联合类型
│   ├── molecules.ts   26 条分子词条
│   ├── steps.ts       8 步叙事：解说、要点、深入阅读、误区纠正
│   ├── glossary.ts    26 条术语
│   └── references.ts  14 篇文献（只写引文文本，不写 DOI/URL）
├── three/           与 React 无关的三维底层
│   ├── palette.ts     配色 + 尺度常量（1 单位 = 50 nm，夸张系数集中在此）
│   ├── textures.ts    程序化贴图：六方密排磷脂法线贴图、噪声、光晕
│   ├── materials.ts   共享材质（含"自发光跟随顶点色"的着色器注入）
│   ├── membrane.ts    可形变磷脂双分子层 + 真几何融合孔
│   ├── quality.ts     三档画质与自动升降档参数
│   └── geometry/      病毒体 / 宿主表面 / 复制机器 / 细胞器 的程序化几何
├── anim/            播放头（唯一时间源）与缓动函数
├── scene/           场景组件 + 导演台本（choreography.ts）+ 逐帧更新总线
├── state/           zustand UI 状态 + URL 参数
└── ui/              顶栏、信息面板、图例、时间轴、弹层
scripts/            验收流水线：本地服务器、无头截图、像素分析、部署打包
docs/SCIENCE.md     科学依据与准确性说明（供专家评审）
```

### 三条关键设计

1. **一切都是播放头 `p` 的纯函数**。`p ∈ [0, 8]`，整数部分是步骤、小数部分是步内进度。
   任意跳步、拖动进度条、倒放都能得到自洽画面，不需要维护过渡状态机；
   也正因为如此，才能把整条时间轴扫一遍做自动化科学校验。
2. **逐帧动画不进 React**。播放头是模块级可变对象，场景更新走一条按 order 排序的
   更新总线（`scene/updateBus.ts`），保证"膜先形变 → 受体贴上去 → 相机最后跟随"的顺序；
   进度条这类 UI 直接写 DOM style。60fps 下不触发任何组件重渲染。
3. **数据 / 视觉 / 编排三层分离**。文案在 `data/`，坐标与时序在 `scene/choreography.ts`，
   颜色与尺度在 `three/palette.ts`。改剧情节奏只动一份文件，改配色只动另一份。

## 五、性能

三档画质（dpr、后处理、细分级别、实例数量、透射折射均分档），首屏按设备启发式选档，
之后依据实时帧率**自动升降档**（连续 3 秒 < 26fps 降档，连续 8 秒 ≥ 57fps 升档）；
手动切换后自动调节关闭。检测到软件渲染（SwiftShader 等）直接降到最低档。

实测渲染预算（1600×1000，页面内自检实测峰值）：

| 画质 | 峰值三角形 | 峰值绘制调用 | 说明 |
| --- | --- | --- | --- |
| 高 | 约 88 万 | 69 | 含病毒囊膜的真实折射（transmission）额外一遍场景 |
| 中 | 约 36 万 | 69 | 关闭折射与景深，保留泛光 |
| 低 | 更低 | 更少 | 关闭后处理与磷脂特写实例 |

优化手段：所有重复结构走 InstancedMesh（几十个绘制调用撑起整个场景）；膜片 1.6 万顶点
只在形变位点附近逐帧重算；RNA 管道顶点缓冲一次分配、逐帧就地更新；几何与材质模块级缓存，
切步骤不重建 shader；拾取用简化面片，不对高精度网格做射线检测。

## 六、科学准确性

详见 **`docs/SCIENCE.md`**（分步机制、规避的常见错误、比例与时间夸张、两条进入途径、
参考文献）。刻意规避的错误包括：

- 基因组是**正义单链 RNA**，不是 DNA，画面中**不出现双螺旋**
- 病毒 RNA **全程不进入细胞核**（细胞核始终可见并有醒目标注作为对照）
- 膜融合发生在**质膜**（主线）或**内体膜**（备选），与核膜无关
- 病毒体**必须画出刺突冠**，且不是光滑球体（囊膜带噪声位移，外形不规则）
- 刺突是**三聚体**（S1 含 NTD 与 RBD、S2 含融合肽与 HR1/HR2），不是单根尖刺
- 复制发生在**双膜囊泡**内，装配在 **ERGIC**，释放靠**胞吐**而非"细胞爆裂"

### 自动化验收

```bash
npm run build
npm run verify        # = scripts/acceptance.ps1：构建 → 无头截图 → 页面内自检 → 像素分析
npm run shots:preview # 把截图转成字符画，直接在终端里看构图
```

`?selftest=1` 会把 `p` 从 0 扫到 8 共 160 个采样点，逐点核对：几何无 NaN、融合前病毒体
留在细胞外、**RNA 不进入细胞核**、脱衣壳后基因组在细胞质、融合孔时序、刺突数量区间、
单链单管、渲染预算。当前状态：**高画质与中画质均 8/8 通过**。

`scripts/analyze-shot.mjs` 会解码截图并统计亮度与四种约定配色的像素占比，
把"深色背景 + 关键分子荧光高亮"这类视觉要求也变成可比对的数字。
