# GREENFALL · 绿蚀纪元

**体素建造（Minecraft 骨架）× 绿植吞噬的丧尸末世（生存骨肉）**
零依赖、单页、浏览器直接运行。所有贴图、音效、地形与建筑都由代码程序化生成，没有一个外部资源文件。

> 世界不是被炸平的，是被**长满**的。
> 混凝土裂缝里挤出巨藤，医院走廊被苔毯覆盖，高架桥墩上垂着几十米长的藤蔓。
> 游荡者只是这片绿色里最不重要的麻烦 —— 真正会杀死你的是脱水、失温、感染和一把断掉的斧子。

## 立刻开始

**方式一（最省事）**：双击 `index.html`。
**方式二（推荐，避免个别浏览器对 `file://` 的限制）**：

```bash
node serve.mjs          # 然后打开 http://127.0.0.1:8123/
# 或
npm start
```

需要支持 **WebGL2** 的浏览器（Chrome / Edge / Firefox 近年版本都可以）。
第一次进入会生成出生点周围 25 个区块，约 1 秒。**点击画面**锁定鼠标即可行动。

### 开局 60 秒（照着做就不会卡住）

1. 面朝营地**南边的碎石滩**，左键刨砂砾 → 得到「砂砾」和「燧石」（多刨几块，要 6 份砂砾）
2. 左键撕营地周围的**高草** → 「植物纤维」（要 6 根）
3. 按 `C` → 徒手：**纤维绳** ×2（每条 3 纤维）、**木棍** ×2（用开局的树枝）、把砂砾合成**燧石**
4. 还是 `C` → 徒手：**石斧**（燧石 3 + 木棍 2 + 绳 2）。**从这一刻起你才能砍树**
5. 顺手做**篝火堆**（树枝 4 + 碎石 4 + 落叶 2），放下点火；用开局的**空罐头**在火上煮那瓶生水
6. 搜刮营地的补给木箱和帐篷（右键），拿到手绘地图后按 `M` 看世界

卡住了就按 `J` 看任务，每个任务都写了下一步和提示。

## 它和 Minecraft 有什么不一样（"更贴近现实"的部分）

这是本作的核心设计线：**手不是工具**。

| MC 的做法 | 这里的做法 |
|---|---|
| 徒手打树 | **不行**。木头必须用斧，石头必须用镐，泥沙用铲，金属用撬棍/切割器，隔墙用锤，铁丝网用断线钳 |
| 无限手挖石头 | 石头 `tier 1`、钢筋混凝土 `tier 3`。石镐撬不动钢筋，得先炼钢 |
| 方块能悬空放 | **必须有依托**：新方块至少要贴着一个已有方块，植物/火把必须放在实心面上 |
| 喝水随便喝 | 生水有 **60% 概率生病**。必须用锅煮沸，或做手压净水器（消耗活性炭滤芯） |
| 只有饥饿 | **饥饿 + 口渴 + 体温 + 潮湿 + 体力 + 疲劳 + 疼痛 + 疾病 + 流血 + 感染** 十项独立推进 |
| 食物永不变质 | 食物有新鲜度，会腐败；腌制/晾干（肉干）能长期保存 |
| 挨打只掉血 | 咬伤会**流血**并累积**感染度**，感染到 100 直接结束。碘伏→抗生素→抗孢血清→疫苗，越早越好 |
| 工具无损 | 全部工具/武器/护具有耐久，会断；磨石、缝纫包、综合修理包可以修 |
| 背包无限 | 格数由背包决定，**负重**超限会大幅拖慢移动并疯狂掉体力 |
| 怪物无脑冲 | 游荡者靠**声音与光**发现你。奔跑、挖掘、枪声、篝火都会引来它们；铺木地板走路更安静 |
| 徒手抓任何东西 | 徒手掰碎玻璃、巨藤、铁蒺藜会**割伤流血**，戴劳保手套才免疫；工装靴免疫扎脚 |

### 冷启动路线（被测试保证不会死锁）

```
徒手撕草 → 植物纤维 → 搓纤维绳
徒手刨砂砾 → 燧石 + 从砂砾里挑出碎石块
徒手掰树枝 → 木棍
  ↓
石斧（燧石×3 + 木棍×2 + 绳×2）  ← 第一件真正的工具
石镐 / 燧石刀 / 石锤
  ↓
斧头砍原木 → 木板 → 工作台 → 篝火（需火柴/打火机/钻木弓）
黏土 + 碎石 → 土窑 → 木炭 / 红砖 / 生石灰 / 玻璃
  ↓
红砖×16 → 锻炉 → 铁锭 → 铁斧铁镐撬棍砍刀…
  ↓
【图纸】炼钢 / 枪械维护 / 离网供电 / 野战制药 / 净水工程 / 复合护甲 / 温室农业 / 长波通讯
```

八条科技线全部靠**搜刮到的图纸**解锁 —— 这就是"自由拓展"的进度设计：
你不是按等级解锁，而是按**你走到过哪里**解锁。

### 绿蚀都市：破败高楼群

`genHighrise` 是专门为"被绿植吞掉的城市"写的生成器，一栋楼包含：

- **玻璃幕墙**：每 5 格一根钢筋角柱，柱间是窗下墙 + 两排幕墙玻璃
  （破碎 / 污浊 / 淡绿镀膜四种随机混合），楼层越高整片脱落得越厉害
- **核心筒**：贯通全楼的爬梯（实测最长连续 40 格），能一路爬到屋顶，室内隔断永不堵住它
- **塌层剪切**：约 42% 的楼有一整个角被削掉，暴露出楼板断面与断口钢筋
- **屋顶**：女儿墙、楼梯出屋面小屋、水箱 / 空调机组 / 桅杆航空灯三选一，
  以及 **72% 概率的屋顶花园** —— 腐殖土、野草、灌木，还有真的从楼顶长出来的小树
- **绿植侵蚀**：四个角有巨藤从地面爬到 60–85% 楼高；窗洞垂藤密度随高度递减
  （底层近乎绿幕，顶层只剩零星几缕）；低层混凝土苔化、室内苔毯蕨类荧光苔；底部一圈瓦砾与野草
- **室内**：轻钢隔断、文件柜 / 储物柜 / 行李箱 / 书架战利品，顶层核心筒旁 55% 有保险柜（爬上去的奖励）

`genStreetGrid` 铺出车道 + 人行道 + 路灯 + 行道树（花坛里长疯了）+ 车骸，
`genCityBlockFill` 把每个街区随机填成"占满街区的塔楼 / 两栋窄塔 / 裙房+塔楼 / 野化废墟"四种形态。

新港 CBD 实测：基准 y=38，最高 y=89（**51 格 ≈ 13 层**），幕墙玻璃 6969 块（20 格以上高空 2255 块），
绿植 35951 块（24 格以上 7245 块），路面 3262 块，生成 16.7ms/区块。

## 生存系统细节

- **体温**：由生物群系基准温度 + 日照 + 昼夜 + 降雨 + 海拔 + 附近火源 + 衣物保暖 + 潮湿度共同决定。
  < 34.5℃ 开始失温掉血，> 39.6℃ 中暑。雨衣、篝火、屋顶、热汤都有用。
- **潮湿**：下雨/涉水会持续上升，火边和室内会下降。湿透后夜里非常危险。
- **感染**：被咬（受装备"防撕咬"减免）、孢子区（受防毒面具减免）、脏绷带都会累积。
  会缓慢自我恶化，睡觉时加重。疫苗给 240 秒免疫窗口并压制感染。
- **噪音**：脚步（受鞋/地板/负重/潜行影响）、跳跃、挖掘、破坏、枪声都会生成噪音事件，
  游荡者按听觉半径 × 噪音强度决定是否转入"追踪"。响铃诱饵可以把它们引开。
- **僵尸低存在感**（按需求设计）：默认密度 **55%**，且夜间/城区权重远高于白天/野外。
  三种变体：游荡者（慢）/ 苔壳者（厚甲高感染）/ 奔行者（快而脆，稀有）。
  设置里可以把密度从 0% 调到 200%。
- **真正的日常威胁**：野狗（最多 2 只一群）、野猪（受攻击才反击但很痛）、拾荒匪（会用武器）、
  孢子云（静态区域伤害）、失温、脱水、食物中毒、坠落、碎玻璃与铁蒺藜。
- **追击冷却（有喘息时间）**：每种敌人都有"最长连续追击秒数"和"放弃后的锁定冷却"，
  野猪 5s/18s · 野狗 7s/15s · 奔行者 16s/10s · 拾荒匪 15s/12s · 游荡者 26s/6s · 苔壳者 30s/5s。
  掠食者放弃时会有明确提示；血量掉到 30% 左右的野生动物会直接认输逃跑。
  另外掠食者成群刷新后有 55–105 秒的全局冷却，同时存在的敌对生物上限为 7 只 —— 不会被无限围攻。
- **睡觉**：床可设为重生点；附近有敌人时睡不着；睡眠恢复疲劳与生命，消耗食水，加重感染。

## 主线

1. **睁开眼** — 做石斧 + 喝一次干净水
2. **第一夜** — 点起篝火并活到第二天
3. **工具时代** — 工作台 + 石镐
4. **铁与火** — 锻炉 + 第一块铁锭
5. **拼凑真相** — 收集 5 张手写笔记
6. **权限** — 拿到任意钥匙卡
7. **四个零件** — 功放电子管 / 调谐主板 / 定向天线 / 稳压模块
8. **把信号发出去** — 在长风电波塔装好四件并通电，按下发送

支线：一个家（设重生点）、重新种地（收获 8 份）、绘制这片土地（发现 8 处地标）、
一线希望（拿到疫苗）、猎手（击杀 12）、钢的时代。

**两种结局**：带着疫苗发信号（结局 A：一线希望）/ 空手发信号（结局 B：把门开着）。
发完信号后世界继续，可以一直玩下去。

## 自由拓展（MOD）

复制 `mods/example-mod.js` 改个名字，在 `index.html` 里加一行 `<script>` 就行。
**所有注册调用必须在 `GF.boot()` 之前**（即脚本加载阶段）。

```js
GF.registerMod({
  name: 'my-mod',
  setup(GF) {
    // ① 贴图（程序化绘制，可用 P.bg/px/speckle/blobs/brick/planks/tiles/cracks/plant/hangVine…）
    GF.Atlas.addTile('my_tex', (P) => { P.bg('#334422'); P.speckle(['#556633'], .5); });

    // ② 方块（tool:null 才能徒手采集；tier 0徒手 1石器 2铁器 3钢/动力）
    GF.Blocks.define('my_block', {
      name: '我的方块', tex: 'my_tex', hard: 3, tool: 'pick', tier: 1, light: 8,
      drops: [GF.Blocks.drop('my_item', 1, 2)],
    });

    // ③ 物品
    GF.Items.define('my_item', '我的物品', 'res', 0.5, 20, '说明文字', { place: 'my_block' });

    // ④ 科技解锁项 + 配方
    GF.Recipes.defineUnlock('my_tech', '我的技术');
    GF.Recipes.define('my_item', 2, [['iron_ingot', 1], ['fiber', 4]], 'workbench', 8,
      { unlock: 'my_tech', need: 'hammer', needItem: 'pot', fuel: 0 });

    // ⑤ 战利品表
    GF.Landmarks.addLoot('tools', [{ item: 'my_item', w: 3, min: 1, max: 2 }]);

    // ⑥ 定制地标（可复用内置生成器 GF.Landmarks.gen.house/tower/hall/road/camp/underground/field…）
    GF.Landmarks.addLandmark({
      key: 'my_place', name: '我的据点', x: 300, z: 300, r: 40, icon: '★', noVeg: true,
      desc: '地图与日志里会显示这段描述',
      build(b) {
        GF.Landmarks.gen.house(b, b.x, b.z, 11, 9, 2, { wall: 'brick' });
        b.loot(b.x + 2, b.ground(b.x + 2, b.z + 2) + 1, b.z + 2, 'crate_supply', 'supply', ['my_item']);
      },
    });

    // ⑦ 无限刷新的程序化小据点
    GF.Landmarks.addPOI({ key: 'my_poi', w: 6, build(b, x, z, rnd) { /* … */ } });
  },
  ready(game, GF) {
    // 运行期钩子：block:set / block:placed / block:broken / entity:die / craft /
    //             player:hit / player:death / day:new / weather / toast / noise …
    GF.bus.on('day:new', (d) => game.ui.toast('第 ' + d + ' 天'));
  },
});
```

**建造器 API**（`build(b)` 里的 `b`）：
`b.set/get/ground/fill/fillMat/walls/clearBox/forXZ/part/scatter/overgrow/loot/rnd/hash`，
`b.B` 是方块 id 表，`b.x/b.z/b.y` 是地标中心与基准高度。
`b.forXZ` 与 `b.fill` 会**自动裁剪到当前区块**，这是保持生成性能的关键 —— 写大范围循环时请用它们。

**图集剩余 44 格**可供模组使用（`GF.Atlas.freeSlots()`）。

## 测试

```bash
npm test        # 三套无头测试全跑（82 项）
npm run check   # 数据层交叉引用（贴图/掉落/配方/放置目标是否都存在）：13 项
npm run sim     # 无头玩法模拟：52 项
npm run draw    # Canvas 桩 + GLSL/手感静态校验：17 项（实跑 212 张贴图 + 340 个图标共 3.2 万次绘制调用）

# 可选：真实浏览器端到端自测（需要本机装有 Edge / Chrome）
npm start &     # 先起服务器
npm run e2e     # 用 CDP 驱动无头浏览器打开 tools/e2e.html，跑完 20+ 项在线自测后回传报告
```

`tools/e2e.html` 是一份**在真实浏览器里跑的自测页**：启动游戏 → 等世界生成 → 检查渲染三角形数、
逐个打开全部面板、挖掘、放置、合成、进食、装备、开箱、近战击杀僵尸、受击流血感染、切到夜间、
下雨粒子、存档往返、死亡与重生、MOD 内容、`gl.getError()`，最后汇总 JS 运行时错误。
也可以直接在浏览器里打开 `tools/e2e.html` 手动看报告（左上角绿色文字）。

> 注：本项目开发环境的浏览器渲染进程受沙箱限制，`npm run e2e` 在该环境下无法执行；
> 在普通机器上可以正常运行。无头的 59 项测试不依赖浏览器，任何环境都能跑。

`simulate.mjs` 覆盖的关键回归（沙箱里注入固定种子的 `Math.random`，结果完全可复现）：

- 区块生成 / 光照分布 / 网格化顶点一致性 / 射线检测 / 放置破坏 / 增量存档
- **开局资源的空间可达性**：出生点 3×3 区块内地表徒手可采的砂砾/碎石 ≥12 处、纤维源 ≥20 处；
  并在世界四个远端坐标各验证一次（保证"没有斧子也能开局"不只是配方上成立）
- **31 处地标全部实际建造一遍**，统计人造方块数量，任何异常直接失败
- 堆叠分堆与溢出返回值、工具耐久归零销毁、背包扩容与负重上限、护甲汇总
- **合成链死锁检测**：从"什么都没有"开始 BFS 推演整棵科技树
  （冷启动 10 项 / 中期 12 项 / 图纸后 18 项必须可达；且钢、弹药、抗生素等必须被图纸正确锁住）
- 禁止徒手挖树挖石、工具等级门槛（石镐不能拆钢筋混凝土）
- 饥渴衰减、生水 60% 致病率、毒菇中毒、感染累积致死、血清压制、失温掉血、睡眠恢复
- 16 张战利品表全部有产出、容器懒加载与保底物品、掉落耐久范围
- 僵尸感知追击命中、动物逃跑、击杀掉落、玩家重力落地
- **操作手感**：A/D 的移动基向量必须与 `M4.lookAt` 得出的"屏幕右"逐位吻合（防左右颠倒）；
  地面摩擦（6 m/s → 0.35 m/s 需 < 0.5s、滑行 < 0.75 格）；空中仍保留惯性（冲刺跳可跨 ≈2.8 格）
- **追击冷却**：野狗必须在 `chaseMax` 内放弃、进入冷却、且冷却期内即使看见玩家也不重新锁定；
  重伤动物转为逃跑；掠食者权重、刷新冷却与敌对上限三重限制
- **破败高楼群**：CBD 必须长出 ≥30 格的高层、幕墙玻璃总量与 20 格以上高空玻璃都要达标
  （专门盯死"柱距判断把整面墙当柱子导致一块玻璃都没有"这个 bug）、核心筒爬梯连续 ≥20 格、
  屋顶花园在 24 格以上有植被、街网铺到位、城区生成 <60ms/区块
- 任务前置链推进、14 篇笔记完整、存档往返（方块改动 / 装备 / 地图缩略图）

`dom-smoke.mjs` 额外做了**渲染层与手感的静态校验**：提取 10 段 GLSL，检查 `#version` 位置、
`precision`/`out` 声明、顶点 `out` 与片元 `in` 逐个对应、JS 里引用的 28 个 uniform 与 5 个 attribute
是否都在着色器中声明、括号配对、有无误用 GLSL ES 1.0 语法（`gl_FragColor`/`attribute`/`varying`）、
`BLEND` / `depthMask` / `CULL_FACE` 的状态开关是否成对；以及粒子尺寸是否走"世界米 × 透视缩放 + 像素上限"
（防止碎屑大得像方块）、移动右向是否等于 `cross(前向, 上)`、地面阻尼系数是否够高且与帧率无关。

## 性能说明

- 区块 16×96×16，`Uint16Array` 存储；地形生成约 **18–34ms/区块**，
  以时间预算流式生成（默认每帧 ≤7ms 生成 + ≤9ms 网格化），不阻塞画面。
- 网格化带 **环境光遮蔽（AO）** 与四邻域光照平滑，顶点格式 pos(f32×3) + uv(f32×3) + 光照(u8×4)。
- 洞穴使用 4×4×4 降采样噪声场 + 三线性插值（比逐体素 fBm 快约一个数量级）。
- 地标查询使用 128 格粗网格空间索引，把逐列 O(地标数) 降到 O(1)。
- 默认视距 8 区块 ≈ 128 格（设置里 3–14 可调，看 CBD 天际线可以往上调），远处区块自动卸载但保留玩家改动。
- HUD 分频刷新：状态条每帧、其余 8Hz，目标信息按内容变化才重写 DOM。

## 存档

自动存到浏览器 `localStorage`（键 `greenfall.save.v1`），`F5` 手动保存、`F9` 读取，关闭页面时也会存。
只保存**玩家改动过的方块**（增量）、容器状态、地图缩略图、背包、状态、任务与设置，
因此存档很小，而世界随时可以由种子重新生成。设置面板里有"新游戏（换种子）"。

## 已知取舍

- 合成是**即时完成**的（消耗体力代替耗时），配方上的秒数目前作为体力消耗与说明展示。
- 掉落物不是独立实体：背包放不下时会在原地生成一个"遗弃背包"容器，点开就能拿。
- 光照跨区块传播有一帧延迟（边界处会在下次网格化时收敛）。
- 电力系统是"附近有发电机/太阳能板 + 有燃料"的简化判定，没有做完整线路。
- 没有多人联机。
