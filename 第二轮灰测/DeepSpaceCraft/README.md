# DEEP SPACE CRAFT · 深空方块

**《我的世界》方块玩法 × 《无人深空》星际探索** 的融合网页游戏。
零依赖、零素材、零联网 —— 纯 WebGL2 + WebAudio 实时程序化生成，双击 `index.html` 即玩。

## 快速开始

1. **双击 `index.html`**（或 `启动游戏.bat`），用 Chrome / Edge 打开。
2. 点击任意位置启动音频核心，看完开机自检。
3. 「开始新宇宙」→ 你在太空中 —— 对准星球，按住 **W**（加油门）+ **Shift**（脉冲引擎）俯冲，
   **穿过大气层燃烧 → 冲破云层 → 自动着陆**。
4. 出舱后就是方块世界：采矿、建造、扫描、精炼、合成、起飞、曲速。

> 存档自动写本地（菜单内可手动保存），标题界面可「继续旅程」。

## 玩法循环（NMS 味）

- **进入大气层**：俯冲 → 橙红等离子燃烧 + 镜头抖动 + 音效渐变 → 白光破云 → 悬停降落 → 行星信息卡打字机展开。
- **起飞**：点火 → 爬升 → 天空渐变为星空 → 回到星系。
- **曲速**：曲速电池（铟+钠合成）→ 星系图选目标 → 充能/隧道/到达三段式跳跃，26 个程序化星系。
- **生存四表**：生命 / 护盾 / 氧气 / 危险防护；按群系有高温/严寒/毒性/辐射伤害；钠充防护、氧气罐补氧、医疗包回血。
- **9 种星球群系**（lush / toxic / frozen / desert / radioactive / exotic / barren / volcanic / ocean），
  各有专属天空配色、地形、方块组、天候与大气颜色。
- **经济**：发现星球/扫描星系得单位，精炼提纯、合成科技（曲速电池、起飞推进剂、发光面板……）。
- **死亡**：生命归零后在飞船处重生。

## 技术要点

- **零依赖**：不 fetch、不 import、无 CDN、无素材文件。57 种 16×16 方块贴图全部 canvas 程序化像素画；
  86 个音效 + 6 场景音乐全部 WebAudio 实时合成（含 10 材质 dig/break/place/step、引擎、曲速、大气摩擦、洞穴/水下氛围）。
- **体素引擎**：16×96×16 区块流式生成（约 14ms/区块）、MC 手感平滑光照（天光+方块光 BFS）、
  逐面 AO、破坏裂纹 10 级贴图、水面顶点波浪、视锥剔除、泛光/暗角/色差/扫描线后处理。
- **太空渲染**：视线方向程序化星空（多层星点+十字星芒+星云纤维+银河带）、fbm 星球（海洋/极冠/昼夜终结线/
  夜面城市灯光/云层/Fresnel 大气光晕/环带）、恒星日冕、曲速隧道、3500 实例化太空尘埃速度线。
- **过渡动画**：进入 = 俯冲(1.5s)→燃烧(2s)→白光(0.4s)→穿云(1.2s)→降落→停机；全程约 7.5 秒，世界流式生成不卡帧。
- **存档**：`localStorage['dsc.save.v1']`，含银河标记、背包、生存数值、按区块稀疏存储的方块改动。

## 调试与自检

- `?auto=1&scene=planet&p=0` —— 直接降落到第 p 颗行星
- `?auto=1&scene=entry&p=1` —— 直接播放大气层进入动画
- `?selftest=1` —— 渲染 + DOM 自检（readPixels 统计画面 + UI 契约断言，结果写进页面与标题）
- `?audiotest=1` —— 音频自检（OfflineAudioContext 离线渲染全部 86 个音效，逐个报峰值/RMS；**需在真实浏览器里跑**，无头虚拟时钟下会停在 RENDERING）
- `?lowfx=1&dbg=1` —— 低配 + 调试读数

命令行（需要 Node）：

```
node tools/check.cjs        # 模块契约 / 音效名 / 贴图名 / DOM id / CSS 覆盖 / GLSL / 地形逻辑
node tools/audioaudit.cjs   # 音频图审计：86 个音效是否都有"源→非零增益→destination"可听通路
node tools/png.cjs shot.png # 截图像素统计（自写 PNG 解码）
```
