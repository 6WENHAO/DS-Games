# 方块冒险 · Block Adventure

**我的世界画风的马里奥式横版闯关游戏**。纯 HTML5 Canvas + 原生 JS，
**零依赖、零构建、离线可玩** —— 双击 `index.html` 就能开始。

四关：青翠平原 → 地下洞穴 → 下界烈焰 → 末地终点。内容不多，重点全部压在**模型精度与美观**上。

---

## 开始玩

双击 `index.html`（Chrome / Edge / Firefox 均可）。

| 操作 | 说明 |
| --- | --- |
| `A` `D` / `←` `→` | 左右移动 |
| `空格` / `W` / `↑` | 跳跃（**长按跳更高**，松手即止） |
| `Shift` | 疾跑 |
| `W` `S` | 在梯子上攀爬 |
| `ESC` / `P` | 暂停（切窗口自动暂停） |
| `M` | 静音 |
| `1`~`4` | 菜单里直接选关 |

**玩法**：踩在怪物头上消灭它们（史莱姆会分裂成两只小的）·
从下方顶金色奖励块掉出绿宝石/钻石/苹果 · 苹果回血 · 火把是存档点 ·
抵达旗帜（第 4 关是末地传送门）过关。岩浆与地刺一碰就掉血，掉出世界会摔死。

## 美术：为什么看起来"精细"

这次的重点。全部素材都是**运行时用代码逐像素画出来的**，没有一张图片资源，
但用了几层真正影响观感的处理：

**1. 每个部件都有立体色阶** —— `box()` 画任何一块都会自动生成
「顶部高光 / 左侧亮面 / 底部与右侧阴影」四道边，色阶由 `shade()` 从基色算出，
所以角色的躯干、手臂、靴子、木板、圆石都有体积，而不是纯色方块。

**2. 三道统一后处理**（`finish()`）
- `outline()` —— 逐像素扫描 alpha，给精灵描 1px 外轮廓，任何背景上都清晰
- `aoShade()` —— 越靠下越暗的环境光遮蔽，立刻有"站在地上"的重量感
- `topLight()` —— 顶部若干行提亮，模拟天光

**3. 方块自动拼接** —— `PX.tile(kind, mask, variant)` 按四邻掩码出图：
草皮只长在暴露的顶面（被埋住就是纯泥土）、原木只有顶面露出时才显示年轮、
暴露的顶边加亮线、暴露的底边压暗、块与块之间留缝，地形轮廓一眼可读。
每格还带 4 种随机变体，避免平铺重复感。

**4. 侧视角骨架 + 真正的跑步循环** —— 角色是 24×40 的侧视骨架，
四肢沿 X 前后摆动、抬腿时屈膝变短，跑步 6 帧 + 待机 2 帧 + 跳/落/落地/受伤/欢呼共 14 帧姿态。
脸上有眉骨阴影、白眼球 + 虹膜 + 高光、鼻梁受光、颊部亮面。

**5. 场景层次** —— 每个主题有独立的天空色带（平原带太阳、末地带星空、下界带飘灰）、
两层视差剪影（远山/近树林、岩层/钟乳石、地狱岩柱/岩浆瀑布、悬浮岛）、
草地上程序化长出树/花/草丛、洞穴天花板挂钟乳石、云层单独视差。

**6. 光照** —— 洞穴/下界/末地用"暗场挖洞"：整屏铺主题色，再用
`destination-out` 径向渐变在玩家和萤石/岩浆位置挖出光圈，最后叠一层暗角。

## 项目结构

```
index.html        页面 + MC 风格 GUI
css/style.css     浮雕面板、关卡卡片、HUD
js/core.js        数学/噪声、输入（含跳跃缓冲）、WebAudio 程序化音效
js/art.js         全部美术：立体色阶 box() + 描边/遮蔽/顶光后处理
                  + 自动拼接方块 + 侧视角色骨架 + 天空与视差层
js/levels.js      4 关地图（地面用「段落规格」生成，避免手数字符出错）
js/entities.js    玩家物理与动画、5 种怪物 AI、道具、粒子
js/game.js        关卡构建、瓦片查询、相机、渲染管线、光照、HUD、状态机
tools/            验收工具（见下）
preview/          渲染出的素材表与实机画面 PNG
```

## 手感（平台跳跃的命脉）

- 可变跳跃高度：松手立刻削减上升速度
- **土狼时间** 0.09s：踏出平台边缘后仍可起跳
- **跳跃缓冲** 0.13s：落地前提前按跳也会生效
- 地面/空中分别的加速度与摩擦力，疾跑 212 / 走 142
- 单向木平台：可从下方穿过、从上方落下站住
- 踩头判定带 14px 宽容，踩中后弹起 300

## 开发与验收工具（零依赖 Node 脚本）

```bash
npm test          # 无头冒烟测试（见下）
npm run preview   # 用自写光栅器把素材表与真实游戏画面渲染成 PNG
npm run art       # 全部素材的数值体检（描边/明暗方向/色阶数）
npm run list      # 列出所有素材名

node tools/ascii.js idle --luma      # 用亮度 ramp 在终端"看"精灵的明暗与形体
node tools/ascii.js dragon --sil     # 只看剪影（判形状）
node tools/ascii.js run --anim --sil # 逐帧看动画
```

`tools/env.js` 是从零实现的**纯 JS 2D 光栅器 + PNG 编码器**
（仿射变换、逐像素逆变换采样、alpha 混合、线性/径向渐变、`destination-out`、
以及真正可用的 `getImageData`/`putImageData` —— 描边后处理就依赖它）。

### `npm test` 会验证什么

1. **素材**：160 张精灵/瓦片全部生成成功；精灵描边覆盖 57/60；上亮下暗（体积感）139/160
2. **关卡数据**：行长一致、字符合法、终点存在
3. **可达性 BFS**：用保守跳跃模型（水平 ≤5 格、上升 ≤4 格）从出生点搜索，
   确认**四关的终点都真的走得到**，并报告可达格数
4. **地形可通过性**：无敌机器人用真实物理从头跑到尾 —— 四关全部走到终点
5. **普通机器人**：3 颗心、会疾跑会跳障碍 —— 通关 3/4（第二关被地刺+骷髅打死，属正常难度）
6. **渲染管线**：跑 30 帧不抛错，并统计画面颜色数与亮度，防止黑屏
