# ⚜ Altbrücken · 西式小镇 3D 模型

一个**完全程序化生成**的欧洲小镇立体模型：没有任何外部模型 / 贴图文件，所有砖墙、屋瓦、鹅卵石、玻璃、
水面纹理都是 Canvas 现场绘制，所有房屋、教堂、风车、火车都是代码「盖」出来的。

* 🧱 **26,000+ 个几何构件**，按材质合并为 **~590 个网格**（约 99 万三角面，569 个 draw call）
* 🏘 **8 个功能片区**，含 130 余栋建筑、300 余棵树、200 多个道具
* 🚶 **72 位会走路的镇民**（迈腿、摆身、偶尔停下聊天）+ 5 组马车板车 + 走动吃草的羊群
* 🌗 **完整昼夜循环**：太阳/月亮轨迹、星空、云、雾，天黑后窗户与路灯逐一亮起
* ⚙️ **40 余处持续动画**：3 座风车、水车、5 面塔钟、摆动的教堂大钟、蒸汽机车、帆船、晃动的招牌、炊烟、喷泉、飞鸟
* 🗺 界面：片区导览卡、镇域小地图（含视锥）、时刻滑杆、自动巡游

## 🚀 运行

ES Module 必须经 HTTP 加载（`file://` 会被浏览器拦），仓库自带一个零依赖静态服务器：

```bash
node server.mjs          # 然后打开 http://localhost:5173/
node server.mjs 8080     # 指定端口
```

> 需要 Node 18+ 与支持 WebGL2 的现代浏览器。three.js r166 已随仓库放在 `vendor/`，**完全离线可用**。

### 🖱 不想敲命令？双击 `西式小镇.html`

浏览器出于安全策略会拦截 `file://` 下的 ES Module 加载，所以仓库额外提供**单文件离线版**：

* `西式小镇.html` —— 全部 JS（含 three.js）与 CSS 已内联进一个文件，**双击即可打开**，无需服务器、无需 Node。
  * 想加参数一样可以：`file:///…/西式小镇.html?tod=21.5&cycle=0` 或 `?quality=low`
* 重新生成：`node tools/make-西式小镇.mjs`（打包 17 个模块为内联脚本）
* 打包验证：`node tools/verify-西式小镇.mjs`（Node 端对打包结果跑完整建模 + 40 帧动画，与 `smoke.mjs` 同口径）

### URL 参数

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `view` | 直接飞到某个片区 | `?view=cathedral` |
| `tod` | 指定时刻（0–24 小时） | `?tod=21.5` |
| `cycle=0` | 关闭昼夜自动循环 | `?tod=8&cycle=0` |
| `shadows=0` | 关闭阴影 | `?shadows=0` |
| `quality=low` | 低画质（关阴影 + 1x 像素比），老显卡/核显用 | `?quality=low` |

## 📁 结构

```
index.html            页面骨架 + importmap
styles.css            界面样式（暗色 + 金色，衬线标题）
server.mjs            零依赖静态服务器
vendor/               three.js r166 + OrbitControls + BufferGeometryUtils（离线）
src/
  main.js             渲染器 / 相机 / 分步加载 / 主循环 / 交互
  lib/
    rng.js            确定性随机（mulberry32）、地形噪声、插值工具
    textures.js       13 种程序化 Canvas 贴图（砖/瓦/石/木/鹅卵石/草/水/茅草/彩窗/招牌…）
    geom.js           几何工厂（盒/坡屋顶/四坡/金字塔/拱墙/台阶/路带…）+ Sculptor
    materials.js      86 种共享材质 + 夜间发光材质表
  world/
    terrain.js        地形高度场、河道、街道网络、远景森林
    props.js          40 余种配件（路灯/长椅/水井/喷泉/树/篱笆/墓碑/摊位/船/动物/居民…）
    buildings.js      建筑生成器（民居/联排/教堂/市政厅/风车/水磨/谷仓/车站/工厂/城门…）
    motion.js         会动的对象（走路镇民/马车/羊群/野鸭/划桨小船/柱式风车）
    districts.js      片区元数据（范围、说明、机位）
    town.js           总装：逐个片区摆放 + 行走路线 / 车马路线
  fx/
    sky.js            天空球 shader、太阳月亮星空云、昼夜调色与光照
    particles.js      单 Points 粒子系统（炊烟 / 水花 / 灯晕 / 飞鸟）
  ui/ui.js            导览卡、控制台、小地图、状态栏
tools/                自检工具（见下）
```

### 核心设计：Sculptor（雕刻器）

`src/lib/geom.js` 里的 `Sculptor` 是整个项目的骨架，解决两个问题：

1. **变换栈** —— `s.push(x, y, z, ry)` / `s.pop()`，于是可以「在局部坐标里盖房子，再整体摆到街边」，
   所有建筑生成器都只关心自己的局部坐标；
2. **按材质合并** —— 所有静态图元先按材质分桶，`finalize()` 时用 `mergeGeometries` 合并，
   于是 26,000 个构件只产生 ~460 个 draw call。需要动画的部件走 `s.attach()` + `s.onUpdate()` 单独保留。

所有图元的局部原点统一在**底面中心**（球体/圆环在几何中心），UV 按「世界尺寸 ÷ tile」现算，
所以贴图密度在任何尺寸的墙面上都一致，不会被拉伸。

## 🔬 自检工具

因为是纯程序化建模，仓库带了三个脚本用来「无人验收」：

```bash
node tools/smoke.mjs      # 用最小 DOM 桩在 Node 里跑完整建模 + 40 帧动画
                          # 报告构件数/三角面/材质数，检查 NaN 顶点、缺 uv、合并失败、片区越界
node tools/make-西式小镇.mjs   # 重新打包单文件离线版 西式小镇.html
node tools/verify-西式小镇.mjs # 对打包产物跑同样的建模体检（双击版自检）
node tools/diag.mjs farm  # 列出某片区最靠西/东/最高的网格（按材质名定位问题构件）
node tools/cdp-check.mjs "http://localhost:5173/?quality=low" tools/shot.png
                          # 无头 Chrome 真机跑一遍：收集控制台错误、读运行时统计、截图
node tools/png-stats.mjs tools/shot.png
                          # 把截图转成终端可读的亮度图 / 配色图 / 配色占比
```

## ⚡ 性能

| 项 | 数值 |
| --- | --- |
| draw call | ~569 |
| 三角面 | ~99 万 |
| 纹理 | 60 张（全部 Canvas 生成，≤256²） |
| 着色器程序 | 18 |
| 构建耗时 | 0.6–1.0 s（首帧前一次性） |

72 位镇民只用 **10 个 draw call**：8 种衣着各一个 `InstancedMesh`（顶点色区分布料/皮肤/帽子），
双腿再各用一个共享的 `InstancedMesh`，每帧只更新实例矩阵。羊群与野鸭同理（各 1 个）。

阴影用单方向光 + 跟随视线焦点的自适应正交范围（90–460）；核显或老机器建议 `?quality=low`。

## 📐 坐标约定

* `+X` 东，`+Z` 南，`Y` 向上，1 单位 = 1 米，小镇尺度约 400 × 400 m
* 中央广场在原点，主街沿 `x=0` 南北贯通，东西大街沿 `z=0`
* 河流自西向东横穿北部（`z ≈ -88 + 6.5·sin(0.0115x)`），石桥在 `x=0` 处跨河
* 建筑生成器约定：**原点 = 建筑底面中心，正面朝 `+Z`**；用 `facePos(face, u, w, d)` 在四面墙上开门窗
