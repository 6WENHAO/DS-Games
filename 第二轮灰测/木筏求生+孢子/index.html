怎么玩　先把压缩包整个解压出来（不要在压缩包里直接双击），然后打开这个 index.html，点上面任意一张卡片即可。
需要什么　只要一个现代浏览器（Chrome / Edge / Firefox），不需要联网、不需要装 Node， 也不需要任何账号。
声音　浏览器规定必须先有一次交互才能出声，所以点一下鼠标或按一下键之后音效才会响。
载入要几秒　所有贴图和音效都是打开时实时生成的（游戏里没有任何图片/音频文件）， 进度条走完就好，不是卡住。
存档　存在浏览器本地（localStorage），换浏览器或清缓存会丢。游戏里按 F5 手动存档。
如果画面打不开　极少数浏览器对本地文件限制较严。装了 Node.js 的话可以在本文件夹里执行 node serve.mjs，再访问它打印出的地址即可。
