# 网页 3D 游戏合集 · 木筏求生 + 孢子五阶段

两套纯前端、**完全离线**的网页 3D 游戏。不需要联网、不需要安装、不需要账号。

## 怎么玩

1. 把压缩包**整个解压出来**（不要在压缩包里直接双击）。
2. 双击 `index.html`，在页面上点想玩的那个。
   也可以直接双击 `raft-survival/index.html` 或 `spore/index.html`。
3. 打开后有几秒载入 —— 那是在实时生成所有贴图和音效，不是卡住。
4. 浏览器规定必须先有一次交互才出声，**点一下鼠标或按一下键**之后音效才会响。

浏览器：Chrome / Edge / Firefox 等现代浏览器都可以（需支持 WebGL）。

**如果本地文件打不开**（极少数浏览器限制较严）：装了 Node.js 的话，在本文件夹执行
`node serve.mjs`，然后访问它打印出的地址。

存档存在浏览器本地（localStorage），换浏览器或清缓存会丢。游戏内按 `F5` 手动存档。

## ① 木筏求生 Raft Survival

海上漂流生存。核心循环：抛钩打捞 → 扩建木筏 → 净水烤鱼 → 研究解锁 → 升帆找岛 →
潜水采矿 → 提防鲨鱼「布鲁斯」。

### 操作

| 键 | 作用 |
|---|---|
| `W A S D` | 移动，`Shift` 疾跑 |
| `空格` | 跳跃；在水中上浮 |
| `Ctrl` | 水中下潜 |
| 鼠标 | 视角 |
| **左键** | 使用手持物（挥锤 / 蓄力抛钩 / 砍伐 / 捅矛 / 舀水 / 抛竿 / 吃喝） |
| **右键** | 建造模式旋转朝向；持锤时拆除 |
| `E` | 交互（设施 / 采集 / 拾取） |
| `F` | 一键升帆 / 抛锚 |
| `Q` | 丢弃手中一格 |
| `1`-`8` / 滚轮 | 切换快捷栏 |
| `Tab` 或 `I` | 背包 |
| `C` | 合成　`B` 建造目录　`R` 建造时旋转朝向 |
| `Esc` | 暂停 / 关闭面板　`F5` 存档 |

### 上手提示

* 一开始拿着**打捞钩**，按住左键蓄力、松手抛出，命中海面漂来的木板堆就能拉回来。
* 有了木板就按 `B` 打开建造目录选**地基**，把木筏扩大。
* **千万别喝咸水**（会掉血、更渴）。用杯子对着海面舀咸水，再造**简易净水器**烧成淡水。
* 生鱼有几率食物中毒，造**简易烤架**烤熟再吃。
* 鲨鱼来啃地基时，用**矛**捅它两三下就能赶走；被咬穿的地基会连上面的东西一起消失。
* 想去岛上就造**船帆**（配**舵轮**可以主动转向），到了岛边**抛锚**再上岸。
* 潜水前看一眼左下角**氧气条**。海草床和铜矿脉都在水下。

### 玩法系统

生存数值（血/饿/渴/氧）· 2 米网格建造（22 种建筑、地基有耐久）· 13 种设施（净水器、
烤架兼熔炉、收集网、集水器、储物箱、研究台、帆、舵轮、锚、种植槽、吊床、油灯、鲨鱼头颅）·
抛钩打捞与自动收集网 · 张力式钓鱼小游戏（5 种鱼）· 鲨鱼完整 AI（巡游/啃筏/追人/突袭/被打退/
被杀/重生，可用诱饵引开）· 程序化岛屿与 12 种采集节点 · 9 项研究解锁 20 条配方 · 6 种作物种植 ·
昼夜与晴/多云/雨/暴风雨 · 13 个任务 · 自动与手动存档。

## ② 孢子 SPORE · 五阶段

单细胞 → 生物演化 → 部落 → 文明 → 星际。五个阶段共用一套**可自由编辑的生物基因组**，
你捏出来的物种会一路跟到银河尽头。

通用操作：`WASD` 移动 · 鼠标视角/瞄准 · **左键**主行动 · **右键**次行动 · `E` 交互 ·
`1`-`9` 底部技能/命令条 · `P` 打开编辑器 · `Esc` 暂停 · `F5` 存档

> 主菜单有「**阶段跳转**」按钮，可以直接跳到任意一个阶段试玩（会自动生成一个随机物种）。

### 🦠 第一阶段 · 细胞

俯视潮池，**鼠标控制游动方向**，左键攻击。绿色碎块是植物、红色是肉 —— 你的嘴决定能吃哪种
（草食 / 肉食 / 杂食）。撞开发光的陨石、或吃掉带某种部件的细胞可以**解锁部件**。
按 `E` 花 DNA 进编辑器加装纤毛、鞭毛、尖刺、毒囊、电囊、喷射器。长到体型上限就能爬上陆地。

### 🦎 第二阶段 · 生物演化

第三人称 3D 大陆。两条路线都能推进演化：**攻击**（撕咬/冲撞/打击/吐射）或**社交**
（歌唱/舞蹈/魅惑/摆姿），技能等级由你装的部件决定。
对其他物种用社交技能会开始**结盟表演**：对方给出一串动作，你照着重复，连续三轮成功即结盟，
其成员可加入你的队伍。挖**骨骸**解锁部件，回**巢穴**按 `E` 恢复并交配进化。
地图外围有 1000 血的 **Epic 巨兽**。演化条满 → 部落。

### 🔥 第三阶段 · 部落

即时策略，**食物是唯一货币**。点选成员后右键下命令。四路食物来源：采集果树、鱼叉捕鱼、
狩猎野兽、围栏驯养产蛋。生小孩扩充人口，买石斧长矛开战、买乐器表演结盟。
解决全部 **5 个敌对部落** → 文明。

### 🏙️ 第四阶段 · 文明

行星地图。占领**香料喷口**赚钱，生产陆/海/空载具。开局选**军事**（武力占领）、
**经济**（花钱收购）或**宗教**（传教转化），各自解锁一种超级武器。
拿下全部 **10 座城市** → 星际。

### 🚀 第五阶段 · 星际

**银河视图 ↔ 行星视图**双级切换。8 种工具：扫描、牵引绑架、地球化改造、殖民、香料贸易、
激光导弹、修理补给、纪念碑。与外星帝国外交或开战，穿过 **Grox** 的封锁抵达**银河中心**。

## 目录结构

```
index.html            ← 双击这个（两个游戏的入口页）
vendor/three.min.js   three.js r149（唯一第三方库，已内置）
raft-survival/        木筏求生
spore/                孢子五阶段
serve.mjs             可选：本地服务器（仅在直接打开失败时才需要）
```

游戏里没有任何图片、音频、模型文件 —— 所有贴图由 canvas 程序化绘制，所有音效由 WebAudio
实时合成。整包除 three.js 外没有其他依赖，源码全部是可读的普通 JavaScript。
