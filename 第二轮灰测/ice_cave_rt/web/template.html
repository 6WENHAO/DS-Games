这个浏览器没有可用的 WebGPU

需要 Chrome / Edge 113+(或 Firefox 141+)。如果版本够新但仍然失败,通常是 硬件加速被关闭 或 显卡驱动被列入黑名单:
打开 edge://gpu / chrome://gpu 查看 “WebGPU” 一行; 在 edge://flags 里启用 #enable-unsafe-webgpu 后重启浏览器。

也可以直接跑原生版本(同一套 WGSL,Vulkan 后端):ice_cave_rt.exe --preset hero
