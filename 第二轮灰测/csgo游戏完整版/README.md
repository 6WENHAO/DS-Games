# CS:GO Web —— 网页版反恐精英（完整版）

纯前端、**零依赖、零外部素材**的 CS:GO 风格 3D FPS。渲染、贴图、音效、物理、AI、比赛规则全部从零手写，
打开浏览器即玩。

```
双击运行:  启动游戏.bat
或命令行:  node tools/serve.mjs
然后打开:  http://127.0.0.1:8123/
```

> 必须通过 http:// 打开（浏览器不允许 `file://` 加载 ES Module）。需要支持 WebGL2 的现代浏览器
> （Chrome / Edge / Firefox 最新版），并开启硬件加速。

## 玩法内容

- **模式**：竞技 MR12（先胜 13 局、半场交换、平局进加时）、休闲 MR8、死斗（无限复活比击杀）。
- **地图 4 张**：`de_dust2`（炙热沙城 II）、`de_mirage`（沙漠迷城）、`cs_office`（办公楼，改为炸弹模式）、
  `aim_arena`（对称竞技场，死斗）。
- **炸弹拆除**：C4 安放 3.2 秒、40 秒倒计时（滴答随剩余时间加速）、拆弹 10 秒 / 有拆弹器 5 秒、
  掉包可拾取、爆炸范围伤害。
- **武器 36 把 + 6 种投掷物 + 护甲/拆弹器**，数值贴近 CS:GO：
  伤害、护甲穿透、射速、弹匣、距离衰减、移速惩罚、击杀奖励一应俱全。
  - 30 发**真实喷射弹道**（AK 的"7 字"、M4 的碎抖、P90 的画圈），后坐力会同步推动视角。
  - 精度模型复刻 CS：站立 / 移动 / 下蹲 / 跳跃各有独立 inaccuracy，连射递增惩罚，开镜几乎归零。
  - 子弹**可穿墙**（按武器穿透力决定能穿几层、每层伤害衰减 48%）。
  - 命中盒：头 / 胸 / 腹 / 手臂 / 腿，倍率 4.0 / 1.0 / 1.25 / 1.0 / 0.75，头盔单独判定。
- **投掷物**：高爆（范围衰减 + 遮挡判定）、闪光（按视线夹角与距离算致盲时长，烟雾可挡）、
  烟雾（真实体积遮挡，会**同时挡住 Bot 的视线**、能灭火）、燃烧瓶 / 燃烧弹（持续伤害）、诱饵。
- **经济**：起始 $800、上限 $16000、胜负奖金、连败补偿五档（1400→3400）、
  下包 $300（团队 $800）、拆包 $300、各枪独立击杀奖励。
- **Bot AI**：4 档难度。自动导航网格 + A\* 寻路，会买枪、分点进攻、守角、
  下包/拆包、拉枪线点射、被闪后撤、听枪声支援、扔手雷、卡视角蹲射。
- **HUD**：血量护甲、金钱变动、动态准星（**间隙实时反映当前散布**）、旋转雷达（含烟雾/火焰/包点）、
  击杀提示、伤害方向指示、报点区域名、记分板、MVP、回合横幅。

## 技术实现

| 模块 | 说明 |
|---|---|
| `src/render/renderer.js` | 自研 WebGL2 前向渲染：方向光 + 2048 阴影贴图（PCF 3×3、纹素对齐防抖）、半球环境光、8 个动态点光、程序化天空（渐变 + 日晕 + FBM 云）、指数雾、ACES 色调映射、公告板精灵 / 贴花 / 曳光、独立近裁剪的第一人称模型通道 |
| `src/render/textures.js` | **24 张贴图 + 14 个精灵全部用 Canvas 2D 程序化生成**，可播种 PRNG 保证确定性，噪声环绕采样保证无缝平铺 |
| `src/audio/audio.js` | **119 个音效全部用 Web Audio 实时合成**（无任何音频文件）：34 把枪各有独立音色参数表、HRTF 3D 定位、总线压缩、并发限流 |
| `src/game/maps/build.js` | 声明式平面图编译器：只描述"哪里能走"，自动生成实心地板、0.5m 厚封闭墙壳、门窗开洞、楼梯与报点区域 |
| `src/game/navmesh.js` | 从几何体**自动生成**导航网格（0.5m 栅格、多层平台、蹲行通道识别、台阶可踩判定）+ 二叉堆 A\* + 视线路径平滑 + 出生点种子连通域剪枝 |
| `src/game/movement.js` | 复刻 Source 移动：`sv_accelerate 5.5` / `sv_airaccelerate 12` / `sv_friction 5.2`、空中转身、0.45m 自动上台阶、蹲伏高度过渡、落地伤害 |
| `src/game/world.js` | 轴对齐 brush 碰撞 + XZ 均匀网格加速、DDA 射线检测、内部面自动剔除（减少 ~20% 三角） |

## 自测工具

```bash
node tools/validate_map.mjs      # 地图校验：几何合法性、连通性、出生点、最长通视审计
node tools/smoke.mjs all         # 无头逻辑自测：真实跑 Game 主循环，检查 Bot/回合/性能
npm test                         # 两个都跑
```

`smoke.mjs` 用 `new Game(null, { headless: true })` 直接驱动**真实**的游戏主循环
（渲染/音频/DOM 全部替换为桩件），因此能在 Node 里回归测试 AI、经济、回合与物理。

## 已知取舍

- Bot 感知距离上限 55m，而 mirage / office 的中央长廊存在 60m+ 通视，
  因此 Bot 不会在出生点就隔着大半张图对枪（真人玩家仍可远程对狙）。
- Bot 只在导航网格覆盖的平面与楼梯上活动；需要"跳箱子"才能上的高点是玩家专属空间。
- 角色与武器都是方块模型（无骨骼蒙皮网格），动画为程序化关节旋转。
