# 紫云山古建群 · 体素中式建筑群（Three.js Voxel）

纯前端、无后端的 **3D 体素（Minecraft 风格）中国古典建筑群**场景。打开页面即自动推镜进场，
无需任何操作即可看到中轴对称院落全貌；可切换 **晨 / 午 / 昏 / 夜** 四种时辰光照。

所有建筑均由 **1×1×1 体素块程序化堆叠生成**（无外部模型、无贴图），
通过「相邻面剔除 + 每材质单个 InstancedMesh」把 11.3 万体素压到 **8.7 万可见块 / 38 次绘制调用**。

---

## 一、快速开始

```bash
# 1. 安装依赖（需要 Node ≥ 18）
npm install

# 2. 开发模式（热更新）
npm run dev            # → http://127.0.0.1:5173/

# 3. 生产构建 + 本地预览
npm run build
npm run serve          # → http://127.0.0.1:4173/   （或 npm run preview）
```

浏览器打开上述地址即可。首次进入会有约 5 秒开场推镜，随后进入缓慢自动环绕。

**交互**：拖拽旋转 · 滚轮缩放 · 右键平移 · 快捷键 `1`/`2`/`3`/`4` 切换时辰 · `R` 开关自动环绕。

**调试用 URL 参数**（便于截图与排查）：

| 参数 | 说明 | 示例 |
|---|---|---|
| `preset` | 初始时辰 | `?preset=dusk` |
| `view` | 机位：`hero`/`front`/`axis`/`side`/`close` | `?view=axis` |
| `nointro` | 跳过开场推镜 | `?nointro=1` |
| `rotate` | `0` 关闭自动环绕 | `?rotate=0` |
| `shadow` | 阴影贴图尺寸 | `?shadow=1024` |
| `dpr` | 像素比上限 | `?dpr=1` |
| `fog` | `0` 关闭雾 | `?fog=0` |

## 二、建筑群与空间布局

场地约 **152 × 194 体素**，中轴线为 `x = 0`，前（南）为 `z` 小的一端。七座建筑，主次分明：

| # | 建筑 | 位置 (x, z) | 屋顶形制 | 瓦作 | 顶高(体素) |
|---|---|---|---|---|---|
| ① | **山门** | (0, 14) | 庑殿顶 · 三门洞（中门可穿视） | 青瓦 | 27 |
| ② | **钟楼** | (−44, 32) | 两层 · 重檐攒尖顶 + 宝顶 | 绿琉璃 | 45 |
| ③ | **鼓楼** | (+44, 32) | 同上（内置鼓，与钟楼镜像） | 绿琉璃 | 45 |
| ④ | **西配殿** | (−44, 68) | 歇山顶（正脊沿 z，门朝中轴） | 绿琉璃 | 32 |
| ⑤ | **东配殿** | (+44, 68) | 歇山顶（镜像） | 绿琉璃 | 32 |
| ⑥ | **大雄宝殿** | (0, 100) | **重檐歇山顶** · 五层台基 + 月台 | 金琉璃 | **55** |
| ⑦ | **七级浮屠** | (0, 147) | 八角密檐塔 · 攒尖 + 塔刹相轮 | 金/青相间 | 67 |

**动线**：山门（三门洞）→ 御道（宽 15 体素，白石镶边）→ 前庭（铜鼎香炉）→
横向甬道分别通往钟楼 / 鼓楼、东西配殿 → 主殿月台踏道（4 级 + 御路石）→ 主殿 →
后院甬道 → 宝塔。四周由**红墙青瓦院墙**（x = ±64，z = 4…163）围合成三进院落。

**中轴对称度实测 99.18%**（对 54,577 块建筑构件做 x → −x 镜像比对，
残差来自钟 / 鼓陈设差异与随机植栽，见 `npm run smoke`）。

## 三、中式建筑做法（体素化）

* **屋顶举折曲线**：`roofInsets()` 用 `1-(1-t)^1.7` 生成逐层内收量 —— 檐口坡缓、近脊转陡，
  再按层间收量自动加厚瓦垄（`thickness = Δinset + 1`）以免仰视露空。
* **飞檐翘角**：四角沿对角线逐层外挑并抬升 3 格，末端置金色角兽 / 宝珠。
* **形制区分**：`hipInset = null` → 庑殿；给定值 → 歇山（山面冻结成博风板 + 山花）；
  `halfX = halfZ` 且层数收尽 → 攒尖；`buildOctRoof()` → 八角塔檐（含八条垂脊）。
* **脊饰**：正脊 + 两端吻兽起翘，各层转角连成金色垂脊 / 戗脊。
* **斗拱层**：额枋（暗木）→ 彩画枋（红）→ 斗拱（木，逐间向外挑出一格）+ 金色雀替点。
* **殿身**：外圈檐柱（形成外廊）内退一格砌红墙；朱漆板门带门钉门槛、直棂格心窗、金框匾额。
* **台基**：须弥座束腰 + 压边石；月台设望柱栏板石栏（踏道处留豁口）。
* **陈设**：石狮一对、华表一对、铜鼎香炉、假山、放生池（荷叶）、经幡杆、
  檐下宫灯与塔角风铃、御道石灯柱、松柏与阔叶乔木约 90 株、体素云 6 朵。

调色板（`src/voxel/palette.js`，共 38 种材质）：宫墙红、朱漆、木作、金 / 绿 / 青三色琉璃瓦、
汉白玉、青石铺装、草地苔痕、青铜、灯笼自发光等。

## 四、光影与氛围

* **主光**：`DirectionalLight` 投射阴影，3072² 贴图，正交视锥紧贴场地（±155），
  `normalBias 0.22` 消除体素自阴影摩尔纹。
* **静态阴影优化**：场景为静态，故 `shadowMap.autoUpdate = false`，
  仅在切换时辰 / 开关阴影时重算一帧，省去每帧阴影 pass。
* **补光**：半球光（天空色 ↔ 地面反射色）+ 环境光；夜间额外 6 盏无阴影点光模拟宫灯。
* **天空**：ShaderMaterial 天穹（三段渐变 + 日轮 + 霞光辉光），并接入 tonemapping / 色彩空间。
* **伪 AO**：网格化时按上方与斜上方遮挡数逐块压暗（檐下、廊道自然变深），
  叠加逐块明度噪点模拟 Minecraft 材质颗粒感。
* **四时辰**：晨曦（暖金侧逆光）、正午（高对比顶光）、黄昏（橙紫霞光 + 灯笼渐亮）、
  夜色（冷蓝月光 + 暖黄灯火）。每套预设同步调整日照方向、色温、雾色、天穹、曝光与自发光强度。

> 三点提醒：本项目按 three r155+ 的**物理光照单位**（BRDF 除以 π）标定强度，
> 故 `DirectionalLight` 强度在 9 ~ 10.5 量级；ACES Filmic + sRGB 输出。

## 五、性能

| 指标 | 数值 |
|---|---|
| 体素总数 | 113,344 |
| 相邻面剔除后实际绘制 | **86,874**（剔除 23.4%） |
| 绘制调用 | **38**（每材质一个 InstancedMesh） |
| 三角面 | ≈ 1.04 M |
| 场景构建耗时 | 约 40 ms（体素）+ 160 ms（网格化） |

优化手段：稀疏 Map 存体素 → 六面被不透明块包围即剔除（并把 `y<0` 视为基岩，
使建筑下方地面全部剔除）→ 按材质合并 InstancedMesh（实例色承载调色板颜色与 AO）
→ 静态阴影贴图 → **自适应分辨率**（连续低于 28fps 自动降像素比，高于 56fps 回升，
保证弱机也维持 30fps 以上）。

## 六、项目结构

```
├─ index.html                 页面骨架 + HUD（标题 / 时辰面板 / 图例 / 帧率统计）
├─ vite.config.js
├─ src
│  ├─ main.js                 渲染器、相机、OrbitControls、开场推镜、HUD 绑定、主循环
│  ├─ voxel
│  │  ├─ palette.js           38 种材质定义与 Three 材质工厂
│  │  └─ VoxelWorld.js        体素世界：写入 API、相邻面剔除、伪 AO、InstancedMesh 生成
│  ├─ build
│  │  ├─ roof.js              屋顶生成器：举折曲线 / 庑殿 / 歇山 / 攒尖 / 腰檐 / 八角塔檐 / 翘角
│  │  ├─ parts.js             台基、踏道、石栏、门窗、匾额、斗拱、殿身、灯笼
│  │  ├─ buildings.js         七座建筑 + 院墙
│  │  ├─ props.js             石狮、华表、松柏、香炉、假山、水池、云、幡杆
│  │  └─ site.js              总平面：地面、铺装、御道甬道、绿地、建筑落位、陈设、植栽
│  └─ scene
│     ├─ sky.js               渐变天穹 shader
│     └─ lighting.js          四时辰光照预设与应用
├─ scripts
│  ├─ smoke.mjs               Node 端冒烟测试（构建 + 材质校验 + 对称度）
│  ├─ serve.mjs               零依赖静态服务器
│  ├─ probe.mjs               CDP 探针：读取控制台异常、帧率、绘制统计，并可 CDP 截图
│  └─ inspect.mjs             PNG 解码 → ASCII 材质图（无图形环境下的构图校验）
└─ preview                    无头浏览器实拍截图（六个机位 / 时辰）
```

## 七、实际运行结果

本项目已在本机实际构建并运行验证（Windows / Node v24.17.0 / Vite 6.4.3 / three 0.180.0）：

1. **`npm install`** → 15 个包，无警告阻塞。
2. **`npm run build`** → `✓ built in 1.8s`，产物 `dist/assets/index-*.js` 535 kB（gzip 138 kB）。
3. **`npm run smoke`** → 全部通过：

   ```
   体素总数 113,344 / 剔除后绘制 86,874 / InstancedMesh 36
   包围盒 x -78..78  y -1..145  z -20..178
   中轴对称度 99.18% (建筑构件 54,577 块)
   未知材质 无
   ✓ 通过：7 座建筑，86,874 块可见体素
   ```
4. **无头 Chrome (CDP) 实跑** `npm run probe`：
   `hasScene: true`、7 座建筑全部就位、`calls: 38`、`tris: 1044k`、
   `loaderHidden: true`、`errorShown: false`、`glLost: false`、**控制台无任何异常**。
   开发服务器（5173）与生产预览（4173）两种方式均验证通过。
5. **截图验证**：`preview/` 下六张 1600×900 实拍图（`hero` 默认全景、`front` 中轴立面、
   `axis` 高空平面、`close` 主殿近景、`dusk` 黄昏、`night` 夜色），
   均由 CDP `Page.captureScreenshot` 实拍：

   ```bash
   npm run serve                                     # 另开一个终端
   node scripts/probe.mjs "http://127.0.0.1:4173/?nointro=1&rotate=0&view=front" 30 preview/front.png
   node scripts/inspect.mjs preview/front.png        # ASCII 构图校验
   ```

   并用 `scripts/inspect.mjs` 逐张做像素级校验 —— 确认天空渐变、金 / 绿 / 青三色瓦分布、
   红墙、白石台基、御道走向、阴影方向与院落对称性均符合预期。例如中轴立面图中
   可清晰读出「宝塔顶 → 主殿重檐 → 钟鼓楼 → 配殿 → 山门」的高度层次。

> 说明：无头环境使用 SwiftShader **软件光栅化**，帧率仅个位数，不代表真实性能
> （此时自适应分辨率会自动降采样，行为已验证）。真实 GPU 下 38 次绘制调用、
> 约 1M 三角面、无逐帧阴影重算，可稳定 60fps。
