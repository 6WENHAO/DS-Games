# 地牢元气 · ROGUE KNIGHT

一个纯 `HTML + Canvas 2D + 原生 JS` 手写的**俯视角肉鸽动作射击 + 角色养成**游戏（元气骑士 / Soul Knight 风格）。
无外部素材、无需构建、无需联网：人物、怪物、武器、地牢、特效、音效与 BGM 全部**运行时程序化生成**。

**打开方式**：双击 `rogue-knight/index.html`（在标题界面按一次 `Enter` 后声音/BGM 启动）。
如需本地服务器：`cd rogue-knight && python3 -m http.server 8000`。

---

## 一、操作

| 操作 | 键位 |
|---|---|
| 移动 | `W A S D` / 方向键 / 手柄左摇杆 |
| 瞄准 | 鼠标 / 手柄右摇杆 / **自动瞄准**（`R` 切换，默认开） |
| 射击 | **鼠标左键**（按住连续射击）/ `J` / 手柄 RT |
| 翻滚（带无敌帧） | `空格` / 手柄 A |
| 英雄技能 | `F` 或 **鼠标右键** / 手柄 B |
| 切换武器（2 把） | `Q` 或 鼠标滚轮 / 手柄 X |
| 拾取 · 互动（宝箱/商店/传送门/祭坛） | `E` / 手柄 Y |
| 暂停 · 判定框 · 音乐 | `P` · `F1` · `M` |

命中时有手柄震动反馈；`F1` 会显示所有碰撞圈、攻击扇形、房间与门的判定。

## 二、核心循环

1. 标题 → 选英雄（宝石可解锁）→ 进入第 1 层。
2. 地牢由**程序生成**：起始房 → 若干战斗房 → 支线（宝箱房 / 商店 / 祭坛）→ Boss 房。
3. 走进战斗房 → **门自动落锁**，清空全部敌人才会开门并掉落金币/宝箱奖励。
4. 打败 Boss → 出现**传送门** → 进入下一层（共 5 层，通关即胜利）。
5. 死亡或通关后，本局收集的**宝石进入永久仓库**，用于「天赋强化」与解锁新英雄 —— 越玩越强。

## 十、设计取舍

- 所有武器**按住即连续射击**（射速由武器 `rate` 决定），蓄力武器满蓄自动释放，手感更接近手游。
- 空中/地面统一为俯视平面，没有高度差；子弹会被墙体吸收，近战不会穿墙。
- 战斗房内的敌人被「牵引」限制在房间内，避免出现清不掉的死局。
- 难度随楼层线性提升（怪物血量 +42%/层、伤害 +20%/层、精英出现率提升），第 5 层通关。
