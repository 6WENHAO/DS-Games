# 《千禧回廊》 Millennium Corridor

一个**中式千禧年建筑 + 中式梦核**风格的第一人称网页探索游戏。
零依赖、零素材 —— 画面、音效、字体排版全部**实时程序生成**，整个游戏打包成一个 194 KB 的 HTML 文件。

```
   米黄的墙，墨绿的墙裙，声控灯亮了三秒。
   黄柜子里有樟脑丸的味道，电视在放雪花。
   整栋楼都听得见，谁也看不见。
```

---

## 怎么玩

**Windows：双击 `启动游戏.bat`** —— 起服务、自动开浏览器，一步到位。

```
启动游戏.bat            默认端口 8123，自动开浏览器
启动游戏.bat 9000       换端口
启动游戏.bat 8123 -n    不自动开浏览器
启动游戏.bat 8123 -b    先重新打包单文件版，再启动
```

> 端口上已经跑着这个游戏时，脚本会认出来，直接给你打开，不会再起一个。
> `qianxi.bat` 是同一个脚本的英文名（`启动游戏.bat` 只是转发过去）。
> bat 内容故意全是 ASCII —— cmd 用 OEM 代码页逐字节解析 bat，UTF-8 中文会把解析器搞崩，
> 所以中文横幅一律由 Node 打印。

命令行：

```bash
npm start          # → http://127.0.0.1:8123/
npm run open       # 顺便自动打开浏览器
```

**不想装 Node.js？** 直接双击 **`dist/qianxi-huilang.html`** —— 单文件构建，全部代码内联，离线可玩。

| 操作 | |
|---|---|
| `W A S D` | 走路 |
| 鼠标 / `← → ↑ ↓` | 转头（点画面锁定鼠标，`Esc` 松开）。上下视角会一直保持 |
| `C` | 视角归正 |
| `Shift` | 快走 |
| `E` | 看 / 用 |
| `Tab` | 记忆手册 |
| `M` | 静音 |

> 建议戴耳机。这个游戏一半的内容在声音里。
> 记得抬头看 —— 斗拱、玻璃采光顶、客厅那盏吸顶灯都在上面。

## 风格实现

### 建筑：千禧年 = 后现代 + 中华复兴式

| 母题 | 在哪 | 怎么做的 |
|---|---|---|
| 彩色玻璃幕墙 | 大堂三面墙 | 蓝绿/墨绿/蓝玻璃拼色 + 铝合金框 + 天空反射渐变 + 斜向高光 |
| 几何造型与尖塔 | 第四幕整座塔 | 环形窄廊 + 一圈竖长窄窗；天际线里还有带尖塔的地标 |
| 大体量公共建筑 | 世纪大厦大堂 | 4.8 m 层高、玻璃采光顶、大理石拼花地面、红地毯中轴 |
| 斗拱 / 大屋檐 | 大堂的电梯厅门洞 | 朱红梁枋 + 三层交错斗拱 + 青灰瓦当 + 旋子彩画金环 |
| 小区立面 | 楼道外墙 | 马赛克瓷砖 + 雨痕 + 青苔 |

### 家居：中式梦核

黄柜子（漆面木纹 + 银色长拉手）、原木色板材护墙板、暖白涂料、
红木沙发配蕾丝盖布、大理石贴面电视柜、竹壳热水瓶、红塑料凳、
2000 年的挂历、十字绣牡丹、磨砂冰花玻璃推拉门、吊扇、蚊香、水磨石地面……
全部是代码画的像素图，共 **44 张材质 + 30 件精灵**。

### 梦核：场景不变，只让"不协调"发生

- **声控灯**：你不动，楼道就是暗的。走一步，"咔"一声灯亮，六秒后又灭。
- **上不完的楼梯**：一层一层往上，每一层都一模一样。到第三层，楼梯没了，墙上多了个口子。
- **有声音，没有人**：沙发那边两个人在聊天、卧室在打麻将、厨房在颠勺、楼上在打乒乓球。走过去，声音就停了，锅底是凉的。
- **镜子**：镜子里的房间和这间一模一样，暖黄的灯、原木的柜子 —— 只是没有你。
- **不动的东西**：太阳卡在对面楼的第七层；电子钟停在 `2000-01-01 00:00:00`；挂历永远是 1 月 1 日。
- **自己动的东西**：你关掉电视，回头它又亮了；电话响，接起来是自己的声音。
- **背影**：走廊尽头站着一个人。你走过去，那里只有一扇窗。

## 技术

**没有任何第三方依赖，没有任何图片/音频文件。**

```
index.html                 外壳 + 全部 CSS（宋体叙事 / 黑体标签 / 红金配色 / CRT 覆盖层）
src/
  gfx/pixels.js            像素绘制内核：木纹 / 大理石 / 瓷砖 / 水渍 / 噪声 / 自发光遮罩
  gfx/palette.js           千禧年色板 + 各场景环境光雾参数
  gfx/textures.js          44 张 64×64 程序化材质（墙 / 地 / 顶）
  gfx/props.js             30 件精灵物件（含会动的：电视雪花、风扇叶、蚊香烟）
  gfx/sky.js               512×160 黄昏天空全景：云 + 不动的落日 + 三层城市天际线
  gfx/glyph.js             把真汉字渲染进材质（横幅"热烈庆祝新千年"、小广告"开锁"）
  gfx/raycast.js           渲染器：DDA 墙 + 逐行地/顶投射 + 精灵 z-buffer
                           + 点光源 + 距离暖雾 + HDR 浮点缓冲 + 泛光 + 胶片色调映射
  world/compile.js         字符网格 → 世界结构；运行时改格（开门/长走廊）；圆形碰撞
  world/zones.js           五个场景（用代码"砌墙"，一格 = 一米）
  game/audio.js            WebAudio 全合成音景（见下）
  game/script.js           梦核事件脚本 + 全部文本
  game/game.js             主循环：移动 / 交互 / 字幕 / 转场 / 结局
  game/hud.js              DOM 外壳
  main.js                  入口
```

### 渲染

内部分辨率 384×216，CSS 放大到全屏（`image-rendering: pixelated`）—— 这个像素密度本身就是千禧年的质感。
管线：`天空全景 → 地面/天花逐行投射 → 墙 DDA → 精灵广告牌 → 泛光 → 色调映射 → 暗角/扫描线/颗粒`。

几个值得一提的点：

- **渲染器只操作裸像素缓冲**，不碰 canvas API。所以同一份渲染代码能在浏览器里跑，也能在 Node 里离屏出图 —— 这是下面所有自动化验证的基础。
- **真实层高**：一格 = 1 米，层高 2.6–4.8 m 逐场景配置，还支持"矮墙"（天台的女儿墙只有 1.15 m，所以你能看到天际线）。
- **自发光遮罩**：每张材质带一层 emit 通道，窗户/玻璃幕墙/灯管/电视屏幕不吃雾、不吃黑暗，配合泛光"发出来"。
- **HDR + 胶片肩部**：渲染过程走 Float32 缓冲，允许过曝，最后用 1024 项查表做软肩压回 —— 灯下的桌布不会糊成一块纯白。

### 声音

全部用振荡器和噪声现场合成，一个字节的音频素材都没有：

- **蝉鸣**：带通噪声 + 41 Hz 颤音
- **无人的聊天声**：两个共振峰带通 + 4~7 Hz 音节包络 + 重度低通（隔着墙的感觉）；笑声是把音节率提到 9 Hz 并整体升调
- **麻将**：随机成簇的高 Q 带通噪声脉冲
- **炒菜**：3.4 kHz 以上的噪声沙沙 + 三角波锅铲声
- **走音的欢庆曲**：五声音阶随机取音 + ±5.5% 音准漂移 + `tanh` 削波 + 喇叭带通 + 长混响
- **老式电话铃**：22 Hz 颤音调制的双音
- **脚步**：按地面材质（水磨石 / 木地板 / 瓷砖 / 地毯 / 天台水泥）换滤波器与低频撞击
- **混响**：程序生成冲激响应（噪声 × 指数衰减 + 五个早期反射），各场景不同长度（家 1.1 s，大堂 4.2 s）
- **定位音源**：厨房的炒菜声、卧室的麻将声有坐标，走近变大，并带左右声像

## 自动化验证（没有眼睛也能做美术）

这个项目是在**无法查看图片**的条件下做出来的，所以配了一整套把画面变成数字和文字的工具：

```bash
npm run check       # 关卡 + 渲染 端到端体检
node tools/playtest.mjs   # 无头机器人从头通关一遍
node tools/ascii.mjs home -90 8.5 12.6   # 把某个机位渲成 ASCII 灰阶图打到终端
node tools/analyze.mjs    # 44 张材质逐张数值体检
node tools/texsheet.mjs   # 材质总览 → preview/textures.png
node tools/bench.mjs      # 帧率
npm run build       # 打包成单文件 HTML（并在 Node 里验证模块接线）
```

`npm run check` 会验：

1. 每格都有归属（既不是墙又没地面 = 数据错）
2. 出生点站得下
3. **格子连通性**（传送门算通道）
4. **身体真的过得去** —— 用玩家的碰撞体在 0.25 m 格子上泛洪，专抓"格子上通、身体过不去"的几何夹点
5. 每个可交互物都有落脚点
6. 精灵没被埋在墙里
7. 每个场景四个朝向离屏渲染，统计亮度 / 色彩丰富度 / 过曝比例 / 材质缺失

这套东西真的抓到过：门厅到楼梯间只有 0.38 m 的斜向夹缝、鱼缸把挂历堵死、垃圾桶挡住唯一通道、
每平方米一盏吸顶灯、天际线剪影糊死整片天空、桌布被点光源打成纯白、
以及最后那个「检视工具自己的眼高还留着旧值 0.52 m，一直在用爬行视角看图」。

`tools/playtest.mjs` 是个真机器人：它用玩家的碰撞体寻路、走到目标前面、等游戏真的把目标高亮出来才按 `E`，
然后验证五幕能依次推进到结局。它也抓到过真 bug：站在花盆前按 E，选中的永远是花盆而不是门。
