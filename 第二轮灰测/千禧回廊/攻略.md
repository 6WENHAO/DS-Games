# 《千禧回廊》简易攻略

> 全程没有失败、没有敌人、不会死。走错路最多是多绕两圈。
> 下面的坐标/次数都是从代码里核对过的。

---

## 先记三件事

1. **抬头看。** 上下视角会一直保持（`C` 归正）。斗拱、玻璃采光顶、客厅那盏吸顶灯、楼道的声控灯，全在头顶上。
2. **`E` 是"看"，不是"用"。** 大部分东西按了只是给你一段字。但**记忆**必须按出来才算。
3. **`Tab` 随时查记忆手册**，左上角有 `记忆 x / 5` 的计数。

---

## 第一幕 · 单元楼道

**目标：上三层楼，找钥匙，进 302。**

1. 开场灯是灭的。**往前走两步**，声控灯会"咔"一声亮 —— 它靠脚步声触发，安静 **6 秒**就灭，继续走就一直亮。
2. 你在单元门厅，面朝**东**。沿门厅一直往东走到头，然后**往北**拐进楼梯间。
3. 之后就一路**往北**：平台 → 上行通道 → 走到通道尽头会白光一闪，你"上了一层"，出现在一个一模一样的平台上。
4. **重复 3 次**。字幕会报数：`五层` → `六层` → `七层`。
5. 第三次之后字幕说「左边的墙上多了一个口子」—— 这时在平台上**往西**走，进入那条有三户人家的楼道。
6. 楼道北墙上三扇门：**301 / 302 / 303**，中间那扇是 302，你家。门锁着。
7. **钥匙在 302 左手边那个花盆底下。** 对着花盆按 `E`。
8. 再对 302 按 `E` → 开门。

> 走错了？楼梯是个循环，往北走总会回到平台，不会卡死。
> 顺路可看：小广告墙、电表箱、楼道尽头的窗、楼梯间的窗、门厅的二八大杠、推不开的单元门。

## 第二幕 · 302

**目标：凑够 5 段记忆，然后从入户门出去。**

### 屋子长这样

```
                 阳台（磨砂玻璃推拉门后面）
                      │
   ┌──── 客厅 ────────┴──┐   ┌── 卧室 ──┐
   │  北墙 = 一整面黄柜子  │   │  麻将桌  │
玄关┤  西墙 = 挂历/画/柜   ├走廊┤  东墙镜子 │
（入户门）                 │   └──────────┘
   └────────────────────┘   ┌── 厨房 ──┐
                             │   灶台   │
                             └──────────┘
```

- 玄关往**东**进客厅
- 客厅**东墙中间有门洞** → 走廊 → 往**北**是卧室，往**南**是厨房
- 客厅**北墙偏东有一个缺口**（两扇磨砂玻璃推拉门之间）→ 阳台

### 10 段记忆，任选 5 段

| 记忆 | 在哪 |
|---|---|
| **挂历** | 客厅西墙，最靠北那一格（2000年1月1日） |
| **中堂画** | 客厅西墙，挂历下面一格 |
| **玻璃柜** | 客厅西墙，再下面一格 |
| **黄柜子** | 客厅北墙那一整面 |
| **鱼缸** | 客厅东南角 |
| **电话** | 客厅中间折叠圆桌上 |
| **阳台的窗** | 穿过推拉门到阳台，正对北窗 |
| **麻将桌** | 卧室里 |
| **镜子** | 卧室最东边的墙 |
| **灶台** | 厨房里 |

最省事的一趟：**挂历 → 中堂画 → 黄柜子 → 电话 → 鱼缸**，全在客厅，不用出门。
但**卧室的麻将桌、镜子和厨房的灶台是最好的三段**，值得多走两步。

> **电视机不算记忆**，但一定要按一下 —— 然后走开、再回头看它。
> 客厅里会有两个人聊天。沙发上没有人。走近声音就没了。

凑够 5 段后，回玄关对**入户门**按 `E`。门外不再是楼道。

## 第三幕 · 世纪大厦·大堂

**目标：坐电梯。**

沿**红地毯一直往北**，穿过朱红描金的斗拱门洞，尽头就是**电梯**，按 `E` 走人。

一分钟就能过，但这一幕是整个游戏最好看的地方，建议绕一圈：

- **玻璃幕墙** —— 出生点身后那面南墙（蓝绿玻璃，外面的黄昏永远不变）
- **横幅** —— 北墙「热烈庆祝新千年」
- **电子钟** —— 电梯厅右侧，`2000-01-01 00:00:00`，秒数不动
- **斗拱** —— 门洞西侧那根柱子，**记得抬头**
- **红地毯** —— 走到地毯中段按 `E`
- **灭了灯的角落** —— 西南角
- 站着别动听一会儿：走音的欢庆曲、没人却一直开合的电梯、大理石上不属于你的脚步声

---

## 第四幕 · 塔

**目标：绕三圈。**

塔里是一圈环形走廊，中间是实心的。规则很简单：

> **走到西北角 = 上一层。但两次之间必须先去一趟东南角。**

所以路线是：

```
西北角 → 东南角 → 西北角 → 东南角 → 西北角
 (一层)            (二层)            (三层 → 中间开了)
```

出生点在西边偏南，先沿西墙往北走到**西北角**，然后斜穿到**东南角**，来回三趟。
字幕会报：`窗外的楼矮了一点` → `又一圈` → `塔的中间开了`。

开了之后回到**北面那段走廊**，核心的北墙上会多出一个门洞 —— 往**南**走进去，里面一台电视，按 `E`。

> 顺路：窄窗（北面正中）、核心的墙（开之前贴上去听）。

---

## 第五幕 · 天台

**目标：坐下来。**

从楼梯间小屋往**北**走出去，然后一直往北、走到屋面最北端偏中间的位置。
那里有**一把红色塑料凳，正对着落日**，按 `E` —— 结局。

按之前先站一会儿，这一幕是给你听的：

- **女儿墙**（最北边，只有 1.15 米高，能看清整片天际线：板楼、塔吊、带尖塔的地标、大屋檐）
- **水塔**（东边）
- **晾衣绳**（中间，三件衣服，最小那件是你的）
- 楼下会一直传上来：电视、炒菜、麻将、自行车铃、有人喊孩子回家吃饭

## 通关时间参考

无头机器人（不看不听、直线冲刺）**约 2 分钟**跑完五幕。
正常走、听完声音、把该抬头的地方都抬头，**20~30 分钟**。
