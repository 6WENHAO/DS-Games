# 逆転裁判 ─ 逆转的深夜电波

一个用**纯前端代码实时生成一切**的 NDS 世代《逆转裁判》风格法庭辩论游戏。
没有一张图片文件，没有一个音频文件 —— 立绘、场景、字体、音效、BGM 全部在运行时由代码算出来。

> 同人致敬作品 · 非商业用途。角色与世界观版权属于 CAPCOM。

---

## 立刻开始

**方式一（推荐）**

```bash
node serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

**方式二**：直接双击 `index.html`（全部为传统 `<script>`，无需构建，`file://` 亦可运行）。

打开后点击「▶ 开 始 游 戏」——这一步同时用于解锁浏览器的音频播放权限，请务必点击而不要跳过。
**建议戴耳机**：所有音效与配乐都是实时合成的，动态范围比较大。

## 这一话讲什么

**第 1 话「逆转的深夜电波」**

深夜电台「星屑电台」的王牌主播**音无响**，在录音室 B 中被杀。
警方认定死亡时间是 **23:20** —— 因为那一刻，全城听众都在直播里听到了他的惨叫。
被告是当晚第一次上节目的见习声优**白鸟花音**，凶器上只有她的指纹。

而尸检报告上写着：死亡时间，**22:00 ～ 22:40**。

完整流程：**序章（拘留所）→ 现场调查（录音室）→ 开庭前（法院前厅）→ 法庭（三次突破）→ 尾声**。
一次通关约 40 分钟。举证失败会扣生命条，扣光会被判有罪 —— 可以从上一个检查点重来。

## 技术实现

### 双屏与 NDS 屏幕滤镜

两块 **256×192** 的低分辨率画布拼成 256×384 图集，交给 WebGL 做后处理：

* **15bit 色彩量化** —— NDS 真机每通道只有 5bit，着色器里 `floor(c*31+0.5)/31`
* **液晶余像** —— 帧累积混合，模拟 LCD 的响应延迟
* **像素栅格 + RGB 子像素条纹** —— 缩放倍率 ≥2.7 时按「源像素」对齐，一个源像素 = 一个液晶单元
* **辉光 / 背光泄漏 / 暗角 / 玻璃反光 / 极轻微枕形畸变**
* 无 WebGL 时自动退化为 Canvas2D 扫描线路径

`src/gfx/filter.js` · `src/gfx/screen.js`

### 低多面数 3D 场景

自己写的软件光栅化器，刻意复刻 NDS 时代的特征：

* 顶点投影后**取整** —— 低子像素精度带来的特有「抖动」
* 每面平光 + **阶梯化明暗**（赛璐璐着色），非连续渐变
* **画家算法**排序，没有逐像素深度缓冲
* **仿射式 UV** —— 用双线性映射在面内画细节（木纹、面板、调音台推子）
* 近平面裁剪、雾化衰减
* 相机静止时对整张 3D 画面做一次**颜色吸附**，把抗锯齿抹掉 → 硬边低多边形质感

五个场景（法庭 / 录音室 / 拘留所 / 法院前厅 / 事务所）共 20 个相机预设，法庭在辩护席、检察席、证人席、法官席之间**平滑摇镜**。

**前景遮挡层**：标记为 `occl` 的几何（法官台、证人席、辩护席、拘留所隔栏）会在角色之后再画一遍，所以台面会真的挡住角色下半身 —— 这是「站在台后」而不是「贴在背景上」。

`src/gfx/poly3d.js` · `src/gfx/models.js` · `src/gfx/scenes.js`

### 像素立绘

用矢量图形（贝塞尔 / 多边形 / 锥形带 / 发刺）在 148×232 的低分辨率画布上作画，然后：

1. **颜色吸附**到本帧实际用到的调色板（带色度加权，避免灰调混色被吸成饱和色）
2. **Alpha 阈值化**，抹掉抗锯齿
3. 由 Alpha 边缘检测生成 **1px 描边**

→ 得到真正硬边的像素画，同时保留手绘的造型自由度。

八个角色共享一套**参数化骨架**：手部用「相对肩点的偏移」指定，两骨 IK 自动求肘；姿势只是一组状态参数，所以同一份绘制代码能长出 10 余种姿势 × 说话口型 × 眨眼帧。

`src/core/pixel.js` · `src/chars/rig.js` · `src/chars/*.js`

### 位图字体

把系统字体在目标像素尺寸下渲染，再做 Alpha 阈值化 → 硬边点阵字形并缓存。
支持内联颜色标记（`[r]红[/]`、`[b]蓝[/]`）、CJK 逐字断行与行首禁则。

**关于「粗细」**：低分辨率下 CJK 最怕加粗 —— 无论是 `font-weight` 还是多次偏移叠加，
都会让笔画粘连成一团。用 `tests/font.html` 量化过（指标：每行的笔画段数，越大越清晰）：

| 设置 | 每行笔画段数 | 结果 |
| --- | --- | --- |
| 12px weight500 + 偏移加粗 | 1.29 | 糊 |
| 12px weight600 无加粗 | 1.17 | 更糊（weight 才是主因） |
| 13px weight400 无加粗 | 1.80 | 可读，但「啊/播」等密字仍成实心块 |
| **14px weight400 无加粗** | **2.02** | 密字也能看出内部结构 |

所以正文最终取 **14px / weight 400 / 零加粗**，对比度靠 1px 暗影而不是笔画粗度来撑。
对话框每行 16 字、三行。

`src/core/pixelfont.js`

### 角色站位

相机槽位按**站位**命名（`defense` / `assistant` / `prosecutor` / `witness` / `judge` / `talk`），
`VM.G.roles` 决定每个站位上是谁，剧本用 `{t:'cast', witness:'kuroiwa'}` 换人。
绘制时只遍历当前相机拥有的站位并去重 —— 所以**不可能出现两个立绘同时占位或互相重叠**，
换证人也不需要手动清场。相机摇镜期间只画目标机位上的人，避免过渡帧里两人叠在一起。
`tools/probe-overlap.js` 会枚举全部相机 × 全部登场组合，逐一核对屏幕占位是否相交。


### 声音

全部 WebAudio 实时合成，零音频文件。

* **音效**：文字音、光标、翻页、拍桌、木槌、冲击、顿悟铃、举证、扣血、崩坏、雷鸣、群众骚动、纸吹雪……
* **「异议！」** 用**共振峰合成**做的：富含泛音的声源 → 波形整形器（喊叫的破音）→ 4 个并联带通滤波器按元音共振峰移动，配上气声与音高轮廓。三种喊声（异议 / 等一下 / 看这个）各有男女声版本。
* **BGM**：自带音序器（16 分音符网格记谱 + 脉冲/锯齿/铜管/弦乐/铃/鼓组乐器表），9 首原创曲目 —— 标题、开庭、调查、**尋問 ～ 中庸**、**追い詰め**、疑惑、哀伤、逆转成功、深夜电台。

`src/core/audio.js` · `src/core/sfx.js` · `src/core/music.js`

### 演出

「异议！」爆炸气泡（放射线 + 弹入过冲 + 屏震 + 闪白）、冲击竖条纹背景、证言标题条、聚焦线、生命条扣减、纸吹雪、雷电、回忆滤镜、电影黑边、淡入淡出与擦除转场。

`src/gfx/effects.js`

## 性能

游戏自身每帧只花 **约 0.5ms** CPU（上屏 0.09ms + 下屏 0.08ms + 合成 0.3ms），
25 个相机机位全部渲染一遍共 74ms，1448 张精灵帧全部生成一遍约 2.4 秒（之后全部命中缓存）。
真机上稳定跑满刷新率；若在**软件渲染**（无 GPU / 无头浏览器 / SwiftShader）下运行，
瓶颈会落在 WebGL 合成上，把「LCD 滤镜」拉到 0 可以明显缓解。
