一台 **直列四缸 · 水冷 · 废气涡轮增压 · 空-空中冷 · 直喷 · OHV（下置凸轮轴 + 挺柱 + 推杆 + 摇臂）柴油机**

## 一、运行方式

### 方式 A：本地静态服务器（推荐）

```bash
cd /home/luyun/test1
node serve.mjs            # 默认 8123 端口
# 浏览器打开 http://127.0.0.1:8123/
```

> 因为使用了 ES Module + importmap，**不能用 `file://` 直接打开** `index.html`（浏览器会拦截模块加载）。
> 任何静态服务器均可，例如 `python3 -m http.server 8123`。

### 方式 B：嵌入到现有网页

整套内容是静态资源，把 `index.html`、`src/`、`vendor/` 一起拷到站点目录即可；
若要嵌进别的页面，用 iframe 最省事：

```html
<iframe src="/diesel/index.html" style="width:100%;height:820px;border:0"></iframe>
```

### 环境要求

支持 WebGL2 的现代浏览器（Chrome/Edge/Firefox/Safari 15+）。独立/集成显卡均可；
软件渲染（SwiftShader）下约 40 fps，正常 GPU 下 ≥60 fps（内置画质自动降档保帧率）。

## 三、仿真内容与实现要点

### 1. 结构建模（全尺寸、mm 级参数化）

**1 three.js unit = 1 mm**，所有零件由 `src/core/params.js` 的真实尺寸参数驱动，共 **200+ 个可拾取零件**：

- **固定件**：气缸体（含缸间隔板、主轴承座、挺柱导孔）、湿式气缸套、气缸盖（含进/排气道、气门座圈、导管、喷油器铜套）、油底壳（含集油坑）、飞轮壳、正时齿轮室与齿轮室盖、气门室罩盖。
- **运动件**：活塞（ω 形燃烧室 + 三道环槽）、两道气环 + 一道组合油环（带端隙缺口）、全浮式活塞销与卡环、连杆（I 形杆身 + 小头衬套 + 大头瓦 + 连杆盖 + 连杆螺栓）、曲轴（5 道主轴颈、4 道连杆颈、8 片曲柄臂与平衡重、内部斜油道）、飞轮 + 128 齿齿圈、扭转减振器。
- **配气机构**：凸轮轴（8 个凸轮桃 + 5 道轴颈）、挺柱、推杆、摇臂轴与 8 个摇臂（含气门间隙调整螺钉）、进/排气门、气门弹簧、弹簧座与锥形锁夹、气门杆油封。
- **燃油系统**：直列高压油泵（柱塞偶件、出油阀、油量调节齿杆、机械调速器、输油泵）、4 个喷油器（针阀偶件、铜垫）、4 根等长高压油管、粗/细滤清器、低压与回油管路。
- **润滑系统**：齿轮式机油泵、集滤器与吸油管、限压阀、全流式机油滤清器（含旁通阀）、板翅式机油冷却器、主油道 + 5 条主轴承斜油道 + 缸盖竖直油道 + 摇臂轴油道 + 挺柱/凸轮轴支路、机油尺、压力传感器。
- **冷却系统**：离心式水泵（7 叶叶轮）、蜡式节温器（主阀 + 旁通阀）、散热器（上下水室 + 芯体）、风扇与导风罩、缸体水套 + 缸盖水套、出水/回水/旁通管路、水温传感器。
- **进排气与增压**：进气歧管、排气歧管、废气涡轮增压器（涡轮/压气机蜗壳与叶轮、中间体、废气旁通阀）、空-空中冷器、空气滤清器、连接管路与卡箍。
- **细节件**：缸盖螺栓 16、主轴承螺栓 10、油底壳螺栓 26、飞轮壳螺栓 12、缸垫与火口圈、各类 O 形圈、纸垫、橡胶垫、油封、放油螺塞等（示意模型 + 实例化渲染）。

### 2. 运动仿真（相位严格同源）

- 活塞位移用精确曲柄连杆运动学 `s = r·cosθ + √(L² − r²sin²θ)`，行程实测 **127.0000 mm**，上止点严格在 0°/360°CA。
- **凸轮桃形不是画出来的，而是由配气相位反求生成**：极坐标轮廓 `r(ψ) = R基圆 + camLift(2(ψ−90°) − 该缸相位)`。
  因此凸轮实体的几何与解析升程数学同源，射线实测 8 个凸轮 × 24 个转角，最大偏差 **0.003 mm** —— 相位不可能"跑偏"。
- 传动链完全按机构计算：凸轮 → 挺柱（平动）→ 推杆（两端球窝跟随，实测长度变化 <0.05 mm）→ 摇臂（绕摇臂轴转动，杠杆比 1.5 精确复现）→ 气门（**扣除冷态气门间隙 进 0.30 / 排 0.45 mm，间隙可见**）。
- 连杆大头中心与曲轴连杆颈中心同心误差 **1.3×10⁻¹³ mm**；正时齿轮 22→33→44 齿啮合中心距与分度圆半径之和吻合（137.5 / 192.5 / 72 mm）。
- 四缸相位 0/180/360/540°CA，点火顺序 1-3-4-2，做功间隔 180°CA；气门重叠角 26°CA。
- 冷却液/润滑油/进气/废气以粒子沿真实回路流动，**流量随转速、负荷、节温器开度实时变化**；进排气支管粒子按各缸气门升程脉动。

### 3. 工况模型

增压压力（含涡轮迟滞）、机油压力（限压阀 0.48 MPa 上限）、水温（热平衡 + 节温器 82→95℃ 调节）、
机油温度、排气温度、涡轮转速、扭矩/功率（外特性近似）、缸内压力（简化 Seiliger 循环，压缩/膨胀多变过程）。

### 4. 视觉

PBR（MeshStandardMaterial + RoomEnvironment 生成的 IBL 环境贴图）、ACES Filmic 色调映射、
按真实材料区分的 30+ 种材质（灰铸铁、球铁、锻钢、渗氮钢、铝硅合金、铜铅轴瓦、青铜、弹簧钢、镀铬、紫铜、丁腈橡胶、石墨缸垫…）、
阴影、半透明流道腔、实时剖切（材质级 clippingPlanes，只裁壳体不裁内部零件）。

## 六、精度说明（如何理解"0.1 mm 级"）

- 所有配合尺寸按真实公差建模并可在剖切模式下观察：活塞-缸壁间隙 0.10 mm（头部 0.60）、活塞环侧隙 0.05、
  环端隙 0.35、主轴承间隙 0.06、连杆大头瓦 0.05、活塞销-衬套 0.06、气门杆-导管 0.05、气门间隙 0.30/0.45、
  活塞上止点余隙（squish）1.50 mm。
- 曲面按弦高误差控制分段数（缸套/活塞 48~72 段，φ105 时弦高 < 0.05 mm），故"视觉精度"达 0.1 mm 量级。
- 螺栓、O 形圈、垫片等标准件为**示意模型**（六角头 + 光杆），不含螺纹牙型 —— 这是刻意的性能取舍。
