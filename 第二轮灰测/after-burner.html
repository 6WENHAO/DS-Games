INSERT COIN  ·  ENTER 开始  ·  ←→ 横滚转向  ·  ↑↓ 爬升俯冲  ·  Z 机炮  ·  X 锁定导弹  ·  C 加力 / V 减速  ·  L 或双击←→ 桶滚回避  ·  H 选项  ·  R 分辨率  ·  M 静音  ·  P 暂停  ·  F 全屏  · 

操作 / CONTROLS

← → / A D压杆横滚 + 协调转弯，机体侧移、地平线随之倾斜
↑ ↓ / W S俯仰（默认上=拉杆爬升，可在选项里改成模拟杆）
Z / J / SPACE火神机炮（无限，可打掉来袭导弹）
X / K锁定导弹（准星套住敌机 0.35 秒后 LOCK ON 变红）
C / SHIFT · V / CTRL加力 / 减速：加力后机翼后掠、拉出速度线
L / B / 双击 ← →桶滚：整个天地翻转一圈，可甩掉追踪导弹
ENTER · P · M · R · H · F开始 / 暂停 / 静音 / 切分辨率 / 选项 / 全屏
手柄 / 触屏支持 Gamepad（左摇杆+A/B）与触屏（左半屏虚拟杆，右半屏射击）

■ 23 关战役：沙漠 → 大洋 → 峡谷 → 空中加油 → 落日 → 雪山 → 夜城 → 云海 → 暴风雨 → 最终出击。每 5 关是加油关：贴近加油机保持 2 秒即可补满导弹并加分。

■ 敌导弹逼近时 HUD 会出现 MISSILE ALERT 与方位指示，按 L 桶滚或双击左右可摆脱；也可以用机炮把导弹打爆。

■ 低空会闪 PULL UP，撞地/撞岩石/撞敌机都会坠机。被击落后有 CONTINUE 倒数，按 ENTER 续关。
