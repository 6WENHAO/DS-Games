# AH-64D 阿帕奇·长弓 — 超高精度实时 3D 模型（单 HTML 交付）

`AH-64D-Apache.html` 是**唯一交付物**：双击即可在任意现代浏览器打开，**不需要联网、不需要服务器、不加载任何外部资源**（three.js r160 与全部贴图/几何都在文件内）。

## 特性

- **程序化超精细几何**（约 15 万三角面 / 900+ 零件，全部由代码放样生成）
  - 机身：28 站位截面 + Catmull-Rom 加密的超椭圆放样蒙皮、EFAB 前航电舱、弹药舱鼓包、传动舱整流、尾梁传动轴上盖
  - 座舱：阿帕奇标志性 7 片平板防弹风挡（多面玻璃 + 框架格栅 + 雨刷 + 铰链），内部有弹射座椅、仪表板、MFD、驾驶杆、脚蹬
  - 传感器：可动 TADS 目标截获转塔（DTV/DVO/FLIR/激光四窗口）+ PNVS 夜视转塔（俯仰/方位联动扫描）
  - 旋翼：4 片带扭转/后掠桨尖的翼型桨叶 + 钛合金前缘包条 + 调整片 + 全铰接桨毂（不动环/动环/剪式驱动/3 液压作动筒/变距拉杆/减摆器）
  - AN/APG-78 龙弓桅顶雷达；X 型尾桨（两组跷跷板桨毂互成 55°）；全动平尾
  - 武器：M230 30mm 链式机炮（随动方位/俯仰 + 供弹软管）、M299 四联发射梁 + 8 × AGM-114、2 × M261 19 联装火箭巢（19 管六角排布 + 管内火箭）
  - 起落架：拖曳臂式主起落架（油气支柱 + 斜撑 + 刹车油管 + 带花纹轮胎）+ 尾轮
  - 细节：AN/ALQ-144 红外干扰机、M130 干扰弹投放器、刀形/线天线、雷达告警天线、航行灯/编队灯/防撞灯、系留环、踏板、把手、贴花（星徽/编号/警示/US ARMY）
- **程序化 PBR 材质**：军绿哑光漆（面板缝 + 铆钉 + 检修口盖 + 掉漆 + 划痕 + 油污）、拉丝金属、复合材料编织、热变色排气、光学镀膜镜片、橡胶轮胎花纹、混凝土停机坪 —— 全部 canvas 生成，法线由高度图 Sobel 求解，UV 采用"米"世界尺度盒投影，全机纹理密度统一
- **自研渲染管线**（只用 three 核心，不依赖任何 addon）
  - 程序化 HDR 天空（渐变 + 太阳 + 云层）→ PMREM 烘焙环境光照
  - 4 套环境预设：白昼 / 黄昏 / 夜航 / 棚拍
  - 后处理：多级泛光（亮部提取 + 分离高斯 + 累加）、ACES 色调映射、暗角、色散、胶片颗粒，4× MSAA HDR 目标
  - 4K 阴影贴图（低配设备自动降级 2K）
  - 自研轨道控制器：阻尼惯性、平移、滚轮/双指缩放、镜头飞行插值
- **交互**：启动/停车（旋翼由静态下垂到 289rpm 锥度上扬 + 桨盘虚化 + 机体振动）、12 个机位预设、分解视图、部件标注、线框视图、曝光/泛光调节、渲染倍率、截图

快捷键：`空格` 启动/停车 · `1-9` 机位 · `R` 自动环绕 · `L` 标注 · `W` 线框 · `H` 收起面板 · `P` 截图

## 源码结构（可选，仅用于二次修改）

```
src/three.module.min.js   three.js r160（内联进产物）
src/template.html         UI / CSS / 载入层 / 错误可视化
src/app/00-utils.js       数学、确定性随机、噪声、canvas、高度图→法线
src/app/10-tex.js         程序化贴图工厂
src/app/20-mat.js         材质库
src/app/30-geom.js        放样内核（超椭圆截面 / 翼型 / 世界尺度 UV / 加密）
src/app/40-model-body.js  机身、座舱、传感器、短舱、垂尾、平尾
src/app/50-model-rotor.js 主旋翼总成、桨叶、龙弓雷达、X 尾桨
src/app/60-model-arms.js  机炮、短翼挂架、导弹、火箭巢、起落架、细节
src/app/70-scene.js       环境、光照、地面、后处理
src/app/80-controls.js    轨道控制器与机位
src/app/90-ui.js          总装、UI 绑定、动画主循环
build.mjs                 拼装 → AH-64D-Apache.html
tools/shoot.mjs           无依赖 CDP 截图/取错工具（开发用）
tools/views.mjs           多机位批量截图（开发用）
```

重新构建：

```bash
node build.mjs            # 产出 AH-64D-Apache.html
node --check build/app-check.mjs   # 语法自检
```
