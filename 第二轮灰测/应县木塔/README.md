# 應縣木塔 · 佛宫寺释迦塔 · 大木作数字模型

辽·清宁二年（1056）建，山西应县，**现存世界最高最古的全木结构塔**。
本项目用代码把它「重新盖了一遍」：所有构件尺寸都按《营造法式》**材分制度**推算，
斗拱逐件放样、榫卯逐个做出卯口，**没有任何外部模型或贴图文件**。

```
总高 67.31 m（与实物一致）    构件 63,284 件    斗拱 576 朵
平面八角  五层六檐  5 明层 + 4 暗层  内槽 8 柱 / 外槽 24 柱 / 副阶 32 柱
```

## 🚀 运行

```bash
node server.mjs 5180      # 然后打开 http://localhost:5180/
```

需要 Node 18+ 与支持 WebGL2 的浏览器；three.js r166 已随仓库放在 `vendor/`，**完全离线**。
老显卡加参数 `?quality=low`；也可用 `?view=斗拱详解`、`?view=榫卯图解` 直达。

### 🖱 不想敲命令？双击 `应县木塔.html`

浏览器会拦截 `file://` 下的 ES Module 加载，所以仓库额外提供**单文件离线版**：

* `应县木塔.html` —— 全部 JS（含 three.js）与 CSS 已内联进一个文件，**双击即可打开**，无需服务器、无需 Node。
  * 加参数一样有效：`file:///…/应县木塔.html?quality=low` 或 `?view=榫卯图解`
* 重新生成：`node tools/make-应县木塔.mjs`（打包 14 个模块为内联脚本）
* 打包验证：`node tools/verify-应县木塔.mjs`（Node 端对打包结果跑完整建模体检，与 `smoke.mjs` 同口径）

## 🏛 结构体系

### 竖向：五明四暗，九层叠垒

外观是「五层六檐」（底层有**副阶周匝**，故比层数多一檐），但结构上每个明层之上
都藏着一个**暗层**（结构夹层，不供人上），共 **9 层**：

| 层 | 地面标高 | 檐口标高 | 说明 |
| --- | --- | --- | --- |
| 台基 | −4.00 | — | 下层方台 + 上层八角台，共高 4 m |
| 副阶 | 0.00 | 6.30 | 周匝廊，32 柱，五铺作 |
| 一层 | 0.00 | 10.50 | 柱高 8.1 m，七铺作双抄双下昂 |
| 暗层① | 10.30 | — | 斜撑桁架箍，高 2.5 m |
| 二层 | 14.37 | 20.18 | 平坐 + 柱 + 铺作 |
| 暗层② | 19.98 | — | |
| 三层 | 23.91 | 29.55 | |
| 暗层③ | 29.35 | — | |
| 四层 | 33.14 | 38.62 | |
| 暗层④ | 38.42 | — | |
| 五层 | 42.08 | 47.42 | |
| 攒尖顶 | — | — | 八角攒尖，举高 7.6 m |
| 塔刹 | 55.02 | — | 砖刹座 + 铁制覆钵、九重相轮、圆光、仰月、宝盖、宝珠，8 条铁链拉向垂脊 |

### 平面：双层套筒

每层由**内槽（8 柱）**与**外槽（24 柱，8 角柱 + 每面 2 平柱 = 每面 3 间）**两圈柱网组成，
两圈之间用**乳栿**（径向连系梁）相连，形成两个同心的八边形筒 —— 这就是「双层套筒式」。
逐层**收分**：外槽边心距自一层 10.9 m 递减到五层 8.5 m；用材也逐层递减（材等 1.0 → 0.88）。

柱作三法都做了出来：

* **侧脚** —— 柱身向塔心倾斜 1%，使荷载产生向内的分力，整体抱紧
* **生起** —— 角柱比平柱高 6–7 cm，檐口因而呈缓和的曲线
* **收分** —— 柱径上小下大（上端 0.93×）

### 抗震关键：暗层刚性箍 + 柔性榫卯

四个暗层里，每面外槽柱间施 **X 形斜撑**（中点十字搭交），内外槽之间再加**径向斜撑**，
上下各设圈梁 —— 整层就成了一道刚性的八边形箍。而各层节点全是榫卯，可以微量转动、
摩擦耗能，等于天然阻尼器。**刚箍 + 柔节点**，这就是它经四十余次地震（含数次 5 级以上）
仍屹立近千年的力学答案。

## 🏯 瓦作（屋面）

自下而上严格分层，与真实做法一致：**檐椽 → 飞椽 → 望板 → 板瓦（底瓦）→ 筒瓦（盖瓦）→ 檐口瓦当滴水**。

| 项 | 做法 |
| --- | --- |
| **瓦垄根数** | 由「檐口实长 ÷ 瓦垄中距」定，不跟屋面网格挂钩。中距 34 cm、筒瓦径 16.4 cm，盖瓦率 48%（其余由板瓦面铺满），每檐每面 29–37 道 |
| **板瓦面** | 整面铺满（比望板高 5.5 cm），故任何角度都不露望板；望板双面可见，专供**仰视**时看 |
| **攒尖顶抽垄** | 半径急剧收小，每当垄距挤到不足 0.72 倍即把瓦垄折半（32 → 16 → 8 → 4），并在并垄处加一道横向压边 —— 这正是真实攒尖顶的「抽垄」 |
| **椽随举折** | 屋面有举折（上陡下缓），故椽子按**步架分段**随面铺钉；一根直椽会顶穿屋面，真实做法亦是每步架一段椽 |
| **翼角** | 起翘 + 出翘沿径向做，故相邻两面在角脊自然交汇；老角梁 + 仔角梁（梁头再翘）+ 垂脊脊瓦 + 套兽 |

> 屋面正确性用语义探针核验（见下）：俯视一层屋面 = 筒瓦 36% + 板瓦 21%、望板仅 0.3%；
> 顶层攒尖 = 筒瓦 15% + 板瓦 15%、椽 1.2%（只在檐口露头）。

---

用材取《营造法式》**二等材**，与实物一致：

```
材广 25.5 cm = 15 分°      材厚 17 cm = 10 分°（= 斗口宽）
栔   10.2 cm =  6 分°      足材 = 材 + 栔 = 21 分°
1 分° = 1.7 cm             每跳 30 分°（末跳减 26 分°）
```

外檐柱头做**七铺作双抄双下昂、第一三跳偷心**（辽构常法），实测：

| 项 | 模型值 | 折合 |
| --- | --- | --- |
| 总出跳 | 1.97 m | 116 分° |
| 铺作总高 | 2.23 m | 131 分° |
| 里外总深 | 3.72 m | 里跳 2 跳 + 外跳 4 跳 |
| 单朵构件 | 93 件 | |

构件一件不少，且都按《法式》尺寸：

* **斗**：栌斗（方 32、高 20：耳 8 + 平 4 + 欹 8）、交互斗（方 18）、齐心斗 / 散斗（方 16）
* **拱**：华拱 72、泥道拱 62、瓜子拱 62、令拱 72、慢拱 92（分°），两端**四瓣卷杀**
  （"栱头上留六分，下杀九分，分四瓣"）
* **昂**：下昂两重，斜率 1:3，**批竹昂嘴**，昂下托**华头子**，昂尾向内上挑受枋压
* **其他**：耍头（蚂蚱头）、替木、撩檐枋、罗汉枋、柱头枋

另有**转角铺作**（角缝沿 45° 分角线，出跳加长 1/cos22.5°，两侧另出列拱）、
**平坐铺作**（五铺作卷头造，不用昂）、**内槽铺作**（朝内出跳承内额）。

> 全塔铺作 576 朵、31 种变体。同种铺作只建一次几何、其余用 `InstancedMesh` 摆放，
> 因此 5.4 万构件只占 **177 个 draw call**。

## 🔨 榫卯：七种真做卯口

**关键不是「画得像」，而是「扣得住」** —— 模型里的卯口都是真实的空腔（用多块围出），
榫头都有实际的插入方向，拆解滑块拉开的方向就是当年工匠下榫的方向。

| 榫卯 | 部位 | 作用与做法 |
| --- | --- | --- |
| **馒头榫** | 柱头 ↔ 普拍枋 / 栌斗 | 柱头凿圆榫插入枋底圆卯；只管定位防移，竖向靠木材端面承压 |
| **燕尾榫** | 阑额 ↔ 柱头 | 端头做「外大内小」的燕尾，自上而下入卯，受拉越拉越紧 |
| **十字搭交（刻半榫）** | 华拱 × 泥道拱 | 两拱在栌斗口内十字相交，各刻去断面一半，合起来正好一材 |
| **斗口与斗耳** | 斗 ↔ 拱 | 两斗耳之间的槽即斗口，宽度恰为一材厚；耳下的「平 + 欹」正好一栔 |
| **叉柱造** | 上层柱 ↔ 下层平坐铺作 | 柱脚十字开口，直接叉在栌斗上，被拱与斗耳卡住 —— 楼阁逐层叠垒之法 |
| **透榫 · 半榫 · 木楔** | 乳栿 ↔ 柱 | 透榫贯穿柱身出头、打木楔锁定；半榫只入一半 |
| **斜撑十字搭接** | 暗层桁架 | 成对斜撑中点各刻一半，再穿木销 |

每种都可点击查看说明，并用滑块 0→100% 观察装配 / 拆解过程。

## 📐 取值与简化说明

**按实物 / 文献取值**：总高 67.31 m、台基 4 m、平面八角、五层六檐、5 明 4 暗、
内槽 8 柱 / 外槽 24 柱 / 副阶 32 柱、材广 25.5 cm、外檐七铺作双抄双下昂、
平坐五铺作卷头造、塔刹铁制且以八链拉结垂脊。

**为可视化而简化**：

* 各层柱高、边心距按实物比例推算取整（文献对各层分尺寸记载不一）
* 卷杀以 4 段直线拟合圆弧（《法式》原本就是「四瓣」分段，此为原做法）
* 瓦作以瓦垄（筒瓦）+ 望板表示，未逐块摆板瓦；未做彩画与题记
* 塑像、楼梯、匾额、地面铺装等非大木作内容一概不做（本项目只做木塔本体）
* 卯口用「多块围合」表达（几何上真实存在空腔），而非布尔运算开洞
