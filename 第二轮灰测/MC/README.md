# WebCraft — 网页版 Minecraft

一个尽量还原 Minecraft 的浏览器体素沙盒游戏。基于 **WebGL2** 从零实现，
**零运行时依赖**（不使用 three.js 等引擎），按功能模块拆分为 40 多个源文件。

A faithful browser-based voxel sandbox in the spirit of Minecraft, written
from scratch on WebGL2 with **no runtime dependencies** and split across
40+ focused modules.

---

## 快速开始 / Quick start

双击 **`start.bat`**（Windows）。脚本会：

1. 检测 Node.js（找不到则回退到 Python 3）；
2. 首次运行时自动从公共美术资源站下载贴图；
3. **自动选择一个空闲端口**启动本地服务器；
4. 打开默认浏览器。

```bat
start.bat            :: 自动挑选空闲端口（推荐）
start.bat 8080       :: 指定端口
```

其他方式：

```bash
npm start                    # = node server/server.mjs --open
node server/server.mjs       # 手动启动，自动选空闲端口
python server/server.py      # 无 Node 时的回退方案
```

> 需要支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox / Safari 15+）。

## 已实现的功能 / Features

### 世界生成
- **仿原版的成形管线**：先用少量**大波长**气候噪声（大陆度 3000、
  侵蚀度 1800、异常度 450），再用原版自己的折叠公式导出峰谷度
  `pv = 1 − |3|w| − 2|`，最后经样条曲线转成「基准高度 offset」与
  「起伏强度 factor」——这套结构（而非噪声本身）才是原版地形辨识度的来源。
- **平原真的平、山脉真的陡**：`factor` 在高侵蚀区降到 0.025，
  平原局部高差实测 0.13 格/格；低侵蚀 + 高峰谷区 `factor` 接近 1，
  山体在约 75 格水平距离内爬升约 60 格。
- **崎岖度分级施加**：只有「低侵蚀 **且** 位于山脊」处才有尖锐岩面，
  其余位置该项恒为 0，因此平原不会被噪声污染。
- **4 格晶格 + smootherstep 插值**：平滑分量在 4 格晶格上求值后插值
  （对应原版在 4×8×4 单元上插值密度场），锐利分量再逐列叠加。
  这个「平滑门控 × 锐利细节」的拆分，是同时做到平原平坦与山峰崎岖的关键。
- **河流**沿异常度零值等高线流动，天然位于谷底而非横切山脊。
- **22 种生物群系**：平原、向日葵平原、森林、白桦林、黑森林、
  针叶林、积雪针叶林、雪原、沙漠、热带草原、恶地、丛林、沼泽、
  海洋、深海、冻洋、河流、海滩、石岸、风袭丘陵、积雪坡地、尖峭山峰。
- **4 种世界类型**：`default`、`amplified`（放大化）、`flat`（超平坦）、
  `islands`（群岛）。
- **世界高度 192、海平面 64**：给山脉留出足够垂直空间（实测峰顶 y≈155）。
- **洞穴**：两套 3D 噪声在 4×4×4 粗网格上求值再三线性插值，
  同时生成隧道与大型洞厅；近地表阈值**平滑收紧**使洞口自然收窄；
  深处自动灌入岩浆。
- **矿脉**：12 种矿物按各自的深度区间与数量分布随机成簇。
- **植被**：7 种树形（橡树、白桦、云杉、松树、丛林巨木、金合欢、
  深色橡木）、仙人掌、枯木、草丛、蕨、12 种花、蘑菇、甘蔗。
- **树木两阶段放置**：先做一遍与群系无关的**间距筛选**
  （每列掷候选值，只有在 ±2 格窗口内最强的候选才胜出，
  等价于确定性的 Poisson-disk 过滤），再由群系密度决定该"树位"是否长树。
  这样树干**永远不会相邻**，密度也能直接按原版「每区块树数 ÷ 10」标定。
  两个阶段都是世界坐标的纯函数，因此跨区块的树冠仍然无缝拼接。

### 渲染
- **纹理数组**（`TEXTURE_2D_ARRAY`，268 层）而非传统图集：
  彻底消除贴图渗色，允许 mipmap + 各向异性过滤，
  并让贪心合并后的四边形直接用 UV 重复平铺。
- **贪心网格合并**：光照与 AO 完全一致的共面方块面合并为矩形。
  超平坦世界一个区块的地表由 **1 个四边形**表示。
- **平滑光照 + 环境光遮蔽**：逐顶点烘焙，4 级 AO、
  16 级天空光 / 方块光，双通道 BFS 泛光（含移除光源的两阶段算法）。
- **生物群系染色**：草地 / 树叶 / 水体使用与原版一致的颜色表；
  草方块侧面按群系预合成到独立层，无需额外几何体。
- **昼夜循环**：日出日落由太阳高度角驱动，含天空渐变、地平线辉光、
  1800 颗随时间旋转的星空、月相（8 相）、滚动云层、太阳光晕。
- **水下渲染**：指数雾、群系水色、视野收缩、气泡粒子。
- **粒子系统**：挖掘碎屑（采样方块自身贴图）、脚步扬尘、火焰、
  烟雾、水花、气泡、暴击星火。
- **动画贴图**：水与岩浆的 16 帧动画由着色器按层偏移采样。

### 玩法
- **三种游戏模式**：生存、创造、旁观。
- **原版挖掘公式**：`硬度 × 1.5 ÷ 工具速度`，工具等级不足时可破坏但不掉落
  ——已用单元测试逐项对照原版数值验证。
- **177 种方块**、**256 种物品**、**95 条合成配方**、**17 条熔炼配方**。
- **2×2 与 3×3 合成**：配方支持形状偏移与「任意木板」之类的标签。
- **完整物品栈系统**：堆叠、耐久、盔甲槽、光标拖拽、Shift 快速移动。
- **生存要素**：生命、饥饿、饱和度、耗竭、氧气、溺水、岩浆伤害、
  摔落伤害、护甲减伤、经验与等级、重生。
- **物理**：逐轴 AABB 扫掠碰撞、游泳浮力、梯子攀爬、
  疾跑跳跃加速、潜行改变碰撞箱与视高。
- **实体**：掉落物（旋转图标、拾取、5 分钟消失）、
  7 种生物（猪、牛、羊、鸡、僵尸、苦力怕、骷髅），
  含骨骼动画、寻路、攻击、日光燃烧、战利品表。
- **重力方块**：沙子与沙砾下落；简易水流扩散。
- **命令**：`/help` `/gamemode` `/time` `/daylight` `/tp` `/give`
  `/clear` `/seed` `/kill` `/heal` `/weather` `/fill` `/setblock`
  `/spawn` `/save` `/summon` `/gamerule`（支持 Tab 补全与历史记录）。

### 界面
全部在 canvas 内用原版 GUI 图集绘制，而非 DOM：
- **中文界面**：菜单、按钮、设置、聊天、命令说明、`F3` 调试屏，
  以及全部 176 种方块 / 256 种物品 / 22 个群系 / 7 种生物的名称均已汉化
  （采用官方中文译名）。语言可在**设置**里切换（默认按浏览器语言自动选择），
  英文作为缺失条目的兜底。
  注册表的英文 ID 永不翻译，所以 `/give oak_planks` 在任何语言下都可用。
- 原版位图字体（从 `ascii.png` 逐字量测宽度，支持 `§` 颜色代码与阴影）；
- **多语言文本**：位图字体只有 256 个字形，中文 / 日文 / 韩文 / 西里尔文
  走运行时字形缓存——按需用浏览器自带字体把缺失码位栅格化进 512×512 图集
  （每次只上传变动的 16×16 单元），CJK 按全角方格步进。
  ASCII 仍走像素完美的原版位图路径；
- 文字对齐采用**锚点语义**（同 Canvas2D 的 `textAlign`）：
  `center` 时 `x` 是中心而非左边缘；
- 快捷栏、生命红心（低血量抖动）、饥饿、护甲、氧气泡、经验条；
- 背包 / 工作台 / 创造物品栏（分类标签、滚动、悬浮提示）；
- 等距立方体物品图标（离屏 canvas 预渲染成单张图集，一次绘制调用）；
- `F3` 调试屏与帧时间图；暂停、设置、死亡、标题界面。

### 存档
- 世界存入 **IndexedDB**，仅保存玩家修改过的区块（RLE 压缩），
  其余由种子重新生成；
- 设置存入 `localStorage`；
- 每 2 分钟自动保存，切换标签页与关闭页面时也会保存。

### 关键设计决策

**为什么用纹理数组而不是图集？**
贪心合并产生的四边形需要 UV 超出 `[0,1]` 并重复平铺；图集做不到这一点，
除非在片元着色器里手动 `fract` 并处理导数，而那又会破坏 mipmap。
纹理数组天然支持 `REPEAT` 与逐层 mipmap。

**为什么区块是 16×192×16 的整列？**
按 16³ 分段会让渲染距离 8 时产生 2000+ 次绘制调用。整列使调用数降到约 300，
而重新网格化一整列在 worker 中只需约 8 ms。

**为什么地形要在晶格上求值？**
逐列直接求值时，任何高频噪声都会直接变成逐格锯齿。原版通过在
4×8×4 单元上插值密度场天然获得平滑；本项目的等价做法是把平滑分量放到
4 格晶格上插值，只让「已被门控为山地」的锐利分量逐列叠加。

**顶点格式（20 字节）**
```
偏移 0  : uint32  层索引(12) 面(3) AO(2) 天空光(4) 方块光(4) 标志(5)
偏移 4  : 3×uint16 区块内坐标，单位 1/16 方块
偏移 10 : 2×uint16 贴图 UV，单位 1/16 格
偏移 14 : 4×uint8  群系染色 RGB + 摇曳幅度
```
所有四边形都是 4 顶点固定绕序，因此**全部区块共用一个索引缓冲**。

**线程划分**
主线程持有权威体素数据与光照；worker 负责地形生成与网格化。
网格任务把带一格边界的邻域复制过去（缓冲区循环复用），
从而无需 `SharedArrayBuffer`（也就不需要 COOP/COEP 响应头）。
若 worker 不可用，会自动回退到主线程同步执行。

### 无头验证

由于开发环境没有可视窗口，渲染结果通过无头 Chromium 验证：

```bash
node tools/play-probe.mjs creative tools/shots/x.png    # 驱动真实游戏并截图
node tools/inspect-png.mjs tools/shots/x.png            # 把 PNG 转成可读的文本图
node tools/analyse-terrain.mjs --size 5120 --stride 10  # 地形量化诊断 + 高程图
```

`inspect-png.mjs` 是一个零依赖 PNG 解码器（支持 1/2/4/8/16 位、调色板、
灰度、RGB、RGBA），会输出颜色统计、分带分析，以及「材质地图 / 亮度图」
两张字符画——从而能在纯终端里判断天空、地形、水体、界面是否正确。

`analyse-terrain.mjs` 输出高程分位数、逐格粗糙度、孤立尖刺列计数、
高差分布直方图、群系占比、ASCII 高程图与剖面图。

验证过的关键结论：
- 光照链路数值精确：满光草地顶面测得 `83,97,38`，理论值 `81,97,39`；
- 所有不透明面绕序朝外（0 个反面）；
- 贴图朝向正确（橡木原木竖纹、红砖横纹均与源图一致）；
- 超平坦世界地表贪心合并为每区块 1 个四边形；

## 已知限制 / Known limitations

- 没有台阶、楼梯、栅栏、门、活板门等**非整方块模型**
  （网格器目前支持整方块、十字、火把、液体四种模型）；
- 没有红石逻辑、熔炉燃烧计时、附魔、酿造、村庄、下界与末地；
- 水流是简化扩散，没有原版的流动等级与流向贴图；
- 生物 AI 是「游荡 / 追击」级别，没有寻路网格；
- 地形是高度图 + 洞穴雕刻，没有原版 3D 密度场带来的悬空与拱形结构；
- 世界高度 192（原版为 384），水平方向无限。
