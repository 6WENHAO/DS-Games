# 3D 越野车物理模拟器

单文件 Web 应用：**`index.html`**（双击用浏览器打开，需联网加载 Three.js CDN）。
写实工业风 HUD，3D 场景占满全屏，四块半透明面板悬浮其上。

> 车不是"按曲线播放动画"，而是**六自由度刚体 + 四路射线悬挂**在跑：
> 每根悬挂独立解 F = K·x − C·ẋ，力施加在接触点上、通过力矩改变车身俯仰与侧倾，
> 轮胎用摩擦圆约束纵/侧向力。仪表盘上的支撑力柱状图就是物理求解器的真实输出——
> 四轮支撑力之和恒等于车重（自检实测 ΣN/mg = **1.0005**）。

## 一、操作

| 键 | 作用 | 键 | 作用 |
| --- | --- | --- | --- |
| **W / S** | 油门 / 刹车与倒车 | **空格** | 手刹（后轮锁死，可甩尾） |
| **A / D** | 左转 / 右转（随速降低转向量） | **C** | 切换视角：跟随 / 环绕 / 车头 |
| 鼠标拖拽 | 环视 | **R** | 车辆复位到起点 |
| 滚轮 | 拉近 / 拉远 | | |

出发点正前方（−Z）是**起跳坡道**，右前方是**水坑**（涉水会溅水花、附着系数从 1.08 掉到 0.62）。

## 三、物理模型

**刚体**：质量 1400 kg，惯量 I = (2150, 2520, 560) kg·m²（俯仰/横摆/侧倾），
世界系角速度积分 q̇ = ½·ω⊗q，每帧归一化。

**悬挂（每轮）**：从车身上支点沿 −up 方向对高度场投射射线（10 段扫描 + 13 次二分），
得到接触点与法线；压缩量 x = L₀ − L，法向力

```
N = K·x − C·(v_支点 · n) + 1.2e7·max(0, 限位余量)²      并钳制 N ≥ 0
```

沿接触法线施加于接触点。K = 20000 + 1250·滑块，C = 380 + 62·滑块。
静态下沉 mg/4K 因此随 K 变化——**软簧车身明显下沉**（自检：K=1 时行程 252 mm，K=100 时 129 mm）。

**轮胎**：接触点速度分解为纵向/侧向，纵向 = 驱动 − 制动 − 滚阻，侧向 = −v_lat·4200 N·s/m，
再用摩擦圆 √(F²+F²) ≤ μN 统一截断（μ：干地 1.08，涉水 0.62），超出部分记为滑移率并在受力图上标红。

**其它**：空气阻力 1.55·v²、前后防倾杆（左右行程差 ×14000 N/m）、横摆阻尼、
车底 6 个采样点的地形穿透回弹（防止车身插进坡面）、NaN/越界自动复位。

## 五、说明

- Three.js 由 `importmap` 指向 **unpkg**，运行时失败自动回退 jsDelivr → npmmirror → cdnjs，四者皆不可达时显示错误页。
- 页面暴露 `window.__DBG`（车辆状态、四轮数据、地形采样、渲染器、昼夜时刻可读写），
  既服务于自检脚本，也方便在控制台里调车——符合"车辆调试界面"的定位。
- 无油门且低速时会施加驻车阻力，避免车辆在缓坡上无限蠕动。
