# 沃尔特的房车 · 三维模型与内部实验室场景

致敬《绝命毒师》里那辆 **1986 Fleetwood Bounder**（剧中被称作 "The Krystal Ship"）的**程序化三维场景**：
米白车身 + 棕色飘带条纹、做旧凹陷、六轮（后轮双胎）、顶置空调与排风管、车尾爬梯，
以及**可剖切进入的完整车内场景** —— 驾驶室、实验台、厨房、餐桌、化学桶与防护装备。

零依赖、单文件、纯 WebGL2。

## 开箱即用

```
双击打开 index.html          # 无需服务器 / 无需联网 / 无第三方库
```

```bash
npm run build          # 由 src/* 重新生成单文件 index.html
npm test               # 几何库测试 + 模型结构与"反方块堆砌"量化测试
npm run test:browser   # 无头 Chrome 端到端验收（渲染像素/阴影/剖切/标签/拾取/昼夜/移动端）
```

## 建模了什么

**外部**（车长 8.03 m / 宽 2.44 m / 高 2.98 m，接近真车 25 英尺规格）
圆角车身壳体（横截面圆角轮廓沿车长挤出，带车头收窄与车顶起拱）、三条棕色飘带条纹、
腰线防擦条、车顶滴水槽、7 处车窗（含框与内侧透光面）、侧门 + 折叠踏步 + 门把、行李舱门、
轮眉、前脸（开口式挡风玻璃 + A 柱 + 双层大灯 + 转向灯 + 格栅 + 前保险杠 + 雨刷 + 外伸后视镜）、
车尾（后窗 + 三段式尾灯 + 爬梯 + 保险杠 + 车牌）、车顶（顶置空调含百叶、两处通风口、
排污立管、实验室排风软管、天线、污渍带）、底盘（车架纵梁与横梁、前后桥、传动轴、差速器、
钢板弹簧、排气管与消音器、油箱、丙烷罐、备胎、泥挡板）、六只轮胎（旋成体胎体 + 30 块胎面花纹 +
轮辋 + 轮毂盖 + 五颗螺母）。

**内部**（剖切后可见，31k+ 三角形）
- 驾驶室：两张船长椅（底座/坐垫/靠背/头枕/扶手）、弧面仪表台、三圆表盘、收音机与旋钮、
  方向盘（环 + 三辐 + 轮毂）+ 转向柱、变速杆、踏板、遮阳板、车内后视镜、引擎盖。
- 实验台：**圆底烧瓶**（球体 + 瓶颈 + 磨口 + 瓶内液面）、**加热套**、**蛇形冷凝管**（外管 + 7 圈螺旋盘管 + 接管嘴）、
  铁架台与两副夹具、锥形瓶、两只烧杯、量筒、漏斗、温度计、本生灯（蓝色自发光焰）、电子秤、电热板、
  **结晶托盘**（26 块随机朝向的蓝色晶体）、多段样条管路（烧瓶→冷凝管→接收瓶、冷却水双管、通向车顶的排风软管）。
- 厨房：台面与柜门、水槽 + 弯管龙头、三头灶（炉架 + 燃烧器）、冰箱、吊柜、咖啡机、
  纸巾卷、马克杯、调料架、挂毛巾。
- 生活区：餐桌（圆角桌面 + 镀铬立柱 + 底盘）与两组长椅、窗帘（褶皱）、顶灯 ×2、排风扇、
  电气面板与断路器、烟感、线管、挂钟、小电视、笔记本与笔、地垫。
- 危险品与防护：两只蓝色化学桶 + 一只白桶（含箍圈、桶盖、通气口、标签）、三只试剂桶、
  货架上 9 瓶试剂、水桶、**防毒面具**（面罩 + 双滤罐 + 背带）、**灭火器**（含喷管与铭牌）、
  防化服、行李袋、盘好的软管、折叠椅、蓄电池、工具箱、储物筐、拖把、覆膜塑料布。
- 车外环境：起伏沙地（52×52 网格 + 顶点噪声）、16 块随机变形岩石、12 丛灌木、轮胎压痕、
  折叠营地椅、油桶、铁锹、两只路锥。

## 怎么做到"不是小方块堆砌"

`src/mesh.js` 是一个自研程序化几何库：变换栈 + **真曲面图元**

| 图元 | 用在哪 |
| --- | --- |
`lathe` 旋成体 | 轮胎断面、轮辋、烧瓶颈/量筒/漏斗、桶体、水槽、灯罩、路锥、晶体、加热套 |
`tube` 沿路径挤出（平行传输坐标架） | 全部管路与线束、排气管、保险杠、扶手、爬梯、钢板弹簧、条纹飘带 |
`helixTube` 螺旋管 | 冷凝管内盘管（1500+ 三角形的真螺旋） |
`extrudeProfile` 轮廓挤出（可分段着色/分组） | 整车壳体与内壁、前脸、车尾 —— 剖切分组就来自这里 |
`roundedBox` 圆角盒（球角 + 柱棱 + 平面） | 座垫、柜体、冰箱、空调、门板等所有"箱状"物件 |
`sphere / cylinder / cone / torus / capsule` | 球阀、轮毂螺母、把手、炉架、丙烷罐、桶箍… |
`distortLast` 顶点噪声位移 | 车身做旧凹陷、岩石、行李袋、覆膜布、毛巾褶皱 |

量化自检（`npm test` 每次都会跑）：

```
三角形 117,862 ／ 部件 124 ／ 分组 12
曲面三角形占比        91.1%      （> 55% 通过线）
法线方向多样性        16,343 种   （方块堆砌只有个位数）
轴对齐法线占比        20.7%      （越低越不像方块堆）
部件中心高度层        16 层      （高低错落）
竖向跨度              3.65 m
```

## 渲染

- **方向光阴影贴图**：2048² 深度纹理 + 3×3 PCF + 斜率相关偏移；正交光锥随昼夜滑杆转动。
- **半球环境光**：天空色/地面色按法线朝向混合，配合日落时的暖色太阳。
- **室内点光**：两处顶灯位置的点光源，夜间自动增强，照亮实验台与驾驶室。
- **材质**：逐顶点 `粗糙度 / 金属度 / 自发光`，金属高光更锐、玻璃走透明通道（关闭深度写入、双面法线翻转）。
- **落尘**：`朝上程度 × 离地高度` 决定积灰强度，底盘与轮胎自然变脏。
- **边缘光 + 距离雾 + 天空渐变 + 太阳光斑 + 夜空星点**。

## 验证

`npm test`（Node，无需浏览器）
- 几何库：球面顶点全部落在球面上、非均匀缩放下法线仍单位化（逆转置法线矩阵）、变换栈正确、
  旋成体尺寸符合轮廓、螺旋管三角形数、轮廓挤出按段分组、圆角盒法线多样性、顶点扰动幅度受控。
- 模型：尺寸/比例、上文那组"反方块堆砌"指标、12 个关键分组齐全、124 部件、17 个标签全部能对应到部件、
  剖切分组三角形数、以及**部件位置关系自洽**（方向盘在餐桌前方、空调高于实验台、烧瓶在台面之上、
  冷凝管紧邻烧瓶、侧门在右侧、烧瓶完全位于车厢内部空间…）。

`npm run test:browser`（CDP 直连无头 Chrome，26 项断言全绿）
- WebGL2 无错误、阴影帧缓冲创建成功；
- 外观投影包围盒 1020×634、宽高比 1.61（长条形轮廓）；
- **阴影像素级验证**：车底地面亮度 117 vs 旁侧 199；
- **剖切验证**：隐藏右侧车身与车顶后，6/6 个内部部件（烧瓶/桶/驾驶座/实验台/餐桌/结晶托盘）投影点都有实际像素；
- 17 个标签投影全部落在视口内；
- **拾取审计**：260 次随机采样命中 246 次、命中结果绝不来自被隐藏分组、点天空返回空；
- 8 个视角预设逐个切换正常；
- **昼夜验证**：整体亮度 171→60，顶灯自发光在夜间高于画面均值；
- 线框/素模切换、移动端 414×896 布局、无 console 错误与未捕获异常。

截图输出在 `.shots/`（外观 / 剖切 / 实验台 / 驾驶室 / 昼 / 夜 / 线框 / 移动端）。

开发过程中被这套验收查出并修掉的真实缺陷：
**顶面绕序反了导致被背面剔除**（只剩侧壁在渲染）、**退化轮廓段产生零长法线**、
**AABB 拾取被包裹整车的外壳抢走**（改为三角形级 Möller–Trumbore 求交 + 玻璃不参与拾取）、
**内壁未分段导致剖切后仍被内壁挡住**、**前脸挡风玻璃区域是实心的**（改为开口 + A 柱）。

## 文件结构

```

build.mjs               把 src/* 内联为 index.html
src/mesh.js             程序化几何库（变换栈 + 曲面图元 + 部件/分组登记）
src/rv.js               房车模型：外部 / 内部 / 环境的全部构建代码 + 中文标签表
src/render.js           WebGL2 渲染器（阴影贴图、材质、玻璃通道、拾取、投影）

src/style.css           界面样式
tests/                  几何库测试 / 模型测试 / 浏览器验收 / 渲染诊断 / PNG 分析
```
