## 这部片子在讲什么

10 个工艺步骤，顺序与规格书 §1.1 逐项一致（由自动断言强制校验）：

| # | 步骤 | 时间码 |
| --- | --- | --- |
| 1 | 锡滴发生器在超高真空腔内高频喷射微小锡滴 | 00:30 – 00:47 |
| 2 | 预脉冲激光击打锡滴，压扁成圆盘以提高转换效率 | 00:47 – 00:58 |
| 3 | 主脉冲激光击打圆盘，汽化形成高温等离子体 | 00:58 – 01:08 |
| 4 | 等离子体向空间辐射 13.5 nm EUV（人眼不可见） | 01:08 – 01:18 |
| 5 | Mo/Si 多层膜集光镜收集并聚焦至中间焦点 | 01:18 – 01:38 |
| 6 | 光谱纯化与锡碎屑防护（氢气气流） | 01:38 – 01:50 |
| 7 | 照明光学系统整形为均匀弧形照明狭缝 | 01:50 – 02:02 |
| 8 | EUV 照射反射式多层膜掩模并反射成像 | 02:02 – 02:14 |

## 三条「真源」——本工程的核心设计

科普动画最常见的翻车点是**画面、标注、文档三者互相矛盾**。本工程用三个单一真源在结构上排除这种可能：

| 真源 | 文件 | 谁读它 |
| --- | --- | --- |
| **参数真源** | `src/params.js` | HUD 标注、字幕、术语表、参数校准记录、3D 几何比例 |
| **光学真源** | `src/layout.js` | 硬件摆位、镜面法线、光束折线、摄影机取景、HUD 图版 |
| **叙事真源** | `src/script.js` | 摄影机运镜、光效曲线、HUD、字幕、音频、社媒剪辑表、分镜文档 |

后果：
- 改一个参数只需改 `params.js`，全片同步，物理上不可能前后矛盾；
- 分镜文档 `docs/02` 由 `script.js` **自动生成**，不可能是旧版；
- 字幕 SRT/ASS 与画面来自同一时间轴，**音画同步是结构性保证而非人工对齐**。

## 科学正确性：几个刻意做对的地方

### 1 · 折返式光路（多数科普动画画错的地方）

Mo/Si 多层膜只在**近法向入射**下才有约 70% 反射率。主光线偏转角 Δ 与入射角 θ 的关系是

```
θ = 90° − Δ / 2
```

所以把 EUV 光路画成「大角度折线」等价于 70–85° **掠入射**，物理上完全错误。
本工程以偏转角定义每片镜子，强制近法向：

| 镜面 | 入射角 θ | 偏转角 Δ |
| --- | --- | --- |
| 多层膜集光镜 | 13.05° | 153.9° |
| 场面镜 / 光瞳面镜 / 照明末镜 | 23° | 134° |
| 反射式掩模 | **6.000°** | 168° |
| 投影物镜 M1–M6 | 12° | 156° |

因此片中光路是**折返式的手风琴形态**——这正是真实 EUV 光学系统的样子，并在 S11 用 HUD 图版把这个知识点讲明白。

### 2 · 集光镜是真的椭球，光线是真的收敛

集光镜面片由旋转椭球解析式采样生成，第一焦点 = 等离子体，第二焦点 = 中间焦点。
片中那束收敛光线不是美术曲线，而是对 `reflectOffCollector()` 的真实采样：

```
200 条采样光线，反射后到第二焦点的最大偏离 1.07×10⁻¹⁴ 世界单位 ≈ 3.5×10⁻¹³ mm
```

### 3 · 掩模 6° 是解出来的，不是画出来的

先把掩模法线硬约束为与竖直方向成 6°，再由「反射主光线必须精确竖直向下进入投影物镜」
**反解**入射方向，进而反解照明末镜的位置。入射角实测 6.000°，入射主光线航向 78° = 90° − 2×6°。

### 4 · 全程真空，全程反射

EUV 在大气中的衰减长度不足 1 mm，所以：
- **两个真空腔**都建了模——光源腔与扫描机腔（照明 + 掩模 + 投影 + 晶圆同处真空中），均为剖切式；
- 全片没有任何折射透镜，光路链上只有 `mirror / mask / focus / source / wafer` 五类节点，由断言校验。

### 5 · 夸张表现全部集中声明并标注

不可见光、等离子体、锡滴尺寸、时间尺度、整机比例的夸张倍率集中在 `src/fx.js` 的 `EXAGGERATION` 表，
HUD 据此生成常驻角标与免责文案（如「锡滴直径放大约 490×」「时间放缓约 10⁶×」）。

## 渲染管线

实时 WebGL2 / three.js r0.165.0（规格书 §3 明确允许实时引擎）。

```
场景渲染（master 档：SSAA 单帧内 2^3 = 8 次抖动超采样）
  → Bokeh 景深
  → UnrealBloom 泛光
  → OutputPass（ACES Filmic 色调映射 + sRGB）
  → Grade（暗角 / 胶片颗粒 / 色散 / halation / 白闪 / 黑场 / 遮幅）
  → HUD 叠加层（独立 2D 画布 → 正交全屏四边形，随母版一同入帧）
```

**为什么用单帧内超采样而不是时间累积 TAA**：母版需要逐帧捕获，跨帧累积会导致帧间不一致；
单帧内抖动超采样是确定性的，因此同一帧号可以任意次重复渲染而结果逐字节一致——
这同时也是「无闪烁、无未渲染帧」的工程保证。

**画面是时间的纯函数**：`setTime(t)` 重算摄影机、光效、HUD、材质的全部状态，
不依赖 deltaTime 或任何累积量。拖动时间条与正常播放得到同一帧。

## 交付物产出流程

```bash
# ① 校验（必须全绿）
open http://127.0.0.1:8777/test/verify.html

# ② 浏览器端导出：字幕 / 音频分轨 / 静态资产 / 母版帧序列
open http://127.0.0.1:8777/tools/capture.html
#    → 落盘到 EUV/out/

# ③ 生成分镜文档（依赖 ② 导出的字幕核对表）
python delivery/scripts/gen_script_doc.py --root .

# ④ 关键帧客观图像分析（曝光/噪点/层次/构图/HUD 入帧）
python delivery/scripts/inspect_stills.py out/stills/review1080 \
       --json out/reports/stills_report.json

# ⑤ 封装母版、正片、社媒衍生版（需本机 ffmpeg）
cd delivery/scripts && ./encode_all.sh      # Windows: encode_all.bat
```

> **母版渲染需要 GPU**：master 档 4K 单帧要做 8 次全分辨率超采样 + 景深 + 泛光。
> 有独立显卡时通常 2–10 s/帧；纯软件渲染（SwiftShader）环境下实测可达十分钟以上/帧。
> 请在具备独立显卡的机器上出母版；1920×1080 review 档实测约 1.3 s/帧，适合评审与冒烟测试。

## 接入企业 VI

规格书 §1.3 要求品牌元素按 VI 规范应用。落地只需两步：

1. 把 Logo 放到 `assets/brand/logo.svg`（或 PNG），并在 `src/config.js` 的 `BRAND.logoUrl` 填入路径；
2. 改 `src/config.js` 的 `BRAND` 段：企业名、标题、副标题、标语、色板 `colors`、字体 `fontStack`。

片头、片尾、HUD 主色、参数卡描边、章节条、字幕描边会同步生效，无需改动其它代码。
未提供 Logo 时使用矢量字标回退，**不会出现空白占位或缺图方块**。
