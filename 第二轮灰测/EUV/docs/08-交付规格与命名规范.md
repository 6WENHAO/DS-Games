## 2. 命名规范

统一模板：

```
EUV_{版本}_{语言}_{分辨率}_{帧率}_v{NN}.{ext}
```

- **版本**：`master`（母版）/ `promo`（正片）/ `social60_h`·`social60_v`（60s 横竖）/ `social30_h`·`social30_v`（30s 横竖）。
- **语言**：`zh`（中文）/ `en`（英文）/ `bi`（双语）。
- **分辨率**：`2160p`（3840×2160）/ `1080p`（1920×1080）/ `1080x1920`（竖版）。
- **帧率**：`30fps`。
- **版本号**：`v01` 起始，两位数字，每次交付递增。

真实示例文件名（≥ 12 个）：

1. `EUV_master_bi_2160p_30fps_v01.mov` — ProRes 422 HQ 母版（双语）
2. `EUV_master_bi_2160p_30fps_v01_00001.exr` — 母版 EXR 序列首帧（备选母版方案）

4. `EUV_promo_zh_2160p_30fps_v01.mp4` — 正片 H.264（中文）

## 3. 母版规格

| 项 | 值 |
|---|---|
| 分辨率 | 4K UHD 3840×2160 |
| 帧率 | 30 fps（固定时间步，逐帧确定性） |
| 编码 | ProRes 422 HQ（`.mov`）；备选 EXR 16-bit（half-float RGBA）序列 |
| 色彩空间 | Rec.709（BT.709），无 HDR |
| 帧完整性 | 全帧 5400 帧（180s × 30fps），逐帧无缺号、无坏帧 |
| 音频 | 混音母带 48 kHz / 24-bit，−14 LUFS，≤ −1 dBTP |
| 生成方式 | `src/capture.js` 确定性固定时间步逐帧渲染 → PNG 序列 → ffmpeg 封装 |

```bash
# PNG 序列 → ProRes 422 HQ 母版（示例）
ffmpeg -framerate 30 -i EUV_master_bi_2160p_30fps_v01_%05d.png \
  -c:v prores_ks -profile:v 3 -vendor apl0 \
  -pix_fmt yuv422p10le -colorspace bt709 \
  EUV_master_bi_2160p_30fps_v01.mov
```

## 4. 正片与社媒版（H.264 / H.265）

| 参数 | H.264 正片（4K） | H.265 正片（4K） | 社媒 1080p 横版 | 社媒 1080×1920 竖版 |
|---|---|---|---|---|
| 编码器 | `libx264` | `libx265` | `libx264` / `libx265` | `libx264` / `libx265` |
| Profile | `high` | `main` | `high` / `main` | `high` / `main` |
| Level | 5.1 | 5.1 | 4.2 | 4.2 |
| 码率（建议） | 45–80 Mbps | 25–45 Mbps | 8–12 Mbps | 8–12 Mbps |
| 码率控制 | CRF 18 + `preset slow` | CRF 20 + `preset slow` | CRF 20 + `preset slow` | CRF 20 + `preset slow` |
| GOP | 60（约 2 秒） | 60 | 60 | 60 |
| 像素格式 | `yuv420p` | `yuv420p` | `yuv420p` | `yuv420p` |
| 快启 | `+faststart` | `+faststart` | `+faststart` | `+faststart` |
| 色彩 | BT.709 | BT.709 | BT.709 | BT.709 |

```bash
# H.264 正片（4K）示例
ffmpeg -i EUV_master_bi_2160p_30fps_v01.mov \
  -c:v libx264 -profile:v high -level 5.1 -crf 18 -preset slow \
  -g 60 -pix_fmt yuv420p -colorspace bt709 -movflags +faststart \
  -c:a aac -b:a 256k \
  EUV_promo_zh_2160p_30fps_v01.mp4

# H.265 正片（4K）示例
ffmpeg -i EUV_master_bi_2160p_30fps_v01.mov \
  -c:v libx265 -profile:v main -level 5.1 -crf 20 -preset slow \
  -tag:v hvc1 -g 60 -pix_fmt yuv420p -colorspace bt709 -movflags +faststart \
  -c:a aac -b:a 256k \
  EUV_promo_bi_2160p_30fps_v01.mp4
```

## 5. 字幕规格（SRT / ASS）

| 项 | 规范 |
|---|---|
| 版本 | SRT（简体中文 `.zh.srt` / 英文 `.en.srt`）与 ASS（双语 `.bi.ass`）共三版 |
| 编码 | UTF-8（无 BOM） |
| 行数 | 每条 ≤ 2 行 |
| 行长 | 中文 ≤ 20 字/行；英文 ≤ 42 字符/行 |
| 最短显示时长 | ≥ 1.2 s（短句不低于 1.5 s 更佳） |
| 最长显示时长 | ≤ 7 s（超出须拆条） |
| 字号（1080p 基准） | 中文约 40–48 px；英文约 32–36 px（ASS 在样式中指定） |
| 安全区 | 左右各留 ≥ 5% 画面宽边距；字幕基线距画面底边 ≥ 5% 画面高 |
| 术语 | 与 `src/params.js` 参数真源及术语表一致 |
| 双语排布 | 双语版中文在上、英文在下（或按客户习惯），互不遮挡 |

## 6. 音频规格

| 项 | 规范 |
|---|---|
| 分轨 | 音乐（music）/ 音效（sfx）/ 配音（vo）/ 混音母带（mixmaster）四轨 |
| 采样率 | 48 kHz |
| 位深 | 24-bit（PCM WAV） |
| 响度 | ≈ −14 LUFS（EBU R128） |
| 真峰值 | ≤ −1 dBTP |
| 动态 | 无削波；程序化合成经 `DynamicsCompressorNode` + 离线校准 |
| 测量工具 | ffmpeg `loudnorm`（EBU R128）、Youlean Loudness Meter 2、iZotope RX |

```bash
# 响度/真峰值测量（示例）
ffmpeg -i EUV_promo_zh_2160p_30fps_v01_mixmaster.wav \
  -af loudnorm=I=-14:TP=-1:LRA=11:print_format=json -f null -
```

## 8. 工程文件交付

### 8.1 目录树说明（逐目录一句话）

| 目录/文件 | 说明 |
|---|---|
| `src/config.js` | 品牌 VI、渲染质量档、影片时基（30fps/180s/母版 3840×2160/衍生版本/响度） |
| `src/params.js` | 唯一参数真源与 10 个工艺步骤（中英文案 + 来源标注） |
| `src/layout.js` | 光学布局与光路真源（椭球集光镜、折返式光路、掩模 6° 硬约束） |
| `src/capture.js` | 母版渲染器：确定性固定时间步逐帧渲染 3840×2160 导出 PNG 序列 |
| `assets/brand/logo.svg` | 客户 Logo 矢量文件（VI 落地入口之一） |
| `test/checks.js` / `test/verify.html` | 自动校验套件（93 项断言） |
| `vendor/three/` | three.js r0.165.0（MIT，本地 vendor） |
| `serve.py` | 本地预览服务器（Python 3 标准库，无第三方依赖） |
| `docs/` | 流程与交付文档（05–08） |
| `delivery/` | 交付物与许可证凭证归档 |

### 8.2 如何本地运行

```bash
cd EUV
python serve.py            # 默认 http://127.0.0.1:8777/（可加端口参数）
# 质量档: ?q=preview | review | master    语言: ?lang=zh | en | bi
```

### 8.3 如何改品牌 VI（只改一处 + 一个文件）

1. 编辑 `src/config.js` 的 `BRAND` 段（名称、标题、标语、VI 主色板、字体栈、`logoUrl`）；
2. 将客户 Logo 矢量文件放到 `assets/brand/logo.svg`；
3. 全片片头、片尾、HUD 主色、字幕描边色、进度条**同步生效，无需改动其它代码**；`logoUrl` 留空时自动使用矢量字标回退，不会出现空缺。

### 8.4 如何改参数（只改 `params.js` 并重跑校验）

1. 编辑 `src/params.js`（唯一参数真源，禁止在其它模块硬编码物理数值）；
2. 浏览器打开 `test/verify.html`，确认 **93 项断言全绿**；
3. 涉及「示意值」的新增参数需标注 `provenance: 'schematic'` 并在 `note` 注明「示意」，否则 B 组校验失败。

### 8.5 如何重新出母版

1. 确认 `config.js` `FILM`（时长/分辨率/帧率）与 `QUALITY.master` 档位正确；
2. 运行 `capture.js` 以确定性固定时间步逐帧渲染 3840×2160 PNG 序列（5400 帧）；
3. 执行逐帧完整性校验（见 `docs/07-验收清单.md` 附录 A）；
4. ffmpeg 封装 ProRes 422 HQ 母版，再由母版派生 H.264/H.265 正片与社媒版。
