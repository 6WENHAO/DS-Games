## 3. 变更控制（已确认节点如需变更的走签流程）

1. **变更提出**：任一方向（客户/制片/技术）书面提出变更申请，填写《变更申请单》（变更内容、原因、影响范围、工期/成本影响）。
2. **影响评估**：技术统筹评估对已确认里程碑的波及（是否回溯脚本/布局/参数）。
3. **书面确认**：客户对变更及影响书面确认（邮件/盖章），**未确认前不得改动已确认内容**。
4. **登记与落实**：变更登记到本记录对应节点「意见记录表」，落实到 `src/` 并**重跑 `test/verify.html`** 确认全绿。
5. **版本留痕**：涉及参数/布局/品牌的变更同步更新 `params.js` / `layout.js` / `config.js` 注释与文档版本号。

> 已确认节点（尤其 M0 科学审查结论）的变更，须**重新评审**涉及内容，不得静默覆盖。
