## 1. 「唯一参数真源」机制

规格书 §1.2 要求「关键参数必须与真实技术一致并在全片保持一致」。本项目以 `src/params.js` 作为**全片唯一参数真源（Single Source of Truth）**，实现方式如下：

1. **单一出处**：全片 HUD 标注、字幕、术语表、参数校准记录与 3D 场景几何比例，全部从 `src/params.js` 读取，不在任何其它模块硬编码物理数值（见 `params.js` 文件头注释）。
2. **结构化条目**：每条参数以 `P(id, value, unit, provenance, zh, en, note)` 工厂函数生成，固定携带 `value`（数值）、`unit`（单位）、`provenance`（来源等级）、`zh/en`（中英文名）、`note`（来源/推算说明）。
3. **物理排除前后矛盾**：同一数值只写一次，HUD 与字幕引用同一 ID，故「字幕说 13.5 nm、HUD 标 13.6 nm」这类矛盾在结构上不可能发生。
4. **几何同步**：`src/layout.js` 通过 `import { PARAMS }` 读取参数（如 `maskIncidenceAngle=6°`、`waferDiameter=300 mm`）驱动掩模法线、晶圆直径等几何量，参数改动自动传导到 3D 场景。
5. **取值工具**：`PV(id)` 统一格式化（如 `PV('wavelength')→'13.5 nm'`、`PV('dropletRate')→'50,000 滴/秒'`）；`needsSimTag(id)` 判定是否需要「示意 / Simulation」标注。

> 说明：`dropletRate=50000`、`partCount=100000`、`plasmaTemperature=220000` 等整数值以数字存储，显示时自动加千分位（50,000 / 100,000 / 220,000），数值本身不变。

## 2. 来源等级定义

| 等级 | 标识 | 定义 | 标注要求 |
| --- | --- | --- | --- |
| 公开 | `public` | 公开企业/行业数据，可直接标注数值 | 无需「示意」标注 |
| 推算 | `derived` | 由公开值推算得出，须给出推算式 | 标注推算依据 |
| 示意 | `schematic` | 保密或未公开，使用示意值 | **必须**标注「示意 / Simulation」 |

`src/params.js` 以 `PROVENANCE = { PUBLIC, SCHEMATIC, DERIVED }` 固化上述三级枚举，`test/checks.js` B 组断言「每条参数具备 provenance」「所有示意值的说明文字自带『示意』字样」。

## 7. 变更控制流程

任何物理数值的变更必须走如下流程，禁止在字幕、HUD 或 3D 模型内直接改数：

1. **改源**：仅允许修改 `src/params.js` 中的对应 `PARAMS` 条目（含 value / unit / provenance / note）；如需新增参数，使用 `P(id, value, unit, provenance, zh, en, note)` 工厂函数。
2. **回写关联**：若参数被某工艺步骤引用，同步确认 `PROCESS_STEPS[*].params`；若为示意值，确认 `note` 含「示意」字样。
3. **重跑校验**：打开 `test/verify.html`（或运行 `test/checks.js` 的 `runAllChecks()`），确认 93 项断言全绿，尤其 B 组交叉一致性。
4. **回归几何**：`src/layout.js` 依赖 `PARAMS`（如 `maskIncidenceAngle`、`waferDiameter`），改数后复核 C/D 组光路与几何断言无回归。
5. **更新本记录**：同步更新本《参数校准记录》§3 参数表与 §4 推算校验表，并升级文档版本号。

> 铁律：**改动 `src/` 必须重跑 `test/checks.js`**；93 项断言不绿，不得推进里程碑。
