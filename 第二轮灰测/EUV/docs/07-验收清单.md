## 附录 A · 未渲染帧 / 闪烁检测方法

### A.1 逐帧序列完整性校验（检测未渲染帧 / 坏帧）

母版经 `src/capture.js` 以确定性固定时间步导出 PNG 序列（180s × 30fps = **5400 帧**），封装前必须校验：

1. **帧号连续**：序列文件名 `EUV_…_00001.png … _05400.png`，逐一检查无缺号。
   ```bash
   # 期望输出 1..5400 无缺口（缺号即未渲染帧）
   seq -f 'EUV_master_bi_2160p_30fps_v01_%05g.png' 1 5400 | while read f; do
     [ -f "$f" ] || echo "缺失: $f"
   done
   ```
2. **文件大小离群检测**：全黑/坏帧通常尺寸显著偏小；对每帧字节数求均值与标准差，标记低于 `均值 − 3σ` 的帧。
   ```bash
   ls -l *.png | awk '{print $5, $9}' | sort -n | head   # 检查最小若干帧是否异常
   ```
3. **解码完整性**：用 ffmpeg 逐帧重封装/解码，若遇坏帧会报错：
   ```bash
   ffmpeg -framerate 30 -i EUV_master_bi_2160p_30fps_v01_%05d.png -c:v prores_ks -f null -
   ```

### A.2 相邻帧差分阈值检测（检测闪烁 / 突发亮斑）

对相邻帧做像素差分，统计差分均值与超阈值像素占比，定位异常闪烁或突变帧：

```bash
# 以 ffmpeg 计算每帧平均亮度差异（tblend + signalstats），异常跳变即闪烁嫌疑帧
ffmpeg -framerate 30 -i EUV_master_bi_2160p_30fps_v01_%05d.png -vf \
  "tblend=all_mode=difference,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=diff.log" -f null -
```

判读标准：差分均值曲线应平滑；出现单帧尖峰（远高于相邻帧 3σ）记为闪烁/坏帧，需重渲染该帧；整体噪点水平由 master 档 TAA（每帧 8 次抖动累积，见 `config.js` `QUALITY.master.taaLevel=3`）与 `grain=0.03` 控制，人工复核颗粒观感。
