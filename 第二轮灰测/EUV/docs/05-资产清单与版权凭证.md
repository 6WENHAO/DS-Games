## 2. 逐类资产明细

### 2.1 三维模型（全部程序化生成，无第三方模型）

全片场景不使用任何外购或下载模型。所有几何体由 `src/layout.js`（光学布局与几何真源）给出解析定义，运行时由 three.js 以 `BufferGeometry` / `LatheGeometry` / 参数曲面采样等程序化方式构建。**源码即凭证**，可随时复现。

| 部件 | 源文件 | 定义/生成函数（符号） | 几何类型 |
|---|---|---|---|
| 等离子体点（光源） | `src/layout.js` | `PLASMA` | 解析点 + 体积光/辉光 |
| 多层膜椭球集光镜 | `src/layout.js` | `ELLIPSOID`、`collectorPoint(φ,θ)`、`collectorNormal(pt)` | 旋转椭球面片（参数曲面采样） |
| 集光镜孔径 | `src/layout.js` | `COLLECTOR_APERTURE`、`COLLECTOR_VERTEX`、`COLLECTOR_REF` | 中心孔 / 外缘 |
| 中间焦点 IF | `src/layout.js` | `IF_POINT` | 解析点 |
| 照明系统三镜（场面镜 / 光瞳面镜 / 末镜） | `src/layout.js` | `ILLUMINATOR`、`solveChain()` | 折返式光路求解 + 镜面（concave/faceted） |
| 反射式掩模 | `src/layout.js` | `MASK`、`MASK_NORMAL`、`MASK_INCIDENT_DIR` | 掩模基板（`blank`）+ 图形场（`field`） |
| 投影物镜六镜 M1–M6 | `src/layout.js` | `POB`、`solveChain()`、`POB_ENTRY_DIR` | 折返式光路求解 + 镜面（concave/convex） |
| 晶圆 | `src/layout.js` | `WAFER` | 圆盘 + 曝光场 |
| 光谱纯化与碎屑防护段 | `src/layout.js` | `PURITY`（`gasCurtain` / `spf` / `ifAperture`） | 氢气气帘 / 光谱纯化滤片 / 中间焦点光阑 |

### 2.3 环境光照（程序化生成，不使用第三方 HDRI）

- **实现**：由程序化渐变天空盒 + 解析灯光（关键光/轮廓光/补光）组合，必要时经 `PMREMGenerator` 烘焙为程序化 HDR 环境贴图。
- **不使用第三方 HDRI（如 Poly Haven / HDRI Haven）的理由**：
  1. **许可不可控**：主流 HDRI 站点为 CC0/CC-BY，署名与出处要求在商业交付中易遗漏、易审计歧义；
  2. **确定性要求**：母版渲染采用确定性固定时间步逐帧捕获，外部 HDRI 文件破坏「同一帧可复现」的工程纪律；
  3. **场景本无实景背景**：全片为暗色真空腔 + 金属反射质感，程序化光照已满足观感，无需照片级实景反射；
  4. **凭证闭环**：程序化生成可出具「原创」凭证，无需第三方授权链条。

### 2.5 音乐与音效（WebAudio 程序化合成，原创）

| 元素 | 合成方式 | 说明 |
|---|---|---|
| 主题/氛围音乐 | `OscillatorNode`（正弦 / 锯齿 / 三角）多声部 + 和声叠加 | 原创动机，无第三方音乐 |
| 低频律动 / 铺底 | 低频振荡器 + 慢包络 `GainNode` | 节奏随影片时基推进 |
| 等离子体辉光声 | 白噪/粉噪缓冲 + `BiquadFilterNode` 带通整形 + 慢包络 | 噪声整形合成 |
| 激光脉冲 / 机械运转 | 短促噪声脉冲 + 振荡器瞬态 + `ADSR` 包络 | 与第 2/3 工艺步骤同步 |
| 环境/气流声 | 噪声整形（低通滤波的粉噪） | 真空腔氛围 |
| 空间混响 | `ConvolverNode`，**脉冲响应（IR）程序化生成**（指数衰减噪声序列） | 非采样库 IR，原创 |
| 节拍/事件调度 | WebAudio 时钟（`AudioContext.currentTime`）与影片时基（30fps/180s）锁定 | 保证音画同步 |
| 响度整形 | `DynamicsCompressorNode` + 离线响度校准至 −14 LUFS | 见 `config.js` `FILM.loudness` |
