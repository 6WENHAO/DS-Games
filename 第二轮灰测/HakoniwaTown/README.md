# 箱庭小镇 · Hakoniwa Town

一个用 **Three.js** 手工程序化生成的 3D 箱庭（diorama）小镇：漂浮在展台上的一座海岛小城，
带完整昼夜循环、成体系的动态元素，以及刻意设计的**九层台地高差**（不是方块堆砌）。

![day](tools/shots/day.png)

## 运行

模块化 ES 源码需要通过 HTTP 打开（`file://` 会被浏览器拦截，页面会给出提示）：

```bash
npm start                     # = python -m http.server 8123
# 或任意静态服务器：npx serve . / php -S 127.0.0.1:8123 ...
```

然后浏览器访问 **http://127.0.0.1:8123/** 。three.js 已随仓库内置（`vendor/`），**无需联网**。

自检（Node 下真实构建整张场景图，不需要 WebGL）：

```bash
npm run check                 # = node tools/smoketest.mjs
```

## 设计要点

**高低错落**：地形是一个由圆角矩形"台地"叠加而成的高度场（`src/world/layout.js`），
所有建筑都用同一个 `baseHeight()` 取基面，因此永远不会漂浮或埋进地里：

```
港口 1.95 → 下城 3.5 → 中央广场 6.7 → 集市巷 5.3 → 车站 8.7
→ 上城 10.6 → 农场 8.4 → 山肩 13.8 → 山顶 17.2      （海床 -3.6）
```

台地之间用挡土墙、大台阶、坡道、拱桥连接；一条山泉从山肩切开三级台地，
形成 **三段跌水 + 磨坊潭 + 河口**，铁路则沿海岸与山腰高架爬升、穿岩石隧道、跨海长桥。

**避免方块感**：每栋房子都由「基座 → 逐层外挑（jetty）→ 腰线 → 檐口 → 坡屋顶 → 老虎窗 → 烟囱」
层层收分组成，屋顶有人字/四坡/折线/金字塔/洋葱顶/尖锥六种形制，
外加半木构架、条纹雨棚、招牌、阳台、窗台花箱、百叶窗等细节。

**动态元素**（全部实时）：

- 蒸汽小火车（5 节车厢沿高度变化的环线爬升，车轮转动 + 白烟）
- 6 辆汽车沿环路双向行驶（含公交、货车，车轮转动、夜间开灯）
- 19 位行人沿 7 条步道往返（四肢摆动 + 身体起伏），小狗跟随
- 帆船巡航、渔船随浪起伏、羊群漫步、海鸥拍翅盘旋、热气球升降
- 风车叶片 / 水车 / 摩天轮（吊舱始终水平）/ 旋转木马（木马上下起伏）/ 风向标 / 望远镜 / 秋千
- **钟楼四面钟的指针跟随当前时刻**
- 风场着色器：树冠、麦浪、旗帜、晾衣绳、彩旗、帆布一起飘动
- 粒子：炊烟、火车蒸汽、喷泉水柱、瀑布水雾、萤火虫、灯光光晕

**昼夜**：10 个关键时刻的色板插值（天顶/地平/太阳/环境/雾/曝光/水色），
太阳与月亮沿轨迹升落并投射阴影，入夜后窗户与街灯逐盏亮起、星空浮现、
偶有流星、灯塔光束旋转扫海、萤火虫出现；环境反射贴图随天色实时重建。

## 工程与性能

- 静态件按材质**合批**（`Batch`），几万个小构件最终只剩数十个 draw call；
  会动的部件通过 `userData.keep` 标记从合批中剥离。
- 约 **1.4k 个可见对象 / 37 万三角面**，单方向光阴影（2048，可降档），
  粒子全部在 GPU 端算轨迹；构建整场景约 0.6 秒。
- `tools/smoketest.mjs` 会在 Node 里真实构建场景并检查：
  物件是否贴地、是否互相穿插、是否压占道路、轨道是否被地形埋没、
  几何体是否有 NaN、合批是否失败、动画跑 90 帧是否稳定。
