# 破晓号 · 星际战舰模拟器（DAWNBREAKER）

一个纯前端、零外部素材的可操控星际战舰 Demo：驾驶 **Nova 级重型截击舰「破晓」** 在太阳系中翱翔，
飞越八大行星与小行星带，抵达系统外缘那座会把光线掰弯的**超大质量黑洞**。
电脑端与手机端同一套代码，自动适配。

> 技术栈：Three.js r185（已本地内置，离线可用）+ 原生 ES Module，无需构建工具。
> 所有模型、贴图、星空、行星、黑洞全部由代码程序化生成，仓库里没有一张图片。

---

## 快速开始

```bash
npm start          # 启动本地静态服务器（默认 http://127.0.0.1:5173/）
node serve.mjs 8080   # 或指定端口
```

浏览器打开提示的地址即可。**必须通过 http 访问**（ES Module + importmap 在 `file://` 下会被浏览器拦截）。

要求：支持 WebGL2 的现代浏览器（Chrome / Edge / Safari 15+ / Firefox）。

## 玩法要点

- **飞行手感**：太空没有空气阻力，松油门后会保留惯性漂移；加力时"抓地力"提升，指向更贴合。
  转向会自动配合一点滚转，飞起来更有战斗机的味道。
- **能量**：加力约 9 秒、曲速约 8 秒耗尽，停用后 8 秒左右充满。曲速足够横穿整个太阳系。
- **黑洞很危险**：`引力 = μ/r²` 是真的在算。距事件视界约 30 倍史瓦西半径开始有明显牵引，
  太近就只能靠曲速脱离，否则舰体会被吞没（自动紧急跃迁重生）。
- **恒星会烤船**：靠太阳太近舰体温度上升、护盾闪烁，撑不住会解体。
- **软碰撞**：撞上行星不会穿模，会沿表面法线滑开并扣血；舰体会缓慢自修复。
- **HUD**：速度 / 油门 / 能量 / 舰体、天体屏幕标记（视野外贴边显示）、对数刻度雷达、
  速度矢量指示、警告条。

### 便捷 URL 参数

| 参数 | 作用 |
| --- | --- |

## 战舰是怎么"精致"起来的

`src/ship/starship.js` 约 700 行，全部是程序化建模，成品 **79 个网格 / ≈10 万三角面**：

- **放样舰体**：`loft()` 沿 11 个站位插值变截面（上圆下平、带侧棱的六边形化剖面），
  得到硬朗折面又平滑过渡的主体 —— 这是"不像堆方块"的关键。
- **前掠翼 + 外倾垂尾**：翼型用 NACA 四位数厚度分布生成，翼尖前移形成攻击性剪影。
- **四台矢量推进器**：喷口会随操控输入偏转，尾焰长度/颜色随油门、加力、曲速变化，
  含涡轮叶片、喷口环、发光核心、加法混合尾焰与辉光贴片。
- **真实座舱**：外罩玻璃 + 框架肋条 + 内壳 + 座椅 + 发光仪表台，座舱视角就坐在里面。
- **820+ 程序化堆料**：按几何表面积均匀采样撒面板、管路、散热片、圆顶，
  并按区域分层（引擎段贴金色隔热箔片、机首保持干净、座舱区自动让开）。
- **会动的细节**：旋转雷达天线、双联炮塔缓慢扫视、导航灯（左红右绿）、频闪灯、
  能量导管脉动、护盾在加力/受击时浮现六边形能量网格。
- **贴图也是算出来的**：装甲板分割、铆钉、格栅、警示条纹、涂装编号，
  由 Canvas 生成后再做 Sobel 转法线贴图。

## 太空里有什么

- **太阳**：对流米粒组织 + 边缘变暗 + 色球层 + 日冕外壳 + 六芒星耀斑。
- **八大行星**：等距柱状投影贴图程序化生成 —— 气态行星的条带与大红斑、
  岩质行星的陨石坑、地球的大陆/海洋/极冠/云层/**夜面城市灯光**、土星与天王星的环缝。
- **卫星**：月球、木卫一/二/三、土卫六，各自公转。
- **小行星带**：火木之间 ~960 块 InstancedMesh 岩石，靠近时逐块自转。
- **黑洞**：见下。
- **星空**：3D 网格撒点的多层恒星（含光谱色）+ 银河尘埃带 + 电离氢云 + 暗尘埃遮挡，
  与黑洞透镜共用同一个 `skyColor(dir)`，所以被引力弯折的背景和真实天空严丝合缝。
- **近场尘埃**：以飞船为中心循环复用的短线段，速度越快拉丝越长 —— 速度感的来源。

## 黑洞是怎么算的

`src/world/blackhole.js`：一个面向相机的公告板，在片元着色器里**逐像素积分光线测地线**。

- 光线偏折用 `a = -1.5·h²·p/r⁵`（几何单位 rs=1，弱场极限收敛到 GR 的 `α = 2rs/b`，已验证）
- 落入 `r < 1` 判为捕获 → 纯黑剪影；掠过影响球之外则走解析弱场偏折（省算力）
- 吸积盘按开普勒转速旋转，含**多普勒集束**（近侧更亮）、**引力红移**、温度梯度与湍流条带，
  并按**光学厚**介质处理：穿过一次即遮挡后续，这样视界剪影才是真的黑
- 逃逸光线用共享的 `skyColor()` 采样被弯折后的星空 → 爱因斯坦环与盘的"顶部回环"自然浮现
- 用 `premultipliedAlpha` 混合：`rgb = 盘发光 + 弯折星空·mask`，`alpha = 遮挡量`，
  于是边缘无缝、且能被前方物体正确遮挡
- 极区还有相对论喷流；对飞船施加真实引力

## 两端适配与性能

- **画质档位**自动判定（UA + 触摸 + DPI + 内存），影响：黑洞积分步数（118/74/42）、
  行星贴图分辨率与网格细分、尘埃与小行星数量、泛光强度、像素比上限。
- **动态分辨率**：连续低于 42 FPS 自动降采样（最低 0.62×），回到 57 FPS 以上再逐步恢复。
- **响应式 HUD**：`--hud-scale` 变量 + 断点缩放；触屏模式下油门柱自动避让左摇杆。
- 不使用阴影贴图；透明物体统一 `depthWrite: false` + `renderOrder` 手工排序；
  堆料合并为单一几何以压低 draw call（整帧约 120 次）。

## 自动化验证

```bash
npm run smoke                     # Node 端冒烟测试：39 项几何/物理/相机断言
node tools/browsercheck.mjs "http://127.0.0.1:5173/?selftest=1"            # 无头浏览器图像自检
node tools/browsercheck.mjs "http://127.0.0.1:5173/?selftest=1" --mobile   # 叠加手机视口与触摸巡检
```

`tools/browsercheck.mjs` 是一个零依赖的 CDP 驱动：启动无头 Chrome/Edge（SwiftShader 软渲染），
运行 11 个取景步骤，回读帧缓冲并输出**亮度直方图、过屏幕中心的扫描线、ASCII 亮度图**，
外加 draw call / 三角面 / 着色器程序数 / `glGetError` / 控制台错误。
`--mobile` 还会模拟 iPhone 横竖屏，检查触控区大小、是否出界、控件是否重叠，并真的派发一次触摸事件验证摇杆响应。

这套自检就是开发时的"眼睛"：黑洞视界是否真的是黑的，靠的是扫描线里连续的 `.00`。

## 已知取舍

- 黑洞透镜是**单公告板逐像素积分**，靠得很近时会占满全屏，是最重的一处开销；
  移动端已降到 42 步并配合动态分辨率。
- 行星贴图在加载阶段用 CPU 生成（分步 yield，带进度条），低端机首次进入约 1–2 秒。
- 深度精度靠"压缩宇宙尺度"解决（1 单位 ≈ 10 m，最远天体 ~9.3 万单位，`near/far = 0.6/420000`），
  没有使用对数深度缓冲，以换取移动端的填充率。
