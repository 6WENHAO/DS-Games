# 蚀 · ECLIPSE BLADE

一款**真 3D**（WebGL）第一人称像素风砍杀游戏。你扛着一把两米多长、人类根本挥不动的铁块，
在日蚀之下的地牢里一层层往下砍。参考《剑风传奇》的暗黑基调：低饱和、高对比、大量血肉与铁锈。

**核心卖点：击杀时敌人不是倒下，而是整具身体按体素炸开 —— 骨块、肉块带着物理弹跳飞散，
血喷到墙上和地上，血迹永久留存，屏幕溅血，同时触发顿帧 + 慢放 + 镜头震动。**

## 一、怎么玩

### 启动
直接双击 `index.html` 即可（纯前端，无需服务器、无需构建、无外部资源）。
建议 Chrome / Edge / Firefox 现代版本，按 **F11** 全屏。

> 首次点击画面会锁定鼠标进入战斗视角，按 **Esc** 释放。

### 操作

| 按键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角（真 3D，可自由俯仰 ±76°） |
| **左键** | **横扫斩** —— 扇形范围伤害，一刀可以劈穿一排杂兵 |
| **右键** | **蓄力重斩** —— 上举劈落，附带落地冲击波，必定肢解 |
| `Shift` | 冲刺（消耗体力，冲刺瞬间有短无敌帧） |
| `空格` | 跳跃（空中挥剑落地有伤害加成） |
| `F` | **狂气解放**（狂气槽满时）：攻速 +42%、伤害 +55%、减伤，但持续掉血 |
| `E` | 交互（传送门 / 血祭坛 / 拾取） |
| `Esc` | 暂停（含设置项） |
| `R` | 死亡后快速重开 |

### 战斗要诀
1. **连斩越高剑越快**：每层连斩 +2.2% 攻速、+3.5% 伤害（可被遗物强化到 +8.5%/层）。
2. **命中会顿帧**，趁顿帧继续点左键接下一刀，第 3 刀自动变成上撩劈砍。
3. **重斩打群**：冲击波是以你面前 1.7 米为圆心的范围伤害，人多时收益极高。
4. **血泊可以喝**：拿到「血泊之饮」后，踩过地面血迹回血 —— 越血腥越安全。
5. **狂气是双刃剑**：解放期间你几乎无法被打断，但血条一直在掉，靠杀怪续命。

## 二、Roguelite 流程

```
标题 → 深度 I 简报 → 战斗 → 达成目标 → 传送门 → 三选一遗物 → 深度 II → …
                                                                      ↓
                                     深度 IV / VIII / XII = Boss 层
                                                                      ↓
                                             击败「使徒之王·蛇眼」→ 胜利
```

- **共 12 层**，4 种主题环境：
  | 深度 | 名称 | 特征 |
  |---|---|---|
  | I–III | 腐尸回廊 | 石墙、血渍、泥地 |
  | IV | 祭骨大厅（Boss） | 骨砌墙 + 使徒·食人巨躯 |
  | V–VII | 蚀之肉窖 | 会呼吸的肉壁、血池地面 |
  | VIII | Boss | 使徒·蛆虫主教（召唤 + 弹幕） |
  | IX–XI | 王城废墟 | 砖墙、铁栅、盔甲堆 |
  | XII | 蚀之祭坛（终局） | 使徒之王·蛇眼（4 阶段） |

- **每层目标**随机：
  - `夺取猩红烙印` —— 由一个红光精英携带，杀了它抢烙印开门
  - `肃清此层` —— 清空所有敌人
  - `Boss` —— 打死 Boss

- **6 种敌人**：蚀之尸（慢）、腐肉猎犬（快 + 扑咬）、蚀之信徒（远程暗弹）、
  腐铁重兵（高血 + 冲击波）、亡魂（漂浮 + 闪现）、精英（体型 ×1.22、血 ×2.3、红光）。
  Boss 有 3–4 个阶段，每阶段会咆哮、加速、解锁新招（环形弹幕 / 召唤 / 冲锋）。

- **36 件遗物**，三档稀有度：
  - 常见（18 件）：磨刃石、屠夫之扇、血饮、骨甲…
  - 稀有（12 件）：处刑人（残血 3 倍伤害）、血肉炸弹（尸爆）、不死之烙（复活一次）…
  - **诅咒（6 件）**：狂战士盔甲（伤害 +50%、攻速 +28%，但持续失血且更脆）、
    蚀之契约、蛇眼… 强得离谱，代价写在脸上。

- **血祭坛**（每层 60% 出现）：用魂换血、用血换魂、用生命上限换一件遗物。
- **魂**：击杀掉落，可在遗物界面刷新卡池（花费递增）。
- **存档**：localStorage 记录最深深度 / 累计屠戮 / 通关次数（标题界面显示）。

## 三、技术实现

全手写，**零依赖、零外部资源**（纹理、模型、音效全部运行时程序化生成）。

### 渲染：真 3D + 像素化
- 手写 WebGL：一个着色器程序，顶点格式 `pos(3) uv(2) color(3) light(1) emis(1)`。
- **像素风做法**：画布后备缓冲压到 1/3 分辨率（可在暂停菜单调 1–5 档），
  CSS `image-rendering: pixelated` 最近邻放大；片元着色器里做
  **去饱和 + 提红压蓝 + 暗角 + 4×4 Bayer 有序抖动量化（22 级）** → 复古色带质感。
- 光照：手持火把（跟随摄像机的距离衰减）+ **逐格烘焙静态光写进顶点色**（角点平均 → 平滑过渡）
  + 最多 6 个动态点光源（火盆闪烁、弹丸、蓄力剑光、精英眼光、传送门）+ 指数雾（远处沉入纯黑）。
- 几何：地牢按格子生成合并成一个静态 VBO（约 2–5 万顶点）；
  敌人 / 肢块 / 血雾 / 贴花 / 剑光每帧 CPU 批处理进一个动态 VBO，整场景 4–6 个 draw call。
- 巨剑是**视图模型**：直接用摄像机基向量构造世界矩阵，最后关闭深度测试绘制，永远不会插进墙里。

### 血肉破碎（爽感来源）
- 敌人模型 = 若干带颜色的**体素盒**（躯干/头/双臂/双腿…）。
- **死亡**：遍历模型每个盒子 → 每个盒子变成一块独立刚体肢块（带角速度、重力、
  墙壁反弹、落地静止后作为地面装饰残留），同时喷 34 束血 + 血雾 + 生成血泊贴花。
- **非致命断肢**：重斩或 24% 概率砍飞手臂 / 头颅；断口渲染成血肉截面。砍头触发「斩首」慢放。
- 血滴按速度**拉伸**成条状 → 喷溅感；落地生成随机血迹贴花（上限 520 张，累积成血泊）。
- 逐格 `bloodGrid` 记录血量，供「踩血回血」和踩血的水声使用。
- 打击反馈链：顿帧（0.055–0.10s，全世界减速到 5.5%）→ 镜头踢动 → 屏幕震动 →
  命中标记 → 伤害数字（3D 投影到 2D 叠加层）→ 击杀慢放 → 屏幕溅血。

### 其它
- **音频**：WebAudio 纯合成 —— 噪声扫频做剑风、低频正弦 + 噪声爆做砍肉、
  锯齿波叠加做怪物咆哮、程序生成脉冲响应做地牢混响；带声音预算限流（血肉横飞时不炸音）。
- **纹理**：512×512 图集，64×64 一格，28 张全部用 Canvas2D 现场画（石砖、肉壁、骨墙、
  血渍、火焰、旋涡、Bayer 矩阵…）。
- **地牢生成**：房间随机放置 + 最小生成树连通 + 额外回路，2 格宽走廊，
  房间有不同层高（走廊 2.55 / 大厅 4.6 / 竞技场 7.5）、中央高台 + 台阶（真高低差，可跳上去）。

## 七、已修复的关键问题

### 「受击或攻击时视角锁在脚下」
**成因**：`doSwingHit()` 必须每帧运行（这样一次横扫才能连续砍到多个目标），
但它的打击反馈块原先用 `P.hitThisSwing > 0` 作判断 —— 这个标记在一次挥砍中
命中后会一直为真，于是**挥砍窗口内每一帧都重新触发顿帧与镜头踢动**：

```
命中 → 顿帧 → dt 降到 5.5% → P.wT 推进变慢 → 攻击窗口停留更久
     → 条件依然成立 → 再次顿帧 …（自我维持的循环）
同时 camKickY 每帧 +0.03，而衰减用的是被缩小的 dt（每帧只衰减 0.8%）
     → 累积趋向 ~3.6 rad → 被渲染层夹到 1.45 rad = 俯角 83° = 视角贴在脚下
```

被打断时 `P.combo` 归零 → 攻速下降 → 挥砍窗口更长 → 所以**「受击时」更容易触发**；
窗口最终关闭后会自行恢复，因此表现为「有时」。

**修复（四层防护，任意一层都能阻断该循环）**
1. 反馈只在「本帧真的砍到了新目标」时触发（`newHits > 0`）
2. 镜头踢动统一走 `addKick()`，硬夹在 ±0.20 rad
3. 踢动衰减改用**真实时间** `dtReal`，不再被顿帧 / 慢放拖慢
4. 武器计时保底：即使整帧冻结也按 25% 速度推进，攻击窗口必定关闭；
   单次顿帧封顶 0.16s

**顺带修掉**：从菜单 / 暂停返回战斗时，期间累积的鼠标位移会在第一帧一次性生效
（同样表现为视角瞬间甩到脚下）—— 现在切换状态和刚锁定指针时都会清零，
并对单次事件（±350px）与单帧累计（±1.2 rad）双重限幅。

**回归测试**：`tools/smoke.js` 新增镜头 / 顿帧断言，并复刻了主循环的顿帧与慢放时间管线；
把旧写法改回去会立刻报错（已实测验证）。

## 八、性能

  动态物 3–5 个，肢块上限 300、血滴 620、贴花 520。
