# 杀戮尖塔 · 网页复刻版（铁甲战士 · 第一章）

纯前端实现的《Slay the Spire》复刻版：**无依赖、无构建、无需服务器**，所有美术资源均由 SVG 程序化绘制。
直接双击 `index.html` 即可在浏览器中开始游戏。

---

## 一、如何开始

1. 双击打开 `index.html`（Chrome / Edge / Firefox 均可）。
2. 点击 **「开始攀爬（铁甲战士）」**。
3. 在地图上选择路线 → 打完 15 层 → 击败第 16 层的 BOSS 即为**通关**。

窗口尺寸自适应：内部为 1600×900 的固定舞台，按窗口等比缩放，建议最大化窗口。

---

## 二、操作方式（尽量还原原作）

| 操作 | 说明 |
| --- | --- |
| **拖拽卡牌向上** | 打出卡牌。需要指定目标的牌拖到敌人身上松手，会显示金色目标箭头 |
| **点击卡牌** | 只有一个敌人时直接打出；多个敌人时进入选中态，再点击敌人释放 |
| 悬停卡牌 | 卡牌放大并显示详细说明与关键词解释 |
| `E` | 结束回合 |
| `1` ~ `9` | 打出对应位置的手牌 |
| `D` / `A` / `X` | 查看抽牌堆 / 弃牌堆 / 消耗堆 |
| `Esc` | 取消选择 |
| `M` | 返回地图（非战斗中） |
| 点击药水 | 使用；右键丢弃 |
| 顶栏「牌组」 | 查看当前牌组（战斗中显示全部牌堆） |

## 三、已实现内容

### 战斗系统
- 能量 / 抽牌堆 / 弃牌堆 / 消耗堆 / 洗牌、10 张手牌上限
- 完整伤害管线：力量、敏捷、虚弱（-25%）、易伤（+50%）、脆弱（-25%）、格挡、尖刺、
  中毒、神器、无形、缓冲、镀甲、金属化、壁垒、消耗、虚无、固有、X 费用……
- 敌人**意图系统**：头顶图标区分攻击 / 防御 / 增益 / 减益 / 未知 / 沉睡 / 逃跑，
  并实时显示经过增益减益修正后的**真实伤害数值与段数**
- 卡牌描述中的伤害/格挡数值随力量、易伤等**动态变色**（绿色=被强化，红色=被削弱）

### 铁甲战士（85 张牌）
- 初始：打击 ×5、防御 ×4、痛击
- 75 张可获得卡牌（普通 20 / 罕见 36 / 稀有 16 / 初始 3）：攻击 32、技能 29、能力 14
  —— 顺劈斩、重刃、旋风斩、以血还血、铜墙铁壁、恶魔形态、壁垒、腐化、双重叩击、
  魔鬼之火、收割、突破极限、主宰、残暴、狂战士、无痛、黑暗拥抱……
- 10 张状态牌与诅咒牌：伤口、眩晕、燃烧、黏液、虚空、悔恨、受伤、笨拙、腐朽、痛苦
- 全部卡牌均可升级（灼热打击支持无限次升级）

### 敌人（25 种 / 68 种招式）
- 普通：颚虫、邪教徒、红/绿虱子、酸性史莱姆（大中小）、尖刺史莱姆（大中小）、
  真菌兽、蓝/红奴隶主、强盗、五种小鬼
- 精英：小鬼头目（激怒）、拉加维林（沉睡+金属化）、哨卫 ×3（神器+眩晕）
- **BOSS（随机其一）**：守卫者（模式切换+锋利硬皮）、史莱姆之王（半血分裂）、
  六火幽魂（均分+烈焰地狱）
- 各自还原原作的招式循环与 AI 概率、连招限制、卷曲、愤怒、孢子云、分裂、逃跑等特性

### 地图与房间
- 15 层 + BOSS，7 列 6 条路径的随机地图，含防路径交叉与房间类型约束
  （前 5 层无精英/休息处/商店、同路径不连续出现同类特殊房间、第 9 层固定宝箱、第 15 层固定休息处）
- 普通战斗 / 精英 / 未知事件 / 商店 / 宝箱 / 休息处（休息 or 打铁）
- 12 个随机事件（大鱼、牧师、金色偶像、活墙、废料软泥、闪耀之光、蘑菇丛、
  翼之雕像、死去的冒险者、蛇之低语、灵魂篝火、黏液世界）
- 商店：卡牌 / 遗物 / 药水 / 移除卡牌服务
- 战斗奖励：金币、卡牌三选一、药水、精英掉落遗物

### 遗物（55 个）与药水（18 种）
燃烧之血、赤备、锚、弹珠袋、青铜鳞片、百年积木、笔尖、双截棍、手里剑、苦无、
装饰扇、开信刀、山铜、日晷、纸蛙、枯枝、鸟居、贤者之石、符文金字塔、苦痛印记……

## 四、目录结构

```
index.html            入口（直接双击打开）
css/style.css         全部样式（固定舞台 + 缩放适配）
js/util.js            工具：随机数、DOM、提示条、特效
js/svg.js             全部美术素材（角色/敌人/卡框/图标/场景，纯 SVG）
js/data-powers.js     能力与状态定义
js/data-cards.js      卡牌库
js/data-relics.js     遗物库
js/data-potions.js    药水库
js/data-enemies.js    敌人、招式、AI、遭遇组合
js/data-events.js     事件库
js/map.js             地图生成与地图界面
js/combat.js          战斗引擎（伤害管线、出牌、回合流程）
js/render-combat.js   战斗界面与手牌交互（扇形手牌、拖拽、目标箭头）
js/screens.js         奖励/商店/休息/事件/宝箱/结算/浮层
js/game.js            运行状态与主流程
tools/headless-test.js 开发用：Node 无头自动试玩与全量回归
tools/make-check.js    开发用：生成浏览器布局测量页
```
