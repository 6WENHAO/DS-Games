# DESCENT · 坠入异星

第一人称大气进入模拟游戏。你从轨道（或飞艇）上一跃而下，穿过等离子鞘、体积云、雷暴与沙尘，
最终落到六个截然不同的星球表面——或者沉进一颗永远没有表面的气态巨行星。

**直接打开 `index.html` 即可游玩**（Chrome / Edge 推荐，需 WebGL2）。无任何依赖、无音频素材、无贴图——全部实时生成。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标 | 环视（点击画面锁定指针） |
| W / S | 收拢 / 张开身体（改变阻力） |
| SHIFT | 俯冲（最小阻力，最快但最热） |
| A / D | 侧移；方向键四向机动；左键朝视线滑翔 |
| SPACE | 开伞 / 割伞（动压 > 1500 Pa 会撕伞） |
| T | 时间加速 ×2/×4/×8（高温 / 危险区 / 低空自动解除） |
| R | 重来 · M 静音 · ESC 暂停/返回星球选择 |

## 六个世界

- **塔拉萨 IV** — 海洋星球：全球风暴、闪电、软着水目标
- **伊米尔** — 气态巨行星：没有地面，目标是活着下到 1 巴层并发回数据
- **阿什克伦** — 火山世界：熔岩发光地表 + 上升热柱
- **尼芙尔海姆** — 冰卫星：稀薄大气，伞必须提前开，极光 + 冰晶飑线
- **拉赫特** — 沙漠世界：尘暴、尘卷风、强风切变
- **泰坦尼斯** — 雾霾卫星：低重力浓大气，人类张开双臂就能飞，落进甲烷海

## 系统

- **物理**：指数大气密度、动压阻力、气动加热（超声速门控）、开伞冲击、风切变与近地边界层、G-LOC 黑视、结构损伤
- **渲染**：WebGL2 单通道全屏光线步进——体积云、球面大气雾、程序化海面/冰原/沙丘/熔岩、星空与极光、等离子鞘、水下
- **2D 叠加**：速度线、雨/雪/灰/尘/余烬粒子、面罩结霜/水痕/积灰、雷达与信标/危险区标记、受击裂纹
- **音频**：WebAudio 全实时合成——风噪三层、低频轰鸣、等离子啸叫、雷、开伞爆响、伞布拍打、入水、心跳呼吸、告警
- **动态质量**：按帧率自动调节渲染分辨率与云采样步数

## 验证工具（tools/）

- `ballistics.js` — 离线弹道体检（峰值热/过载/落地速度/时长）
- `pngstat.js` — 零依赖 PNG 解码 + 分块亮度统计
- `look.js` — 调用本地 `ollama qwen3-vl` 视觉模型检查截图
- `shot.ps1` / `shotall.ps1` — headless Edge 批量截图 + DOM 诊断
- `autotest.js` — CDP 驱动的六星球自动驾驶全流程回归（`node tools/autotest.js "auto=all&turbo=300"`）
- 诊断模式：`index.html?diag=1&planet=ymir&alt=70&pitch=-28&t=18`（还可加 `&exp=`、`&sun=` 调曝光/阳光）

## 评分

信标 + 落地柔和度 + 结构完好度 − 过热/过载惩罚。S/A/B/C/D/F 六级，最高分记录存在 localStorage。
