# NO BLOCK'S SKY · 方块深空

《无人深空》的玩法 × 《我的世界》的方块画风 —— 纯浏览器运行，零外部素材（所有贴图、模型、音效、音乐都是代码实时生成的）。

## 怎么运行

游戏必须通过**本地服务器**打开（ES 模块 + Web Worker 不能用 file:// 直接跑）。

### Windows（最简单）
双击 **start-windows.bat** —— 会自动启动服务器并打开浏览器。

### 手动启动
装了 Node.js：
```
node server.mjs
```
装了 Python：
```
python -m http.server 4173
```
然后浏览器打开 http://127.0.0.1:4173/

> 建议 Chrome / Edge，并允许声音（音效是游戏的核心部分，进标题界面后点一下屏幕即可启用音频）。

## 两种模式

| | 说明 |
|---|---|
| **开始新的旅程（生存）** | 1:1 还原《无人深空》开场：飞船坠毁、修复多功能工具、采氧维持生命、造金属板修飞船、合成起飞燃料、离开星球、抵达空间站、建基地、跃迁星系 |
| **创造模式** | 资源无限、免疫伤害、所有配方解锁、飞船三大引擎全部就绪且燃料无限 —— 直接起飞、脉冲穿越、跃迁 |

游戏中随时按 **G** 切换创造模式。

## 操作

**地面**
- `WASD` 移动 · `Shift` 疾跑 · `Ctrl` 蹲下 · `空格` 跳跃（空中长按 = 喷射背包）
- `鼠标左键` 采矿光束（挖方块 / 采资源，会过热）· `鼠标右键` 放置方块
- `1-9` / 滚轮 切换快捷栏 · `E` 互动（精炼器 / 构筑台 / 喂食生物）· `F` 进飞船
- `V` 分析镜（扫描物种换单位与纳米簇）· `C` 扫描脉冲（标记附近资源）
- `R` 一键充能生命维持 / 危害防护 · `L` 头灯
- `Tab` 背包 · `Q` 制作 · `B` 建造 · `J` 发现日志 · `G` 创造模式 · `F3` 调试信息 · `ESC` 暂停

**飞行**
- `鼠标` 控制机头 · `W/S` 推力 · `A/D` 横滚 · `Shift` 加力
- `空格`：地面长按起飞 / 高空长按脱离大气层 / 太空长按进入星球或停靠空间站
- `Tab`（太空）脉冲引擎 · `鼠标左键` 光子加农炮（打小行星得氚）
- `F` 降落 / 下船 · `C` 切换座舱/追尾视角 · `M` 星系地图（跃迁）· `T` 空间站交易

## 生存要点
- 生命维持靠**氧**（红色植物）、危害防护靠**钠**（黄色植物）、飞船起飞靠**二氢**（蓝色晶体）
- 铁质粉尘来自岩石与矿床，50 个可造 1 块金属板（修飞船 / 建基地的通用件）
- 过度破坏地形会引来**哨兵**无人机；夜晚与风暴会加速消耗防护
- 精炼器能把原料提纯（铁→纯铁、碳→浓缩碳、铜→彩色金属），价值翻倍
- 跃迁需要：超光速引擎 + 跃迁元件（反物质 + 反物质容器）

## 性能
设置面板（标题界面「设置」或暂停菜单）里有 **自动 / 高 / 中 / 低** 四档画质。默认「自动」：帧率掉到 34 以下会自动降档。手动想更流畅就选「低」（关泛光、视距 4）。

## 技术
- 无构建步骤：原生 ES 模块 + importmap，three.js 放在 `vendor/`
- 体素地形在 Web Worker 里生成与网格化（16×16×128 区块、面剔除 + 烘焙 AO）
- 贴图图集按星球调色板在运行时用 Canvas 逐像素绘制（16×16 像素画风格）
- 音效与音乐全部是 WebAudio 实时合成（方块材质音、采矿光束、扫描声呐、飞船引擎、大气层进入轰鸣、程序化生成的配乐）
- 存档在浏览器 localStorage
